OutWarning

member of hbe::Logger::SimpleLogger Engine/Log/Logger.h 2 overloads const noexcept Warning, spelled — the level that gets the file flushed

Signature

void OutWarning(const TLogFunction& logFunc) const noexcept
{
        Out(ELogLevel::Warning, logFunc);
}

void OutWarning(const char* text) const noexcept
{
        OutWarning([text](auto& ls) { ls << text; });
}

Function description

Both bodies are in the header and do one thing: call Out with ELogLevel::Warning. They neither read nor modify the bound level, so a logger bound to any level warns at Warning.

What the level buys is durability rather than attention. When the drain renders a batch it watches for level >= Warning and, if the batch contained one, flushes the file stream after writing it — so a warning is on disk shortly after it is produced, while an Info batch in the same run may still be sitting in the stream buffer (ProcessBuffer). That is the only mechanical privilege Warning has.

This is the level where LOG_BREAK_IF_WARNING bites, and where the strictest engine filter stops. With that macro set, AddLog prints the line immediately, calls debugBreak() and returns — the line never enters the queue and never reaches the file. Separately, TaskSystem::Initialize installs a filter keeping only levels strictly above Warning, so a warning logged under the TaskSystem category is discarded by default (the example explains the comparison).

Parameters

ParameterTypeRequirement
logFunc const TLogFunction& Runs on this thread before the call returns, and only if the Log.Level threshold and the category filter have both passed — a line that is going to be dropped is never formatted at all
text const char* NUL-terminated; the pointer is captured, not the bytes, and must live until the call returns. A null pointer renders as Null

Return value

void, with the same meaning as Out: the line was handed over. Whether it survived the threshold, the filter or the 2048-character render limit is not reported here.

Examples

A threshold crossed, with the value that crossed it captured by copy:

From Engine/Core/TaskStream.cpp

const auto log = Logger::Get(name);
...
log.OutWarning([dt = deltaTime](auto& ls) { ls << "Slow DeltaTime = " << dt; });

The same call from inside a lock guard, which is why the callback's cost is charged to whoever holds the lock:

From Engine/Core/ScopedLock.h

auto log = Logger::Get(name);
log.OutWarning([&, this](auto& ls)
{
        ...
});

Warnings are the cheapest level to lose in a review, because a category filter or a level parameter set to Error silences them without any change at the call site. If a warning matters enough to always be seen, it is an error.
