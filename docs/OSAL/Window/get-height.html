GetHeight

member of hbe::Window Engine/OSAL/Window.h the recorded height

Signature

[[nodiscard]] int GetHeight() const

Function description

The recorded height — the object's own number, under exactly the same rules as GetWidth: written by CreateWindow and SetSize, updated by the user-resize events on Linux and Windows, 0 before creation.

Parameters

None.

Return value

The recorded height in pixels; 0 before creation.

Examples

The OSAL's own test checks the pair right after creation: 

			const int width = window->GetWidth();
			const int height = window->GetHeight();
			ls << "Width: " << width << lf;
			ls << "Height: " << height << lf;
