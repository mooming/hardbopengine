GetWidth

member of hbe::Window Engine/OSAL/Window.h the recorded width

Signature

[[nodiscard]] int GetWidth() const

Function description

The recorded width — the object's own number, not a fresh query of the window. It is written by CreateWindow and SetSize, and updated by the event pumps when the user resizes (ConfigureEvent on Linux, WM_SIZE on Windows); on macOS there is no user resize to track. Until the window is created it answers 0.

All three platform units define it identically — return the member (Engine/OSAL/LinuxWindow.cpp, Engine/OSAL/OSXWindow.mm, Engine/OSAL/Win32Window.cpp). The paired getter is GetHeight; the renderer reads both to size its swapchain.

Parameters

None.

Return value

The recorded width in pixels; 0 before creation.

Examples

The renderer reads the pair every frame to keep its aspect ratio: 

	static_cast<float>(extent.width) / static_cast<float>(extent.height), NearZ, FarZ);
