Module Index / OSAL / Window / SetVisible

SetVisible

member of hbe::Window Engine/OSAL/Window.h show or hide — not defined on Linux

Signature

void SetVisible(bool visible)

Function description

Shows or hides the window. macOS orders the NSWindow front or out and records the flag (Engine/OSAL/OSXWindow.mm); Windows calls ShowWindow with SW_SHOW / SW_HIDE and records the flag (Engine/OSAL/Win32Window.cpp). Both refuse to act before the window exists.

Not defined on Linux. Engine/OSAL/LinuxWindow.cpp defines every other member of the class but not this one — no Linux translation unit defines it, so a call from a Linux build does not link. The Linux window is made visible by CreateWindow's XMapWindow and has no hide path; until a definition exists, visibility is create-once on Linux.

Parameters

ParameterTypeRequirement
visiblebooltrue shows the window, false hides it; on an uncreated window the call is a silent no-op.

Return value

Not applicable — returns void; failure is a silent no-op.

Examples

The Vulkan example shows its window right after creation — the one in-tree call: 

	window->SetVisible(true);
