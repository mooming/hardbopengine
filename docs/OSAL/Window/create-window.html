CreateWindow

member of hbe::Window Engine/OSAL/Window.h the member and the OS-scope factory: create and show the real window

Signature

[[nodiscard]] bool CreateWindow(const hbe::HString& title, int width, int height)

[[nodiscard]] std::unique_ptr<Window> CreateWindow(const hbe::HString& title, int width, int height)

Function description

Two spells of one operation: the member creates the platform window on an existing Window object; the free factory at OS:: scope constructs the object and calls the member, handing back nullptr when creation failed. The factory is the intended entry point — it is what the Vulkan example and the OSAL's own tests call (Engine/OSAL/Window.cpp): 

	auto window = std::make_unique<Window>();

	if (window->CreateWindow(title, width, height))
	{
		return window;
	}

	return nullptr;

From Engine/OSAL/Window.cpp, OS::CreateWindow(const hbe::HString&, int, int)

What the member does per platform: Linux opens the X11 display and creates a simple window, stores the title, and maps it — the window is on screen when the call returns (Engine/OSAL/LinuxWindow.cpp). macOS allocates an NSWindow with a titled, closable, miniaturizable style mask — not resizable — sets the title, orders it front and centres it, and installs the close-button delegate (Engine/OSAL/OSXWindow.mm). Windows registers its window class, creates the window with WS_OVERLAPPEDWINDOW and shows it (Engine/OSAL/Win32Window.cpp). All three record the width and height, and the window is on screen when the call returns — on Linux and Windows through the create call itself, on macOS through makeKeyAndOrderFront and the visibleFlag it sets.

The member refuses to run twice on macOS — it returns false when osHandle is already set — while the Linux and Windows units would overwrite their handles. One Window object, one window: call the member once, or make a new object.

Parameters

ParameterTypeRequirement
titleconst hbe::HString&The window title, applied at creation by every platform.
widthintInitial width in pixels; recorded even where the platform picks its own frame (macOS positions at a fixed offset).
heightintInitial height in pixels.

Return value

The member: true when the platform window exists and is visible, false on failure or — on macOS — on a second call. The factory: the created window, or nullptr when the member said no.
