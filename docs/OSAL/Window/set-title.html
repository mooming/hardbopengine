SetTitle

member of hbe::Window Engine/OSAL/Window.h rename the window; silent no-op before creation

Signature

void SetTitle(const hbe::HString& title)

Function description

Renames the window: XStoreName on Linux, setTitle: with a UTF-8 string on macOS, SetWindowText on Windows. Every unit refuses to act before the window exists — the Linux and Windows units guard on the handle, the macOS unit returns early — so a call on an uncreated window is a silent no-op, not an error (Engine/OSAL/LinuxWindow.cpp, Engine/OSAL/OSXWindow.mm, Engine/OSAL/Win32Window.cpp).

Parameters

ParameterTypeRequirement
titleconst hbe::HString&The new title; applied immediately, with no queue and no event.

Return value

Not applicable — returns void; failure is a silent no-op.

Examples

The OSAL's own test renames a window mid-flight, between event pumps:
