SetSize

member of hbe::Window Engine/OSAL/Window.h resize and record; user resizes feed the same fields

Signature

void SetSize(int width, int height)

Function description

Resizes the window and records the new size. Linux calls XResizeWindow, macOS re-frames the NSWindow with setFrame:frame display:YES, Windows calls SetWindowPos keeping position and Z-order — and all three write width / height themselves, so the getters reflect the request immediately (Engine/OSAL/LinuxWindow.cpp, Engine/OSAL/OSXWindow.mm, Engine/OSAL/Win32Window.cpp). A call on an uncreated window is a silent no-op on every platform.

The recorded size is also written by the event pumps when the user resizes — ConfigureEvent on Linux, WM_SIZE on Windows — so the getters track reality, not just requests. macOS has no user-resize to track: the window is created non-resizable.

Parameters

ParameterTypeRequirement
widthintNew width in pixels.
heightintNew height in pixels.

Return value

Not applicable — returns void; failure is a silent no-op.
