Close

member of hbe::Window Engine/OSAL/Window.h destroy the window and mark it closed

Signature

void Close()

Function description

Destroys the window and marks it closed. Linux destroys the X11 window and closes the display, clearing both handles (Engine/OSAL/LinuxWindow.cpp); Windows destroys the HWND and clears it (Engine/OSAL/Win32Window.cpp); macOS closes the NSWindow and releases the delegate — the one ownership the class carries, because NSWindow holds its delegate unretained and the Window allocated it (Engine/OSAL/OSXWindow.mm). All three set closedFlag last, even when there was no window to close — the method is safe on an uncreated window, and it is what the destructor calls. 

	if (osHandle != nullptr)
	{
		auto window = static_cast<NSWindow*>(osHandle);
		[window close];
		[window release];
		osHandle = nullptr;
	}

	closedFlag = true;

From Engine/OSAL/OSXWindow.mm, OS::Window::Close()

After Close, the getters keep answering — the recorded size and the closed flag — but the native handle is gone, and anything the renderer attached to it must have been detached first. There is no re-open: a closed Window object stays closed.

Parameters

None.

Return value

Not applicable — returns void, and cannot fail.

Examples

The OSAL's own test closes explicitly and checks the flag: 

			window->Close();
			ls << "Window closed, verifying IsClosed()..." << lf;

			if (!window->IsClosed())
			{
				ls << "Window should be closed after Close()" << lferr;
			}
