IsVisible

member of hbe::Window Engine/OSAL/Window.h the visibility flag — or a live query on Windows

Signature

[[nodiscard]] bool IsVisible() const

Function description

Whether the window is visible — and the three platforms answer from different sources. Linux and macOS return the recorded visibleFlag (Engine/OSAL/LinuxWindow.cpp, Engine/OSAL/OSXWindow.mm); Windows returns a live IsWindowVisible query on the HWND, and false when there is no window at all (Engine/OSAL/Win32Window.cpp).

An uncreated window answers differently by platform. Linux's constructor starts visibleFlag at true, macOS's at false, and Windows falls back to false for a null handle — so "is the window visible?" before CreateWindow has three answers. After creation all three agree, because all three create the window on screen.

Parameters

None.

Return value

true when the window is shown; see the note for the pre-creation answers.

Examples

The Vulkan example gates nothing on it, but the OSAL's test asserts a freshly created window is visible: 

			if (!window->IsVisible())
			{
				ls << "Window should be visible" << lferr;
			}
