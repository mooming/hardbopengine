Function description

A handle-less window: zero size, no platform window, nothing taken from the operating system. The platform units agree on that and disagree on one initial value — the Linux unit starts visibleFlag at true and the Windows unit at true, while the macOS unit starts it at false (Engine/OSAL/LinuxWindow.cpp, Engine/OSAL/Win32Window.cpp, Engine/OSAL/OSXWindow.mm). Until CreateWindow succeeds, no method reaches the operating system.

The initial-flag divergence is observable through IsVisible on an uncreated window — and on Windows, IsVisible answers false for an uncreated window regardless, because it queries the live window rather than the flag.
