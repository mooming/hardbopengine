IsClosed

member of hbe::Window Engine/OSAL/Window.h the shared close flag — flipped by Close everywhere, by the button on macOS only

Signature

[[nodiscard]] bool IsClosed() const

Function description

The shared close flag, unchanged since the last write: true after Close — on every platform — and, on macOS only, after the close button, whose delegate writes closedFlag directly (Engine/OSAL/OSXWindow.mm).

The close button does not reach this flag on Linux or Windows. The Linux unit's PollEvents has an unimplemented stub where the close message would be handled (Engine/OSAL/LinuxWindow.cpp), and the Windows unit records WM_DESTROY in a shouldCloseFlag that nothing reads (Engine/OSAL/Win32Window.cpp). A render loop that exits on !IsClosed() — the shape the Vulkan example uses — keeps running after the user closes the window on those platforms; only Close flips the flag.

Parameters

None.

Return value

true when the window has been closed — by the object's own Close, or by the close button on macOS; false otherwise, including before creation.

Examples

The render-loop shape that depends on it: 

	while (running && !window->IsClosed())
	{
		app->PollEvents();
