OSMemory

Engine/OSAL/OSMemory.h namespace OS utility header allocation validation, alignment math, page size, and the reserve/free/protect triple of the virtual-memory boundary

Class description

A utility header, not a class: free functions at OS:: scope for the questions the engine's memory layer asks the operating system — is this pointer a live allocation, how big is the allocation behind it, how big is a page, reserve and release address space, and make a range untouchable. It is the boundary the Memory module leans on: SystemAllocator reserves through VirtualAlloc, guards with ProtectMemory, and releases with VirtualFree; the allocators validate with CheckAligned and size with GetAligned.

One function is a template and one is constexpr, both defined in the header; the other six are declared in Engine/OSAL/OSMemory.h and defined per platform in Engine/OSAL/LinuxMemory.cpp, Engine/OSAL/OSXMemory.cpp and Engine/OSAL/WindowsMemory.cpp. The generic unit Engine/OSAL/OSMemory.cpp defines nothing but the test collection: its implementation chain is dead code while a PLATFORM_* macro is defined — which it always is, because the file fails to compile with none.

The platform units disagree in small, caller-visible ways. What counts as a valid allocation (MAP_FAILED is a valid non-null pointer on POSIX, so the POSIX units test for it and the Windows unit does not), and whether the page size is queried every call or cached — see the per-function pages.

Template parameters

None — the entry declares no class or struct. One function, CheckAligned, is itself a function template.

Class methods

None — the entry is a macro and free functions, and the functions carry real contracts, so each owns a page:

NameSignatureWhat a caller depends on
IsValidAllocation [[nodiscard]] bool IsValidAllocation(void* ptr) noexcept Whether the pointer is a live allocation answer — MAP_FAILED counts as invalid on POSIX; no engine code calls it outside the OSAL's own test
CheckAligned template <typename T> [[nodiscard]] bool CheckAligned(T* ptr, uint32_t alignBytes = hbe::Config::DefaultAlign) noexcept Address modulo the alignment, computed inline; the allocators assert on it
GetAligned [[nodiscard]] constexpr size_t GetAligned(size_t size, uint32_t alignBytes = hbe::Config::DefaultAlign) noexcept Round up to the next multiple — usable at compile time, and the sizing every allocator's block math starts from
GetAllocSize [[nodiscard]] size_t GetAllocSize(void* ptr) noexcept The size the platform's allocator gave the pointer — the usable size, asked back from the allocator
GetPageSize [[nodiscard]] size_t GetPageSize() noexcept The OS page size — queried per call on Linux, cached on macOS and Windows
VirtualAlloc void* VirtualAlloc(size_t size) Reserve and commit address space; the name matches the Windows call, and failure is signalled by the platform's sentinel, not an exception
VirtualFree void VirtualFree(void* address, std::size_t n) noexcept Release a reservation — munmap on POSIX, MEM_RELEASE on Windows, where failure asserts
ProtectMemory void ProtectMemory(void* address, std::size_t n) noexcept Makes the range untouchable — PROT_NONE / PAGE_NOACCESS; the guard-page mechanism, and failure asserts

None — the functions above are the entire surface.
