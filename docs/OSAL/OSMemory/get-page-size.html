GetPageSize

member of hbe::OSMemory Engine/OSAL/OSMemory.h namespace OS the OS page size — per call on Linux, cached on macOS and Windows

Signature

[[nodiscard]] size_t GetPageSize() noexcept

Function description

The operating system's page size in bytes — the granularity every virtual-memory operation of this header works in: VirtualAlloc rounds nothing, so the caller rounds with this; ProtectMemory and VirtualFree operate on whole pages.

The platform units agree on the answer and disagree on the cost: Linux calls sysconf(_SC_PAGESIZE) on every invocation (Engine/OSAL/LinuxMemory.cpp), while macOS (Engine/OSAL/OSXMemory.cpp) and Windows (Engine/OSAL/WindowsMemory.cpp, through GetSystemInfo) cache the value in a function-local static — which C++11 initialises exactly once, thread-safely. The page size never changes while a process runs, so the caching is sound.

Parameters

None.

Return value

The page size in bytes — 4096 on the platforms this engine runs on today, but the point of the function is that nobody writes that number.

Examples

The guard-page allocator rounds its allocations up to whole pages before reserving: 

		const auto pageSize = OS::GetPageSize();
