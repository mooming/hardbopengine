GetAligned

member of hbe::OSMemory Engine/OSAL/OSMemory.h namespace OS constexpr round up to the next multiple — usable at compile time

Signature

[[nodiscard]] constexpr size_t GetAligned(size_t size, uint32_t alignBytes = hbe::Config::DefaultAlign)

Function description

Rounds up to the next multiple of the alignment, computed inline in Engine/OSAL/OSMemory.h as ((size + alignBytes - 1) / alignBytes) * alignBytes. It is constexpr, so block sizes can be fixed at compile time, and it is the sizing primitive the allocators' math starts from — Engine/Memory/PoolAllocator.cpp clamps its block size through it before anything else happens.

The default alignment is Config::DefaultAlign, the same constant CheckAligned tests against — a size that passed through GetAligned with the default produces addresses that pass the check with the default.

Parameters

ParameterTypeRequirement
sizesize_tThe size to round up; 0 rounds to 0.
alignBytesuint32_tThe alignment to round to; defaults to Config::DefaultAlign. Must be a power of two for the result to be an alignment the hardware would accept.

Return value

The smallest multiple of alignBytes that is greater than or equal to size — or 0 for a size of 0.

Examples

The pool allocator clamps its block size through it, so every block is a multiple of the engine alignment: 

		auto size = OS::GetAligned(requested, Config::DefaultAlign);
