VirtualAlloc

member of hbe::OSMemory Engine/OSAL/OSMemory.h namespace OS reserve and commit address space — mmap anonymous or VirtualAlloc

Signature

void* VirtualAlloc(size_t)

Function description

Reserves and commits size bytes of address space, readable and writable, backed by no file. On Linux and macOS the work is mmap with MAP_PRIVATE | MAP_ANONYMOUS and PROT_READ | PROT_WRITE (Engine/OSAL/LinuxMemory.cpp, Engine/OSAL/OSXMemory.cpp); on Windows it is ::VirtualAlloc with MEM_RESERVE | MEM_COMMIT and PAGE_READWRITE (Engine/OSAL/WindowsMemory.cpp). The name is the Windows call's, kept because that is the API the operation most resembles — this is the OS's virtual memory, not the engine's MemoryManager.

Nothing is rounded: the caller rounds to whole pages with GetPageSize first, the way Engine/Memory/SystemAllocator.h does. Failure is signalled by the platform's sentinel, not an exception — MAP_FAILED on POSIX, nullptr on Windows — which is exactly the pair IsValidAllocation knows how to read. 

void* OS::VirtualAlloc(size_t size)
{
	auto ptr = mmap(nullptr, size, PROT_READ | PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);

	return ptr;
}

Parameters

ParameterTypeRequirement
sizesize_tBytes to reserve; the caller is expected to have rounded to a multiple of the page size.

Return value

The base address of the reservation, readable and writable; MAP_FAILED on POSIX failure, nullptr on Windows failure — check with IsValidAllocation.

Examples

The guard-page allocator's reserve path — page-count math first, then this call: 

		const auto pageSize = OS::GetPageSize();
		const size_t pageCount = (nBytes + pageSize - 1) / pageSize;
		const size_t allocSize = (pageCount + 1) * pageSize;
		auto rawPtr = OS::VirtualAlloc(allocSize);
