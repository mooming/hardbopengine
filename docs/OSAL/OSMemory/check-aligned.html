CheckAligned

member of hbe::OSMemory Engine/OSAL/OSMemory.h namespace OS template address modulo the alignment, computed inline

Signature

template <typename T>
[[nodiscard]] bool CheckAligned(T* ptr, uint32_t alignBytes = hbe::Config::DefaultAlign)

Function description

Address modulo the alignment, computed inline in Engine/OSAL/OSMemory.h: the pointer is cast to size_t and the answer is whether the remainder is zero. No operating system call, no allocation — pure arithmetic, which is why it lives in the header and is noexcept.

The default alignment is Config::DefaultAlign, the same constant every allocator in the engine sizes its blocks with — so a block that passed this check with the default is a block the allocators will accept.

Parameters

ParameterTypeRequirement
ptrT*The pointer to test; only its numeric address is read.
alignBytesuint32_tThe alignment to check against; defaults to Config::DefaultAlign. Must be a power of two for the answer to mean what an allocator would mean by it.

Return value

true when the address is a multiple of alignBytes, false otherwise.
