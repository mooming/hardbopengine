SetAppend

member of hbe::FileOpenMode Engine/OSAL/OSFileOpenMode.h ORs O_APPEND into value — writes land at end of file

Signature

void SetAppend() noexcept

Function description

ORs O_APPEND into value, so every write the platform performs lands at the current end of file, atomically re-seeking before each write. The body is one OR of the <fcntl.h> constant, and the identical definition exists in Engine/OSAL/LinuxFileOpenMode.cpp (OS::FileOpenMode::SetAppend()) and Engine/OSAL/OSXFileOpenMode.cpp (OS::FileOpenMode::SetAppend()), each behind its platform guard. No Windows definition exists — see the class page.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

No call site for this method exists in the repository. It is the only one of the six setters with neither an engine nor a test caller: the engine's file writes go through mapping or explicit OS::Write calls at explicit offsets, so append mode is a capability the class offers and nothing uses yet.
