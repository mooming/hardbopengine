SetCreate

member of hbe::FileOpenMode Engine/OSAL/OSFileOpenMode.h ORs O_CREAT into value — create the file when it does not exist

Signature

void SetCreate() noexcept

Function description

ORs O_CREAT into value, so the platform open creates the file when it does not exist. The body is one OR of the <fcntl.h> constant, and the identical definition exists in Engine/OSAL/LinuxFileOpenMode.cpp (OS::FileOpenMode::SetCreate()) and Engine/OSAL/OSXFileOpenMode.cpp (OS::FileOpenMode::SetCreate()), each behind its platform guard. No Windows definition exists — see the class page.

The file is created with the permission bits the OS::Open implementation supplies, not anything this class carries — Engine/OSAL/LinuxInputOutput.cpp passes S_IRUSR | S_IWUSR as the mode argument of ::open. The flag combines freely with the access modes and with SetTruncate; callers gate it on a OS::Exist probe rather than trusting O_CREAT's no-op-on-existing behaviour.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

The existence-gated pattern from the file-buffer helpers: 

	if (Exist(path))
	{
		openMode.SetTruncate();
	}
	else
	{
		openMode.SetCreate();
	}
