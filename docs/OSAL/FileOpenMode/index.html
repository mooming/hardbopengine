FileOpenMode

Engine/OSAL/OSFileOpenMode.h namespace OS final the flag word OS::Open passes to the platform open call — setters OR POSIX fcntl.h flags, nothing clears

Class description

OS::FileOpenMode is the argument builder for OS::Open: a public int value, zero by default, that the Set… methods accumulate platform open flags into. Each setter is one OR (|=) of a single flag from <fcntl.h> — O_RDONLY, O_WRONLY, O_RDWR, O_CREAT, O_TRUNC, O_APPEND — and the implementations of OS::Open hand value to the platform's open call verbatim: Engine/OSAL/LinuxInputOutput.cpp passes it as the flags argument of ::open.

The setters are defined on Linux and macOS only. The identical bodies live in Engine/OSAL/LinuxFileOpenMode.cpp and Engine/OSAL/OSXFileOpenMode.cpp, each behind its PLATFORM_* guard, and no Windows unit exists anywhere in the repository — Engine/OSAL/CMakeLists.txt lists none, and Engine/OSAL/WindowsInputOutput.cpp, the only Windows file of the IO surface, is a copyright notice with no code. A Windows build that calls any setter does not link; the file-input surface as a whole has no Windows implementation yet.
Accumulation is the whole model: setters only OR, nothing clears. A fresh FileOpenMode is the only reset. The three access modes are mutually exclusive in POSIX semantics, and the class does not enforce it — OR-ing SetWriteOnly onto SetReadOnly compiles and produces a flag word the platform call may reject. The in-tree callers never do it: they pick one access mode and add SetCreate / SetTruncate as needed, the shape Engine/Resource/BufferUtil.cpp shows.

Class methods

NameSignatureWhat a caller depends on
FileOpenMode FileOpenMode() noexcept Starts at zero — an empty flag word, and the only reset the class offers.
SetReadOnly void SetReadOnly() noexcept ORs O_RDONLY into value — an open that may read but not write.
SetWriteOnly void SetWriteOnly() noexcept ORs O_WRONLY into value — an open that may write but not read.
SetReadWrite void SetReadWrite() noexcept ORs O_RDWR into value — the access mode every in-tree caller uses.
SetCreate void SetCreate() noexcept ORs O_CREAT into value — create the file if it does not exist.
SetTruncate void SetTruncate() noexcept ORs O_TRUNC into value — empty an existing file on open.
SetAppend void SetAppend() noexcept ORs O_APPEND into value — every write lands at end of file.

Non-member helpers

None. The class is consumed only through OS::Open.
