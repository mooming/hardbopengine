SetTruncate

member of hbe::FileOpenMode Engine/OSAL/OSFileOpenMode.h ORs O_TRUNC into value — empty an existing file at open

Signature

void SetTruncate() noexcept

Function description

ORs O_TRUNC into value, so the platform open empties an existing file to zero length. The body is one OR of the <fcntl.h> constant, and the identical definition exists in Engine/OSAL/LinuxFileOpenMode.cpp (OS::FileOpenMode::SetTruncate()) and Engine/OSAL/OSXFileOpenMode.cpp (OS::FileOpenMode::SetTruncate()), each behind its platform guard. No Windows definition exists — see the class page.

Truncation happens at open, before any write; resizing an already-open file afterwards is OS::Truncate's job. The flag is meaningless without a write-capable access mode, and the in-tree callers always pair it with SetReadWrite.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

The existence-gated pattern from the file-buffer helpers, where truncate is chosen precisely because the file already exists: 

	if (Exist(path))
	{
		openMode.SetTruncate();
	}
	else
	{
		openMode.SetCreate();
	}
