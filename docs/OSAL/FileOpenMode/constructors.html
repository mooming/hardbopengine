FileOpenMode

member of hbe::FileOpenMode Engine/OSAL/OSFileOpenMode.h starts at zero — an empty flag word, and the only reset the class offers

Signature

FileOpenMode() noexcept
		: value(0)

Function description

The only constructor: it sets value to 0 and nothing else. A freshly constructed FileOpenMode carries an empty flag word, which is the class's reset — there is no clear method, so a caller that wants to start over constructs a new one. The declaration is in the header and the definition is inline in Engine/OSAL/OSFileOpenMode.h itself; unlike the Set… methods, this one needs no platform unit, which is why it works on every platform the header compiles on.

What an empty flag word means at the open call is the platform's reading of zero — on POSIX, OS::Open's implementations pass value verbatim as the flags argument, so the meaning of 0 is the meaning ::open gives it. The intended use is to build the word up with setters before calling OS::Open, as every in-tree caller does.

Parameters

None.

Return value

Not applicable — constructors return nothing.

Examples

The construct-then-accumulate shape every caller shares, from the file-buffer helpers: 

	FileOpenMode openMode;
	openMode.SetReadWrite();

	if (Exist(path))
	{
		openMode.SetTruncate();
	}
	else
	{
		openMode.SetCreate();
	}
