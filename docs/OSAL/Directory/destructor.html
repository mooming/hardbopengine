~Directory

member of hbe::Directory Engine/OSAL/Directory.h defaulted and virtual — destruction frees the two child vectors

Signature

virtual ~Directory() = default

Function description

Defaulted, and virtual on purpose. Defaulted because there is nothing to hand-write: the destructor's whole job is destroying the two child vectors, and std::vector destroys its elements — the child File strings and the recursively-owned child Directory objects — correctly by itself. Virtual because the class is meant to be walked and held through references in a tree; a deletion through a Directory* that is really a derived object destroys the whole object, not just the base.

Note what destruction costs for a deep tree: each Directory owns its dirList by value, so destroying the root destroys the entire loaded subtree recursively. There is no detached state to leak — the object is its lists.

Parameters

None.

Return value

Not applicable — destructors return nothing.

Examples

No call site exists in the repository — nothing constructs a Directory, so nothing destroys one. The declaration is the contract: virtual, defaulted, and complete without a body.
