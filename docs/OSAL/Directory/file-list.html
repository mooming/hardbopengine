FileList

member of hbe::Directory Engine/OSAL/Directory.h the child files read at construction, each by bare name

Signature

[[nodiscard]] const Files& FileList() const

Function description

The child files, as stored at construction: a const Files& — const std::vector<File>& — with one File per child file, each holding its bare name within this directory, not a path from the root. The list never re-scans: what the constructor read is what this returns for the object's lifetime, and the reference is into the object's own vector.

Names starting with '.' never appear — the constructor skips them — and neither do . or .., which ListFilesInDirectory filters before the constructor sees them.

Parameters

None.

Return value

A const std::vector<File>& into the directory's own storage; valid as long as the Directory is. Empty when the directory had no child files — or when it could not be read at all.

Examples

No call site exists in the repository — nothing outside the OSAL constructs a Directory or reads its lists today. The getter is the read half of the constructor's work.
