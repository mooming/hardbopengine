Directory

Engine/OSAL/Directory.h namespace OS a directory that reads itself at construction — child files by bare name, child directories recursively

Class description

OS::Directory is a directory that reads itself at construction and then hands out its children: a public path string, a fileList of the child files, and a dirList of child Directory objects — so a tree walk is a recursion over DirList(). The reading is done once, in the constructor, through OS::ListFilesInDirectory and OS::IsDirectory from OSAbstractLayer; nothing refreshes it afterwards.

The two lists hold different things: fileList stores each child file as a File carrying its bare name within this directory, while dirList stores child directories whose path is the full child path (parentPath + "/" + name). Dot entries never appear in either list — the constructor skips every name starting with '.'.

The recursion is unbounded, and directory cycles are not detected. The constructor recurses into every child that IsDirectory accepts, and IsDirectory answers true for a symlink that resolves to a directory — Engine/OSAL/LinuxAbstractLayer.cpp tests it with opendir, which follows symlinks. A symlink cycle in the tree therefore recurses until the stack or the file system gives out. There is no depth limit and no visited-set.
Nothing in the repository constructs a Directory today. The class and its helpers are the tree-walking machinery of the OSAL; no engine code, test or application instantiates it, so the recursion above has never run outside a hypothetical caller.

None — the class is not a template.
