DirList

member of hbe::Directory Engine/OSAL/Directory.h the child directories, already recursively loaded — the step of a tree walk

Signature

[[nodiscard]] const Dirs& DirList() const

Function description

The child directories, as stored at construction: a const Dirs& — const std::vector<Directory>& — with one fully-loaded Directory per child directory, each already carrying its own FileList and DirList. A tree walk is therefore a recursion over exactly this accessor, and the whole subtree was read eagerly, when the root was constructed.

Each child's path is the full child path — parentPath + "/" + name — while its position in the tree is what the nesting expresses. The reference is into the object's own vector; the list never re-scans.

Parameters

None.

Return value

A const std::vector<Directory>& into the directory's own storage; valid as long as the Directory is. Empty when the directory had no child directories — or when it could not be read at all.

Examples

No call site exists in the repository — nothing outside the OSAL constructs a Directory or walks a tree today. The recursion it enables is described on the class page, including the symlink-cycle hazard the walk carries.
