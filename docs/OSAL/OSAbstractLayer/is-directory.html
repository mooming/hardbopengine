IsDirectory

member of hbe::OSAbstractLayer Engine/OSAL/OSAbstractLayer.h true exactly when the path opens as a directory, symlinks followed

Signature

bool IsDirectory(const char* path)

Function description

Answers whether the path can be opened as a directory — not what it is. On Linux and macOS the test is opendir followed by closedir: a directory answers true, a regular file answers false, a missing path answers false, and — because opendir follows symlinks — a symlink that resolves to a directory answers true. On Windows the test is GetFileAttributesA: the attributes must exist and carry FILE_ATTRIBUTE_DIRECTORY, which also follows symlinks. 

bool IsDirectory(const char* path)
{
	DIR* dir = opendir(path);

	if (dir != nullptr)
	{
		closedir(dir);

		return true;
	}

	return false;
}

The distinction matters to the one in-tree caller: Directory's constructor recurses into every child for which this answers true, so a symlink cycle in a tree makes that recursion unbounded.

pathconst char*The path to test, NUL-terminated; missing paths answer false rather than failing.

Return value

true when the path resolves to something openable as a directory (following symlinks), false for a file, a broken symlink, or a path that does not exist.
