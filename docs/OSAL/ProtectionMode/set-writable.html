Module Index / OSAL / ProtectionMode / SetWritable

SetWritable

member of hbe::ProtectionMode Engine/OSAL/OSProtectionMode.h ORs PROT_WRITE into value — the mapping may be written

Signature

void SetWritable() noexcept

Function description

ORs PROT_WRITE into value, allowing the mapping to be written. The body is one OR of the <sys/mman.h> constant, and the identical definition exists in Engine/OSAL/LinuxProtectionMode.cpp (OS::ProtectionMode::SetWritable()) and Engine/OSAL/OSXProtectionMode.cpp (OS::ProtectionMode::SetWritable()), each behind its platform guard. No Windows definition exists — see the class page.

Writes through a mapping are what OS::MapSync flushes back to the file, so this bit is what makes the map-modify-sync cycle of Engine/Resource/BufferUtil.cpp possible. Nothing is cleared first — the flag combines freely with SetReadable and SetExecutable.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

The read-write combination, from the OSAL's own IO test, which writes through the mapping and then syncs: 

			ProtectionMode protection;
			protection.SetReadable();
			protection.SetWritable();

			auto ptr = MapMemory(fh, TestSize, protection, 0);
