Module Index / OSAL / ProtectionMode / SetReadable

SetReadable

member of hbe::ProtectionMode Engine/OSAL/OSProtectionMode.h ORs PROT_READ into value — the mapping may be read

Signature

void SetReadable() noexcept

Function description

ORs PROT_READ into value, allowing the mapping to be read. The body is one OR of the <sys/mman.h> constant, and the identical definition exists in Engine/OSAL/LinuxProtectionMode.cpp (OS::ProtectionMode::SetReadable()) and Engine/OSAL/OSXProtectionMode.cpp (OS::ProtectionMode::SetReadable()), each behind its platform guard. No Windows definition exists — see the class page.

This is the one protection bit every in-tree mapping carries: the file-buffer helpers in Engine/Resource/BufferUtil.cpp grant read on all three of their flavours, alone for the read-only one. Nothing is cleared first — the flag combines freely with SetWritable and SetExecutable.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

The read-only combination from the file-buffer helpers — readable mapping over a read-write file open, so the operating system enforces what the mapping may do: 

	FileOpenMode openMode;
	openMode.SetReadWrite();

	ProtectionMode protection;
	protection.SetReadable();

	return GenerateFileBuffer(path, openMode, protection);
