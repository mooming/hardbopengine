ProtectionMode

member of hbe::ProtectionMode Engine/OSAL/OSProtectionMode.h starts at zero — an empty protection word, and the only reset the class offers

Signature

ProtectionMode() noexcept
		: value(0)

Function description

The only constructor: it sets value to 0 and nothing else. A freshly constructed ProtectionMode carries an empty protection word, which is the class's reset — there is no clear method, so a caller that wants to start over constructs a new one. The definition is inline in Engine/OSAL/OSProtectionMode.h itself; unlike the Set… methods, this one needs no platform unit.

What an empty protection word means at the map call is the platform's reading of zero — on POSIX, OS::MapMemory's implementations pass value verbatim as the protection argument of mmap, and a protection argument of 0 is PROT_NONE: the pages are mapped but any access faults. The intended use is to build the word up with setters before calling OS::MapMemory, as every in-tree caller does.

Parameters

None.

Return value

Not applicable — constructors return nothing.

Examples

The construct-then-accumulate shape every caller shares, from the file-buffer helpers: 

	ProtectionMode protection;
	protection.SetReadable();
	protection.SetWritable();
