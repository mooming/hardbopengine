CreateApplication

member of hbe::Application Engine/OSAL/Application.h namespace OS free function creates an Application owned by the caller

Signature

[[nodiscard]] std::unique_ptr<Application> CreateApplication() noexcept

Function description

Creates an Application owned by the caller: std::make_unique<Application>(), defined once in Engine/OSAL/Application.cpp with no platform unit behind it — there is nothing platform-specific about allocation. It is the only way the engine acquires an application object; the Engine calls it when EInitLevel::Application is requested and stores the result for its lifetime.

[[nodiscard]] is load-bearing: the returned unique_ptr is the application's lifetime, and discarding it destroys the application immediately. noexcept is honest — the only operation is one make_unique, and the class's constructor cannot throw.

Parameters

None.

Return value

A std::unique_ptr<Application> — the caller owns the application and its destructor runs when the pointer dies.

Examples

The engine's acquisition, with the assert that guards the rest of the start-up: 

		application = OS::CreateApplication();
		FatalAssert(application != nullptr, "Application level requested, no OS application created");
