operator<

member of hbe::File Engine/OSAL/File.h lexicographic order on the path strings

Signature

bool operator<(const File& rhs) const

Function description

Lexicographic order on the path strings: path < rhs.path, nothing more. Defined inline in Engine/OSAL/File.h. Two files compare by their stored strings, so the order is byte-wise on the text — directory layout, case sensitivity and separator conventions are whatever the strings carry, and the operator adds no semantics of its own. It is the strict-weak ordering a sorted container or std::sort over a Files vector would consume.

A File from a Directory holds a bare name, not a full path — see the constructors. Sorting a Directory's FileList() therefore orders by child name within that one directory, which is the only comparison the stored strings can express.

Parameters

ParameterTypeRequirement
rhsconst File&The file to compare against; the two paths are compared as plain strings.

Return value

true when this file's path string orders before rhs's, in lexicographic order.

Examples

No call site exists in the repository — nothing sorts or searches a Files vector today. The operator is the ordering a sorted container of files would use, offered on the type rather than exercised by the engine.
