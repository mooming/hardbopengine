operator=

member of hbe::File Engine/OSAL/File.h copy and move assignment of the path

Signature

File& operator=(const File& src)

File& operator=(File&& src) noexcept

Function description

Copy and move assignment of the path, both defined inline in Engine/OSAL/File.h and both returning *this. The copy assigns the string; the move moves it and is noexcept. Neither is defaulted — the hand-written bodies are the plain memberwise forms — and neither self-assign check exists, because assigning a std::string to itself is safe by the standard library's guarantee.

Their reason to exist is container mechanics: a std::vector<File> — the OS::Files alias — needs copy and move assignment to reallocate and to run its algorithms. No engine code calls either operator explicitly today.

Parameters

ParameterTypeRequirement
srcconst File& or File&&The file whose path is taken; the source of a move is left with a moved-from string.

Return value

*this, as a File& — the assignment chains as usual.

Examples

No call site for either overload exists in the repository. They are the operations std::vector<File> requires rather than operations the engine performs by name; the construct-then-push shape in the constructors' example is how File values actually travel.
