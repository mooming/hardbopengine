File

member of hbe::File Engine/OSAL/File.h from a C string, or copy/move of another file's path

Signature

		: path(path)

File(const File& src)
		: path(src.path)

File(File&& src) noexcept
		: path(std::move(src.path))

Function description

The only constructor, and the whole behaviour of the class: it trims the path with StringUtil::TrimPath, lists the directory with OS::ListFilesInDirectory, and for every entry that is not a dot-entry either recurses — IsDirectory said yes — or stores a File with the bare name. When the constructor returns, the object is fully loaded; there is no later refresh, no lazy read, and no way to re-list without constructing a new Directory. 

	auto list = ListFilesInDirectory(path);

	for (const auto& element : list)
	{
		const char* name = element.c_str();

		continueIf(name[0] == '.');

		string childPath(path);
		childPath.append("/");
		childPath.append(name);

		if (IsDirectory(childPath.c_str()))
		{
			dirList.push_back(Directory(childPath.c_str()));
		}
		else
		{
			File file(name);
			fileList.push_back(file);
		}
	}

From Engine/OSAL/Directory.cpp, OS::Directory::Directory(const char* path)

A path that is not a directory — or does not exist — constructs an empty, "successful" object. ListFilesInDirectory answers an empty list when opendir fails, and the constructor stores the path regardless; there is no error state, no exception and no log. A caller must check OS::IsDirectory itself before trusting the walk. The recursion into child directories is unbounded — see the class page for the symlink-cycle hazard.
