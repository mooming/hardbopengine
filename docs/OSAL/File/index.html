File

Engine/OSAL/File.h namespace OS a path that orders and prints itself — one string, value-copyable, the element of OS::Files

Class description

OS::File is a path that can be stored, ordered and printed: one private std::string, copyable and movable, ordered lexicographically by operator<, and stream-printable through the friend operator<<. The namespace-scope alias OS::Files is std::vector<File> — the list type the engine passes around. It is a value type with no behaviour beyond the path: no open, no stat, no existence test — the file-input surface lives in OSInputOutput, which works on FileHandle and path strings instead.

Its one in-tree producer is Directory's constructor, which fills a Files list with the child files of a directory — and stores the bare names, not full paths, in them. Nothing in Engine/ outside OSAL, and nothing in Applications/, constructs or touches an OS::File today.

Every member is defined in the header. There is no File.cpp: the constructors, the assignments, the ordering, the printing and the getter are all inline in Engine/OSAL/File.h. The class is pure string plumbing, so no per-platform unit has anything to add — the OSAL pattern of neutral header plus platform implementation does not apply to it.

Template parameters

None — the class is not a template.
