operator<<

member of hbe::File Engine/OSAL/File.h prints the path to a stream

Signature

friend std::ostream& operator<<(std::ostream& os, const File& file)

Function description

Prints the file's path: os << file.path, then returns the stream. It is a friend defined inline in Engine/OSAL/File.h, so it is found by argument-dependent lookup when a File appears on the right of << — which is what lets a log line or a test's << chain print a file, or a whole Files vector element by element, without a conversion.

Remember what the path holds: a File from a Directory prints its bare name, not a path from the root — see the constructors.

Parameters

ParameterTypeRequirement
osstd::ostream&The stream to print to; returned so chains continue.
fileconst File&The file whose path is printed; not modified.

Return value

The stream os, so << chains left to right as usual.

Examples

No call site exists in the repository — nothing prints an OS::File today. The operator exists so a Files vector is printable through the ordinary stream machinery when something needs it.
