GetPath

member of hbe::File Engine/OSAL/File.h the path as a const std::string reference

Signature

[[nodiscard]] const auto& GetPath() const

Function description

The path, by reference. The return type is written const auto& and deduces to const std::string& — a read-only view of the single member, no copy, no conversion. It is the only read access to the state; everything else on the class is construction, assignment, ordering and printing.

The [[nodiscard]] matters more than usual here: the reference is into the file's string, so discarding it is always a mistake — and so is storing it past the file's lifetime, which no attribute can catch. The declaration is defined inline in Engine/OSAL/File.h.

Parameters

None.

Return value

A const std::string& to the stored path — or, for a file a Directory produced, to the bare child name. Valid as long as the File is.

Examples

No call site exists in the repository. The engine constructs Files and stores them without ever reading the path back through this getter; the value is carried, not consumed.
