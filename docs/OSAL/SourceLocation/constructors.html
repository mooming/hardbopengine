Function description

Three constructors, and each one answers "where did this location come from". The default constructor produces the deliberately uninformative location — file and function set to the string "Invalid", line and column 0 — so a SourceLocation that was never captured is recognisable in a log instead of printing a stale or empty path. It is constexpr, so a static or member location can be built at compile time.

The four-argument constructor is the capture path: it is what current calls with the values the Caller* builtins produced, and it is constexpr for the same reason. It takes the pointers as given and copies nothing — the pointed-to strings must outlive the location, which the builtins guarantee because they answer string literals with static storage.

The copy constructor is = default: a location is a value of four const members, and copying it copies those four words. There is no move constructor declared, so a move is a copy — and there is nothing to move that a copy would not do.

All four data members are const, so no constructor can be re-run on a live location. A SourceLocation is written once, at construction, and assignment is the memberwise copy of an already-fixed value. There is no setter and no "update the line" call — where a different location is wanted, a new one is captured.

Examples

The four-argument form is reached through current rather than written by hand; the default form is what a zero-initialised location reads as. The engine's lock code prints a captured location when a ScopedLock times out, which is the shape every consumer shares: 

			ls << "[file: " << srcLoc.file_name() << '(' << srcLoc.line() << ':' << srcLoc.column() << ") "
			   << srcLoc.function_name() << ": TimedOut! "
