Module Index / OSAL / SourceLocation / current

current

member of hbe::SourceLocation Engine/OSAL/SourceLocation.h static constexpr captures the call site through its Caller* default arguments

Signature

static constexpr SourceLocation current(const char* fileName = CallerFile(),
											const char* functionName = CallerFunc(),
											const uint_least32_t lineNumber = CallerLine(),
											const uint_least32_t columnOffset = CallerColumn()) noexcept

Function description

The capture point. It is static and takes no argument a caller must supply: every parameter has a default, and the defaults are the CallerFile() / CallerFunc() / CallerLine() / CallerColumn() macros from Engine/OSAL/Intrinsic.h, which expand to __builtin_FILE and friends. A default argument is evaluated where the call appears, not where the function is defined, so SourceLocation::current() written anywhere records the statement it is written on.

That evaluation site is what makes the default-argument pattern work: a function that declares a parameter as SourceLocation location = SourceLocation::current() — the way Engine/Memory/PoolAllocator.h declares its profiling constructor — captures its caller, without the caller writing a single macro. The parameter keeps its full value: any caller who wants to report a different site can still pass an explicit SourceLocation.

CallerFunc() is __builtin_FUNCTION(): the enclosing function's spelling, not a pretty signature. What lands in function_name() is whatever the compiler calls the function at that point — for a member function on Clang and GCC that is the bare name, not the class-qualified spelling. GCC additionally answers 0 for CallerColumn(), so a location captured there reports line but not column.

Parameters

None that a caller passes. The four parameters exist only to carry the Caller* defaults; passing them explicitly is how a caller fakes or relocates a location.

Return value

A SourceLocation by value, constexpr-constructible: the four pointers and integers the builtins answered at the evaluation site. noexcept — nothing here can fail; a capture in a translation unit the compiler cannot attribute still yields the file and line it has.

Examples

The declared-but-omitted parameter is the intended use, and the engine's allocator layer is where it is used: 

	PoolAllocator(const char* inName, TSize inBlockSize, TSize inNumberOfBlocks,
				  SourceLocation location = SourceLocation::current());

From Engine/Memory/PoolAllocator.h, PoolAllocator constructor (PROFILE_ENABLED build)

A caller that constructs a PoolAllocator without a location argument gets the constructor's own call site recorded; the allocator keeps it alongside its profiling stats for the allocator's lifetime.
