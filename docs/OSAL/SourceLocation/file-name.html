Module Index / OSAL / SourceLocation / file_name

file_name

member of hbe::SourceLocation Engine/OSAL/SourceLocation.h the captured file path, or Invalid when never captured

Signature

[[nodiscard]] constexpr const char* file_name() const noexcept

Function description

The captured file name, as a pointer. It is constexpr, so a location built at compile time can be read at compile time. The string is whatever CallerFile() — __builtin_FILE — answered at the capture site: on Clang and GCC that is the path as written on the compiler command line, so the same source can report a relative or absolute spelling depending on how the build was invoked. A default-constructed location answers "Invalid", which is how a log distinguishes "never captured" from a real file.

The [[nodiscard]] is load-bearing for a getter of a const char*: discarding the pointer is always a mistake, and the attribute makes it a compile error rather than a silent one.

Parameters

None.

Return value

The file path captured at the site, as a NUL-terminated string owned by the compiler's literal pool — never allocated, never to be freed. "Invalid" for a default-constructed location.

Examples

The one in-tree print of this field is the lock-timeout log of Engine/Core/ScopedLock.h, in the PROFILE_ENABLED branch of the primary ScopedLock constructor — file first, then line and column, then function, which is the reading order a reader of the log follows: 

				ls << "[file: " << srcLoc.file_name() << '(' << srcLoc.line() << ':' << srcLoc.column() << ") "
				   << srcLoc.function_name() << ": TimedOut! " << duration << " sec exceeds its timelimt "
				   << timeOutSec;
