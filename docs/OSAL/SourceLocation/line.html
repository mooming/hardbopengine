Module Index / OSAL / SourceLocation / line

line

member of hbe::SourceLocation Engine/OSAL/SourceLocation.h the captured one-based line number

Signature

[[nodiscard]] constexpr uint_least32_t line() const noexcept

Function description

The captured line number, one-based as the compiler numbers lines. The value is whatever CallerLine() — __builtin_LINE — answered at the capture site, and it is exact: the statement the capture appears on, not the opening brace of the enclosing block. A default-constructed location answers 0, which is one way a log tells "never captured" from a real line.

The return type is spelled uint_least32_t without the std:: qualification in this declaration — the header includes <cstdint>, which makes the unqualified spelling valid, and the lineNumber member it reads is declared with the qualified std::uint_least32_t. The two spellings name the same type.

Parameters

None.

Return value

The one-based line of the capture site; 0 for a default-constructed location.

Examples

The profiling allocators pass the whole location onward rather than printing it — a StackAllocator stores the location it was constructed with and hands it to the memory manager when it deregisters, so the line a profiling log eventually names is the line of the allocator's construction: 

	mmgr.DeregisterAllocator(GetID(), srcLocation);
#else // PROFILE_ENABLED
	mmgr.DeregisterAllocator(GetID());
#endif // PROFILE_ENABLED
