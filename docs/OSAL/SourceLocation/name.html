Module Index / OSAL / SourceLocation / function_name

function_name

member of hbe::SourceLocation Engine/OSAL/SourceLocation.h the captured function name as the compiler spells it

Signature

[[nodiscard]] constexpr const char* function_name() const noexcept

Function description

The captured function name, as a pointer. The string is whatever CallerFunc() — __builtin_FUNCTION — answered at the capture site: the spelling of the enclosing function at that point, which for a member function on Clang and GCC is the bare name without its class, and for a template is the name without its argument list. A caller who needs the class-qualified or signature-full spelling should not read it here — the field carries exactly what the builtin gives.

A default-constructed location answers "Invalid", pairing with file_name so a never-captured location is recognisable in either field.

Parameters

None.

Return value

The function name at the capture site, as a NUL-terminated string owned by the compiler's literal pool — never allocated, never to be freed. "Invalid" for a default-constructed location.

Examples

Engine/Core/ScopedLock.h prints this field last in its lock-timeout line, after file, line and column, so a timed-out lock names the code that held the lock too long: 

			ls << "[file: " << srcLoc.file_name() << '(' << srcLoc.line() << ':' << srcLoc.column() << ") "
			   << srcLoc.function_name() << ": TimedOut! "
