Sleep

member of hbe::OSThread Engine/OSAL/OSThread.h namespace OS block this thread for milliseconds

Signature

void Sleep(uint32_t milliseconds) noexcept

Function description

Blocks the calling thread for the given number of milliseconds: std::this_thread::sleep_for(std::chrono::milliseconds(milliseconds)), defined once in Engine/OSAL/OSThread.cpp with no platform unit behind it. The scheduler may sleep the thread longer than asked — the argument is a floor, not a deadline.

This is not the clock side of the boundary. hbe::time::Sleep also exists; this one is the OSAL's, and the difference is which question it answers — "block this thread" here, "advance the engine clock" there. Code that mixes them up waits on the wrong thing.

Parameters

ParameterTypeRequirement
millisecondsuint32_tThe minimum time to stay blocked; 0 returns immediately.

Return value

Not applicable — returns void, and cannot fail.

Examples

The OSAL's own test times a 10 ms sleep and fails it if the thread woke too early: 

		auto start = std::chrono::high_resolution_clock::now();
		OS::Sleep(10);
		auto end = std::chrono::high_resolution_clock::now();
