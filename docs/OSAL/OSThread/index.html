OSThread

Engine/OSAL/OSThread.h namespace OS utility header yield, sleep, core index, affinity, priority — and the CPU-time clock the task budgets are charged from

Class description

A utility header, not a class: free functions at OS:: scope for what a thread asks the operating system to do — yield, sleep, learn which core it is on, and set or read scheduling properties of another thread. Two of them (Yield, Sleep) are defined once in Engine/OSAL/OSThread.cpp on top of the standard library's std::this_thread; the rest are defined per platform in Engine/OSAL/LinuxThread.cpp, Engine/OSAL/OSXThread.cpp and Engine/OSAL/WindowsThread.cpp.

The consumer that shapes this header is the task system: Engine/Core/TaskStream.cpp lowers each stream thread's priority at spawn, and CPUBudget charges stream budgets from GetThreadCPUTime — busy time, not wall time, which is the distinction the whole budgeting story rests on.

One function is defined on macOS only. GetThreadPriority is declared for every platform, but the only definition in the repository is in Engine/OSAL/OSXThread.cpp — no Linux or Windows unit defines it, so a call from a Linux or Windows build does not link. The setter exists on all three; the getter does not.
Affinity has a platform ceiling. The Linux unit applies a 64-bit mask through sched_setaffinity; the Windows unit hands the mask to SetThreadAffinityMask; the macOS unit's definition is an empty body — affinity is not applied at all on macOS, where the engine's scheduler must get by without it.

Template parameters

None — the header declares no types at all.

Class properties

None — the header declares no macros, no aliases, no constants and no data members.

Class methods

None — the functions are free functions, and their contracts are tabled under Non-member helpers below.
