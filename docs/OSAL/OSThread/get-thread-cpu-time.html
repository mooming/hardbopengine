GetThreadCPUTime

member of hbe::OSThread Engine/OSAL/OSThread.h namespace OS busy time of the calling thread — what budgets are charged from

Signature

[[nodiscard]] std::chrono::nanoseconds GetThreadCPUTime() noexcept

Function description

CPU time the calling thread has consumed so far, user plus system time combined. Busy time, not wall time: a thread that sleeps or waits on a lock advances this by almost nothing. Task budgets are charged from it precisely so that work which is merely waiting cannot spend a budget it never executed — CPUBudget brackets each task with two calls and charges the difference.

It is the calling thread that is measured, which is what lets a stream budget itself without a handle on any other thread. Linux and macOS read clock_gettime(CLOCK_THREAD_CPUTIME_ID) (Engine/OSAL/LinuxThread.cpp, Engine/OSAL/OSXThread.cpp, identical definitions); Windows reads GetThreadTimes on its own pseudo-handle and adds kernel and user time (Engine/OSAL/WindowsThread.cpp). 

	struct timespec timeValue{};
	if (clock_gettime(CLOCK_THREAD_CPUTIME_ID, &timeValue) != 0)
	{
		return std::chrono::nanoseconds::zero();
	}

	return std::chrono::seconds(timeValue.tv_sec) + std::chrono::nanoseconds(timeValue.tv_nsec);

From Engine/OSAL/LinuxThread.cpp, OS::GetThreadCPUTime()

Zero means the platform call failed — and a budget then charges nothing. The failure mode is deliberately fail-open: a reader that returned garbage would bill work that never ran, so the zero answer costs a budget nothing and lets the stream keep taking work. On Windows the reading is coarser than the nanosecond type suggests: GetThreadTimes reports at the granularity of the system clock tick, so budgets charged from it are quantised there in a way the POSIX clock readings are not.

Parameters

None. There is no thread parameter — the measurement is always the calling thread.

Return value

The CPU time consumed, user plus system, as std::chrono::nanoseconds; std::chrono::nanoseconds::zero() if the platform call failed.

Examples

The budget bracket that charges a task for what it actually executed: 

void hbe::CPUBudget::BeginTask() noexcept
{
	taskStart = OS::GetThreadCPUTime();
	isMeasuring = true;
}
