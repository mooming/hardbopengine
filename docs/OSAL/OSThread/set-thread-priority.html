SetThreadPriority

member of hbe::OSThread Engine/OSAL/OSThread.h namespace OS set the platform's own priority number

Signature

void SetThreadPriority(std::thread& thread, int priority) noexcept

Function description

Sets a thread's OS priority. Three mechanisms sit behind one signature: Linux applies setpriority(PRIO_PROCESS, thread.native_handle(), priority) (Engine/OSAL/LinuxThread.cpp), macOS applies pthread_setschedparam with the fixed SCHED_FIFO policy and the given sched_priority (Engine/OSAL/OSXThread.cpp), and Windows calls ::SetThreadPriority (Engine/OSAL/WindowsThread.cpp). No unit translates the int — the caller is writing the platform's own scale.

Failures log and continue on every platform: the Linux unit logs through the logger (its message reads "failed to set thread affinity" — a copy-paste slip worth knowing when reading logs), macOS distinguishes EINVAL, ENOTSUP and ESRCH in its log, and Windows routes through the engine's error log. Nothing throws, nothing asserts — a priority that did not take is the caller's problem to notice.

The engine's one production caller is the task system, which lowers every stream thread's priority at spawn: 

	thread = std::thread(func);
	OS::SetThreadPriority(thread, 0);

From Engine/Core/TaskStream.cpp, TaskStream::Start()

Parameters

Return value

Not applicable — returns void. Failures log; nothing throws or asserts.
