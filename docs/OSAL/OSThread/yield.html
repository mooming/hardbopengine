Yield

member of hbe::OSThread Engine/OSAL/OSThread.h namespace OS hand the core to another thread

Signature

void Yield() noexcept

Function description

Hands the core to another runnable thread: std::this_thread::yield(), defined once in Engine/OSAL/OSThread.cpp with no platform unit behind it. The scheduler decides what runs next — the caller has no say, and the call is a hint the scheduler may ignore entirely if nothing else is runnable. It is the cheap park a spin-wait uses before escalating to Sleep.

Parameters

None.

Return value

Not applicable — returns void, and cannot fail.

Examples

No production call site exists in the repository — the OSAL's own test calls it once to prove it returns. Spin-waits in the engine currently yield through other paths, and this function is the boundary's spelling of the operation for whoever needs it.
