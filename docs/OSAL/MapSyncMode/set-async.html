SetAsync

member of hbe::MapSyncMode Engine/OSAL/OSMapSyncMode.h ORs MS_ASYNC into value — queue the flush and return

Signature

void SetAsync() noexcept

Function description

ORs MS_ASYNC into value, asking msync to schedule the write-back and return without waiting for it. The body is one OR of the <sys/mman.h> constant, and the identical definition exists in Engine/OSAL/LinuxMapSyncMode.cpp (OS::MapSyncMode::SetAsync()) and Engine/OSAL/OSXMapSyncMode.cpp (OS::MapSyncMode::SetAsync()), each behind its platform guard. No Windows definition exists — see the class page.

MS_ASYNC and MS_SYNC are mutually exclusive in POSIX semantics and the class does not enforce it; the in-tree callers never mix them. Nothing is cleared first — on a fresh MapSyncMode it is the first call made.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

No call site for this method exists in the repository. Every flush the engine performs is synchronous — SetSync, in Engine/Resource/BufferUtil.cpp's buffer releaser and in the OSAL's own IO test — so asynchronous write-back is a capability the class offers and nothing uses yet.
