SetSync

member of hbe::MapSyncMode Engine/OSAL/OSMapSyncMode.h ORs MS_SYNC into value — block until the flush is done

Signature

void SetSync() noexcept

Function description

ORs MS_SYNC into value, asking msync to block until the mapped pages are written back to the file. The body is one OR of the <sys/mman.h> constant, and the identical definition exists in Engine/OSAL/LinuxMapSyncMode.cpp (OS::MapSyncMode::SetSync()) and Engine/OSAL/OSXMapSyncMode.cpp (OS::MapSyncMode::SetSync()), each behind its platform guard. No Windows definition exists — see the class page.

This is the only sync mode the engine uses. The buffer releaser in Engine/Resource/BufferUtil.cpp flushes with it before unmapping, so a Buffer backed by a file mapping hands its data to the operating system before the mapping disappears; the OSAL's own IO test does the same around its mapped-write phase. Nothing is cleared first — MS_ASYNC and MS_SYNC are mutually exclusive in POSIX semantics and the class does not enforce it.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

The flush-before-unmap shape from the buffer releaser: 

		MapSyncMode syncMode;
		syncMode.SetSync();

		MapSync(ptr, size, syncMode);
		UnmapMemory((void*) data, size);
