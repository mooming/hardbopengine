Invalidate

member of hbe::MapSyncMode Engine/OSAL/OSMapSyncMode.h ORs MS_INVALIDATE into value — drop stale cached copies of the pages

Signature

void Invalidate() noexcept

Function description

ORs MS_INVALIDATE into value, asking msync to invalidate cached copies of the mapped pages so every mapping of the file re-reads what was just written back. The body is one OR of the <sys/mman.h> constant, and the identical definition exists in Engine/OSAL/LinuxMapSyncMode.cpp (OS::MapSyncMode::Invalidate()) and Engine/OSAL/OSXMapSyncMode.cpp (OS::MapSyncMode::Invalidate()), each behind its platform guard. No Windows definition exists — see the class page.

The name is the POSIX one — this is a cache-invalidation flag on a sync call, not the "make this handle empty" operation that OS::FileHandle::Invalidate performs. Nothing is cleared first; the flag combines freely with SetAsync and SetSync.

Parameters

None.

Return value

Not applicable — the method mutates value and returns void.

Examples

No call site for this method exists in the repository. The engine's mappings are single-owner — one Buffer, one mapping, flushed and unmapped by the same code — so cache invalidation across mappings is a capability the class offers and nothing uses yet.
