MapSyncMode

Engine/OSAL/OSMapSyncMode.h namespace OS final the flag word OS::MapSync passes to msync — async, sync, invalidate; setters OR, nothing clears

Class description

OS::MapSyncMode is the argument builder for OS::MapSync: a public int value, zero by default, that the Set… methods accumulate the POSIX msync flags into — MS_ASYNC, MS_SYNC, MS_INVALIDATE from <sys/mman.h>. The implementations of OS::MapSync hand value to msync verbatim: Engine/OSAL/LinuxInputOutput.cpp passes it as the flags argument.

The setters are defined on Linux and macOS only. The identical bodies live in Engine/OSAL/LinuxMapSyncMode.cpp and Engine/OSAL/OSXMapSyncMode.cpp, each behind its PLATFORM_* guard, and no Windows unit exists anywhere in the repository — Engine/OSAL/CMakeLists.txt lists none, and Engine/OSAL/WindowsInputOutput.cpp, the only Windows file of the IO surface, is a copyright notice with no code. A Windows build that calls any setter does not link.
Accumulation is the whole model: setters only OR, nothing clears. A fresh MapSyncMode is the only reset. MS_ASYNC and MS_SYNC are mutually exclusive in POSIX semantics — one returns as soon as the flush is queued, the other blocks until it is done — and the class does not enforce the exclusivity. Every in-tree caller sets exactly one: SetSync, in Engine/Resource/BufferUtil.cpp's buffer releaser and in the OSAL's own IO test.

Class methods

NameSignatureWhat a caller depends on
MapSyncMode MapSyncMode() noexcept Starts at zero — an empty flag word, and the only reset the class offers.
SetAsync void SetAsync() noexcept ORs MS_ASYNC into value — queue the flush and return.
SetSync void SetSync() noexcept ORs MS_SYNC into value — block until the flush is done; the only mode in-tree callers use.
Invalidate void Invalidate() noexcept ORs MS_INVALIDATE into value — ask the kernel to drop stale cached copies of the pages.
