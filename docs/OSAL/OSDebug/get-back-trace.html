GetBackTrace

member of hbe::OSDebug Engine/OSAL/OSDebug.h namespace OS the call stack as a printable string — 128-frame cap, demangled on POSIX, SymFromAddr on Windows

Signature

hbe::StaticString GetBackTrace(uint16_t startIndex = 0, uint16_t maxDepth = 512)

Function description

The current call stack, formatted and returned as an hbe::StaticString. Every platform unit opens the string with "CallStack:\n" and appends one line per frame; the whole answer is built in an 8 KiB InlineStringBuilder, so a trace longer than that is cut at the builder's capacity, and the POSIX units never capture more than 128 frames regardless of maxDepth.

The frame numbering is where the platforms disagree, and the disagreement is in the parameter's meaning. The POSIX units (Engine/OSAL/LinuxDebug.cpp, Engine/OSAL/OSXDebug.cpp, line-for-line identical) increment startIndex by one before walking, so the default 0 starts at the caller of GetBackTrace and the printed numbers count from there — the capture frame never appears. The Windows unit (Engine/OSAL/WindowsDebug.cpp) passes startIndex to CaptureStackBackTrace as-is and prints the walk index directly, so the default 0 includes the frame the POSIX units skip. 

	++startIndex;
	...
	for (int i = startIndex; i < frames && maxDepth > 0; ++i, --maxDepth)

From Engine/OSAL/LinuxDebug.cpp, OS::GetBackTrace(uint16_t, uint16_t) — two non-contiguous lines of one function, elided

On POSIX each line is tokenised; when the symbol line has the expected five tokens, the mangled name is demangled through abi::__cxa_demangle and the line reads <frame>: [<binary>] <module> <demangled name> +<offset>. A line that does not split into five tokens is printed raw. Windows resolves each address with SymFromAddr and prints <index> : <name> (<address>) — no demangling step, different shape.

The parameters are filters, not guarantees. maxDepth counts frames after the start; the POSIX capture is capped at 128 frames before the filter is applied, so a maxDepth of 512 — the default — can never be filled. A failed platform call is not signalled: an empty or partial stack simply comes back as a short string.

Parameters

ParameterTypeRequirement
startIndexuint16_tHow many leading frames to skip — plus one more, on POSIX, for the capture call itself. Default 0 begins at the caller on POSIX.
maxDepthuint16_tMaximum frames to report after the start; effective ceiling is the platform's capture cap (128 on POSIX). Default 512.

Return value

An hbe::StaticString holding "CallStack:\n" plus one formatted line per reported frame; never empty, never an error — a failed capture reads as a short trace.

Examples

The OSAL's own test prints it whole: 

	AddTest("Print CallStack", [this](auto& ls)
	{
		auto callstack = OS::GetBackTrace();
		ls << callstack.c_str() << lf;
	});
