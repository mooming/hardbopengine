OSDebug

Engine/OSAL/OSDebug.h namespace OS utility header one free function: the current call stack as a printable StaticString

Class description

A utility header, not a class: its entire surface is one free function at OS:: scope — GetBackTrace, which walks the current call stack and returns it as an interned hbe::StaticString. It is the OSAL's contribution to the debugging toolbox: the assertion machinery can name a line, this can name the whole road that led there.

The function is declared once in Engine/OSAL/OSDebug.h and defined once per platform — Engine/OSAL/LinuxDebug.cpp and Engine/OSAL/OSXDebug.cpp are line-for-line identical (backtrace plus cxxabi demangling), and Engine/OSAL/WindowsDebug.cpp uses CaptureStackBackTrace plus DbgHelp symbol lookup. The two families format differently and even number their frames differently — see the function's page.

Template parameters

None — the header declares no types at all.
