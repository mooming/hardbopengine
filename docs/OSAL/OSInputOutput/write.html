Write

member of hbe::OSInputOutput Engine/OSAL/OSInputOutput.h namespace OS bytes actually transferred

Signature

size_t Write(const FileHandle& handle, void* buffer, size_t size) noexcept

Function description

Writes up to size bytes from buffer and answers how many actually landed — the same short-count contract as Read, with the same three guard paths answering 0 with a warning before any system call: invalid handle, null buffer, zero size (Engine/OSAL/LinuxInputOutput.cpp, Engine/OSAL/OSXInputOutput.cpp). The write starts at the file's current position unless the mode word carried O_APPEND.

The buffer parameter is void*, not const void* — the signature does not promise not to modify the buffer, but the implementations only read it. Callers cast away const at their own edge; the engine's own callers pass non-const buffers.

Parameters

ParameterTypeRequirement
handleconst FileHandle&An open handle; an invalid one answers 0 with a warning.
buffervoid*Source; must hold at least size readable bytes.
sizesize_tMaximum bytes to write; zero answers 0 with a warning.

Return value

Bytes actually transferred — possibly fewer than size; 0 for the guard paths.

Examples

The OSAL's own IO test fills a file through it before mapping: 

			{
				uint8_t buffer[TestSize];
				Write(fh, buffer, TestSize);
			}
