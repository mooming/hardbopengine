Truncate

member of hbe::OSInputOutput Engine/OSAL/OSInputOutput.h namespace OS resize the open file

Signature

bool Truncate(const FileHandle& handle, size_t size) noexcept

Function description

Resizes the open file to exactly size bytes — growing it with zeros or shrinking it, whichever the current size demands: ftruncate(fd, size) on the POSIX units (Engine/OSAL/LinuxInputOutput.cpp, Engine/OSAL/OSXInputOutput.cpp). An invalid handle answers false with a warning before any system call; a failed truncation logs the platform error text and answers false.

Truncation at open time is a different mechanism — the O_TRUNC flag of the FileOpenMode. This function is the resize of an already-open file, which is how the file-buffer helpers force a mapping to an exact size.

Parameters

ParameterTypeRequirement
handleconst FileHandle&An open handle; an invalid one answers false with a warning.
sizesize_tThe new size in bytes; may be larger or smaller than the current one.

Return value

true when the file is exactly size bytes; false after a logged warning otherwise.

Examples

The file-buffer generator forcing an explicit size before mapping: 

		auto fileSize = fh.GetFileSize();
		if (size != 0)
		{
			fileSize = size;
			if (!Truncate(fh, fileSize))
			{
				log.OutWarning([path, size](auto& ls)
				{ ls << "Failed to resize the file " << path << " to the given size " << size; });

				return;
			}
		}
