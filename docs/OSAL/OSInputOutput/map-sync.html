MapSync

member of hbe::OSInputOutput Engine/OSAL/OSInputOutput.h namespace OS flush a writable mapping — but true even when the flush failed

Signature

bool MapSync(void* ptr, size_t size, MapSyncMode syncMode) noexcept

Function description

Flushes a writable mapping back to its file: msync(ptr, size, syncMode.value) on the POSIX units (Engine/OSAL/LinuxInputOutput.cpp, Engine/OSAL/OSXInputOutput.cpp), with the flag word from MapSyncMode passed verbatim. This is the last step of the map-modify-sync cycle — without it, writes through a MAP_SHARED mapping reach the file only when the operating system gets around to them.

The bool overstates success. The two guard paths behave as documented — a null pointer answers false, a zero size answers true — but a failed msync is only logged at error level, and the function still answers true. A caller that must know the flush reached the disk cannot learn it from the return value; the failure is visible in the log only. 
	auto rc = msync(ptr, size, syncMode.value);
	if (unlikely(rc != 0))
	{
		...
		log.OutError([ptr](auto& ls)
		{ ls << "Failed to set sync. ptr = " << ptr << ", ErrorMsg(" << std::strerror(errno) << ')'; });
	}

	return true;

Examples

		MapSyncMode syncMode;
		syncMode.SetSync();

		MapSync(ptr, size, syncMode);
