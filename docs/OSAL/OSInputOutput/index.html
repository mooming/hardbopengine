OSInputOutput

Engine/OSAL/OSInputOutput.h namespace OS utility header open, close, exist, delete, read, write, truncate, and the map-sync-unmap triple — the file-input surface

Class description

A utility header, not a class: free functions at OS:: scope for the file-input surface — open, close, exist, delete, read, write, truncate, and the mapping triple MapMemory / MapSync / UnmapMemory. Everything travels through a FileHandle, whose ownership rules — move-only, closed on destruction — are what make the function set safe to use.

The functions are declared once in Engine/OSAL/OSInputOutput.h and defined per platform: Engine/OSAL/LinuxInputOutput.cpp and Engine/OSAL/OSXInputOutput.cpp are the same POSIX story told twice (the macOS unit reaches the descriptor through reinterpret_cast helpers where the Linux unit names fd directly), and the engine's file-backed Buffer machinery is the main consumer. Engine/OSAL/OSInputOutput.cpp defines none of them — it is the test collection.

Windows has no implementation. Engine/OSAL/WindowsInputOutput.cpp is a copyright notice with no code, and no other Windows unit defines any of these functions — a Windows build that calls any of them does not link. The whole surface is Linux-and-macOS today.

Template parameters

None — the header declares no types of its own; the four classes it names are forward-declared and defined in their own headers (FileHandle, FileOpenMode, ProtectionMode, MapSyncMode).

Class properties

None — the header declares no macros, no aliases, no constants and no data members.

Class methods

None — the functions are free functions, and their contracts are tabled under Non-member helpers below.
