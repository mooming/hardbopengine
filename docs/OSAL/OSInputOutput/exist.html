Exist

member of hbe::OSInputOutput Engine/OSAL/OSInputOutput.h namespace OS presence test

Signature

bool Exist(hbe::StaticString filePath) noexcept

Function description

Presence test: access(path, F_OK) on the POSIX units — true when the path exists and is reachable, whatever it is (file, directory, symlink); false when it does not or cannot be reached (Engine/OSAL/LinuxInputOutput.cpp, Engine/OSAL/OSXInputOutput.cpp). It says nothing about what the path is — OS::IsDirectory is the question for that — and nothing about permission to open it.

Parameters

ParameterTypeRequirement
filePathhbe::StaticStringThe path to test, by value.

Return value

true when the path exists and is reachable, false otherwise.

Examples

The existence gate before choosing create-or-truncate, from the file-buffer helpers: 

	if (Exist(path))
	{
		openMode.SetTruncate();
	}
	else
	{
		openMode.SetCreate();
	}
