Open

member of hbe::OSInputOutput Engine/OSAL/OSInputOutput.h namespace OS fill the out-handle with the descriptor, or log and fail

Signature

bool Open(FileHandle& outHandle, hbe::StaticString filePath, FileOpenMode openMode) noexcept

Function description

Opens a file and hands the descriptor to the out-parameter. The mode word is passed to the platform open call verbatim — ::open(path, openMode.value, S_IRUSR | S_IWUSR) on both POSIX units — so what the opening does is exactly what the caller built into the FileOpenMode. Created files get owner-read and owner-write permissions; nothing else is granted. 

	auto path = filePath.c_str();
	int fd = ::open(path, openMode.value, S_IRUSR | S_IWUSR);
	if (unlikely(fd < 0))
	{
		...
		log.OutWarning([&filePath](auto& ls)
		{ ls << "File open failed. path = " << filePath << ", reason(" << std::strerror(errno) << ')'; });

		return false;
	}

	outHandle.fd = fd;

	return true;

From Engine/OSAL/LinuxInputOutput.cpp, OS::Open(FileHandle&, hbe::StaticString, FileOpenMode) — logging lines elided with the logger setup

Failure is a logged warning carrying the platform's error text, a false return, and an untouched handle — the caller's FileHandle stays invalid, which is safe to destruct. The macOS unit writes the descriptor through its FileHandleHelper::SetHandle reinterpret instead of naming fd (Engine/OSAL/OSXInputOutput.cpp); the storage is the same.

Parameters

ParameterTypeRequirement
outHandleFileHandle&Receives the descriptor on success; expected to be invalid on entry and never closed by this function.
filePathhbe::StaticStringThe path to open, by value.
openModeFileOpenModeThe flag word for the platform open call — access mode plus behaviour bits; see FileOpenMode.

Return value

true when the descriptor is open and stored in outHandle; false after a logged warning, with the handle left invalid.
