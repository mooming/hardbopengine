Delete

member of hbe::OSInputOutput Engine/OSAL/OSInputOutput.h namespace OS remove a file or empty directory

Signature

bool Delete(hbe::StaticString filePath) noexcept

Function description

Removes the path: remove(path) on the POSIX units, which deletes a file — or an empty directory — and answers false when the removal failed (Engine/OSAL/LinuxInputOutput.cpp, Engine/OSAL/OSXInputOutput.cpp). There is no log on failure: the bool is the whole error report, and the caller decides whether a failed deletion matters. A non-empty directory answers false — remove does not recurse.

Parameters

ParameterTypeRequirement
filePathhbe::StaticStringThe path to remove, by value; a missing path answers false.

Return value

true when the path was removed; false when it was not — including when it did not exist.

Examples

The OSAL's own IO test cleans up after itself through it: 

		if (Delete(path))
		{
			ls << "File removal succeeded. path = " << path << lf;
		}
