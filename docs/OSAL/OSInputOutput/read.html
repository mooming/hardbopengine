Read

member of hbe::OSInputOutput Engine/OSAL/OSInputOutput.h namespace OS bytes actually transferred — the short count is the contract

Signature

size_t Read(const FileHandle& handle, void* buffer, size_t size) noexcept

Function description

Reads up to size bytes into buffer and answers how many actually arrived — the short count is the contract, and the reason a caller usually loops: a read that hits end-of-file returns fewer bytes than asked, and the platform's warning log fires on every such short count (Engine/OSAL/LinuxInputOutput.cpp, Engine/OSAL/OSXInputOutput.cpp).

Three guard paths answer 0 with a warning before any system call: an invalid handle (negative descriptor), a null buffer, a zero size. The handle is taken const — reading does not move ownership.

Parameters

ParameterTypeRequirement
handleconst FileHandle&An open handle; an invalid one answers 0 with a warning.
buffervoid*Destination; must hold at least size bytes — the function cannot know its capacity.
sizesize_tMaximum bytes to read; zero answers 0 with a warning.

Return value

Bytes actually transferred — possibly fewer than size; 0 for the guard paths and at end-of-file.

Examples

The OSAL's own IO test reads back a file it just wrote and compares counts: 

			uint8_t buffer[TestSize];
			auto readBytes = Read(fh, buffer, TestSize);
			if (readBytes != TestSize)
			{
				Close(std::move(fh));
				Delete(path);
				...
				return;
			}
