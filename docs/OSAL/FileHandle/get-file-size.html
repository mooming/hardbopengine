GetFileSize

member of hbe::FileHandle Engine/OSAL/OSFileHandle.h the file's size by fstat — zero for invalid, failure, and empty alike

Signature

[[nodiscard]] size_t GetFileSize() const noexcept

Function description

The file's current size, queried with fstat on the handle's descriptor. An invalid handle answers 0 without touching the operating system; a failed fstat also answers 0. The platform units pin the width with static_assert(sizeof(size_t) == sizeof(statValue.st_size)), so the descriptor's size type and the engine's are the same width on any platform this compiles on.

The three zeros are indistinguishable by design of the signature: an invalid handle, a failed query, and a genuinely empty file all answer 0. A caller that must tell them apart checks IsValid first. The platform units spell the guarantee identically — Engine/OSAL/LinuxFileHandle.cpp reads fd directly, Engine/OSAL/OSXFileHandle.cpp through its GetHandle helper — and both are noexcept as the header declares. 

size_t FileHandle::GetFileSize() const
{
	if (unlikely(fd < 0))
		return 0;

	struct stat statValue;
	int result = fstat(fd, &statValue);

	if (unlikely(result != 0))
		return 0;

	static_assert(sizeof(size_t) == sizeof(statValue.st_size));

	return statValue.st_size;
}

Parameters

None.

Return value

The size in bytes as st_size reports it; 0 for an invalid handle, a failed fstat, or an empty file.

Examples

The file-buffer generator reads the size to decide what to map — and overrides it when the caller asked for an explicit size, truncating first: 

		auto fileSize = fh.GetFileSize();
		if (size != 0)
		{
			fileSize = size;
			if (!Truncate(fh, fileSize))
			{
				log.OutWarning([path, size](auto& ls)
				{ ls << "Failed to resize the file " << path << " to the given size " << size; });

				return;
			}
		}
