IsValid

member of hbe::FileHandle Engine/OSAL/OSFileHandle.h true exactly when the descriptor is non-negative

Signature

[[nodiscard]] bool IsValid() const noexcept

Function description

True exactly when the descriptor is non-negative. The invalid state is fd == -1, which is what the default constructor and Invalidate write and what a move leaves in its source — so "invalid" has one meaning across the handle's whole life: no descriptor is held. A valid handle holds a descriptor that some OS::Open implementation wrote.

The platform units agree on the test and differ on the spelling: Engine/OSAL/LinuxFileHandle.cpp compares fd directly, Engine/OSAL/OSXFileHandle.cpp reads it through its GetHandle helper.

Parameters

None.

Return value

true when the handle holds a descriptor, false when it holds -1.

Examples

No engine or application code calls this method today — the declared callers of the handle check validity by other means (OS::Open's return value, fd < 0 inside the OSAL's own units). The method is the public spelling of the test the platform units apply internally, offered for callers who hold a handle across a boundary where OS::Open's result is no longer in reach.
