Module Index / String

String

namespace hbe Engine/String 9 headers, 6 sources — the mutable string, the interned string, builders, and character utilities

Module description

Two string types with different jobs. String is the ordinary one: a shareable buffer plus the operations you expect, where the transforming operations return a new value and the To… forms mutate in place. StaticString is interned into one global table, so comparing two of them is comparing pointers — which is why engine identifiers, log categories and task names are StaticString and not String. The builders exist so formatting text does not allocate per piece, and StringUtil holds the operations that do not need an object at all.

String (Engine/String/String.h)

Class description

The engine's text type. It holds a shareable buffer and a cached hash, so copying a String is cheap and StringUtil::CalculateHash is not repeated on every use. Naming carries the contract here: a method beginning Get or Sub returns a new string, one beginning To mutates this one.

Template parameters

None — String is not a template. The element type is TChar.

Class properties

The shareable character buffer and the cached hash code; both private, read through Length, HashCode and c_str.

Two families, one letter apart. GetLowerCase() returns a new string; ToLowerCase() returns nothing and changes the receiver. Append returns a new string; AppendSelf mutates. The pair is easy to type wrong and both spellings compile, so the rule worth remembering is the first letter: Get builds, To changes.
Contains is Find(keyword) < Length(), so the "not found" value of a search is a length-or-greater index rather than a negative number. Comparing a Find result against -1 is the classic bug, and here it silently reads as "found".

StaticString (Engine/String/StaticString.h)

Class description

A string interned in one global table, so its identity is a pointer. Two StaticString values naming the same text compare with one pointer equality, which is why log categories, task names and component keys are this type rather than String. Interning costs a table lookup at construction and pays it back on every comparison.

Template parameters

None — StaticString is not a template.

Class properties

The interned StaticStringID; private, exposed by GetID().

Class methods

StaticString() noexcept;
StaticString(StaticStringID id) noexcept;
StaticString(const char* string) noexcept;            // interns, or finds the existing entry
StaticString(const std::string_view& str) noexcept;

[[nodiscard]] const char* c_str() const noexcept;
[[nodiscard]] StaticStringID GetID() const noexcept;
[[nodiscard]] bool IsNull() const noexcept;

[[nodiscard]] bool operator==(const StaticString& rhs) const noexcept;  // pointer equality
Comparison is identity, not content. operator== compares interned pointers. Two separately built buffers naming the same text are equal after both have gone through interning — which a value reaching you as raw characters from a file has not. Convert first, compare second.

InlineStringBuilder (Engine/String/InlineStringBuilder.h)

Class description

The same << interface writing into a fixed inline buffer, so a formatter inside a frame or a logger pays no allocation. This is what StringUtil writes into (InlineStringBuilder<64> for a timestamp), and what the log line's inline text exists to receive.

Template parameters

ParameterDefaultMeaning
BufferSize1024Bytes inline in the object — a hard ceiling, not a starting size
TCharcharCharacter type

Class properties

The inline buffer and the write cursor; private.

Class methods

The << set of StringBuilder, plus Clear() to reuse one builder without releasing the buffer.

There is no growth. Writing past BufferSize cannot be answered by allocating, so a caller choosing 64 for a value it did not measure is choosing truncation. Pick the size from the largest thing that will be written, not from what is usually written.

EndLine (Engine/String/EndLine.h)

Class description

A marker type rather than a string constant: it converts to "\n" when a builder takes it. Making it a type means a builder can give it its own overload, and the call site reads as intent instead of an escape sequence at the end of a line where it is invisible. 

class EndLine final
{
public:
    [[nodiscard]] operator const char*() const { return "\n"; }
};

static constexpr EndLine hendl;

Template parameters

None — EndLine is not a template.

Class properties

None; the conversion is the whole class.

Class methods

operator const char* above, and nothing else — the class page carries the detail, including why the one instance is one object per translation unit.

Non-member helper functions

The single instance hendl, declared static constexpr in the header so every translation unit shares the value without a link-time definition.
