GetBuffer

member of hbe::String Engine/String/String.h the raw buffer — bypasses the hash invariant

Signature

[[nodiscard]] TChar* GetBuffer() noexcept

[[nodiscard]] const TChar* GetBuffer() const noexcept

Function description

The raw buffer — buffer->data() — mutable in the non-const overload. This is the escape hatch for in-place edits that the method set does not cover, and it comes with two exposures. The terminator discipline is the caller's: content longer than the buffer's allocation cannot be written, and a write must leave a terminator for Length-based logic to stay coherent. And the cached hash is not updated — only the mutating methods call CalculateHashCode — so after a raw write, operator== compares against a stale hash and can call two equal strings unequal.

Parameters

None.

Return value

The buffer's characters — writable in the non-const form, valid until the string grows or dies.

Examples

The engine's own users are the mutating methods — ToLowerCase and ToUpperCase take the pointer, edit in place, and then call CalculateHashCode to restore the invariant. That two-step is the pattern any raw writer must follow.
