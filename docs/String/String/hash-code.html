HashCode

member of hbe::String Engine/String/String.h the cached djb2 hash

Signature

[[nodiscard]] Index HashCode() const noexcept

Function description

The cached hash — returned from the member, never recomputed here. It is the djb2 value CalculateHashCode maintains, the same algorithm StringUtil::CalculateHash uses, and it is what lets operator== reject most unequal pairs without a byte comparison.

The cache is only as current as the last mutating method. Writes through GetBuffer do not update it; a hash read after such a write is stale, and equality comparisons inherit the staleness.

Parameters

None.

Return value

The cached djb2 hash as Index; 0 for an empty string.

Examples

No production call site reads the hash directly — its consumers are operator== and any future hash-keyed container of String.
