ToLowerCase

member of hbe::String Engine/String/String.h in place, ASCII-only, hash recomputed

Signature

void ToLowerCase() noexcept

Function description

Lower-cases this string in place: every character Letter::IsUpperCase accepts (ASCII 'A'–'Z') is shifted by 'a' - 'A', everything else is untouched — then the hash is recomputed. ASCII-only, like the whole module's case handling; no locale, no Unicode. 

	constexpr TChar diff = 'a' - 'A';

	auto tmp = GetBuffer();
	const auto length = Length();
	for (Index i = 0; i < length; ++i)
	{
		if (Letter::IsUpperCase(tmp[i]))
		{
			tmp[i] += diff;
		}
	}

	CalculateHashCode();

Note the pattern GetBuffer's page prescribes: raw edit, then CalculateHashCode — this method restores the hash invariant itself. For the building form see GetLowerCase.
