StartsWith

member of hbe::String Engine/String/String.h begins with this character or prefix

Signature

[[nodiscard]] bool StartsWith(const TChar ch) const noexcept

[[nodiscard]] bool StartsWith(const String& header) const noexcept

Function description

Two spellings of "begins with". The character form compares the first character directly (empty answers false); the string form is ContainsAt(header, 0) — the keyword must fit entirely, so a header longer than the string is false. An empty header answers true, per ContainsAt's empty rule.

Parameters

ParameterTypeRequirement
chconst TChar The character the string must begin with.
headerconst String& The prefix to test; read-only.

Return value

true when the string begins with the given character or prefix.

Examples

No production call site today — the engine's prefix work on paths goes through StringUtil::StartsWith, which operates on HString rather than this class.
