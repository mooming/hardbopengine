operator=

member of hbe::String Engine/String/String.h move swaps; copies never write a shared buffer in place

Signature

String& operator=(String&& rhs) noexcept

String& operator=(const char* text) noexcept

String& operator=(const String& rhs) noexcept

Function description

Three assignment forms with one shared idea: a shared buffer is never written in place. The move form swaps — Swap(std::move(rhs)) — so rhs walks away with this string's old content. Both copy forms check buffer.GetReferenceCount() > 1 first: when others share the buffer, they build a fresh string and swap it in rather than corrupting the sharers' text: 

String& String::operator=(const char* text) noexcept
{
	if (text == nullptr)
	{
		text = "";
	}

	if (buffer.GetReferenceCount() > 1)
	{
		Swap(String(text));
	}
	else
	{
		const auto textLength = strlen(text) + 1;
		buffer->resize(textLength);
		memcpy(buffer->data(), text, textLength);
	}

	return *this;
}

From Engine/String/String.cpp, String::operator=(const char* text) noexcept

When the buffer is uniquely owned, the assignment resizes in place and copies. The const String& form copies the whole buffer including the terminator; the const char* form accepts null as "". Note there is no operator=(const String&&) distinct from the move — a const rvalue binds the copy form and pays the copy.
