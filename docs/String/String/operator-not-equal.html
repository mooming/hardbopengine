operator!=

member of hbe::String Engine/String/String.h the explicit negations of the three equality forms

Signature

bool operator!=(const String& rhs) const noexcept

bool operator!=(const char* rhs) const noexcept

bool operator!=(std::nullptr_t) const noexcept

Function description

The explicit negations of the three operator== forms, declared inline — !(*this == rhs) in each case. They are declared rather than left to C++20's rewrite so the const char* and nullptr_t comparisons need no conversion on the left operand.

Parameters

ParameterTypeRequirement
rhsconst String& / const char* The compared operand; read-only. The pointer form accepts null (null != a non-empty string).

Return value

The negation of the matching operator==.
