ToPointer

member of hbe::String Engine/String/String.h parse as hexadecimal, reinterpret as pointer

Signature

[[nodiscard]] void* ToPointer() const noexcept

Function description

Parses the text as hexadecimal and reinterprets it as a pointer — std::stoull(buffer->data(), 0, 16), then reinterpret_cast<void*>. The base-16 radix is the contract's sharpest edge: String("42").ToPointer() is 0x42, not 42. The round trip pairs with the Pointer constructor, which formats with %p — on platforms where %p prints hex without a 0x prefix the two compose; on any other spelling they do not.

Parameters

None.

Return value

The parsed address as void*; nullptr when no buffer is held. Garbage text terminates, per the family contract on ToInt.

Examples

No production call site today; the intended use is pointer logging round trips with the String(const Pointer) constructor.
