GetLowerCase

member of hbe::String Engine/String/String.h Clone then ToLowerCase

Signature

[[nodiscard]] String GetLowerCase() const noexcept

Function description

String str = Clone(); str.ToLowerCase(); return str; — the building form: a deep copy, lower-cased, receiver untouched. Same ASCII-only folding as ToLowerCase; the pair is the class's most easily confused Get/To duo, and the rule is the first letter — Get builds, To changes.

Parameters

None.

Return value

A new lower-cased String.

Examples

		String str("Hello? World!");

		auto lower = str.GetLowerCase();
		ls << lower.c_str() << lf;
