IsValidIndex

member of hbe::String Engine/String/String.h the range guard the range APIs clamp with

Signature

[[nodiscard]] bool IsValidIndex(Index index) const noexcept

Function description

index >= 0 && index < Length() — the range guard the module's own APIs clamp with. With Index being size_t, the >= 0 half is always true and the test is effectively index < Length(); it is written both ways so the meaning survives a change of index type.

Parameters

ParameterTypeRequirement
indexIndex The candidate index.

Return value

true when index names an existing character.

Examples

	const Index actualEndIndex = !IsValidIndex(endIndex) ? strLength : endIndex;
	const Index actualOffset = !IsValidIndex(offset) ? 0 : offset;
