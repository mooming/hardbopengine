ToChar

member of hbe::String Engine/String/String.h first character, not a parse

Signature

[[nodiscard]] char ToChar() const noexcept

Function description

return buffer ? (*buffer)[0] : '\0'; — the first character, or the terminator when there is no buffer. Note this is not a numeric parse: String("42").ToChar() is '4'. For parsing see ToInt.

Parameters

None.

Return value

The first character; '\0' when the string has no buffer.

Examples

No production call site today; the conversion set exists for config-style parsing paths that read single characters.
