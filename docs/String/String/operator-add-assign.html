operator+=

member of hbe::String Engine/String/String.h AppendSelf through a template — the loop spelling

Signature

template <typename U>
	void operator+=(U str) noexcept

Function description

AppendSelf(str) — the mutating form of appending, templated so one spelling covers every type AppendSelf takes: char, int, float, const char*, and String. Anything else fails to compile inside AppendSelf's overload set rather than converting silently. The Performance test in Engine/String/String.cpp builds strings with exactly this operator in a loop, which is the pattern it exists for.

Parameters

ParameterTypeRequirement
strU (template parameter) One of the five AppendSelf types; the overload resolution happens there.

Return value

None — the receiver is modified.
