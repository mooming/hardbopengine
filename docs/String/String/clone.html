Clone

member of hbe::String Engine/String/String.h a genuine deep copy, even from a shared buffer

Signature

[[nodiscard]] String Clone() const noexcept

Function description

The genuine deep copy — the counterpart to the sharing copy constructor. A fresh String is built and the entire buffer content is assigned into it: 

String String::Clone() const noexcept
{
	String str;
	Assert(str.buffer);

	*(str.buffer) = *buffer;

	return str;
}

From Engine/String/String.cpp, String::Clone() const noexcept

Use it when a caller with a shared buffer needs its own bytes — the case the String(String&) copy constructor does not cover, since sharing is its whole point. Every building method that needs an untouched copy of *this as its base (ReplaceAll's character form, GetLowerCase) starts from here.

Parameters

None.

Return value

A new String with its own copy of the bytes and the same hash.
