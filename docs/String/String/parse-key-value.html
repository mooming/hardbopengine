ParseKeyValue

member of hbe::String Engine/String/String.h split at the first '=', trim both halves

Signature

void ParseKeyValue(String& outKey, String& outValue) noexcept

Function description

Splits this at the first = and hands back the trimmed halves — Config-file line parsing in one call: 

	auto index = Find('=');
	key = SubString(0, index).Trim();
	value = SubString(index + 1).Trim();

From Engine/String/String.cpp, String::ParseKeyValue(String&, String&) noexcept

Edge behaviour is defined by Find and SubString's clamping. No separator: Find answers Length(), so the key is the whole string trimmed and the value is empty. Multiple separators: the key stops at the first = and everything after it — further = signs included — is the value.

Parameters

ParameterTypeRequirement
outKeyString& Receives the text before the first =, trimmed. Overwritten.
outValueString& Receives the text after it, trimmed. Overwritten; empty when there is no separator.

Return value

None — results arrive through the out-parameters.

Examples

No production call site today — Engine/Config/ConfigFile.cpp implements its own split with StringUtil::Trim, which is the pattern this method condenses.
