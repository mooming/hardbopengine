Find

member of hbe::String Engine/String/String.h first occurrence — of a char, a set, or a substring in a range

Signature

[[nodiscard]] Index Find(const TChar ch) const noexcept

[[nodiscard]] Index Find(const Array<TChar>& chs) const noexcept

[[nodiscard]] Index Find(const String& keyword) const noexcept

[[nodiscard]] Index Find(const String& keyword, Index startIndex, Index endIndex = InvalidIndex) const noexcept

Function description

Four searches over one rule: the answer is an index, and "absent" is Length() — never a sentinel, never a negative. Compare against Length(), or use Contains.

Single character — first position equal to ch, scanning from 0. Any of a set — chs is an Array<TChar>; the first position matching any character in it, which is what Head uses for its whitespace set. Substring — the first position where ContainsAt succeeds, scanning every start; an empty keyword is found at 0. Ranged substring — the same, confined to [startIndex, endIndex), with the range clamped before use: 

	Assert(startIndex < length);
	if (startIndex >= length)
	{
		startIndex = length - 1;
	}

	Assert(endIndex >= startIndex);
	if (endIndex < startIndex)
	{
		endIndex = startIndex;
	}

	Assert(endIndex <= length);
	if (endIndex > length)
	{
		endIndex = length;
	}

From Engine/String/String.cpp, String::Find(const String& keyword, Index startIndex, Index endIndex) const noexcept — the clamp block

The asserts fire before the clamps. A startIndex at or past the length is a debug-build Assert failure even though the release behaviour is defined (clamped to length - 1); a caller passing out-of-range values is relying on undocumented tolerance.

Return value

The first matching index, or Length() when nothing matches within the range.
