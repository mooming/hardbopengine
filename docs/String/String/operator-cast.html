Module Index / String / String / operator const char*

operator const char*

member of hbe::String Engine/String/String.h forwards to ToCharArray; the const-copy path

Signature

[[nodiscard]] operator const char*() const noexcept

Function description

Forwards to ToCharArray — the buffer's characters, or "". This conversion is also the hidden path in the class's copy semantics: a const String cannot reach the copy constructor (String(String&)), so a copy-initialisation from a const source selects String(const char*) through this conversion — a deep copy where a non-const source would have shared the buffer. Verified by compile probe and by running it; the details are on the constructors page.

Parameters

None.

Return value

The buffer's zero-terminated characters; valid until the string is mutated or destroyed.

Examples

The logging stream is the everyday consumer — ls << str in the test collection reads the characters through a builder overload that takes the text, and call sites passing a String where a const char* is declared rely on this conversion.
