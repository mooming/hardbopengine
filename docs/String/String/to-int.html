ToInt

member of hbe::String Engine/String/String.h std::stoi — garbage input terminates

Signature

[[nodiscard]] int ToInt() const noexcept

Function description

return buffer ? std::stoi(buffer->data()) : 0; — a real numeric parse via the standard library, not a character read. Two consequences worth their weight:

Garbage input terminates the process. std::stoi throws std::invalid_argument on text that is not a number and std::out_of_range on overflow — and this function is noexcept, so the exception escapes the function and std::terminate ends the program. An empty buffer (one terminator, as a default-constructed String has) is garbage by this rule. Validate before converting; there is no error-returning variant.

The buffer test guards only the absence of a buffer, not emptiness — a held-but-empty buffer still reaches std::stoi.

Parameters

None.

Return value

The parsed int; 0 only when no buffer is held. Throws-through-noexcept otherwise on bad input.

Examples

The whole numeric family (ToLong, ToFloat, …) shares this contract; this page carries the warning they all inherit.
