CalculateHashCode

member of hbe::String Engine/String/String.h private — recompute the cached hash

Signature

void CalculateHashCode() noexcept

Function description

Private. Recomputes the cached hash — djb2 from 5381, hash * 33 + byte over the characters, the same algorithm StringUtil::CalculateHash runs. Every mutating method that changes content calls it before returning; a raw write through GetBuffer cannot, which is exactly the exposure that page describes. No public caller exists: the invariant "hash is current" is the class's, not yours to refresh.

Parameters

None.

Return value

None — the private hashCode member is updated.

Examples

Documented for completeness; being private, it is called only by the class's own mutating methods and constructors.
