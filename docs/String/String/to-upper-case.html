ToUpperCase

member of hbe::String Engine/String/String.h in place, ASCII-only, hash recomputed

Signature

void ToUpperCase() noexcept

Function description

Upper-cases this string in place: every character Letter::IsLowerCase accepts (ASCII 'a'–'z') is shifted by 'A' - 'a', then the hash is recomputed. The mirror of ToLowerCase, with the same raw-edit-then-rehash pattern through GetBuffer.

Parameters

None.

Return value

None — the receiver is modified.

Examples

		auto upper = str.GetUpperCase();

		if (upper != "HELLO? WORLD!")
		{
			ls << "To uppercase failed. " << upper << lferr;
		}
