Swap

member of hbe::String Engine/String/String.h exchange state; the rvalue ref demands std::move

Signature

void Swap(String&& target) noexcept

Function description

Exchanges the entire state — hash code and shareable buffer — with target: 

	Index tmpHashCode = hashCode;
	hashCode = target.hashCode;
	target.hashCode = tmpHashCode;

	buffer.Swap(target.buffer);

From Engine/String/String.h, String::Swap(String&&) noexcept

The parameter is an rvalue reference, not a plain reference — the call site must spell std::move, which is the type system saying "your operand is consumed". This is the move assignment's engine: operator=(String&&) is one call to it, and the copy-on-write branches of the copy assignments swap fresh strings in with it too.

Parameters

ParameterTypeRequirement
targetString&& The string to exchange with; pass std::move(s). Its old content becomes this string's.

Return value

None.
