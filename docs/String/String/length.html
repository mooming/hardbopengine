Length

member of hbe::String Engine/String/String.h characters excluding the terminator

Signature

[[nodiscard]] Index Length() const noexcept

Function description

Characters excluding the terminator — the buffer stores the terminator as part of its contents, so the length is one less than its size: 

	[[nodiscard]] Index Length() const noexcept
	{
		return static_cast<bool>(buffer) && buffer->size() > 0 ? buffer->size() - 1 : 0;
	}

From Engine/String/String.h, String::Length() const noexcept

Every search's "not found" answer is this number, not a sentinel — the idiom Find(x) < Length() (see Contains) is built on that. An empty String has length 0 and a buffer of one terminator.

Parameters

None.

Return value

The character count as Index (size_t).

Examples

	String str("Hello? World!");
	auto lastL = str.FindLast('l');
	auto afterL = str.SubString(lastL);
