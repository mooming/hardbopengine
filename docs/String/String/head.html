Head

member of hbe::String Engine/String/String.h the first word

Signature

[[nodiscard]] String Head() const noexcept

Function description

The first word: everything before the first whitespace, where whitespace is the four-character set {' ', '\t', '\n', '\r'} searched with the any-of Find overload. A string with no whitespace returns a Clone of the whole thing — the head of one word is the word: 

	[[nodiscard]] String Head() const noexcept
	{
		Index index = Find(Array<TChar>({' ', '\t', '\n', '\r'}));
		if (index < Length())
		{
			return SubString(0, index);
		}

		return Clone();
	}

Parameters

None.

Return value

A new String up to (not including) the first whitespace; a clone when there is none.
