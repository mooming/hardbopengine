Module Index / String / String / operator<

operator<

member of hbe::String Engine/String/String.h lexicographic by byte; a prefix sorts before its extension

Signature

bool operator<(const String& rhs) const noexcept

Function description

Lexicographic by byte, hand-rolled rather than delegated: compare characters up to the shorter length, first difference decides; if one is a prefix of the other, the shorter sorts first: 

	const Index shorterLen = std::min(Length(), rhs.Length());
	Index matchCount = 0;

	for (Index i = 0; i < shorterLen; ++i)
	{
		if ((*buffer)[i] == (*rhs.buffer)[i])
		{
			++matchCount;

			continue;
		}

		if ((*buffer)[i] > (*rhs.buffer)[i])
		{
			return false;
		}

		return true;
	}

	if (matchCount == shorterLen)
	{
		return Length() < rhs.Length();
	}

	return true;

From Engine/String/String.cpp, String::operator<(const String&) const noexcept

The comparison is on raw bytes — char may be signed, so bytes above 0x7F compare as negative values; the ordering is consistent within a build but is not Unicode collation by any reading. The other three relational operators are defined from this one, so their pages are one line each.

Examples

No call site in the engine sorts Strings today — the interned identifiers sort through StaticString::operator< instead. This operator exists so String satisfies ordered-container requirements.
