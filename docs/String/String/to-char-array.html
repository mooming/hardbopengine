ToCharArray

member of hbe::String Engine/String/String.h the characters, or the empty literal

Signature

[[nodiscard]] const char* ToCharArray() const noexcept

Function description

return buffer ? buffer.Get().data() : ""; — the buffer's zero-terminated characters, or the literal empty string when the shareable buffer is not held. This is the canonical accessor: c_str and operator const char* both forward to it, and it is the path a const-source copy travels (see constructors).

Parameters

None.

Return value

Zero-terminated characters, valid until the string is mutated (growth moves bytes) or destroyed; never null.

Examples

	ls << str.c_str() << lf;
