SubString

member of hbe::String Engine/String/String.h range-clamped slice; empty range gives an empty string

Signature

[[nodiscard]] String SubString(Index startIndex, Index endIndex = InvalidIndex) const noexcept

Function description

return String{*this, startIndex, endIndex}; — the slice is built by the substring constructor, whose clamping is the contract: startIndex at or past the length clamps to the length, endIndex past the length clamps to the length, startIndex above endIndex falls to endIndex, and an empty range produces an empty string — a buffer with no characters, not one terminator. The default endIndex (InvalidIndex) means "to the end", so SubString(i) is the suffix from i. 

	String str("Hello? World!");
	auto lastL = str.FindLast('l');
	auto afterL = str.SubString(lastL);

	if (afterL != "ld!")
	{
		ls << "Substring failed: " << afterL << lferr;
	}

Return value
