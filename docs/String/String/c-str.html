c_str

member of hbe::String Engine/String/String.h the characters, valid until the next mutation

Signature

[[nodiscard]] const char* c_str() const noexcept

Function description

return ToCharArray(); — the same pointer ToCharArray returns: the buffer's zero-terminated characters, or "" when the shareable buffer is not held. Valid until the string is mutated (growth can move the bytes) or destroyed.

Parameters

None.

Return value

The characters as const char*; never null.

Examples

	String str("Hello? World!");
	ls << str.c_str() << lf;
