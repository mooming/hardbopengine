ResetBuffer

member of hbe::String Engine/String/String.h reserve size+1, then empty with one terminator

Signature

void ResetBuffer(size_t size) noexcept

Function description

Reserve size + 1, clear, and write a single terminator — an empty string with size characters of headroom. The +1 is the terminator's seat. Content is discarded; capacity is kept above the requested size. The hash is not recomputed here — the buffer now holds one terminator, whose correct hash is the empty hash, and no mutating-method call follows — so a caller that resets and then compares should be aware the cached value predates the reset.

Parameters

ParameterTypeRequirement
sizesize_t Character capacity to guarantee, terminator excluded.

Return value

None.

Examples

No production call site today — the assignment operators resize in place, which covers the reuse case without a separate reset.
