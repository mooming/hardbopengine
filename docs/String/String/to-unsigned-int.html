ToUnsignedInt

member of hbe::String Engine/String/String.h std::stoul, narrowed

Signature

[[nodiscard]] unsigned int ToUnsignedInt() const noexcept

Function description

std::stoul on the buffer, narrowed to unsigned int. The parse contract — including the throw-on-garbage behaviour that noexcept turns into termination — is ToInt's; this page only adds the narrowing: a value above the unsigned int range is truncated by the cast, not detected.

Parameters

None.

Return value

The parsed value as unsigned int; 0 when no buffer is held.

Examples

No production call site today — config parsing uses ConfigSystem's own typed getters.
