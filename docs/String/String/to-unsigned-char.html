ToUnsignedChar

member of hbe::String Engine/String/String.h first byte through unsigned char, narrowed back

Signature

[[nodiscard]] char ToUnsignedChar() const noexcept

Function description

return buffer ? static_cast<unsigned char>((*buffer)[0]) : 0; — the first character routed through unsigned char, and then narrowed back to char by the return type. The round trip preserves the byte value; the spelling is the odd part, and a caller wanting the unsigned value should cast the result itself.

Parameters

None.

Return value

The first character's byte value as char; 0 when there is no buffer.

Examples

No production call site today; see ToChar for the signed spelling of the same access.
