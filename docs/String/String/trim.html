Trim

member of hbe::String Engine/String/String.h whitespace off both ends via IsGenuineLetter

Signature

[[nodiscard]] String Trim() const noexcept

Function description

Whitespace off both ends, in one scan: the first and last character for which Letter::IsGenuineLetter holds — the predicate that is true for everything except the four whitespace characters — bound the kept range, and the answer is a SubString of it: 

	[[nodiscard]] String Trim() const noexcept
	{
		Index startIndex = InvalidIndex;
		Index endIndex = InvalidIndex;

		const auto length = Length();
		for (Index i = 0; i < length; ++i)
		{
			if (Letter::IsGenuineLetter((*buffer)[i]))
			{
				if (startIndex >= length)
				{
					startIndex = i;
				}

				endIndex = i;
			}
		}

		if (startIndex >= length)
		{
			return {};
		}

		return SubString(startIndex, endIndex + 1);
	}

From Engine/String/String.h, String::Trim() const noexcept

An all-whitespace or empty string returns a default-constructed String. Note the class's Trim and StringUtil::Trim agree on which characters are whitespace only because IsGenuineLetter tests the same four characters the default separator set does — space, tab, newline, carriage return.

Parameters

None.

Return value

A new String without leading or trailing whitespace; empty when there is no content.
