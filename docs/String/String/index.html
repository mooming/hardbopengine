String

Engine/String/String.h namespace hbe shareable-buffer string with a cached hash — Get builds, To changes

Class description

The engine's text type: a shareable, ref-counted character buffer plus a cached hash code. Copying is cheap by design — the buffer is a Shareable<Vector<TChar>>, so sharing increments a count rather than copying bytes — and the hash is computed once per mutation, so comparisons short-circuit on it before reading a single character.

Naming carries the contract. A method that builds returns a new String and leaves the receiver alone: Clone, SubString, Append, Replace, ReplaceAll, Trim, Head, ExceptHead, GetLowerCase, GetUpperCase. A method that changes this string returns nothing: ToLowerCase, ToUpperCase, AppendSelf, Swap, ResetBuffer. The one letter — Get builds, To changes — is the rule to remember, because both spellings compile for the lower-case pair.

Copying a const String is not the copy constructor. The copy constructor takes String& — a non-const lvalue — and shares the buffer. Given a const source, that constructor is not viable, and the conversion operator const char* routes the call into String(const char*): a fresh, deep copy (verified against the engine's own headers and libraries). The result is correct but allocated; the sharing copy requires a non-const source.
Writes through GetBuffer bypass the cached hash. The hash is recomputed only by the mutating methods; a caller that edits the buffer through the raw pointer leaves hashCode stale, and operator== — which compares hashes first — can then report two equal strings unequal.

Template parameters

None — String is not a template. The character type is the alias TChar (char), and the buffer element type is Vector<TChar>.
