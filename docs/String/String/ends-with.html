EndsWith

member of hbe::String Engine/String/String.h ends with this character or suffix

Signature

[[nodiscard]] bool EndsWith(const TChar ch) const noexcept

[[nodiscard]] bool EndsWith(const String& tail) const noexcept

Function description

Two spellings of "ends with". The character form compares the last character (empty answers false). The string form guards the length, then tests ContainsAt(tail, Length() - tail.Length()) — the tail must fit, and a tail longer than the string is false: 

	[[nodiscard]] bool EndsWith(const String& tail) const noexcept
	{
		if (Length() < tail.Length())
			return false;

		return ContainsAt(tail, Length() - tail.Length());
	}
