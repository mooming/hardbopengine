ReplaceAll

member of hbe::String Engine/String/String.h every occurrence, character or substring form

Signature

[[nodiscard]] String ReplaceAll(char from, char to) const noexcept

[[nodiscard]] String ReplaceAll(String from, String to) const noexcept

Function description

Every occurrence, two ways. The character form clones and maps bytes in place — no search, no reallocation, and no terminator games. The string form scans and builds the result as it goes, appending either the replacement or the original character; adjacent and overlapping matches are consumed left to right, so "aabbcc" with "ab" → "X" gives "aXbcc": 

	while (i <= lastIndex)
	{
		bool match = true;

		{

		if (match)
		{
			for (Index j = 0; j < toLength; ++j)
			{
				result.buffer->push_back(to.buffer->data()[j]);
			}

			i += searchLength;
		}
		else
		{
			result.buffer->push_back((*buffer)[i]);
			++i;
		}
	}

The string form takes its operands by value and guards what Replace does not: an empty from returns a clone, and a from longer than the string returns a clone before the scan starts. Not found also returns a clone. Both forms recompute the result's hash before returning.

Parameters

ParameterTypeRequirement
fromchar / String The text to replace; empty (string form) returns a clone.
tochar / String The replacement; any length, including empty.

Return value

A new String with every occurrence replaced, or a clone when there was nothing to do.
