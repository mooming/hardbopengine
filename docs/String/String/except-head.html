ExceptHead

member of hbe::String Engine/String/String.h everything from the first whitespace on

Signature

[[nodiscard]] String ExceptHead() const noexcept

Function description

Everything from the first whitespace onward — the complement of Head, including the whitespace character itself: 

	[[nodiscard]] String ExceptHead() const noexcept
	{
		Index index = Find(Array<TChar>({' ', '\t', '\n', '\r'}));
		if (index < Length())
		{
			return SubString(index);
		}

		return {};
	}

From Engine/String/String.h, String::ExceptHead() const noexcept

Note the asymmetry with Head: no whitespace returns an empty string here, not a clone — there is nothing after the head, by definition, when there is no head boundary.

Parameters

None.

Return value

A new String starting at the first whitespace; empty when the string has none.
