Function description

Four families. The default constructor starts with a single terminator — buffer->push_back('\0') — so an empty String is a buffer of one character and Length() is 0.

The share-and-move pair. String(String& rhs) is the copy constructor, and it takes a non-const lvalue: it shares rhs's buffer (the refcount rises) and copies the hash — no bytes move. String(String&& rhs) moves the buffer and copies the hash, leaving rhs with a zeroed hash.

A const source cannot reach the copy constructor. The probe removes operator const char* from a copy of the header; without the conversion, the compile fails: 
error: no matching constructor for initialization of 'hbe::String'
note: candidate constructor not viable: 1st argument ('const hbe::String') would lose const qualifier
   34 |         String(String& rhs) noexcept

From a compile probe against the engine headers (c++ -std=c++2b -fsyntax-only), const-source copy-initialisation with the conversion operator removed

With the conversion in place the same call compiles and selects String(const char*) through it — a deep copy, confirmed by running it (the copy reads back identical text). The substring constructor below needs at least two arguments — startIndex has no default — so it is not a candidate for a one-argument call either way.

The numeric set — fifteen explicit constructors from bool, Pointer, the character types and every arithmetic type — format through snprintf into a freshly sized buffer and hash the result. The spellings: bool writes true/false in full, Pointer uses %p, unsigned char uses 0x%02X (hexadecimal, unlike every other integer), the signed and unsigned integers use %d/%u with the l/ll modifiers, and the floating types use %f — %Lf for long double.

The text constructors. String(const char* text) accepts null (becomes "") and copies strlen + 1 bytes. String(const std::string str) takes the string by value — the copy is the price of the convenience — and delegates to its c_str(). The substring constructor builds from a range of another string with clamping: startIndex at or past the source length and an endIndex past it both clamp to the length, startIndex above endIndex falls back to endIndex, and an empty range produces an empty buffer with hash 0 — the one shape for which operator==(std::nullptr_t) answers true.
