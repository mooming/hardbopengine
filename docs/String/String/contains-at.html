ContainsAt

member of hbe::String Engine/String/String.h does the keyword sit exactly here

Signature

[[nodiscard]] bool ContainsAt(const String& keyword, Index startIndex) const noexcept

Function description

The search primitive: does keyword sit exactly at startIndex. The end is computed as startIndex + keyword.Length(); if that runs past this string's length the answer is false, otherwise the bytes are compared one by one. An empty keyword is contained everywhere — the loop body never runs and the function answers true. 

	const Index endIndex = startIndex + keyword.Length();

	if (endIndex > Length())
	{
		return false;
	}

	Index index = 0;

	for (Index i = startIndex; i < endIndex; ++i, ++index)
	{
		if ((*buffer)[i] != (*keyword.buffer)[index])
		{
			return false;
		}
	}

	return true;
