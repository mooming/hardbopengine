Module Index / String / StaticString / c_str

c_str

member of hbe::StaticString Engine/String/StaticString.h the interned characters; a null id reads as None

Signature

[[nodiscard]] const char* c_str() const noexcept

Function description

Reads the characters back from the table: StaticStringTable::Get(id), which for a null id answers the literal "None" and otherwise reinterprets the id pointer as const char*. The returned pointer is stable for the life of the process — interning never moves or frees a registered string until the table's destructor runs — so a caller may hold it across calls, which is exactly what log categories and task names rely on.

Parameters

None.

Return value

The interned zero-terminated characters; never nullptr. Pointing into the intern table — do not write through it, and do not expect the bytes to be freed with the wrapper.

Examples

The logger takes the characters directly — Engine/Log/Logger.cpp builds categories from StaticString and prints them through this pointer; the test collection prints with it too: 

	StaticString str("Hello?");
	ls << str.c_str() << lf;
