operator<<

member of hbe::StaticString Engine/String/StaticString.h ostream sink through c_str

Signature

friend std::ostream& operator<<(std::ostream& os, const StaticString& str) noexcept

Function description

An in-class friend so the operator is found by ADL: writes str.c_str() to the stream and returns it. This is the std::ostream sink — debug printing and the test collections — not the engine's builder path, which has its own operator<< overloads taking a StaticString by value.

Parameters

ParameterTypeRequirement
osstd::ostream& The stream to write to; returned for chaining.
strconst StaticString& The wrapper whose characters are written; null ids print as None.

Return value

The stream os, so << chains left to right as usual.

Examples

		StaticString str(hello);
		ls << str << lf;
		ls << str.c_str() << lf;
