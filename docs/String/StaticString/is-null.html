IsNull

member of hbe::StaticString Engine/String/StaticString.h true only for a wrapper built from the null id

Signature

[[nodiscard]] bool IsNull() const noexcept

Function description

id.ptr == nullptr — true exactly when the wrapper was built from the null id (StaticStringID's default). Note the asymmetry with construction: a default-constructed StaticString is not null, because its constructor interns "None" and adopts that id. Only the StaticStringID constructor can produce a null wrapper, since it is the one that stores the id verbatim.

Parameters

None.

Return value

true when the id is Default (nullptr); false otherwise.

Examples

The complement is worth naming: c_str() never returns nullptr even for a null wrapper — it answers "None" — so a caller that needs to distinguish "no string" from "the string None" must call this, not compare characters.
