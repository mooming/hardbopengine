operator==

member of hbe::StaticString Engine/String/StaticString.h pointer equality — the point of the type

Signature

[[nodiscard]] bool operator==(const StaticString& rhs) const noexcept

Function description

id.ptr == rhs.id.ptr — the pointer comparison the whole type exists for. Two wrappers are equal when both texts were interned, because the table hands out one address per distinct text; the characters are never read. Inequality is reachable through C++20's rewritten candidates from this operator — the header declares no operator!=, and the test collection's str != strInline relies on the rewrite. 

	AddTest("Two Strings Comparison", [this](auto& ls)

		StaticString strB("Hello?");

		}
	});
