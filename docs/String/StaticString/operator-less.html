Module Index / String / StaticString / operator<

operator<

member of hbe::StaticString Engine/String/StaticString.h table-address ordering, not alphabetical

Signature

[[nodiscard]] bool operator<(const StaticString& rhs) const noexcept

Function description

id.ptr < rhs.id.ptr — the same table-address ordering as StaticStringID::operator<, forwarded through the ids. Deterministic for a given run and allocation history; unrelated to the characters. An ordered container of StaticString iterates in intern order, which is stable within a run but not across runs.

This is not alphabetical order. For display or lexicographic needs, compare the characters — e.g. through StringUtil::EqualsIgnoreCase for case-insensitive text comparison — never the wrappers.

Parameters

ParameterTypeRequirement
rhsconst StaticString& Another wrapper. Its text is never read — only its id pointer.

Return value

true when this id's table address sorts before rhs's.

Examples

The test collection exercises only equality; ordering exists so the type satisfies the requirements of ordered containers. No call site in the repository relies on the ordering today.
