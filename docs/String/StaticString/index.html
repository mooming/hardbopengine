StaticString

Engine/String/StaticString.h namespace hbe final interned string — construction interns, comparison is one pointer test

Class description

A string interned into one global table, so its identity is a pointer. Two StaticString values naming the same text compare with one pointer equality, which is why log categories, task names and component keys are this type rather than String. Interning costs a table lookup at construction and pays it back on every comparison afterwards.

Construction is the only moment the table is touched: every constructor from characters routes through StaticStringTable::Register, and everything after — copying, comparing, hashing, printing — moves or reads one StaticStringID. The default constructor interns "None" once, through a function-local static, so a default-constructed StaticString prints as None and is equal to every other default-constructed one. 

static StaticString null("None");
id = null.id;

From Engine/String/StaticString.cpp, the default constructor — the file defines four constructors and this one alone takes no parameters, so the caption cannot carry a parameter list for the quotation checker

Comparison is identity, not content. Two separately built buffers naming the same text are equal after both have gone through interning — which a value reaching you as raw characters from a file has not. Convert first, compare second.

Template parameters

None — the class is not a template. The one constructor template accepts any type with a c_str() member, guarded by the CToZeroTerminateStr concept.

Non-member helpers

std::hash<hbe::StaticString> is specialised in this header as the reinterpreted id pointer, so a StaticString works as an unordered key directly.
