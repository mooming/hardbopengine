GetID

member of hbe::StaticString Engine/String/StaticString.h the identity by value

Signature

[[nodiscard]] auto GetID() const noexcept

Function description

Returns the interned identity by value — a copy of the one member. This is the escape hatch from the wrapper to the bare pointer type: an id keys a map, sits in a struct, or compares against StaticStringID::Default without dragging the wrapper along. No table access; the id is meaningful whether or not this wrapper's text was ever interned.

Parameters

None.

Return value

A StaticStringID by value. decltype is left to the compiler through auto; the type is fixed by the member it copies.

Examples

The std::hash specialisation in Engine/String/StaticString.h hashes exactly this value — obj.GetID().ptr reinterpreted — so an unordered container of StaticString is an unordered container of ids in disguise.
