Destructor

member of hbe::StaticString Engine/String/StaticString.h defaulted — the id is a pointer, nothing is freed

Signature

~StaticString() = default

Function description

Defaulted, and that is the contract: a StaticString owns one pointer, destroys nothing, and never touches the intern table. The bytes behind the id live in the table's banks until the table itself is destroyed, so copying and destroying wrappers is free and interning is never undone — there is no unregister.

Parameters

None.

Return value

None — a destructor.

Examples

Consequence worth knowing rather than a call to make: StaticString objects held in static storage outliving StaticStringTable's destruction would read freed bytes — the table is a singleton destroyed at process exit, and its destructor releases the banks. Ordinary engine lifetime never hits this; see StaticStringTable's destructor page for the exact claim.
