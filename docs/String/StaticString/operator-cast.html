Module Index / String / StaticString / operator const char*

operator const char*

member of hbe::StaticString Engine/String/StaticString.h implicit conversion to the characters

Signature

[[nodiscard]] operator const char*() const noexcept

Function description

Forwards to c_str — the same pointer, the same "None" answer for a null id. The conversion is what lets a StaticString flow into APIs that take a C string, and it is also the trap in String's constructor set: a const String copy-initialised from another String selects String(const char*) through this kind of conversion, so conversions of string types are worth a second look at every call site.

Parameters

None.

Return value

The interned characters as const char* — stable for the life of the process, never nullptr.

Examples

Engine/String/StaticString.cpp's test collection streams a StaticString into the logger through operator<<, but ordinary engine code passes the object where a const char* parameter is declared and lets this conversion fire.
