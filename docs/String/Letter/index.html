Letter

Engine/String/Letter.h namespace hbe three static character predicates — and one whose name says letter while the code tests whitespace

Class description

Letter is a namespace-shaped utility: three static predicates over a single char, with no state and no instance. Two of them classify ASCII case, and one classifies whitespace by its absence — IsNotWhiteSpace is true for every character that is not a space, tab, newline or carriage return.

Template parameters

None — the class is not a template.

Class methods

IsLowerCase static bool IsLowerCase(TChar letter) True exactly for 'a' through 'z'; everything else, including digits and upper case, is false.
IsUpperCase static bool IsUpperCase(TChar letter) True exactly for 'A' through 'Z'; everything else is false.
IsNotWhiteSpace static bool IsNotWhiteSpace(TChar letter) True for every character that is not whitespace — letters, digits and punctuation all pass.

Coverage
