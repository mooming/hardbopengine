IsGenuineLetter

member of hbe::Letter Engine/String/Letter.h despite the name: true for everything that is not whitespace

Signature

[[nodiscard]] static bool IsGenuineLetter(TChar letter)

Function description

Despite the name, this is a whitespace test in reverse: returnValueIf(false, letter == ' ' || letter == '\t' || letter == '\n' || letter == '\r') returns false for the four whitespace characters and true for everything else. A caller reading the name as "is this a letter" gets the wrong answer for every letter of the alphabet only in the sense that letters pass — but so do digits, punctuation and every non-ASCII byte, so the predicate distinguishes whitespace from non-whitespace, not letters from non-letters.

The name does not match the behaviour. The class page carries this note too, because a reader who arrives from a call site needs it before anything else. The four whitespace characters tested are space, horizontal tab, newline and carriage return — vertical tab and form feed are true here.

Parameters

ParameterTypeRequirement
letterTChar (char) The character to classify. Any byte value is accepted.

Return value

true for every character except ' ', '\t', '\n' and '\r'; false for those four.

Examples

The natural caller is tokenising: ForEachToken in StringUtil splits on exactly these four separators, so this predicate and that function's default separator set agree character for character.
