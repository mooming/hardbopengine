Module Index / String / Letter / IsUpperCase

IsUpperCase

member of hbe::Letter Engine/String/Letter.h true exactly for 'A' through 'Z'

Signature

[[nodiscard]] static bool IsUpperCase(TChar letter)

Function description

The mirror of IsLowerCase: true exactly for the closed range 'A'–'Z', the twenty-six upper-case ASCII letters. Digits, lower-case letters, punctuation and every non-ASCII byte are false.

Parameters

ParameterTypeRequirement
letterTChar (char) The character to classify. Compared numerically against ASCII bounds; any byte value is accepted.

Return value

true exactly when letter is in ['A', 'Z']; false otherwise.

Examples

Together with IsLowerCase this partitions the ASCII letters; a character that passes neither is a digit, punctuation, whitespace or a non-ASCII byte.
