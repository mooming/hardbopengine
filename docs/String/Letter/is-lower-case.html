Module Index / String / Letter / IsLowerCase

IsLowerCase

member of hbe::Letter Engine/String/Letter.h true exactly for 'a' through 'z'

Signature

[[nodiscard]] static bool IsLowerCase(TChar letter)

Function description

Two range comparisons: returnValueIf(false, letter < 'a') and returnValueIf(false, letter > 'z'), then true. The macro reads as "return false if the condition holds", so the answer is true exactly for the closed range 'a'–'z' — the twenty-six lower-case ASCII letters and nothing else. Digits, upper-case letters, punctuation and every non-ASCII byte are false.

Parameters

ParameterTypeRequirement
letterTChar (char) The character to classify. Compared numerically against ASCII bounds; any byte value is accepted.

Return value

true exactly when letter is in ['a', 'z']; false otherwise.

Examples

The paired test is IsUpperCase; a caller that wants "a letter of either case" writes the disjunction of the two — there is no combined predicate, and IsGenuineLetter does not mean this despite its name.
