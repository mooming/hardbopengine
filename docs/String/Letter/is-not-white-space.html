IsNotWhiteSpace

member of hbe::Letter Engine/String/Letter.h true for every character that is not whitespace — letters, digits and punctuation alike

Signature

[[nodiscard]] static bool IsNotWhiteSpace(TChar letter)

Function description

True when the character is not whitespace: returnValueIf(false, letter == ' ' || letter == '\t' || letter == '\n' || letter == '\r') returns false for the four whitespace characters and true for everything else. The predicate distinguishes whitespace from non-whitespace — letters, digits, punctuation and every non-ASCII byte pass alike; it does not distinguish letters from non-letters.

Named IsGenuineLetter until 2026-10-25. The old name promised a letter test while the code tested whitespace, and the one caller — String::Trim — needed the whitespace meaning, so the name was the defect and the behaviour was the contract. The rename is the fix; the four characters tested are unchanged: space, horizontal tab, newline and carriage return — vertical tab and form feed are true here.

Parameters

ParameterTypeRequirement
letterTChar (char) The character to classify. Any byte value is accepted.

Return value

true for every character except ' ', '\t', '\n' and '\r'; false for those four.

Examples

The natural caller is tokenising: ForEachToken in StringUtil splits on exactly these four separators, so this predicate and that function's default separator set agree character for character.
