operator==

member of hbe::StaticStringID Engine/String/StaticStringID.h one pointer comparison — the interned identity

Signature

[[nodiscard]] bool operator==(const StaticStringID& rhs) const

Function description

ptr == rhs.ptr — one pointer comparison. Because a pointer is minted once per distinct text by the intern table, equality here is equality of the interned string, however each operand obtained its id. This is the comparison StaticString::operator== forwards to.

Parameters

ParameterTypeRequirement
rhsconst StaticStringID& Another id. Its text is never read — only the address matters.

Return value

true when both ids name the same address in the intern table; false otherwise.

Examples

Config keys compare their ids — Engine/Config/ConfigSystem.cpp builds StaticString keys whose operator== reduces to this test, so two lookups of the same key cost one pointer comparison each.
