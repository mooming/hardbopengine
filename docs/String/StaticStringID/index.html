StaticStringID

Engine/String/StaticStringID.h namespace hbe final the interned pointer on its own — identity by address

Class description

StaticStringID is the interned pointer on its own: a struct final whose entire state is one const uint8_t* naming where a string's bytes live inside the global intern table. The pointer is the identity — two ids are equal exactly when they name the same address, which is what makes StaticString comparison a single pointer test. A caller that wants the identity without the string wrapper — a hash key, a value in a lookup table — uses this type directly.

An id is constructed from nothing but nothing. The only constructor default-constructs to Default (nullptr); ids pointing at real text are minted by StaticStringTable::Register and read back through StaticStringTable::Get, which answers "None" for the null id.

None — the struct is not a template.

Non-member helpers

std::hash<hbe::StaticStringID> is specialised in this header as the reinterpreted pointer, so an id works as an unordered key. The specialisation lives in namespace std, which is why this header has to be included for the hash to exist at all.

Coverage

This page documents the struct completely: both properties, the constructor and both comparison operators, and the hash specialisation above. The lifetime of the bytes behind a non-null pointer is owned by StaticStringTable, whose pages carry that contract.
