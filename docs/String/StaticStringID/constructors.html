member of hbe::StaticStringID Engine/String/StaticStringID.h default-construct to the null entry

Signature

StaticStringID()
		: ptr(Default)

Function description

Default-constructs to the null entry: ptr is initialised with Default, which is nullptr. No text is read, no table is touched, and there is deliberately no constructor from characters — an id that names real text is minted only by interning, in StaticStringTable::Register. Every other way of obtaining an id copies one that already exists.

Parameters

None.

Return value

None — a constructor.

Examples

StaticStringTable::PrintStringTable builds a default-constructed id per element to print; the null default is also the value behind a default-constructed StaticString, which interns "None" instead of staying null.
