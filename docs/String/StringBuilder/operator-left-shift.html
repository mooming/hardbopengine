Function description

Every overload appends to the buffer and returns *this; the buffer is a std::basic_string, so append is growth, never truncation — the contract difference from InlineStringBuilder in one sentence. The twenty-one overloads fall into three families.

Direct appends. char push_backs; const char*, std::string_view and the std::basic_string overload (which casts to a view and re-dispatches) append; StaticString appends its c_str(). A null const char* appends the literal Null instead of crashing.

Spellings. nullptr_t writes Null, bool writes True or False, and EndLine appends "\n" — the same spellings the intern table pre-registers.

Numbers through a stack temp. Every numeric overload formats into a fixed stack buffer with snprintf and appends the result: InlineBufferSize (32) for unsigned char and the integers plus void* (%u, %d, %ld, %lu, %lld, %llu, %p), InlineFloatBufferSize (64) for float (%f), InlineLongDoubleBufferSize (512) for double (%lf) and long double (%Le). A value whose digits exceed the temp is truncated by the temp, then the truncated text is appended — the growth of the big buffer never rescues a formatted value that did not fit its temp.
