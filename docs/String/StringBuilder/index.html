StringBuilder

Engine/String/StringBuilder.h namespace hbe template <class TCh = char, class TAlloc = DefaultAllocator<TCh>> final stream-style formatting into a growing engine-allocated buffer

Class description

Stream-style formatting into a growing buffer: builder << "score " << score << hendl;. Each << appends to one std::basic_string specialised on the engine's allocator, so a multi-part line is one allocation strategy rather than one string per piece. This is the allocating sibling of InlineStringBuilder — same interface, same overload set, but the buffer grows instead of clamping, and the price is that growth goes through the allocator.

The class template is explicitly instantiated for StringBuilder<char, DefaultAllocator<char>> in Engine/String/StringBuilder.cpp — the only instantiation the binary carries, so callers using the defaults pay no template bloat and callers wanting another character type or allocator instantiate their own.
