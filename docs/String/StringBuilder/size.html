Size

member of hbe::StringBuilder Engine/String/StringBuilder.h the content length

Signature

[[nodiscard]] auto Size() const noexcept

Function description

buffer.size() — characters written, terminator excluded. Unlike InlineStringBuilder::Size, growth means this number carries no truncation information; it is simply the content length.

Parameters

None.

Return value

The content length as size_t; 0 for a fresh or cleared builder.

Examples

No production call site reads Size() today — callers consume the text through c_str instead.
