Clear

member of hbe::StringBuilder Engine/String/StringBuilder.h empty in place, capacity kept

Signature

void Clear() noexcept

Function description

buffer.clear() — the content is gone, the capacity stays. A builder reused across iterations keeps its grown allocation and pays no further reallocation; that is the difference from destroying and re-constructing, which releases and re-grows through the allocator every time.

Parameters

None.

Return value

None.

Examples

No production call site clears a StringBuilder today — the allocation-heavy users build one string and log it. The reuse pattern is the same one InlineStringBuilder::Clear demonstrates.
