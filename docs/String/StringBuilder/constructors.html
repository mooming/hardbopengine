member of hbe::StringBuilder Engine/String/StringBuilder.h defaulted — empty, nothing allocated yet

Signature

StringBuilder() = default

Function description

Defaulted: an empty builder whose buffer has allocated nothing yet. The first append pays the first allocation; a caller that knows the size ahead of time skips the growth series with Reserve. There are no other constructors — a builder is not constructed from text; text arrives through <<.

Parameters

None.

Return value

None — a constructor.
