From Engine/String/StaticStringTable.cpp, StaticStringTable::~StaticStringTable()

Each bank's destructor frees its malloc'd buffer, so the destructor releases every byte of interned text at once. The consequence is the sharpest edge in the interning design: after static destruction, every id ever minted is dangling. A StaticString or raw StaticStringID that outlives the singleton — a wrapper in static storage, a value captured by a thread that ends after the engine shuts down — reads freed memory if it calls c_str(). Nothing in the type system prevents that; the guard is the engine's own lifetime discipline.

Parameters

None.

Return value

None — a destructor.

Examples

Not called directly; the singleton's static destruction runs it at process exit, after main returns.
