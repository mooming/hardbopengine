GetName

member of hbe::StaticStringTable Engine/String/StaticStringTable.h the table's own interned name

Signature

[[nodiscard]] StaticString GetName() const

Function description

The table's own name, interned once through a function-local static fed by StringUtil::ToCompactClassName(__PRETTY_FUNCTION__) — the self-documenting trick the engine uses everywhere a class needs its own name without writing it twice: 

StaticString StaticStringTable::GetName() const
{
	static StaticString className = StringUtil::ToCompactClassName(__PRETTY_FUNCTION__);

	return className;
}

From Engine/String/StaticStringTable.cpp, StaticStringTable::GetName() const

The result is "StaticStringTable", and it is the log category the table's diagnostic output uses — PrintStringTable opens its logger with it.

Parameters

None.

Return value

A StaticString naming the class — the interned "StaticStringTable", identical address on every call.

Examples
