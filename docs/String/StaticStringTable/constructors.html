Constructor

member of hbe::StaticStringTable Engine/String/StaticStringTable.h interns the predefined strings

Signature

StaticStringTable()

Function description

Runs once, from GetInstance's function-local static: the only work is RegisterPredefinedStrings, which interns the handful of literal strings the engine's own defaults rely on. After construction every bucket exists and is empty except for those entries; there is no lazily created state left for a caller to trip over.

Parameters

None.

Return value

None — a constructor.

Examples

Not called directly — GetInstance() owns the single construction. The predefined strings are visible in any PrintStringTable dump as the first elements of their buckets.
