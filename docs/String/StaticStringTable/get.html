Get

member of hbe::StaticStringTable Engine/String/StaticStringTable.h id back to characters; null reads as None

Signature

[[nodiscard]] const char* Get(StaticStringID id) const

Function description

Id back to characters. The null id maps to the literal "None"; anything else is the id pointer reinterpreted as const char* — no search, no lock, no hash. The bytes never move after registration, so the pointer is stable for the life of the table (see the destructor for the one boundary). 

const char* StaticStringTable::Get(StaticStringID id) const
{
	if (id.ptr == nullptr)
	{
		return "None";
	}

	return reinterpret_cast<const char*>(id.ptr);
}
