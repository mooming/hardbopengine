GetTableID

member of hbe::StaticStringTable Engine/String/StaticStringTable.h bucket selection — CalculateHash modulo NumTables

Signature

TIndex GetTableID(const char* text) const

TIndex GetTableID(const std::string_view& str) const

Function description

Private. Bucket selection: StringUtil::CalculateHash(text) % NumTables, with NumTables = Config::StaticStringNumHashBuckets. The two overloads delegate to the two CalculateHash overloads, which implement the identical djb2 loop — so a const char* and a std::string_view over the same characters select the same bucket, which is what lets both Register overloads share one interning space. Callers assert the result unsigned (static_assert(!std::is_signed<decltype(tableID)>()) in Register) and that it is below NumTables — both guaranteed by the modulo.

Parameters

ParameterTypeRequirement
textconst char* Zero-terminated text to hash.
strconst std::string_view& Character span to hash; termination is irrelevant to the hash.

Return value

A bucket index in [0, NumTables).

Examples

Both Register overloads open with it; no other caller exists.
