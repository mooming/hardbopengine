RegisterPredefinedStrings

member of hbe::StaticStringTable Engine/String/StaticStringTable.h nine literals the engine's defaults rely on

Signature

void RegisterPredefinedStrings()

Function description

Private; runs once from the constructor. Interns nine strings whose addresses other engine code relies on being present and stable: the empty string, "None", "NONE", "Null", "NULL", "True", "False", "Unknown" and "HardbopEngine". They are the values behind StaticString's default construction ("None") and the builders' null and boolean spellings ("Null", "True", "False").

Parameters

None.

Return value

None.

Examples

The builder operator<<(nullptr_t) appends "Null" and operator<<(bool) appends "True"/"False" — spellings that match this list, so those literals share one interned address with everything the engine interns under the same text.
