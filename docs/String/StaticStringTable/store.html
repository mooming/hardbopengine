Store

member of hbe::StaticStringTable Engine/String/StaticStringTable.h copy the bytes into bank memory, terminate, return the view

Signature

std::string_view Store(const char* text)

std::string_view Store(const std::string_view& str)

Function description

Private. The copy step of registration: carve length + 1 bytes from the banks via Allocate, copy the characters, write the terminator, and return a view over the stored bytes. That returned view is what the bucket keeps and what the minted id points at — after Store returns, the caller's buffer is out of the picture entirely. 

	const auto strLen = str.length();

	auto ptr = (char*) Allocate(strLen + 1);
	std::copy(str.begin(), str.end(), ptr);
	ptr[strLen] = '\0';

	return std::string_view(ptr, strLen);

From Engine/String/StaticStringTable.cpp, StaticStringTable::Store(const std::string_view& str) — the view overload; the const char* overload wraps a view around the text and forwards here

Called only while tableLock is held (from Register), so the store is serialized per table; the allocation beneath it takes memLock in the fixed order noted on Allocate.

Parameters

Return value

A view over the table's copy — length characters, NUL one past the end in memory but not counted in the view.
