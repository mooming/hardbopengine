StrCopy

member of hbe::StringUtil Engine/String/StringUtil.h bounded copy; termination is the caller's problem

Signature

[[nodiscard]] const char* StrCopy(char* dst, const char* src, size_t n)

Function description

Bounded copy via strncpy (strncpy_s on Windows). Four rejected inputs — null destination, null source, destination and source the same pointer, zero n — each trip a debugBreak() in non-release builds and return dst untouched: 

	if (unlikely(dst == nullptr || src == nullptr || dst == src || n == 0))
	{
#if !RELEASE_BUILD
		debugBreak();
#endif // !RELEASE_BUILD
		return dst;
	}

#ifdef _MSC_VER
	strncpy_s(dst, n, src, n);

	return dst;
#else // _MSC_VER
	return strncpy(dst, src, n);
#endif // _MSC_VER

From Engine/String/StringUtil.cpp, StringUtil::StrCopy(char*, const char*, size_t)

The destination is not necessarily terminated. strncpy copies at most n bytes and pads only when the source is shorter; a source of n characters or more leaves dst without a terminator, and the function does not add one. Callers that need a terminated result must reserve n + 1 and pass the larger bound, or terminate afterwards.

Parameters

ParameterTypeRequirement
dstchar* Destination buffer of at least n bytes. Never written on a rejected input.
srcconst char* Source; need not be terminated within n, but the copy stops at its terminator.
nsize_t Copy bound in bytes; zero is a rejected input.

Return value

dst, whether the copy ran or was rejected — the pointer, never the text.

Examples

No call site for this function exists in the repository today — the engine's string types copy through their own buffers, and the C-string layer exists for the platform and log code that predates them. The illustrative shape, with the terminator reserved: 

	char buffer[32];
	StringUtil::StrCopy(buffer, text, sizeof(buffer) - 1);
	buffer[sizeof(buffer) - 1] = '\0';
