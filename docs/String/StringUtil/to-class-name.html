ToClassName

member of hbe::StringUtil Engine/String/StringUtil.h namespace-qualified class name, from __PRETTY_FUNCTION__

Signature

[[nodiscard]] StaticString ToClassName(const char* PrettyFunction)

Function description

The namespace-qualified class name from __PRETTY_FUNCTION__ — hbe::StringUtilTest for the test collection's own Prepare(). The algorithm: cut the text before the final :: (dropping the method name), then keep what follows the last space: 

	auto end = str.find_last_of("::") - 1;
	if (end == TStr::npos)
	{
		return StaticString();
	}

	str = str.substr(0, end);

	auto start = str.find_last_of(" ") + 1;
	str = str.substr(start);

	return StaticString(str);

From Engine/String/StringUtil.cpp, StringUtil::ToClassName(const char*)

The find_last_of(" ") + 1 wrap is load-bearing here rather than dead: for a constructor's signature — hbe::Foo::Foo() — there is no space, the wrap lands on 0, and the whole pre-:: text is the answer, which is correct. The end == npos guard, by contrast, is dead (npos - 1 is never npos), so the empty StaticString it returns is unreachable; an input with no :: at all loses its last character to the substr instead.
