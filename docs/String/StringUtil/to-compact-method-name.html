ToCompactMethodName

Function description

Class::Method without namespaces — StringUtilTest::Prepare for the test's own Prepare(). The compact form of ToMethodName: it locates the method after the final ::, then looks one scope further up for the class that immediately owns it: 

	subStr = str.substr(0, start - 2);
	auto upperStart = subStr.find_last_of("::") + 1;
	if (upperStart == TStr::npos)
	{
		str = str.substr(start);

		return StaticString(str);
	}

	str = str.substr(upperStart, bracketStart - upperStart);

	return StaticString(str);

From Engine/String/StringUtil.cpp, StringUtil::ToCompactMethodName(const char*) — the back half; bracketStart is find_last_of('(') and start is one past the final '::' of the pre-parenthesis text, both guarded earlier in the function

An input with no ( comes back verbatim. The upperStart == npos guard is dead (the npos + 1 wrap lands on 0), so a signature with only one scope separator — a free function in a namespace — runs the arithmetic and returns its text up to the parenthesis, qualifiers included. Member-function signatures, the intended input, always have the second ::.
