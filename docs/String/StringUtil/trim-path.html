TrimPath

member of hbe::StringUtil Engine/String/StringUtil.h backslashes to slashes, one trailing slash dropped

Signature

[[nodiscard]] TString TrimPath(const TString& path)

Function description

Two normalisations in one pass: every backslash becomes a forward slash, and a single trailing slash is removed — unless the character before it is a dot, so "dir/" loses its slash while "./" and "../" keep theirs: 

	char tmp[PATH_MAX + 1];
	auto cStr = path.c_str();

	for (size_t i = 0; i < path.length(); ++i)
	{
		if (cStr[i] == '\\')
		{
			tmp[i] = '/';
		}
		else
		{
			tmp[i] = cStr[i];
		}
	}

	if (path.length() > 2 && tmp[path.length() - 2] != '.' && tmp[path.length() - 1] == '/')
	{
		tmp[path.length() - 1] = '\0';
	}

	tmp[path.length()] = '\0';

	return TString(tmp);

A path longer than PATH_MAX overflows the stack buffer. The copy loop writes tmp[i] for every character of the input with no length check — tmp is PATH_MAX + 1 bytes on the stack (MAX_PATH on Windows, where the guard #ifndef PATH_MAX defines it). Every caller in the engine passes file-system paths the OS itself bounds; a caller with a longer string has a buffer overflow, not a trim.

Parameters

ParameterTypeRequirement
pathconst TString& A file-system path no longer than PATH_MAX characters. Read-only.

Return value

A new TString with slashes normalised and at most the final slash removed. A path that is one or two characters long keeps its trailing slash (the length guard > 2).

Examples

Directory construction normalises its path on the way in — Engine/OSAL/Directory.cpp: 

Directory::Directory(const char* path)
	: path(hbe::StringUtil::TrimPath(path))
