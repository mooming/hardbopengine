EqualsIgnoreCase

member of hbe::StringUtil Engine/String/StringUtil.h equality after ASCII folding

Signature

[[nodiscard]] bool EqualsIgnoreCase(const TString& a, const TString& b)

Function description

ToLowerCase(a) == ToLowerCase(b) — equality after folding, which means two temporary TStrings are allocated on every call. For a hot path that compares the same strings repeatedly, lowercasing once and comparing the results is cheaper. The folding is ToLowerCase's: ASCII 'A'–'Z' only, so a byte outside that range compares exactly as itself — case-insensitive equality here does not fold accented letters or any non-ASCII text.

Parameters

ParameterTypeRequirement
aconst TString& First operand; read-only.
bconst TString& Second operand; read-only.

Return value

true when the two strings are equal after ASCII case folding.

Examples

Illustrative — no call site for this function exists in the repository today. The intended shape is option-or-key matching where the user's spelling of the case is not trusted: 

	if (StringUtil::EqualsIgnoreCase(key, "Enabled"))
	{
		...
	}
