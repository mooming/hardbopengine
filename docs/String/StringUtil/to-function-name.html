ToFunctionName

member of hbe::StringUtil Engine/String/StringUtil.h function name with parameter list, from __PRETTY_FUNCTION__

Signature

[[nodiscard]] StaticString ToFunctionName(const char* PrettyFunction)

Function description

The function name with its parameter list, read out of __PRETTY_FUNCTION__: cut at the last (, find the last :: before it, and keep everything from one past that scope separator through the closing parenthesis: 

	auto bracketEnd = str.find_last_of(')') + 1;
	auto bracketStart = str.find_last_of('(');
	if (unlikely(bracketStart == TStr::npos))
	{
		return StaticString(PrettyFunction);
	}

	auto subStr = str.substr(0, bracketStart);
	auto start = subStr.find_last_of("::") + 1;
	if (start == TStr::npos)
	{
		return StaticString(PrettyFunction);
	}

	str = str.substr(start, bracketEnd - start);

	return StaticString(str);

From Engine/String/StringUtil.cpp, StringUtil::ToFunctionName(const char*)

For void hbe::StringUtilTest::Prepare() the answer is Prepare() — the test accepts Prepare(void) too, for compilers that spell it that way. Two fallbacks to know. An input with no ( comes back verbatim. An input with a parenthesis but no scope separator should come back verbatim — but find_last_of("::") + 1 wraps npos to 0, so the guard never fires and the result is instead the text up to the closing parenthesis. The reader functions all share this dead-guard shape; the intended input, a member-function signature, is unaffected.

The result is interned through StaticString's constructor, so repeated calls with the same signature cost one pointer comparison each.
