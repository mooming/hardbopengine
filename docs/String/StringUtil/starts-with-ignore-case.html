StartsWithIgnoreCase

member of hbe::StringUtil Engine/String/StringUtil.h prefix test after folding both sides

Signature

[[nodiscard]] bool StartsWithIgnoreCase(const TString& src, const TString& startTerm)

Function description

StartsWith(ToLowerCase(src), ToLowerCase(startTerm)) — the prefix test after ASCII-folding both sides. The cost is two lowercased copies plus the head substring of the folded source; correctness inherits ToLowerCase's ASCII-only rule, so a term containing non-ASCII bytes can only match itself, never a differently-cased spelling.

Parameters

ParameterTypeRequirement
srcconst TString& The string tested; read-only.
startTermconst TString& The prefix to look for; read-only.

Return value

true when src begins with startTerm ignoring ASCII case.

Examples

Illustrative — no call site for this function exists in the repository today. It exists as the paired spelling of StartsWith for callers that cannot trust their input's case.
