PathToName

member of hbe::StringUtil Engine/String/StringUtil.h the file name without its directory

Signature

[[nodiscard]] TString PathToName(const TString& path)

Function description

Everything after the last / or \ — the file name without its directory, for either separator spelling. The scan keeps the index of the last separator seen and slices from one past it: 

	bool found = false;
	Index lastIndex = 0;

	for (Index i = 0; i < length; ++i)
	{
		const char ch = buffer[i];
		if (ch == '/' || ch == '\\')
		{
			lastIndex = i;
			found = true;
		}
	}

	if (!found || lastIndex >= (length - 1))
	{
		return path;
	}

	return TString(buffer + lastIndex + 1);

From Engine/String/StringUtil.cpp, StringUtil::PathToName(const TString&)

Two inputs come back unchanged rather than empty: a path with no separator at all (the whole path is already a name), and a path ending in a separator (lastIndex is the final character, and there is nothing after it to return). Note the function does not call TrimPath — normalising separators is the caller's business; this function only splits.

Parameters

ParameterTypeRequirement
pathconst TString& A path in either separator convention; read-only.

Return value

The substring after the last separator, or path itself when there is no separator or the path ends with one.

Examples

Illustrative — no call site for this function exists in the repository today. The logging paths that need a bare file name (Engine/Log/Logger.cpp) compute their lengths with StrLen instead.
