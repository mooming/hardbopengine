EndsWithIgnoreCase

member of hbe::StringUtil Engine/String/StringUtil.h suffix test after folding both sides

Signature

[[nodiscard]] bool EndsWithIgnoreCase(const TString& src, const TString& endTerm)

Function description

EndsWith(ToLowerCase(src), ToLowerCase(endTerm)) — the suffix test after ASCII-folding both sides, with the same two-copies cost and the same ASCII-only folding rule as its prefix counterpart StartsWithIgnoreCase.

Parameters

ParameterTypeRequirement
srcconst TString& The string tested; read-only.
endTermconst TString& The suffix to look for; read-only.

Return value

true when src ends with endTerm ignoring ASCII case.

Examples

Illustrative — no call site for this function exists in the repository today. It completes the four-way prefix/suffix × case-sensitive/insensitive set with EndsWith.
