EndsWith

member of hbe::StringUtil Engine/String/StringUtil.h suffix test, byte for byte

Signature

[[nodiscard]] bool EndsWith(const TString& src, const TString& endTerm)

Function description

Suffix test, case-sensitive. After the same length guard as StartsWith, the tail is built directly from the source's character pointer rather than by substr: 

	if (src.length() < endTerm.length())
	{
		return false;
	}

	const char* srcStr = src.c_str();
	TString last(srcStr + (src.length() - endTerm.length()));

	return last == endTerm;

From Engine/String/StringUtil.cpp, StringUtil::EndsWith(const TString&, const TString&)

The const char* constructor that builds last reads up to the terminator, so the comparison covers the tail and relies on the source being zero-terminated — true for TString (HString) as the engine maintains it. An empty term is a suffix of everything and answers true.

Parameters

ParameterTypeRequirement
srcconst TString& The string tested; read-only, zero-terminated as HString guarantees.

Return value

true when src ends with exactly endTerm, byte for byte.
