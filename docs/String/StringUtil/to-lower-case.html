ToLowerCase

member of hbe::StringUtil Engine/String/StringUtil.h ASCII-folded copy

Signature

[[nodiscard]] TString ToLowerCase(const TString& src)

Function description

A lowercased copy — the source is never touched. The transformation is one fixed offset: constexpr char diff = 'A' - 'a' (negative), subtracted from every character in ['A', 'Z'], which adds 32 and lands exactly on the lower-case letter. Everything else — digits, punctuation, already-lower-case letters, every non-ASCII byte — passes through unchanged. std::transform writes into a result resized to the source's size, so the output has the same length as the input.

ASCII-only, by construction. No locale is consulted and no Unicode case mapping exists here; a caller with real text needs a different tool.

Parameters

ParameterTypeRequirement
srcconst TString& The string to convert; read-only.

Return value

A new TString, same length, with ASCII upper-case letters replaced by their lower-case forms.

Examples

Illustrative — no call site for this function exists in the repository today. The natural use is normalising an identifier before comparison, which is what EqualsIgnoreCase does internally: 

	auto key = StringUtil::ToLowerCase(configKey);
