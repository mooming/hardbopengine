ToMethodName

member of hbe::StringUtil Engine/String/StringUtil.h qualified Class::Method, no parameter list

Signature

[[nodiscard]] StaticString ToMethodName(const char* PrettyFunction)

Function description

Class::Method, namespace-qualified, without the parameter list — hbe::StringUtilTest::Prepare for the test's own Prepare(). The algorithm: cut at the last (, drop the method name by cutting before the final ::, take what follows the last space of that as the class, then splice class and method back together from the original text: 

	auto subStr = str.substr(0, bracketStart);
	auto start = subStr.find_last_of("::") + 1;
	if (start == TStr::npos)
	{
		return StaticString(PrettyFunction);
	}

	subStr = str.substr(0, start - 2);
	start = subStr.find_last_of(" ") + 1;
	str = str.substr(start, bracketStart - start);

	return StaticString(str);

From Engine/String/StringUtil.cpp, StringUtil::ToMethodName(const char*) — bracketStart is find_last_of('('), guarded two lines above

An input with no ( comes back verbatim. The start == npos guard is dead — the npos + 1 wrap lands on 0 — so a scope-less input runs the arithmetic anyway; the intended input, a member-function signature, always carries the :: the algorithm needs.
