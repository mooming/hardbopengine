ToCompactClassName

member of hbe::StringUtil Engine/String/StringUtil.h bare class name — the log-category form

Signature

[[nodiscard]] StaticString ToCompactClassName(const char* PrettyFunction)

Function description

The bare class name, no namespace — StringUtilTest for the test's own Prepare(). This is the log-category form: Logger::Get is fed it throughout the engine so every class names its own log channel without writing the name twice. The algorithm: cut before the final :: (one character earlier than ToClassName does, dropping the method name and one colon), then keep what follows the last :: of the remainder: 

	auto end = str.find_last_of("::") - 1;
	if (end == TStr::npos)
	{
		return StaticString();
	}

	str = str.substr(0, end);
	auto start = str.find_last_of("::") + 1;
	str = str.substr(start, (end - start));

	return StaticString(str);

From Engine/String/StringUtil.cpp, StringUtil::ToCompactClassName(const char*)

The end == npos guard is dead — npos - 1 is never npos — so the empty StaticString return is unreachable; an input with no :: runs the arithmetic and loses its last character instead. The intended input, a member-function signature, is unaffected.
