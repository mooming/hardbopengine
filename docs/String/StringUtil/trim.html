Trim

member of hbe::StringUtil Engine/String/StringUtil.h whitespace off both ends; all-whitespace comes back empty

Signature

[[nodiscard]] TString Trim(const TString& str)

Function description

Whitespace stripped from both ends, with the result built from the narrowed range rather than by erasing: 

	auto start = str.begin();
	auto end = str.end();

	while (start != end && std::isspace(*start))
	{
		++start;
	}

	do
	{
		--end;
	} while (std::distance(start, end) > 0 && std::isspace(*end));

	return TString(start, end + 1);

From Engine/String/StringUtil.cpp, StringUtil::Trim(const TString&)

The trailing loop is a do–while that steps back before testing, guarded by std::distance(start, end) > 0 — which is what keeps an all-whitespace or empty input from walking past begin(): after the leading loop consumes everything, the first backward step makes the distance negative and the loop exits. The result for such input is an empty string. Whitespace is whatever std::isspace says in the default C locale — space, tab, newline, vertical tab, form feed, carriage return.

Parameters

ParameterTypeRequirement
strconst TString& The string to trim; never modified, the result is a new TString.

Return value

A new TString over the trimmed range; empty when the input is empty or all whitespace.

Examples

Config parsing trims both halves of every key–value pair before use — Engine/Config/ConfigFile.cpp: 

			keyValue.first = StringUtil::Trim(key);
			keyValue.second = StringUtil::Trim(value);
