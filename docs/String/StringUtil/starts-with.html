StartsWith

member of hbe::StringUtil Engine/String/StringUtil.h prefix test, byte for byte

Signature

[[nodiscard]] bool StartsWith(const TString& src, const TString& startTerm)

Function description

Prefix test, case-sensitive. A term longer than the source is false before any comparison; otherwise the source's head is cut to the term's length and compared whole: 

	if (src.length() < startTerm.length())
	{
		return false;
	}

	TString head = src.substr(0, startTerm.length());

	return head == startTerm;

From Engine/String/StringUtil.cpp, StringUtil::StartsWith(const TString&, const TString&)

The substr makes one temporary — the case-insensitive variant (StartsWithIgnoreCase) makes three. An empty term is a prefix of everything and answers true.

Parameters

ParameterTypeRequirement
srcconst TString& The string tested; read-only.
startTermconst TString& The prefix to look for; read-only.

Return value

true when src begins with exactly startTerm, byte for byte.
