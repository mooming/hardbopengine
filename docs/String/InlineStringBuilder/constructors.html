Function description

Starts empty, with the terminator written at both ends of the buffer: 

InlineStringBuilder() noexcept
	: length(0)
{
	buffer[0] = '\0';
	buffer[LastIndex] = '\0';
}

From Engine/String/InlineStringBuilder.h, InlineStringBuilder() noexcept

Terminating slot LastIndex up front is part of the overflow story: however far a write clamps, the buffer already reads as a terminated (possibly truncated) string. No allocation happens here or anywhere else in the class — that is the entire point of the type.
