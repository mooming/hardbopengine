Function description

Every overload appends to the buffer and returns *this, and every one of them clamps at LastIndex (BufferSize - 1): a write that does not fit is cut short, length stops at the ceiling, and the terminator is rewritten — truncation, never growth, never an exception. The twenty-two overloads fall into four families.

Characters and raw memory. char is the one overload that checks before writing (if (length >= LastIndex) return *this;) and then places the byte by hand. const char* measures with StringUtil::StrLen and memcpys; the array overload operator<<(char str[N]) measures with the bounded StrLen(str, N); std::string_view memcpys its span directly. A null const char* recurses into the nullptr_t overload, so it prints Null. The std::basic_string overload casts to a view and re-dispatches; the StaticString overload forwards its c_str().

Spellings, not numbers. nullptr_t writes Null, bool writes True or False, and EndLine writes '\n' — the marker's whole purpose. These spellings are exactly the strings StaticStringTable::RegisterPredefinedStrings interns at startup, so the common short outputs share interned addresses with everything else that spells them.

Numbers through snprintf. Every integer and floating-point overload formats into the free space at the write cursor — snprintf(&buffer[length], remained, fmt, value) with remained = BufferSize - length — then clamps. The format strings, one per family: %d for the signed integers, %u for unsigned char and the unsigned integers, %ld/%lld and %lu/%llu for the long forms, %f for float, %lf for double, %Le for long double (scientific, unlike the other two), and %p for void*. Each checks written >= 0 with an Assert.

A truncated number is silently wrong, not short. When the remaining space cannot hold the formatted digits, the clamp keeps whatever fit — "1234567" into a nearly full buffer can come out as "1234" with no error beyond the debug Assert. For values a reader will trust, size the buffer for the worst case.
