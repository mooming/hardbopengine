Hex

member of hbe::InlineStringBuilder Engine/String/InlineStringBuilder.h printable bytes as characters, the rest as hex

Signature

TThis& Hex(uint8_t value) noexcept

Function description

The byte-level formatter, for hex dumps: a printable byte is written as the character itself (%c), anything else as two hex digits (%02x) — so a dump of text with binary noise stays readable. The write goes through the same clamp as every other append: length = std::min(LastIndex, length + written), with an Assert that snprintf reported success. Returns *this, so it chains in a << sequence like the operators do.

Parameters

ParameterTypeRequirement
valueuint8_t The byte to append. Any value; the printable test decides the spelling.

Return value

*this, for chaining.

Examples

No call site in the repository today — the memory dumps that would use it go through the Memory module's own formatting. The illustrative shape is a hex dump loop: 

	for (uint8_t byte : data)
	{
		builder.Hex(byte);
	}

Illustrative — the method is real; the call site is not
