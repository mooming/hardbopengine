InlineStringBuilder

Engine/String/InlineStringBuilder.h namespace hbe template <size_t BufferSize = 1024, class TChar = char> final the builder that never allocates — a hard inline ceiling

Class description

The builder that never allocates: a << interface writing into a TChar buffer[BufferSize] carried inside the object itself. This is what a formatter inside a frame, a per-stream name builder, or a logger's inline text path uses when even one heap allocation is one too many — Engine/Core/TaskSystem.cpp builds stream names with InlineStringBuilder<64>, and the pool allocators name their banks with InlineStringBuilder<1024>.

There is no growth, and overflow is silent truncation. Every append clamps: length = std::min(LastIndex, length + written), where LastIndex is BufferSize - 1 — the slot the terminator permanently owns. A write that does not fit is cut off mid-content, an Assert fires in debug builds, and nothing throws or grows. Pick the size from the largest thing that will be written, not from what is usually written.

The whole surface is one shape: every operator<< appends and returns *this, so a line reads left to right and ends with << hendl for the newline. The interface matches StringBuilder's entry for entry — the two are interchangeable at a call site that does not care where the bytes live.
