c_str

member of hbe::InlineStringBuilder Engine/String/InlineStringBuilder.h the buffer, terminated — even after truncation

Signature

[[nodiscard]] auto c_str() const noexcept

Function description

The buffer as a zero-terminated C string: static_cast<const char*>(buffer). The cast is unconditional — whatever TChar the template was instantiated with, the result is const char*, so TChar is char in every real use. The terminator is guaranteed by construction and by every append, including the truncating ones: a builder that overflowed still returns a readable, terminated (cut-off) string, never an unterminated one.

Parameters

None.

Return value

const char* into the object's own buffer — valid as long as the builder lives and is not written to again. Not owned, not to be freed or kept across mutations.

Examples

		InlineStringBuilder<1024> str;
		str << name << '_' << config.blockSize << '_' << config.numberOfBlocks;

		banks.emplace_back(str.c_str(), config.blockSize, config.numberOfBlocks);
