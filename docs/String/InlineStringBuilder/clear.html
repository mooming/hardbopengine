Clear

member of hbe::InlineStringBuilder Engine/String/InlineStringBuilder.h reset to empty in place

Signature

void Clear() noexcept

Function description

Reset to empty in place: length = 0 and the two terminator slots rewritten. The buffer's bytes are not zeroed — only the terminator at slot 0 makes the content empty again, which is why clearing is three writes and not a fill. This is the reuse path for a builder in a loop: construct once outside, clear per iteration.

Parameters

None.

Return value

None.
