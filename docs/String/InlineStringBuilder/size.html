Size

member of hbe::InlineStringBuilder Engine/String/InlineStringBuilder.h the write cursor

Signature

[[nodiscard]] auto Size() const noexcept

Function description

Returns length — the characters written so far, terminator excluded. This is the number to check against BufferSize - 1 when a caller needs to know whether a write was truncated; there is no separate "did it overflow" flag, so a caller that must detect truncation compares Size() against the ceiling after the last write.

Parameters

None.

Return value

The write cursor as size_t; 0 for a fresh or cleared builder.

Examples

The tests use it implicitly — every formatting testlet reads the result back through c_str and compares whole strings rather than asking the size. No production call site reads Size() today.
