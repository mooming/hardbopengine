VkRenderPass란？ | What is VkRenderPass？

VkRenderPass은 렌더링 작업을 정의하는 객체입니다. 어떤 어태치먼트를 사용할지, 어떤 순서로 연산을 수행할지 정의합니다.


VkRenderPass is an object that defines rendering operations. It specifies which attachments to use and the order of operations.

Render Pass 구성 요소 | Render Pass Components

구성 요소 | Component 설명 | Description
Attachment 렌더링 대상 이미지 (컬러,.depth 등)
Subpass 하나의 렌더링 단계 (여러 개의 어태치먼트 사용 가능)
Dependency 서브패스 간 순서 및 동기화 정의

어태치먼트 정의 | Define Attachment

1 VkAttachmentDescription 구조체 초기화
VkAttachmentDescription attachment{}; attachment.format = surfaceFormat.format; // Swapchain 이미지 포맷 attachment.samples = VK_SAMPLE_COUNT_1_BIT; attachment.loadOp = VK_ATTACHMENT_LOAD_OP_CLEAR; // 렌더 시작 시 지우기 attachment.storeOp = VK_ATTACHMENT_STORE_OP_STORE; // 렌더 후 저장 attachment.stencilLoadOp = VK_ATTACHMENT_LOAD_OP_DONT_CARE; attachment.stencilStoreOp = VK_ATTACHMENT_STORE_OP_DONT_CARE; attachment.initialLayout = VK_IMAGE_LAYOUT_UNDEFINED; attachment.finalLayout = VK_IMAGE_LAYOUT_PRESENT_SRC_KHR; // 프레젠테이션 준비
핵심 | Key Point: loadOp와 storeOp는 각 서브패스 시작과 끝에서 어태치먼트에 어떤 연산을 수행할지 정의합니다.

서브패스 정의 | Define Subpass

2 VkAttachmentReference 구조체로 어태치먼트 참조
VkAttachmentReference colorAttachmentRef{}; colorAttachmentRef.attachment = 0; // 첫 번째 어태치먼트 (인덱스 0) colorAttachmentRef.layout = VK_IMAGE_LAYOUT_COLOR_ATTACHMENT_OPTIMAL;
3 VkSubpassDescription 구조체 초기화
VkSubpassDescription subpass{}; subpass.pipelineBindPoint = VK_PIPELINE_BIND_POINT_GRAPHICS; subpass.colorAttachmentCount = 1; subpass.pColorAttachments = &colorAttachmentRef;

Render Pass 생성 | Create Render Pass

4 VkRenderPassCreateInfo 구조체 초기화
VkRenderPassCreateInfo renderPassCreateInfo{}; renderPassCreateInfo.sType = VK_STRUCTURE_TYPE_RENDER_PASS_CREATE_INFO; renderPassCreateInfo.attachmentCount = 1; renderPassCreateInfo.pAttachments = &attachment; renderPassCreateInfo.subpassCount = 1; renderPassCreateInfo.pSubpasses = &subpass;
5 vkCreateRenderPass 호출
VkRenderPass renderPass; VkResult result = vkCreateRenderPass(device, &renderPassCreateInfo, nullptr, &renderPass); if (result != VK_SUCCESS) { std::cerr << "Failed to create render pass: " << result << std::endl; return false; } this->renderPass = renderPass;

레이아웃 전환 | Layout Transitions

중요 | Important: 이미지 레이아웃은 렌더링 전에 적절한 레이아웃으로 전환되어야 합니다.
레이아웃 | Layout 사용 | Usage
UNDEFINED 초기 상태, 내용 무시
COLOR_ATTACHMENT_OPTIMAL 컬러 렌더링 대상
DEPTH_STENCIL_ATTACHMENT_OPTIMAL 깊이/스테실 렌더링 대상
PRESENT_SRC_KHR 프레젠테이션 준비
TRANSFER_SRC_OPTIMAL 데이터 소스
TRANSFER_DST_OPTIMAL 데이터 대상
