VkSurfaceKHR란？ | What is VkSurfaceKHR？

VkSurfaceKHR은 Vulkan이 이미지를 프레젠테이션할 수 있는 플랫폼별 윈도우 시스템과 연결된 객체입니다.


VkSurfaceKHR is a platform-specific object that connects Vulkan to the windowing system for image presentation.

플랫폼별 Surface 생성 | Platform-Specific Surface Creation

핵심 | Key Point: 각 플랫폼마다 Surface 생성 함수가 다릅니다. OSAL의 GetNativeHandle() 메서드를 사용하여 플랫폼별 핸들을 얻어야 합니다.

Linux (XCB)

1 XCB Surface 생성
// Linux 플랫폼 VkXcbSurfaceCreateInfoKHR surfaceCreateInfo{}; surfaceCreateInfo.sType = VK_STRUCTURE_TYPE_XCB_SURFACE_CREATE_INFO_KHR; surfaceCreateInfo.connection = // XCB 연결 (OSAL에서 가져옴); surfaceCreateInfo.window = static_cast<xcb_window_t>(window->GetNativeHandle()); VkResult result = vkCreateXcbSurfaceKHR(instance, &surfaceCreateInfo, nullptr, &surface); if (result != VK_SUCCESS) { return false; }
팁 | Tip: OSAL에서 XCB 연결을 제공하는지 확인하세요. 연결이 없으면 Xlib로 전환할 수 있습니다.

macOS

1 macOS Surface 생성
// macOS 플랫폼 VkMacOSSurfaceCreateInfoMVK surfaceCreateInfo{}; surfaceCreateInfo.sType = VK_STRUCTURE_TYPE_MACOS_SURFACE_CREATE_INFO_MVK; surfaceCreateInfo.pView = // NSView pointer (OSAL에서 가져옴); VkResult result = vkCreateMacOSSurfaceMVK(instance, &surfaceCreateInfo, nullptr, &surface); if (result != VK_SUCCESS) { return false; }

Windows

1 Win32 Surface 생성
// Windows 플랫폼 VkWin32SurfaceCreateInfoKHR surfaceCreateInfo{}; surfaceCreateInfo.sType = VK_STRUCTURE_TYPE_WIN32_SURFACE_CREATE_INFO_KHR; surfaceCreateInfo.hwnd = reinterpret_cast<HWND>(window->GetNativeHandle()); VkResult result = vkCreateWin32SurfaceKHR(instance, &surfaceCreateInfo, nullptr, &surface); if (result != VK_SUCCESS) { return false; }
