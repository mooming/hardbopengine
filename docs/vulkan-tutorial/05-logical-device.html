VkDevice란？ | What is VkDevice？

VkDevice는 물리 장치에서 생성되는 로직 장치입니다. 실제 GPU 작업 (렌더링, 컴퓨트) 은 이 장치를 통해 수행됩니다.


VkDevice is the logical device created from a physical device. Actual GPU operations (rendering, compute) are performed through this device.

Queue Family 이해 | Understanding Queue Families

GPU는 여러 개의 Queue Family을 가질 수 있습니다. 각 Queue Family은 특정 작업 (그리기, 컴퓨트, 전송) 을 처리합니다.

Queue Flag 설명 | Description 사용 | Usage
VK_QUEUE_GRAPHICS_BIT 그래픽스 작업 처리 렌더링
VK_QUEUE_COMPUTE_BIT 컴퓨트 작업 처리 컴퓨트 셰이더
VK_QUEUE_TRANSFER_BIT 데이터 전송 처리 메모리 복사
VK_QUEUE_SPARSE_BINDING_BIT 스패스 바인딩 처리 스패스 메모리

구현 단계 | Implementation Steps

Step 1: Queue Family 조회 | Query Queue Families

1 사용 가능한 Queue Family 확인
uint32_t queueFamilyCount = 0; vkGetPhysicalDeviceQueueFamilyProperties(physicalDevice, &queueFamilyCount, nullptr); std::vector<VkQueueFamilyProperties> queueFamilies(queueFamilyCount); vkGetPhysicalDeviceQueueFamilyProperties(physicalDevice, &queueFamilyCount, queueFamilies.data());

Step 2: Graphics Queue Family 찾기 | Find Graphics Queue

2 그래픽스 작업을 처리할 Queue Family 식별
uint32_t graphicsQueueFamily = UINT32_MAX; for (uint32_t i = 0; i < queueFamilyCount; i++) { if (queueFamilies[i].queueFlags & VK_QUEUE_GRAPHICS_BIT) { graphicsQueueFamily = i; break; } } if (graphicsQueueFamily == UINT32_MAX) { std::cerr << "No graphics queue family found" << std::endl; return false; }

Step 3: Present Queue Family 확인 | Check Present Support

3 Surface 프레젠테이션 지원 Queue Family 확인
uint32_t presentQueueFamily = UINT32_MAX; for (uint32_t i = 0; i < queueFamilyCount; i++) { VkBool32 presentSupport = false; vkGetPhysicalDeviceSurfaceSupportKHR(physicalDevice, i, surface, &presentSupport); if (presentSupport) { presentQueueFamily = i; break; } } if (presentQueueFamily == UINT32_MAX) { std::cerr << "No presentable queue family found" << std::endl; return false; }

Step 4: Queue Create Info 생성 | Create Queue Info

4 Queue 생성 정보 구성
std::vector<VkDeviceQueueCreateInfo> queueCreateInfos; std::set<uint32_t> uniqueQueueFamilies = {graphicsQueueFamily, presentQueueFamily}; float queuePriority = 1.0f; for (uint32_t queueFamily : uniqueQueueFamilies) { VkDeviceQueueCreateInfo queueCreateInfo{}; queueCreateInfo.sType = VK_STRUCTURE_TYPE_DEVICE_QUEUE_CREATE_INFO; queueCreateInfo.queueFamilyIndex = queueFamily; queueCreateInfo.queueCount = 1; queueCreateInfo.pQueuePriorities = &queuePriority; queueCreateInfos.push_back(queueCreateInfo); }

Step 5: Device Create Info 생성 | Create Device Info

5 VkDeviceCreateInfo 구조체 초기화
VkDeviceCreateInfo deviceCreateInfo{}; deviceCreateInfo.sType = VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO; // Queue 정보 설정 deviceCreateInfo.queueCreateInfoCount = static_cast<uint32_t>(queueCreateInfos.size()); deviceCreateInfo.pQueueCreateInfos = queueCreateInfos.data(); // 검증 레이어 설정 deviceCreateInfo.enabledLayerCount = static_cast<uint32_t>(validationLayers.size()); deviceCreateInfo.ppEnabledLayerNames = validationLayers.data(); // 디바이스 확장 기능 설정 const std::vector<const char*> deviceExtensions = { VK_KHR_SWAPCHAIN_EXTENSION_NAME }; deviceCreateInfo.enabledExtensionCount = static_cast<uint32_t>(deviceExtensions.size()); deviceCreateInfo.ppEnabledExtensionNames = deviceExtensions.data(); // 디바이스 기능 설정 deviceCreateInfo.pEnabledFeatures = &deviceFeatures;

Step 6: Device 생성 | Create Device

6 vkCreateDevice 호출
VkDevice device; VkResult result = vkCreateDevice(physicalDevice, &deviceCreateInfo, nullptr, &device); if (result != VK_SUCCESS) { std::cerr << "Failed to create logical device: " << result << std::endl; return false; } this->device = device;
