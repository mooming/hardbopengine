Vulkan이란 무엇인가요？ | What is Vulkan？

Vulkan은 크로스 플랫폼 3D 그래픽스 API입니다. OpenGL의 후계자로, 더 낮은 오버헤드와 더 나은 멀티스레딩 성능을 제공합니다.


Vulkan is a cross-platform 3D graphics API. It is the successor to OpenGL, offering lower overhead and better multithreading performance.

                핵심 개념 | Key Concept:

                Vulkan은 개발자에게 더 많은 제어를 제공하지만, 그만큼 더 많은 설정이 필요합니다.

Vulkan SDK 설치 | Installing Vulkan SDK

Linux (Ubuntu/Debian)

1 Vulkan SDK 다운로드
# Vulkan SDK 다운로드 wget https://sdk.lunarg.com/sdk/download/1.3.239.0/linux/vulkansdk-linux-x86_64-1.3.239.0.tar.gz # 압축 해제 tar -xzf vulkansdk-linux-x86_64-1.3.239.0.tar.gz # 환경 변수 설정 export VULKAN_SDK=$(pwd)/1.3.239.0/x86_64 export PATH="$VULKAN_SDK/bin:$PATH" export LD_LIBRARY_PATH="$VULKAN_SDK/lib:$LD_LIBRARY_PATH"

macOS

1 Homebrew로 설치
# Homebrew로 Vulkan SDK 설치 brew install vulkan-sdk # 환경 변수 설정 (약간 다름) export VULKAN_SDK=/opt/homebrew export PATH="$VULKAN_SDK/bin:$PATH" export DYLD_LIBRARY_PATH="$VULKAN_SDK/lib:$DYLD_LIBRARY_PATH"

Windows

1 인스톨러 실행
# Vulkan SDK 다운로드 # https://vulkan.lunarg.com/sdk/home#windows # 인스톨러 실행 후 기본 경로 사용 # C:\VulkanSDK\1.3.239.0 # 환경 변수 자동 설정됨
팁 | Tip: 설치 후 vulkaninfo --summary 명령으로 설치가 제대로 되었는지 확인하세요.

프로젝트 구조 | Project Structure

HardBop Engine의 새로운 Renderer 모듈 구조입니다.

Applications/TriangleExample/
├── Main.cpp                          # 애플리케이션 진입점
├── MinimalVulkanRenderer.h           # 렌더러 클래스 선언
├── MinimalVulkanRenderer.cpp         # 렌더러 구현
├── VulkanComponents.h                # ECS 컴포넌트 정의
├── VulkanSystems.h                   # 시스템 클래스
├── VulkanPipeline.h                  # Vulkan 파이프라인 관리
├── VulkanPipeline.cpp                # Vulkan 구현
├── Shaders/
│   ├── vertex.vert                   # Vertex Shader
│   └── fragment.frag                 # Fragment Shader
└── CMakeLists.txt                    # 빌드 설정
1 디렉토리 생성
mkdir -p Applications/TriangleExample/Shaders
2 쉐이더 파일 생성
# Shaders/vertex.vert #version 450 layout(location = 0) in vec3 inPosition; layout(location = 1) in vec4 inColor; layout(location = 0) out vec4 fragColor; void main() { gl_Position = vec4(inPosition, 1.0); fragColor = inColor; }
