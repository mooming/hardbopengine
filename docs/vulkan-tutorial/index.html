Vulkan Tutorial

Vulkan 튜토리얼

Step-by-step learning guide 단계별 학습 가이드

Introduction 소개

This tutorial is a step-by-step guide for learning the Vulkan API from scratch.
This tutorial was written to redesign the Render module of the HardBop Engine project.

이 튜토리얼은 Vulkan API를 처음 배우는 분들을 위한 단계별 가이드입니다.
이 튜토리얼은 HardBop Engine 프로젝트의 Render 모듈을 재설계하기 위해 작성되었습니다.

Prerequisites 선행 지식

  • C++23 programming language basics
  • C++23 프로그래밍 언어 기본기
  • Graphics programming fundamentals (optional)
  • 그래픽스 프로그래밍 기본 개념 (선택 사항)
  • Vulkan SDK installed
  • Vulkan SDK 설치 완료
