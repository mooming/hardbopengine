VkInstance란？ | What is VkInstance？

VkInstance은 Vulkan API의 루트 객체입니다. 이 객체는 Vulkan 라이브러리와 애플리케이션 간 연결을 담당합니다.


VkInstance is the root object in the Vulkan API. This object handles the connection between the Vulkan library and the application.

확장 기능 | Extensions

Vulkan은 플랫폼별 기능을 확장 기능을 통해 제공합니다. Surface 생성을 위해 플랫폼별 확장이 필요합니다.

플랫폼 | Platform 확장 기능 | Extension 설명 | Description
Linux VK_KHR_XCB_SURFACE XCB 기반 Surface 생성
Linux VK_KHR_XLIB_SURFACE Xlib 기반 Surface 생성
macOS VK_KHR_MACOS_SURFACE macOS Surface 생성
Windows VK_KHR_WIN32_SURFACE Win32 Surface 생성

검증 레이어 | Validation Layers

검증 레이어는 Vulkan 호출 시 오류를 감지하고 디버깅 정보를 제공합니다. 개발 단계에서는 반드시 활성화해야 합니다.

권장 | Recommended: 개발 단계에서는 검증 레이어를 활성화하세요. 배포 단계에서는 성능을 위해 비활성화할 수 있습니다.
레이어 이름 | Layer Name 설명 | Description
VK_LAYER_KHRONOS_validation Khronos 공식 검증 레이어 (가장 중요)

Step 1: 확장 기능 정의

1 플랫폼별 확장 기능 정의
// MinimalVulkanRenderer.h class MinimalVulkanRenderer { private: VkInstance instance = VK_NULL_HANDLE; VkDebugUtilsMessengerEXT debugMessenger = VK_NULL_HANDLE; }; // MinimalVulkanRenderer.cpp const std::vector<const char*> instanceExtensions = { VK_KHR_SURFACE_EXTENSION_NAME, #ifdef __linux__ VK_KHR_XCB_SURFACE_EXTENSION_NAME, #elif defined(__APPLE__) VK_KHR_MACOS_SURFACE_EXTENSION_NAME, #elif defined(_WIN32) VK_KHR_WIN32_SURFACE_EXTENSION_NAME, #endif };

Step 2: 검증 레이어 정의

2 검증 레이어 설정
#ifdef ENABLE_VALIDATION_LAYERS const std::vector<const char*> validationLayers = { "VK_LAYER_KHRONOS_validation" }; #else const std::vector<const char*> validationLayers = {}; #endif

Step 3: Application Info 생성

3 VkApplicationInfo 구조체 초기화
VkApplicationInfo appInfo{}; appInfo.sType = VK_STRUCTURE_TYPE_APPLICATION_INFO; appInfo.pApplicationName = "Triangle Example"; appInfo.applicationVersion = VK_MAKE_VERSION(1, 0, 0); appInfo.pEngineName = "HardBop Engine"; appInfo.engineVersion = VK_MAKE_VERSION(1, 0, 0); appInfo.apiVersion = VK_API_VERSION_1_0;

Step 4: Instance Create Info 생성

4 VkInstanceCreateInfo 구조체 초기화
VkInstanceCreateInfo createInfo{}; createInfo.sType = VK_STRUCTURE_TYPE_INSTANCE_CREATE_INFO; createInfo.pApplicationInfo = &appInfo; createInfo.enabledExtensionCount = static_cast<uint32_t>(instanceExtensions.size()); createInfo.ppEnabledExtensionNames = instanceExtensions.data(); createInfo.enabledLayerCount = static_cast<uint32_t>(validationLayers.size()); createInfo.ppEnabledLayerNames = validationLayers.data();

Step 5: Instance 생성

5 vkCreateInstance 호출
VkInstance instance; VkResult result = vkCreateInstance(&createInfo, nullptr, &instance); if (result != VK_SUCCESS) { std::cerr << "Failed to create Vulkan instance: " << result << std::endl; return false; } this->instance = instance;
