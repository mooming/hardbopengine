VkPhysicalDevice란？ | What is VkPhysicalDevice？

VkPhysicalDevice은 실제 GPU를 나타냅니다. 시스템에 여러 GPU가 있을 수 있으며, 적절한 GPU를 선택해야 합니다.


VkPhysicalDevice represents an actual GPU. There may be multiple GPUs in the system, and you need to select the appropriate one.

장치 선택 기준 | Device Selection Criteria

criteria | 기준 설명 | Description 우선순위 | Priority
Device Type Discrete GPU > Integrated GPU > Virtual GPU 높음 | High
Version 더 높은 Vulkan 버전 지원 중간 | Medium
Memory 더 많은 비디오 메모리 중간 | Medium
Features 필요한 기능 지원 여부 높음 | High

구현 단계 | Implementation Steps

Step 1: 물리 장치 열거 | Enumerate Physical Devices

1 사용 가능한 GPU 목록 가져오기
// 사용 가능한 물리 장치 수 확인 uint32_t deviceCount = 0; vkEnumeratePhysicalDevices(instance, &deviceCount, nullptr); if (deviceCount == 0) { std::cerr << "Failed to find GPUs with Vulkan support" << std::endl; return false; } // 모든 물리 장치 가져오기 std::vector<VkPhysicalDevice> devices(deviceCount); vkEnumeratePhysicalDevices(instance, &deviceCount, devices.data());

Step 2: 장치 정보 조회 | Query Device Properties

2 각 장치의 속성 확인
// 첫 번째 장치의 속성 확인 VkPhysicalDeviceProperties properties; vkGetPhysicalDeviceProperties(devices[0], &properties); // 장치 이름 출력 std::cout << "Device: " << properties.deviceName << std::endl; std::cout << "Driver: " << properties.driverVersion << std::endl; std::cout << "Type: " << static_cast<int>(properties.deviceType) << std::endl;

Step 3: 장치 선택 | Device Selection

3 최적의 장치 선택 알고리즘
VkPhysicalDevice selectedDevice = VK_NULL_HANDLE; for (const auto& device : devices) { VkPhysicalDeviceProperties prop; vkGetPhysicalDeviceProperties(device, &prop); // Discrete GPU 우선 if (prop.deviceType == VK_PHYSICAL_DEVICE_TYPE_DISCRETE_GPU) { selectedDevice = device; break; } // Discrete GPU가 없으면 Integrated GPU 사용 if (selectedDevice == VK_NULL_HANDLE && prop.deviceType == VK_PHYSICAL_DEVICE_TYPE_INTEGRATED_GPU) { selectedDevice = device; } } if (selectedDevice == VK_NULL_HANDLE) { std::cerr << "Failed to find a suitable GPU" << std::endl; return false; } this->physicalDevice = selectedDevice;

Step 4: 기능 확인 | Check Features

4 필요한 기능 지원 여부 확인
VkPhysicalDeviceFeatures features; vkGetPhysicalDeviceFeatures(selectedDevice, &features); // 필수 기능 확인 if (!features.geometryShader) { std::cerr << "Geometry shader not supported" << std::endl; return false; } if (!features.samplerAnisotropy) { std::cerr << "Anisotropic filtering not supported" << std::endl; return false; } // 선택적 기능 저장 this->deviceFeatures = features;

Step 5: 메모리 확인 | Check Memory

5 비디오 메모리 양 확인
VkPhysicalDeviceMemoryProperties memoryProperties; vkGetPhysicalDeviceMemoryProperties(selectedDevice, &memoryProperties); std::cout << "Memory Heaps: " << memoryProperties.memoryHeapCount << std::endl; for (uint32_t i = 0; i < memoryProperties.memoryTypeCount; i++) { std::cout << "Type " << i << ": " << memoryProperties.memoryTypes[i].propertyFlags << std::endl; }

디버깅 팁 | Debugging Tips

팁 | Tip: 여러 GPU가 있는 시스템에서는 선택한 장치가 예상한 것인지 확인하세요.
  • vulkaninfo --summary 명령으로 시스템의 모든 GPU 정보 확인
  • 선택된 장치의 이름과 타입을 로그로 출력
  • 예상과 다른 장치가 선택되면 선택 로직 수정

체크리스트 | Checklist

  • ☐ 적어도 하나의 GPU 발견
  • ☐ 최적의 GPU 선택
  • ☐ 필요한 기능 확인
