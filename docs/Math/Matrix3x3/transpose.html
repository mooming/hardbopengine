Transpose

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h the in-place transpose, swapping the three off-diagonal pairs

Signature

void Transpose() noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::Transpose(). Performs std::swap on m12/m21, m13/m31 and m23/m32 and returns nothing. LookAt finishes with it. The copy-returning form is the shared Transposed.

Parameters

None.

Return value

None; the transpose lands in *this.
