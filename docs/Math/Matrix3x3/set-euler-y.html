SetEulerY

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h rotation about y, in radians, written into the 3x3 block

Signature

void SetEulerY(float radian) noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::SetEulerY(). The angle is a radian, unconverted. Writes m22 = 1, m12 = m21 = m23 = m32 = 0, m11 = m33 = c, m13 = s, m31 = -s — all nine elements, so the block is fully replaced. Compare SetEulerAngles, which takes degrees.

Parameters

ParameterTypeRequirement
radianfloatThe angle in radians.

Return value

None; the rotation lands in *this.
