operator TMat2x2

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h a new 2x2 built from the top-left block

Signature

explicit operator TMat2x2() const noexcept

Function description

Defined in Engine/Math/Matrix3x3.h. An explicit conversion operator that builds a Matrix2x2 through its nullptr constructor and copies m11, m12, m21, m22 into it — all four elements the 2-by-2 has, so the result is fully initialized. explicit, so it happens only where written.

Parameters

None; the conversion applies to the object it is written on.

Return value

TypeWhat you get
TMat2x2A new Matrix2x2 holding the top-left block; the source is untouched.
