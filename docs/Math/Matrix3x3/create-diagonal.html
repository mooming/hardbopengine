CreateDiagonal

member of hbe::Matrix3x3 Engine/Math/MatrixCommonImpl.inl a diagonal matrix from one scalar or from a vector

Signature

[[nodiscard]] static This CreateDiagonal(const TNumber diagonal) noexcept

[[nodiscard]] static This CreateDiagonal(const TVec& diagonal) noexcept

Function description

Defined in Engine/Math/MatrixCommonImpl.inl as Matrix3x3::CreateDiagonal(); the file is included into the class body, so this is a member of every matrix class, not a free function. Two static overloads. Both start from a default-constructed matrix — which is the identity — and overwrite the diagonal, so the off-diagonal entries are zero. The scalar form puts diagonal on every diagonal entry; the vector form puts diagonal.a[i] on entry i. Matrix4x4::ToMatrix() builds its scale block with the vector form.

Parameters

ParameterTypeRequirement
diagonalTNumber or const TVec&Scalar: one value for every diagonal entry. Vector: one value per entry, taken from a[i].

Return value

TypeWhat you get
ThisA matrix with the requested diagonal and zeros elsewhere.

Examples

auto perAxis = TFloat2x2::CreateDiagonal(TFloat2(2.0f, 3.0f));  // 2, 0, 0, 3
