IsOrthogonal

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h all three rows mutually orthogonal and each unit length

Signature

[[nodiscard]] bool IsOrthogonal() const noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::IsOrthogonal(). Returns the conjunction of IsZero on the three pairwise row dots and IsUnity on each row — all through the vector class's tolerance tests. This is the precondition the Quaternion matrix constructor asserts before converting a matrix.

Parameters

None.

Return value

booltrue when the rows form an orthonormal basis.
