Transposed

member of hbe::Matrix3x3 Engine/Math/MatrixCommonImpl.inl a transposed copy — entries mirrored across the diagonal

Signature

[[nodiscard]] This Transposed() const noexcept

Function description

Defined in Engine/Math/MatrixCommonImpl.inl as Matrix3x3::Transposed(); the file is included into the class body, so this is a member of every matrix class, not a free function. Builds a result whose result.m[j][i] = m[i][j] and returns it; the original is untouched. The in-place counterparts are the header-declared Transpose() (Matrix3x3, Matrix4x4) and Transpse() (Matrix2x2, as spelled).

None.
