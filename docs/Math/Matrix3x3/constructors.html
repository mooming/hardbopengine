Function description

Four constructors. The default form is the identity — element{1, 0, 0, 0, 1, 0, 0, 0, 1} — which is what the Identity constant is defined as. The nullptr form is explicit and initializes nothing; the shared implementation builds result matrices through it. The array form is explicit and takes nine elements in row-major order via std::move. The Matrix2x2 form copies its four elements into the top-left block, writes 0 in m13, m23, m31, m32 and 1 in m33 — completing the identity.
