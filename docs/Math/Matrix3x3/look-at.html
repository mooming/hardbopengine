LookAt

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h a rotation basis from unit forward and up vectors, written into the rows and transposed

Signature

void LookAt(const TVec& forward, TVec up) noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::LookAt(). Both inputs are asserted unit length, and their dot product is asserted to satisfy cosAngle * cosAngle < 1.0f — the two vectors must not be parallel. The right-handed branch (the build default) computes right = forward.Cross(up), re-derives up = forward.Cross(right) unless the inputs are already perpendicular, and fills the rows:

rows[0] = right;
rows[1] = forward;
rows[2] = up;

From Engine/Math/Matrix3x3.h, Matrix3x3::LookAt() — right-handed branch

The member ends with Transpose(), so in the stored matrix the basis vectors sit in the columns. forward is taken by const reference, up by value — the re-derivation writes into the local copy.

The left-handed branch does not compile. It assigns to raws, a member this class does not declare. RIGHT_HANDED_COORDINATE is defined unconditionally by Engine/Config/BuildConfig.h, so the branch is excluded in every build; a probe compiling the header without the define reports:
Engine/Math/Matrix3x3.h:177:3: error: use of undeclared identifier 'raws'; did you mean 'rows'?
