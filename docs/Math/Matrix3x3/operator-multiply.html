operator*

member of hbe::Matrix3x3 Engine/Math/MatrixCommonImpl.inl matrix times matrix, or matrix times vector, returning a copy

Signature

[[nodiscard]] This operator*(const This& rhs) const noexcept

[[nodiscard]] TVec operator*(const TVec& rhs) const noexcept

Function description

Defined in Engine/Math/MatrixCommonImpl.inl as Matrix3x3::operator*(); the file is included into the class body, so this is a member of every matrix class, not a free function. Two overloads. The matrix form returns Multiply(rhs) — the row-major product, computed by transposing rhs first and taking row dots. The vector form returns Multiply(rhs) with the vector as a column vector on the right: result.a[i] = rows[i].Dot(rhs). v * M does not compile — the vector always sits on the right.
