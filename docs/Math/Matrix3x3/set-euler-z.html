SetEulerZ

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h rotation about z, in radians — but m33 is written 0.0f, so the result is not a rotation

Signature

void SetEulerZ(float radian) noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::SetEulerZ(). The angle is a radian. The element writes are:

m21 = s;
m22 = c;
m23 = 0.0f;
m31 = 0.0f;
m32 = 0.0f;
m33 = 0.0f;

From Engine/Math/Matrix3x3.h, Matrix3x3::SetEulerZ() — the tail

A z rotation needs m33 = c; the code writes 0.0f instead, so the matrix this member produces is not a rotation about z — its (3, 3) entry collapses and vectors with a z component do not survive the transform. Matrix4x4::SetRotationZ() carries the same write. Until the code changes, build a z rotation through SetEulerAngles, whose formula is correct.
