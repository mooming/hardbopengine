operator=

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h copies a 2x2 into the top-left block, leaving the rest as it was

Signature

This& operator=(const TMat2x2& rhs) noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::operator=(const TMat2x2&). Assigns m11, m12, m21, m22 and returns *this. Nothing else is written: m13, m23, m31, m32, m33 keep their previous values — this is assignment onto an existing matrix, not a conversion that completes an identity.

Parameters

rhsconst TMat2x2&The source of the four top-left elements.

Return value

This&*this, with the other five elements unchanged.
