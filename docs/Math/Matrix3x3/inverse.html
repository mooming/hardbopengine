Inverse

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h the adjugate scaled by 1/det twice — exact only for determinant-1 matrices

Signature

[[nodiscard]] This Inverse() const noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::Inverse(). The determinant is asserted non-zero with Assert — compiled out of Release builds, where a singular matrix divides by zero and produces infinities. Every entry of the result is the cofactor term already scaled by invDet, and then the whole matrix is scaled again:

temp.m31 = invDet * (m21 * m32 - m22 * m31);
temp.m32 = invDet * (m12 * m31 - m11 * m32);
temp.m33 = invDet * (m11 * m22 - m12 * m21);

return temp.Multiply(invDet);

From Engine/Math/Matrix3x3.h, Matrix3x3::Inverse() — the tail

The returned matrix is therefore the adjugate over det², not over det. For a rotation matrix (determinant 1) the two coincide and the result is correct; for any other matrix the result is off by a factor of 1/det. Read IsInvertible and the determinant before trusting the result on non-rotation input.
