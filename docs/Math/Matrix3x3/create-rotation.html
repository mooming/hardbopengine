CreateRotation

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h a rotation matrix from Euler angles in degrees

Signature

[[nodiscard]] static This CreateRotation(float x, float y, float z) noexcept

[[nodiscard]] static This CreateRotation(const TVec euler) noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::CreateRotation(). Two static overloads — three floats or a Vector3 of angles, both in degrees. Each builds an uninitialized matrix and hands it to SetEulerAngles, which writes all nine elements, so the result is fully initialized. The angles are converted with DegreeToRadian inside the setter; the factory takes no radians anywhere.
