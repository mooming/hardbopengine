Column

member of hbe::Matrix3x3 Engine/Math/MatrixCommonImpl.inl one column of the matrix, gathered into a vector

Signature

[[nodiscard]] TVec Column(int index) const noexcept

Function description

Defined in Engine/Math/MatrixCommonImpl.inl as Matrix3x3::Column(); the file is included into the class body, so this is a member of every matrix class, not a free function. Asserts index < column (Assert, compiled out of Release builds) and gathers colVec.a[i] = rows[i].a[index] — entry i of column index — into a vector built through the nullptr constructor, i.e. uninitialized before the loop fills it. The row counterpart needs no member: rows[i] is already a vector.

Parameters

ParameterTypeRequirement
indexintThe column to gather; must be within [0, column).

Return value
