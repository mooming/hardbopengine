SetEulerAngles

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h full Euler rotation from degrees, overwriting the 3x3 block

Signature

void SetEulerAngles(const TVec& euler) noexcept

void SetEulerAngles(float x, float y, float z) noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::SetEulerAngles(). Two overloads — three floats or a Vector3, both in degrees, each converted with DegreeToRadian before the trig. The nine-element formula writes every entry of the 3-by-3 block (a standard yaw-pitch-roll composition), so the block is fully replaced; nothing else of the matrix exists to touch. This is the setter CreateRotation delegates to, and the one z rotation path whose m33 is written correctly — see SetEulerZ.
