Determinant

member of hbe::Matrix3x3 Engine/Math/Matrix3x3.h the full 3-by-3 cofactor expansion

Signature

[[nodiscard]] TNumber Determinant() const noexcept

Function description

Defined in Engine/Math/Matrix3x3.h as Matrix3x3::Determinant(). The six-term expansion over the float named elements:

return m11 * m22 * m33 + m12 * m23 * m31 + m13 * m21 * m32 - m11 * m23 * m32 - m12 * m21 * m33 -
	   m13 * m22 * m31;

From Engine/Math/Matrix3x3.h, Matrix3x3::Determinant()

It is the value IsInvertible tests and Inverse divides by.
