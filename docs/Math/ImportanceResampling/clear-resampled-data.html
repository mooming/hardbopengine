ClearResampledData

member of hbe::ImportanceResampling Engine/Math/ImportanceResampling.h empty the stores, keep the buffers

Signature

void ClearResampledData() noexcept

Function description

Defined in Engine/Math/ImportanceResampling.h as ImportanceResampling::ClearResampledData(). Sets totalWeight = 0 and calls clear() on all three vectors — contents destroyed, capacity kept. The fixture calls it between passes so a new Resample starts from an empty history without reallocating.

Parameters

None.

Return value

None; the emptied state lands in *this.
