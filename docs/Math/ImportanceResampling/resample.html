Resample

member of hbe::ImportanceResampling Engine/Math/ImportanceResampling.h draw, weight by norm(f/p), accumulate — the stage that fills the stores

Signature

template <typename TFunction, typename TPDF, typename TRandomSampler, typename TOutputNorm>
	[[nodiscard]] bool Resample(const TFunction& f, const TPDF& p, const TRandomSampler& sampler,
								const TOutputNorm& norm, const TInteger numSourceSamples) noexcept

Function description

Defined in Engine/Math/ImportanceResampling.h as ImportanceResampling::Resample(). Returns false immediately for a non-positive numSourceSamples. Each iteration draws x = sampler(), evaluates the source density — p_x <= 0 fails the whole call — computes weight = norm(f(x) / p(x)), and skips the sample when the weight is not positive (continueIf). Accepted samples append to weights and samples. When the accepted weight sum is zero the call returns false; otherwise totalWeight grows by it and the entire normalizedWeights vector is recomputed — every stored weight scaled by numSamples / totalWeight, over the accumulated history of all Resample calls, not just this one. The fixture runs it before every Integrate pass.
