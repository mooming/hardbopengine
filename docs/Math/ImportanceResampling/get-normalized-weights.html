GetNormalizedWeights

member of hbe::ImportanceResampling Engine/Math/ImportanceResampling.h the discrete PDF Integrate samples, by const reference

Signature

[[nodiscard]] auto& GetNormalizedWeights() const noexcept

Function description

Defined in Engine/Math/ImportanceResampling.h as ImportanceResampling::GetNormalizedWeights(). Returns normalizedWeights — each raw weight scaled by numSamples / totalWeight, recomputed over the whole accumulated history at the end of every successful Resample. The sum approaches 1 as the history grows; Integrate draws indices into exactly this vector.
