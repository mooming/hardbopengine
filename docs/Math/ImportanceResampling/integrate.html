Integrate

member of hbe::ImportanceResampling Engine/Math/ImportanceResampling.h pick, perturb, average — the estimate from the resampled stores

Signature

template <typename TFunction, typename TDiscreteSampler, typename TUniformSampler>
	[[nodiscard]] bool Integrate(TOutput& result, const TFunction& f, const TDiscreteSampler& discreteSampler,
								 const TUniformSampler& uniformSampler, const TInteger numIterations) noexcept

Function description

Defined in Engine/Math/ImportanceResampling.h as ImportanceResampling::Integrate(). Zeros result, then fails — through returnValueIf — for a non-positive iteration count, a null f, or empty stores. Each iteration draws an index from discreteSampler(), reads the normalized weight q_x = normalizedWeights[chosenIndex] — a non-positive one fails the call — perturbs the stored sample by delta = uniformSampler(), and accumulates f(x + delta) / q_x. Finally result /= numIterations and the member returns true.

The f == nullptr guard is a function-pointer idiom. A captureless lambda converts to a function pointer, so the comparison compiles and is always false — the fixture's callables are captureless. A capturing callable does not convert, and a call with one does not compile; a probe reports invalid operands to binary expression ('const (lambda at …)' and 'std::nullptr_t').
