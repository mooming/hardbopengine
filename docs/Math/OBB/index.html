OBB

Engine/Math/OBB.h an oriented bounding box: center, half-extents and a rotation quaternion

Class description

OBB is an oriented bounding box: a center point, half-extents along the box's own axes, and a rotation quaternion orienting those axes. It is the tighter cousin of AABB for anything that turns — the same volume, plus a rotation — and it is built around one convention the parameter names make easy to miss: the query methods take a point, subtract the center, and apply the inverse rotation, so the caller passes the point in the space the box lives in and the members work in the box's local frame.

Two absences a caller must know. HasIntersection is a stub that always returns false — no intersection test exists yet. And Closest rounds-trips through two private conversions that are not inverses of each other: ToObjectSpace subtracts the center where the inverse of ToOBBSpace would add it, so for a box with a non-zero center the returned point is displaced by -2 * center. Both are stated on their pages with the code quoted.
