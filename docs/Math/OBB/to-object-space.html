ToObjectSpace

member of hbe::OBB Engine/Math/OBB.h out of the box's local frame — rotate, then subtract the center

Signature

[[nodiscard]] TVec3 ToObjectSpace(const TVec3& obbSpacePoint) const noexcept

Function description

%s The private conversion back:

auto point = rotation * obbSpacePoint;
point -= center;

return point;

From Engine/Math/OBB.h, OBB::ToObjectSpace()

It rotates first and then subtracts the center — where the true inverse of ToOBBSpace would add the center. See Closest for what that asymmetry does to the round trip.

Parameters

ParameterTypeRequirement
obbSpacePointconst TVec3&A point on the box's axes, relative to the center.

Return value

TypeWhat you get
TVec3The rotated point with the center subtracted — not, for a non-zero center, the point ToOBBSpace was fed.
