ToOBBSpace

member of hbe::OBB Engine/Math/OBB.h into the box's local frame: subtract the center, unrotate

Signature

[[nodiscard]] TVec3 ToOBBSpace(const TVec3& objSpacePoint) const noexcept

Function description

%s The private conversion every query runs first:

auto point = objSpacePoint - center;
point = rotation.Inverse() * point;

return point;

From Engine/Math/OBB.h, OBB::ToOBBSpace()

The result is the query expressed on the box's own axes, relative to its center — the frame IsContaining and Closest compare against half. rotation.Inverse() asserts unit length in Debug and Dev, per Quaternion::Invert.
