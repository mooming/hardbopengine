Defined in Engine/Math/OBB.h as OBB::HasIntersection(). The body is a single return false;. The parameters name an OBB, a position and a rotation, but nothing is computed: no OBB-OBB intersection test exists yet. A caller relying on this member gets "no intersection" for every input, including two boxes occupying the same space.
