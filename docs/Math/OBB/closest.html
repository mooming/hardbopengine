Closest

member of hbe::OBB Engine/Math/OBB.h the nearest point of the box — displaced by -2*center for non-zero centers

Signature

[[nodiscard]] TVec3 Closest(const TVec3& objSpacePoint) const noexcept

Function description

%s Converts the query with ToOBBSpace, clamps each axis into [-h, h] with ClampFast, and converts back with ToObjectSpace:

auto point = rotation * obbSpacePoint;
point -= center;

return point;

From Engine/Math/OBB.h, OBB::ToObjectSpace() — the conversion back

The inverse of ToOBBSpace (which computes rotation.Inverse() * (point - center)) would add the center after rotating; ToObjectSpace subtracts it. The round trip therefore yields point - 2 * center instead of point: for a box centered at the origin the member is correct, and for any other center the returned point is displaced by -2 * center. The clamp itself — the [-h, h] per-axis clamp in OBB space — is computed correctly.
