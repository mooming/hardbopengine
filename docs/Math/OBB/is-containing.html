IsContaining

member of hbe::OBB Engine/Math/OBB.h exact per-axis containment in the box's local frame

Signature

[[nodiscard]] bool IsContaining(const TVec3& objSpacePoint) const noexcept

Function description

Defined in Engine/Math/OBB.h as OBB::IsContaining(). Converts the query with ToOBBSpace — subtract the center, apply the inverse rotation — then returns false at the first axis where Abs(point.x) > half.x (and the y, z counterparts). Exact comparisons, no epsilon: a point exactly on a face counts as contained. The conversion is the whole contract — pass the point in the space the box's center and rotation are expressed in, or the answer is about a different box.
