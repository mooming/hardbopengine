StratifiedSampling

Engine/Math/StratifiedSampling.h an interval split into strata: one draw per stratum, advanced and wrapped by ChangeSubGroup

Class description

StratifiedSampling splits an interval into numSubGroups equal strata and hands out one stratum at a time: Sample computes the sub-range for the current subgroup index and passes its two ends to a caller-supplied range sampler, and ChangeSubGroup advances — wrapping to the first subgroup when it runs off either end. The engine's rendering tests use it to spread sample positions evenly before an integration pass, one subgroup per iteration.

The strata are fixed at construction: interval = (end - start) / numSubGroups, with the subgroup count clamped to at least 1. Nothing recomputes them afterwards, and nothing validates that start is below end — a reversed interval produces negative-width strata and the class computes on regardless.
