Sample

member of hbe::StratifiedSampling Engine/Math/StratifiedSampling.h one draw from the current stratum

Signature

template <typename TRangeSampler>
	[[nodiscard]] TReal Sample(const TRangeSampler& sampler) noexcept

Function description

Defined in Engine/Math/StratifiedSampling.h as StratifiedSampling::Sample(). Computes rangeStart = start + interval * subGroupIndex and rangeEnd = rangeStart + interval, then returns sampler(rangeStart, rangeEnd). The sampler's contract, as the header states it: TReal sampler(TReal rangeStart, TReal rangeEnd), returning a random number within the given range — the class supplies the stratum, the caller supplies the randomness. No bounds check runs: with the default-constructed state, both ends are 0.
