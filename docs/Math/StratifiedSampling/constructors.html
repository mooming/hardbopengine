Function description

Defined in Engine/Math/StratifiedSampling.h as StratifiedSampling::StratifiedSampling(). Two constructors. The default form zero-initializes everything — numSubGroups 0, interval 0 — so sampling from it hands the sampler zero-width ranges. The sized form clamps inNumSubGroups to at least 1, computes interval = (end - start) / numSubGroups once, and starts at subgroup 0. Nothing validates start < end; a reversed interval produces negative-width strata.
