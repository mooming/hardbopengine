ChangeSubGroup

member of hbe::StratifiedSampling Engine/Math/StratifiedSampling.h advance to the next stratum, wrapping at both ends

Signature

void ChangeSubGroup(TInteger delta = 1) noexcept

Function description

Defined in Engine/Math/StratifiedSampling.h as StratifiedSampling::ChangeSubGroup(). Adds delta (default 1) to subGroupIndex, then resets it to 0 when it has run past the last subgroup or before the first — subGroupIndex <= 0 || subGroupIndex >= numSubGroups. Negative deltas therefore wrap around too, and a delta that jumps past the end lands on 0, not on the overflowed position.

Parameters

ParameterTypeRequirement
deltaTIntegerThe step; defaults to 1; may be negative.

Return value

None; the new stratum index lands in the object.
