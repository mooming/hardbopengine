At

member of hbe::PerlinNoise Engine/Math/PerlinNoise.h the double-permutation lookup p[p[p[x] + y] + z]

Signature

[[nodiscard]] TUInt At(TUInt x, TUInt y, TUInt z) const noexcept

Function description

Defined in Engine/Math/PerlinNoise.h as PerlinNoise::At(). Indexes the doubled table three times. The caller masks the coordinates with permutationMask and offsets by 1 before calling, so the intermediate sums stay inside the table without a mask here — that is what the doubling pass in the constructor buys.
