PerlinNoise

Engine/Math/PerlinNoise.h deterministic 3D gradient noise with fractal Brownian motion, seeded by a specified shuffle

Class description

PerlinNoise is deterministic 3D gradient noise — Ken Perlin's "improved noise" — with fractal Brownian motion on top. The permutation table is shuffled by an explicitly specified generator: a golden-ratio counter fed through the Murmur3 finalizer, driving a hand-written Fisher-Yates pass over the 256 entries. Nothing uses std::shuffle, whose algorithm the standard leaves unspecified — a voxel terrain generated from a seed has to come out identical on every platform and compiler, and the Noise Determinism test pins that: same seed, identical field; different seed, different field.

Two properties are load bearing and pinned by unit tests:

PropertyWhat the tests pin
Zero at the lattice Noise is exactly 0.0f at every integer coordinate — the Lattice Zeros test walks a 9×9×9 block around the origin and demands not one non-zero value
Bounded output Noise never leaves [-1, 1]; the true bound is about ±0.87. The Range Bounds test samples negative coordinates and coordinates past the table period and demands finite values within the bound — for Noise and Fbm alike

A third test pins Noise's continuity — the largest single-step jump over 2000 steps of 0.02 must stay small, which is what catches a wrong fade or a seam at the table period.

Template parameters

PerlinNoise is not a template. Its scalars are the engine-wide typedefs from Core/Types.h: TUInt, TByte and TReal.

Class properties

Type + NameDefault ValueDescription
static constexpr TUInt permutationMask = 255; public 255 The table period — coordinates are masked with it, and it sizes the table.
TUInt seed = 0; private 0 The seed the instance was built with; GetSeed reports it and nothing else reads it.
TUInt randomState = 0; private 0 The generator's counter, seeded from seed and consumed by the shuffle — kept separate so GetSeed stays reportable while shuffling consumes state.
std::array<TByte, (permutationMask + 1) * 2> p = {}; private {} The doubled permutation table: 512 bytes. Only the low half is shuffled; the high half repeats it so At's lookups never need a mask.

Fadeprivate static TReal Fade(TReal t) noexcept The quintic fade t³(t(6t−15)+10) — what makes the lattice zeros exact and the field C1 continuous.
Lerpprivate static TReal Lerp(TReal t, TReal a, TReal b) noexcept a + t * (b - a) — the scalar blend the corner interpolation is built from; unrelated to the vector classes' Lerp.

Non-member helper functions

None. PerlinNoise.h declares the class and, under TEST_ENABLED, the test collection — nothing at namespace scope in between.
