Fbm

member of hbe::PerlinNoise Engine/Math/PerlinNoise.cpp fractal Brownian motion — octaves of Noise, normalized by the summed amplitude

Signature

[[nodiscard]] TReal Fbm(TReal x, TReal y, TReal z, TUInt octaves, TReal frequency = 1.0f, TReal lacunarity = 2.0f,
							TReal gain = 0.5f) const noexcept

Function description

Defined in Engine/Math/PerlinNoise.cpp as PerlinNoise::Fbm(). Sums amplitude * Noise(x·freq, y·freq, z·freq) over octaves iterations, multiplying freq by lacunarity and amplitude by gain each octave, then divides by the summed amplitude. The normalization is the contract: the return stays inside a single Noise call's range no matter how many octaves — the Fbm Normalisation test pins it for octaves 1 through 6 — and zero octaves returns 0.0f (the normalisation is zero, and the guard returns zero rather than dividing by it).

Parameters

octavesTUIntOctave count; zero returns zero.
frequencyTRealFirst octave's frequency; defaults to 1.

gainTRealAmplitude multiplier per octave; defaults to 0.5.

Return value

Examples
