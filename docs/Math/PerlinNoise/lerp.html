Lerp

member of hbe::PerlinNoise Engine/Math/PerlinNoise.h the scalar blend a + t(b − a)

Signature

[[nodiscard]] static TReal Lerp(TReal t, TReal a, TReal b) noexcept

Function description

Defined in Engine/Math/PerlinNoise.h as PerlinNoise::Lerp(). The private scalar interpolation the corner blending runs on. Despite the shared name, it is unrelated to the vector classes' Lerp — this one blends two scalars by a weight.

Parameters

a, bTRealThe endpoints.
