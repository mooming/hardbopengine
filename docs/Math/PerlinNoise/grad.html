Grad

member of hbe::PerlinNoise Engine/Math/PerlinNoise.cpp Perlin's reference gradient selection, over hash & 15

Signature

static TReal Grad(TUInt hash, TReal x, TReal y, TReal z) noexcept

Function description

Defined in Engine/Math/PerlinNoise.cpp as PerlinNoise::Grad(). A sixteen-case selection over hash & 15, returning one of the axis-pair combinations ±x ± y, ±x ± z, ±y ± z, y + x and y - x — Ken Perlin's reference implementation for "improved noise", including its own duplicated cases (13 and 15 repeat 5 and 7's forms). The hash comes from At; the offsets are the fractional parts the corners see.

Parameters

ParameterTypeRequirement
hashTUIntThe permutation lookup; only the low four bits matter.
x, y, zTRealThe corner-relative offsets.

Return value

TypeWhat you get
TRealThe gradient dot product for that corner.

Examples

const TReal n000 = Grad(At(X, Y, Z), fx, fy, fz);
const TReal n100 = Grad(At(X + 1, Y, Z), fx - 1.0, fy, fz);
