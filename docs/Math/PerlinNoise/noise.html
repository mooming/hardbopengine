Noise

member of hbe::PerlinNoise Engine/Math/PerlinNoise.cpp the noise value at a point — zero on the lattice, bounded to [-1, 1]

Signature

[[nodiscard]] TReal Noise(TReal x, TReal y, TReal z) const noexcept

Function description

Defined in Engine/Math/PerlinNoise.cpp as PerlinNoise::Noise(). Floors the coordinates to find the cell, masks the cell indices into the table — casting through TInt before masking, so negative coordinates wrap instead of truncating toward zero — and blends the eight corner gradients with the quintic Fade and scalar Lerp. Two properties are pinned by tests: the value is exactly 0.0f at every integer coordinate (all eight corner blends cancel), and it never leaves [-1, 1] — the true bound is about ±0.87. Negative coordinates and coordinates past the table period are sampled by the Range Bounds test on purpose, since they are table-indexing traps.
