NextRandom

member of hbe::PerlinNoise Engine/Math/PerlinNoise.cpp the golden-ratio counter plus Murmur3 finalizer

Signature

TUInt NextRandom() noexcept

Function description

Defined in Engine/Math/PerlinNoise.cpp as PerlinNoise::NextRandom(). Advances randomState by the golden-ratio constant 0x9E3779B9, then mixes it through the Murmur3 finalizer — two multiply-xor rounds with 0x85EBCA6B and 0xC2B2AE35 — and returns the final xor-shift. Every step is specified arithmetic, not a library call, which is what makes the shuffle — and therefore the noise field — identical on every platform and compiler. Non-const: it advances the state.

None.

Return value
