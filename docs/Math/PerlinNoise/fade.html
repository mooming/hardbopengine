Fade

member of hbe::PerlinNoise Engine/Math/PerlinNoise.h the quintic fade t³(t(6t−15)+10)

Signature

[[nodiscard]] static TReal Fade(TReal t) noexcept

Function description

Defined in Engine/Math/PerlinNoise.h as PerlinNoise::Fade(). The interpolation weight Ken Perlin's improved noise is built on: zero slope and curvature at both ends of [0, 1], which is what makes the lattice zeros exact and the field C1 continuous — the Continuity test watches for exactly the jump a wrong fade would produce.
