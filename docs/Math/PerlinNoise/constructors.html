member of hbe::PerlinNoise Engine/Math/PerlinNoise.cpp the permutation table, built deterministically from the seed

Signature

explicit PerlinNoise(TUInt seed = 0) noexcept

Function description

Defined in Engine/Math/PerlinNoise.cpp as PerlinNoise::PerlinNoise(). Initializes seed and randomState from the argument, fills p[0..255] with the identity, runs a Fisher-Yates shuffle over the low half — drawing each swap index from NextRandom — and then copies the low half into the high half, so At's lookups never need a mask. The shuffle consumes randomState but never seed, which is why GetSeed keeps reporting the construction seed.
