IsOrthogonal

member of hbe::Matrix2x2 Engine/Math/Matrix2x2.h rows mutually orthogonal and each unit length

Signature

[[nodiscard]] bool IsOrthogonal() const noexcept

Function description

Defined in Engine/Math/Matrix2x2.h as Matrix2x2::IsOrthogonal(). Returns IsZero(rows[0].Dot(rows[1])) && rows[0].IsUnity() && rows[1].IsUnity() — the two rows must be perpendicular and both unit length, all through the vector class's tolerance tests. This is the precondition the Quaternion matrix constructor asserts before converting a matrix.

Parameters

None.

Return value

TypeWhat you get
booltrue when the rows form an orthonormal basis.
