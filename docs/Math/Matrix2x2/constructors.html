Function description

Three constructors. The default form is the identity — element{1, 0, 0, 1} — which is what the Identity constant is defined as and what the shared CreateDiagonal starts from. The nullptr form is explicit and initializes nothing; the shared implementation builds result matrices through it (This result(nullptr)) before filling every element. The array form is explicit and takes four elements in row-major order via std::move.
