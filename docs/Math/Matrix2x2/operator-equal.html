operator==

member of hbe::Matrix2x2 Engine/Math/MatrixCommonImpl.inl per-row tolerance equality, inherited from the vector class

Signature

[[nodiscard]] bool operator==(const This& rhs) const noexcept

Function description

Defined in Engine/Math/MatrixCommonImpl.inl as Matrix2x2::operator==(); the file is included into the class body, so this is a member of every matrix class, not a free function. Walks the rows and returns false at the first row where rows[i] != rhs.rows[i]. The comparison is the vector class's operator== — a tolerance test within Epsilon, not bitwise equality.
