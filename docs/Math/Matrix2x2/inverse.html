Inverse

member of hbe::Matrix2x2 Engine/Math/Matrix2x2.h the adjugate over the determinant, terminating on a singular matrix

Signature

[[nodiscard]] This Inverse() const noexcept

Function description

Defined in Engine/Math/Matrix2x2.h as Matrix2x2::Inverse(). Computes det = Determinant(), FatalAsserts that it is non-zero — a check that fires in every build and terminates rather than unwinds — then fills the result with the adjugate scaled by 1/det:

result.m11 = invDet * m22;
result.m22 = invDet * m11;
result.m12 = -invDet * m12;
result.m21 = -invDet * m21;

From Engine/Math/Matrix2x2.h, Matrix2x2::Inverse()

The reads and writes go through the float named elements; for the engine's TFloat2x2 that is the same storage as m[2][2]. Check IsInvertible first when a singular matrix is a possible input — Inverse itself does not return a failure, it stops the program.

Parameters

None.

Return value

TypeWhat you get
ThisThe inverse; m * m.Inverse() is the identity within float rounding.

Illustrative — no call site for this method exists in the repository.
