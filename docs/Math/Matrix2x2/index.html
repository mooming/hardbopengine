Matrix2x2

Engine/Math/Matrix2x2.h a 2-by-2 row-major matrix: identity by default, shared matrix arithmetic, and its own inverse, determinant and transpose

Class description

Matrix2x2 is a fixed 2-by-2 matrix stored row-major: rows[row] of Vector2, aliased with a TNumber m[2][2] array, a flat std::array, and named elements m11…m22. The shared arithmetic lives in Engine/Math/MatrixCommonImpl.inl, included into the class body and shared with Matrix3x3 and Matrix4x4; the class adds the 2-by-2 inverse, determinant, orthogonality test, and an in-place transpose.

The default constructor is the identity — element{1, 0, 0, 1} — which is why Identity is defined as a default-constructed matrix and why the shared CreateDiagonal can start from one. Vectors sit on the right of operator* and are applied as column vectors: result.a[i] = rows[i].Dot(v).

The named elements are float, whatever TNumber is. The union's struct arm declares float m11, m12, m21, m22; — untemplated. For Matrix2x2<float> (the only instantiation the engine builds) this is the same storage as m[2][2]; for any wider TNumber the names would read 32-bit slices of 64-bit elements. Inverse() and Determinant() compute through these names.

Coverage

GapDetail
Shared-implementation methods documented from the .inl Every method above except constructors, Inverse, Transpse, Determinant and IsOrthogonal is declared in Engine/Math/MatrixCommonImpl.inl, included into the class body. Their pages cite the .inl as the definition site; docs_pass.py signatures verifies them against a header with the .inl inlined, because the checker reads the .h alone.
No caller, no test fixture Matrix2x2.h is included by Matrix3x3.h and Matrix4x4.h, and Matrix2x2.cpp only instantiates Matrix2x2<float>. The header declares no test collection and no code in Engine/ or Applications/ outside Engine/Math/ uses the type. Every example on the method pages is therefore illustrative.
The Transpse spelling The header declares the in-place transpose as Transpse — as written. The correctly spelled Transposed() comes from the shared implementation and returns a copy; there is no in-place Transpose() on this class.
