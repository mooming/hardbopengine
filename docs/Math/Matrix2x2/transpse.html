Transpse

member of hbe::Matrix2x2 Engine/Math/Matrix2x2.h the in-place transpose, spelled as declared

Signature

void Transpse() noexcept

Function description

Defined in Engine/Math/Matrix2x2.h as Matrix2x2::Transpse() — the declared spelling, without the second o. It swaps m12 and m21 and returns nothing. The copy-returning transpose is the shared Transposed; there is no correctly-spelled in-place Transpose() on this class, unlike Matrix3x3 and Matrix4x4.

Parameters

None.

Return value

None; the transpose lands in *this.

Examples

Illustrative — no call site for this method exists in the repository.

m.Transpse();  // m12 and m21 exchanged, in place
