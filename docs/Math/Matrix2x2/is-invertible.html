IsInvertible

member of hbe::Matrix2x2 Engine/Math/MatrixCommonImpl.inl true when the matrix is square with a non-zero determinant

Signature

[[nodiscard]] bool IsInvertible() const noexcept

Function description

Defined in Engine/Math/MatrixCommonImpl.inl as Matrix2x2::IsInvertible(); the file is included into the class body, so this is a member of every matrix class, not a free function. Returns (row == column) && Determinant() != 0. Every matrix in this module is square, so the test is the determinant — an exact != 0, with no tolerance: a matrix whose determinant is 1e-30f counts as invertible and Inverse will divide by it.

None.
