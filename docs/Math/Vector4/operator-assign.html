operator=

member of hbe::Vector4 Engine/Math/Vector4.h copies a Vector2 or Vector3 into the leading components, leaving the rest

Signature

This& operator=(const TVec2& v) noexcept

This& operator=(const TVec3& v) noexcept

Function description

Defined in Engine/Math/Vector4.h. Two overloads. From a Vector2: assigns x and y. From a Vector3: assigns x, y and z. Neither writes w — it keeps whatever value it had, which is the difference from constructing Vector4(v), where w becomes 1.

Parameters

ParameterTypeRequirement
vconst TVec2& or const TVec3&The source of the leading components.

Return value

TypeWhat you get
This&*this, with the trailing components unchanged.
