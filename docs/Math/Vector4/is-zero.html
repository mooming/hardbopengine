IsZero

member of hbe::Vector4 Engine/Math/VectorCommonImpl.inl true when the sum of absolute components is below Epsilon

Signature

[[nodiscard]] bool IsZero() const noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector4::IsZero(); the file is included into the class body, so this is a member of every vector class, not a free function. Accumulates Abs(a[i]) over every component and compares the total against Epsilon. This is a tolerance test, not an exact one: a vector whose components cancel is still not zero here, because the absolute values are summed — and conversely a vector of very small non-zero components is zero. operator== is built on it.
