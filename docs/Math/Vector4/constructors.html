Function description

Five constructors. The default form delegates to This(0, 0, 0, 0), so a default-constructed vector is the zero vector — the Vector4Test fixture asserts it. The nullptr form is explicit and initializes nothing: the shared implementation builds result vectors through it, and a caller who uses it gets indeterminate components. Every remaining form defaults w to 1: the component form takes (x, y, z = 0, w = 1), the Vector2 form (v, z = 0, w = 1), and the Vector3 form (v, w = 1). Constructing from a three-component vector therefore produces a point, not a direction — pass w explicitly to change that.
