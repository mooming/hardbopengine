Normalize

member of hbe::Vector4 Engine/Math/VectorCommonImpl.inl scales the vector to unit length, in place, and returns the length it had

Signature

float Normalize() noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector4::Normalize(); the file is included into the class body, so this is a member of every vector class, not a free function. Divides every component by Length(). A vector whose length is zero is not left alone and not divided by zero: it is replaced by This::Forward (for Vector4, Forward is the handedness-dependent axis listed among the class constants — (0, 1, 0, 1) in the default right-handed build) and 0.0f is returned. Not const — it rewrites the vector it is called on; the non-mutating form is Normalized.

Parameters

None.

Return value

TypeWhat you get
floatThe length the vector had before the call — 0.0f in the degenerate case where the vector became Forward.
