Slerp

member of hbe::Vector4 Engine/Math/VectorCommonImpl.inl spherical interpolation of direction with linear interpolation of length

Signature

[[nodiscard]] static This Slerp(const This& from, const This& to, float t) noexcept

[[nodiscard]] This Slerp(const This& to, float t) const noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector4::Slerp(); the file is included into the class body, so this is a member of every vector class, not a free function. Normalizes both endpoints, takes angle = acosf(a.Dot(b)), and when the angle is below Epsilon falls back to Lerp of the originals, re-normalized. Otherwise the returned direction is the spherical blend (a * sin((1-t)·angle) + b * sin(t·angle)) / sin(angle) and the returned length is the linear blend of the original lengths. Unlike Quaternion::Slerp, magnitude survives.
