From Engine/Math/Vector4.h, Vector4 conversion operators

No copy is made and no conversion runs: the alias shares the vector's storage, valid because the components are the first members of the union's struct arm. None of the four is explicit, unlike Vector3's pair — a Vector4 converts to a Vector2& or Vector3& wherever the type is wanted, silently dropping z or z/w from the view. The Signature section shows the first one; the other three are quoted here because the signature checker groups the family under the one name it can resolve.

Parameters

None; the conversion applies to the object it is written on.

Return value

TypeWhat you get
TVec2&, const TVec2&, TVec3& or const TVec3&A reference aliasing the leading components; writes through it land in the vector.
