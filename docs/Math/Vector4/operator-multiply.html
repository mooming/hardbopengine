Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector4::operator*(); the file is included into the class body, so this is a member of every vector class, not a free function. Two overloads. The scalar form multiplies every component by rhs; the vector form multiplies component by component (a Hadamard product — for the dot product use Dot). Neither mutates the operands.
