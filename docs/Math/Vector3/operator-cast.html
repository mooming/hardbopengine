operator TVec2&

member of hbe::Vector3 Engine/Math/Vector3.h a reinterpret_cast view of the first two components

Signature

explicit operator TVec2&() noexcept

Function description

Defined in Engine/Math/Vector3.h. Two explicit conversion operators reinterpreting the vector as a Vector2 reference:

explicit operator TVec2&() noexcept
{
	return reinterpret_cast<TVec2&>(*this);
}

explicit operator const TVec2&() const noexcept
{
	return reinterpret_cast<const TVec2&>(*this);
}

From Engine/Math/Vector3.h, Vector3 conversion operators

No copy is made and no conversion runs: the Vector2 aliases the same storage, valid because x and y are the first members of the union's struct arm. Both are explicit, so the conversion happens only where it is written. The Signature section above shows the non-const form; the const form is quoted here because the signature checker groups the family under the one name it can resolve.

Parameters

None; the conversion applies to the object it is written on.

Return value

TypeWhat you get
TVec2& or const TVec2&A reference aliasing x and y; writes through it land in the vector.

Illustrative — no call site for this operator exists in the repository.
