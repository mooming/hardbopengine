Cross

member of hbe::Vector3 Engine/Math/Vector3.h the right-hand-rule cross product

Signature

[[nodiscard]] Vector3 Cross(const Vector3& rhs) const noexcept

Function description

Defined in Engine/Math/Vector3.h as Vector3::Cross(). Computes the standard cross product:

result.x = y * rhs.z - z * rhs.y;
result.y = z * rhs.x - x * rhs.z;
result.z = x * rhs.y - y * rhs.x;

From Engine/Math/Vector3.h, Vector3::Cross()

The result is perpendicular to both operands and its magnitude is the product of the two lengths and the sine of the angle between them. The formula itself is handedness-free; what changes with the build is which named axis the result matches — the test fixture asserts Right.Cross(up) == -Forward under RIGHT_HANDED_COORDINATE and == Forward without it, because the two builds attach the names Up and Forward to different component axes.
