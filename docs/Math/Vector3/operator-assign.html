Module Index / Math / Vector3 / operator=

operator=

member of hbe::Vector3 Engine/Math/Vector3.h copies a Vector2 into x and y, leaving z as it was

Signature

This& operator=(const TVec2& v) noexcept

Function description

Defined in Engine/Math/Vector3.h as Vector3::operator=(const TVec2&). Assigns x = v.x and y = v.y and returns *this. z is not written: it keeps whatever value it had, which is the difference from constructing Vector3(v), where z becomes 0.
