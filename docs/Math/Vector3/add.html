Add

member of hbe::Vector3 Engine/Math/VectorCommonImpl.inl componentwise addition, in place

Signature

void Add(const This& rhs) noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector3::Add(); the file is included into the class body, so this is a member of every vector class, not a free function. Adds rhs component by component into this vector. Nothing is asserted and nothing is allocated; the in-place core that operator+ and operator+= both route through.

Parameters

rhsconst This&The addend. May be the vector itself.

Return value

None; the sum lands in *this.
