AngleTo

member of hbe::Vector3 Engine/Math/Vector3.h the angle between two vectors, in radians, as float

Signature

[[nodiscard]] float AngleTo(const Vector3& to) const noexcept

Function description

Defined in Engine/Math/Vector3.h as Vector3::AngleTo(). Both operands are asserted non-zero (Assert, compiled out of Release builds), then the result is std::acos(Dot(to) / sqrt(SqrLength() * to.SqrLength())) as a float — the angle in radians, in [0, π]. The asserts are the only guard: with a zero operand in Release, the division feeds std::acos a value outside its domain and the result is NaN.
