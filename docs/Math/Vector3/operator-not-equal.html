operator!=

member of hbe::Vector3 Engine/Math/VectorCommonImpl.inl the negation of the tolerance equality

Signature

[[nodiscard]] bool operator!=(const This& rhs) const noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector3::operator!=(); the file is included into the class body, so this is a member of every vector class, not a free function. Returns !(*this == rhs), so it inherits the Epsilon tolerance of operator==: vectors differing by less than the tolerance compare equal, and this operator reports false for them.
