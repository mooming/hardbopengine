Vector3

Engine/Math/Vector3.h a three-component vector: the shared vector arithmetic plus cross product, angles, and a reinterpret view of its first two components

Class description

Vector3 is the fixed-size three-component vector: x, y, z in an anonymous union with a raw array a[3]. It shares Engine/Math/VectorCommonImpl.inl with Vector2 and Vector4 — included into the class body, so the arithmetic is one implementation stamped three times — and adds what only three dimensions can have: the Cross product and the angle between vectors, AngleTo. It also narrows: an explicit conversion reinterprets a Vector3 as a Vector2, and operator= copies a Vector2's x and y in while leaving z as it was.

The named axes are a build decision, not a constant: Right, Up and Forward are defined in two #ifdef branches, and Engine/Config/BuildConfig.h defines RIGHT_HANDED_COORDINATE by default — so in this build Forward is (0, 1, 0) and Up is (0, 0, 1), while X, Y, Z stay the component axes in every build.

Coverage

GapDetail
Shared-implementation methods documented from the .inl Every method above except constructors, Cross, AngleTo, operator= and the conversion operator is declared in Engine/Math/VectorCommonImpl.inl, included into the class body. Their pages cite the .inl as the definition site; docs_pass.py signatures verifies them against a header with the .inl inlined, because the checker reads the .h alone.
Handedness is a build property The Right/Up/Forward definitions exist in two #ifdef branches. Both are stated in the property table; the module page's CoordinateOrientation section carries the build-level decision. The branch compiled here is the right-handed one, the BuildConfig.h default.
Callers outside the module Engine/Renderer/Vertex.h stores a Vector3<float> position. Otherwise the class is exercised by the Vector3Test fixture in Engine/Math/Vector3.cpp, which the examples quote where they are real.
Vector3Test Declared under TEST_ENABLED, defined in Vector3.cpp; a test fixture, not engine API.
