Lerp

member of hbe::Vector3 Engine/Math/VectorCommonImpl.inl linear interpolation between two vectors

Signature

[[nodiscard]] static This Lerp(const This& from, const This& to, float t) noexcept

[[nodiscard]] This Lerp(const This& to, float t) const noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector3::Lerp(); the file is included into the class body, so this is a member of every vector class, not a free function. Two forms of one computation, from * (1.0f - t) + to * t: the static form takes both endpoints, the member form interpolates from *this toward to. t is float regardless of TNumber and is not clamped — values outside [0, 1] extrapolate. t = 0 reproduces from, t = 1 reproduces to.
