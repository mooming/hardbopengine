Divide

member of hbe::Vector3 Engine/Math/VectorCommonImpl.inl componentwise division, in place, guarded per component

Signature

void Divide(const This& rhs) noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector3::Divide(); the file is included into the class body, so this is a member of every vector class, not a free function. Divides each component of this vector by the matching component of rhs. Every component is checked before it is used: Assert(!hbe::IsZero(static_cast<float>(rhs.a[i]))) fires, per component, when a divisor is zero — and Assert is compiled out of Release builds, where a zero divisor divides anyway. No scalar form exists here; scalar division is operator/ and operator/=.

Parameters

ParameterTypeRequirement
rhsconst This&Per-component divisors; every component should be non-zero.

Return value

None; the quotient lands in *this.
