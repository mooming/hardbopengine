Dot

member of hbe::Vector3 Engine/Math/VectorCommonImpl.inl the sum of the componentwise products

Signature

[[nodiscard]] TNumber Dot(const This& rhs) const noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector3::Dot(); the file is included into the class body, so this is a member of every vector class, not a free function. Returns a[0]*rhs.a[0] + … + a[order-1]*rhs.a[order-1] as a TNumber. The building block of SqrLength and, on Vector3, of Cross and AngleTo.

Parameters

ParameterTypeRequirement
rhsconst This&The other operand. May be the vector itself.

Return value

TypeWhat you get
TNumberThe dot product. Zero for perpendicular inputs, the squared length when rhs is *this.
