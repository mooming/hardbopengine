Function description

Five constructors. The default form delegates to This(0, 0, 0), so a default-constructed vector is the zero vector — the Vector3Test fixture asserts it. The nullptr form is explicit and initializes nothing: the shared implementation builds result vectors through it (every This result(nullptr) in VectorCommonImpl.inl), and a caller who uses it gets indeterminate components. The two-component form zeroes z; the three-component form takes all three. The Vector2 form is explicit and defaults z to 0.
