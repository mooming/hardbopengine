IsUnity

member of hbe::Quaternion Engine/Math/Quaternion.h true when the quaternion is unit length within SqrEpsilon

Signature

[[nodiscard]] bool IsUnity() const noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::IsUnity(). Returns vector.IsUnity() — Abs(SqrLength() - 1) < SqrEpsilon over all four components. This is the test Invert and Slerp assert, and the one to run before trusting a quaternion that has been through composition.

Parameters

None.

Return value

TypeWhat you get
booltrue when unit length within SqrEpsilon.
