EulerAngles

member of hbe::Quaternion Engine/Math/Quaternion.h the rotation as Euler angles, in degrees

Signature

[[nodiscard]] TVec3 EulerAngles() const noexcept

Vector3<T> e = q.EulerAngles()

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::EulerAngles(). Extracts the three angles with RotationAtan2/RotationAsin and converts each with RadianToDegree — the return is degrees. The pitch term 2(w·y - x·z) is clamped: when its absolute value reaches 1 the angle is copysign(HalfPi, sinp) — ±90° — instead of an asin outside its domain. Euler extraction from a quaternion is not unique; this returns one representative.

None.
