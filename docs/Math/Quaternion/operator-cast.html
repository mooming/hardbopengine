operator TMat3x3

member of hbe::Quaternion Engine/Math/Quaternion.h implicit conversion to the rotation matrix

Signature

operator TMat3x3() const noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::operator TMat3x3(). Two non-explicit conversion operators delegating to ToMat3x3 and ToMat4x4. Non-explicit, so a quaternion converts to a matrix wherever the type is wanted — including in the comparisons and arithmetic of the matrix classes.

Parameters

None; the conversion applies to the object it is written on.

Return value

TypeWhat you get
TMat3x3 or TMat4x4The rotation matrix; the source is untouched.
