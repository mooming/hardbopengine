ToMat3x3

member of hbe::Quaternion Engine/Math/Quaternion.h the rotation as a 3-by-3 matrix

Signature

[[nodiscard]] TMat3x3 ToMat3x3() const noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::ToMat3x3(). Builds an uninitialized Matrix3x3 and fills the nine elements from the standard quaternion-to-matrix formulas (1 - 2(y²+z²) on the diagonal, cross terms elsewhere). For a unit quaternion the result is orthonormal with determinant 1 — the precondition Quaternion's own matrix constructor demands in the other direction.
