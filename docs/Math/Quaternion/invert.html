Invert

member of hbe::Quaternion Engine/Math/Quaternion.h the in-place inverse of a unit quaternion — which is its conjugate

Signature

void Invert() noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::Invert(). Asserts the quaternion is non-zero and unit length (IsEqual(vector.SqrLength(), 1.0f)) — Assert, compiled out of Release builds — then conjugates. For a unit quaternion the conjugate is the inverse; the asserts are what make that identity safe to apply. A non-unit quaternion in Release is "inverted" by conjugation alone, which is not its inverse.

Parameters

None.

Return value

None; the result lands in *this.

Examples

Illustrative — no call site for this method exists in the repository.

q.Invert();  // asserts unit length first, in Debug and Dev
