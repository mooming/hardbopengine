Quaternion

Engine/Math/Quaternion.h unit-quaternion rotation: Euler and axis-angle factories, matrix conversion, composition, and interpolation

Class description

Quaternion represents 3D rotation as x, y, z, w — imaginary parts first, real part last — with the components aliasing a Vector4, a Vector3-plus-scalar pair, and a raw array through one anonymous union. The header's standing assumption, which every member is written against: assume every quaternion is a unit quaternion. The members that need it enforce it where a wrong input would silently corrupt a rotation — Slerp and Invert assert unit length, and the matrix constructor asserts an orthogonal, determinant-1 source — while the arithmetic operators do not re-check.

Angle conventions split the class in two halves: every Euler setter, factory and constructor that takes an angle takes degrees and converts through DegreeToRadian — the CreateRotation* factories, the SetEuler* family, the Euler constructors — and EulerAngles() returns degrees. The axis-angle members take radians: SetRotationAround, its factory RotationAround, and SetRotationFromTo through its AngleTo call. All rotation trig goes through CoordinateOrientation, so handedness is the build's RIGHT_HANDED_COORDINATE decision.

Multiplying a quaternion by a vector rotates the vector. operator*(const TVec3&) applies the rotation and returns a TVec3, not a quaternion — the vector sits on the right. Composing rotations is quaternion-times-quaternion, also operator*.

Coverage

GapDetail
The unit-length assumption Stated in the description because it is the class's standing precondition, written as a sentence in the header itself. Members that depend on it assert it; the arithmetic operators do not, and nothing here re-normalizes after composition drift.
Handedness branches The rotation tests in QuaternionTest differ per build because the named axes differ; the class's own formulas are handedness-free. LookAt inherits Matrix3x3::LookAt's right-handed branch — see that page for the left-handed compile finding.
Callers outside the module None found in Engine/ outside Engine/Math/ or in Applications/. The class is exercised by the QuaternionTest fixture in Engine/Math/Quaternion.cpp, which the pages quote where real.
