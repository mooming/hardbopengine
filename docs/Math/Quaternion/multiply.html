Multiply

member of hbe::Quaternion Engine/Math/Quaternion.h the Hamilton product, or the rotation of a vector

Signature

[[nodiscard]] Quaternion Multiply(const Quaternion& rhs) const noexcept

[[nodiscard]] TVec3 Multiply(const TVec3& rhs) const noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::Multiply(). Two overloads. The quaternion form is the Hamilton product, component by component — result.x = w*rhs.x + x*rhs.w + y*rhs.z - z*rhs.y and so on. The vector form expands the rotation q * v * q⁻¹ into straight arithmetic and returns a TVec3. operator* delegates to both.
