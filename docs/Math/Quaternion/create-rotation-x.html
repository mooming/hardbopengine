CreateRotationX

member of hbe::Quaternion Engine/Math/Quaternion.h rotation about x, from degrees

Signature

[[nodiscard]] static Quaternion CreateRotationX(const float x) noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::CreateRotationX(). Builds an uninitialized quaternion and hands it to SetEulerX, which converts the angle with DegreeToRadian — the argument is degrees, half-angle trig inside.
