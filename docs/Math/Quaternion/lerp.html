Lerp

member of hbe::Quaternion Engine/Math/Quaternion.h componentwise interpolation, then normalized

Signature

[[nodiscard]] static This Lerp(const This& from, const This& to, float t) noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::Lerp(). Interpolates all four components — from.vector * (1 - t) + to.vector * t — and normalizes the result, so the output is a unit rotation even though the path is not constant-speed. The inputs are not required to be unit. Cheaper than Slerp; Slerp falls back to it when the rotations are nearly identical.
