ToMat4x4

member of hbe::Quaternion Engine/Math/Quaternion.h the rotation as a homogeneous 4-by-4 matrix

Signature

[[nodiscard]] TMat4x4 ToMat4x4() const noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::ToMat4x4(). The same nine formulas as ToMat3x3, written into the 3-by-3 block; the fourth column and row are zero except m44 = 1 — no translation, no scale.

Parameters

None.

Return value

TypeWhat you get
TMat4x4The rotation in homogeneous form.

Examples

TMat4x4 mat = rotation.ToMat4x4();
mat.SetTranslation(translation);
