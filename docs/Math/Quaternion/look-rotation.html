LookRotation

member of hbe::Quaternion Engine/Math/Quaternion.h the rotation that looks along forward, with up as reference

Signature

[[nodiscard]] static Quaternion LookRotation(const TVec3& forward, const TVec3& up) noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::LookRotation(). Builds an uninitialized quaternion and runs LookAt — which builds a Matrix3x3 basis and converts it, inheriting that member's unit-input and non-parallel asserts and its right-handed branch.

Return value
