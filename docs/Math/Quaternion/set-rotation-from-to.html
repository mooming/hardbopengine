SetRotationFromTo

member of hbe::Quaternion Engine/Math/Quaternion.h the rotation carrying one direction onto another

Signature

void SetRotationFromTo(const TVec3& from, const TVec3& to) noexcept

Function description

Defined in Engine/Math/Quaternion.h as Quaternion::SetRotationFromTo(). When from == to (the vector tolerance comparison), stores Quaternion::Identity and returns. Otherwise the axis is from.Cross(to), normalized, and the angle is from.AngleTo(to) — radians, handed to SetRotationAround. Degenerate inputs — opposite vectors, where the cross product is zero — normalize to a zero axis and trip SetRotationAround's unit assert in Debug and Dev.

Parameters

ParameterTypeRequirement
from, toconst TVec3&Non-zero directions; not opposite.

Return value

None; the result lands in *this.

Examples

		auto axis = from.Cross(to);
		axis.Normalize();

		SetRotationAround(axis, from.AngleTo(to));
