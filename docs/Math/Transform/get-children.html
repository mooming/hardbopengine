GetChildren

member of hbe::Transform Engine/Math/Transform.h the live child list, by reference

Signature

[[nodiscard]] Vector<Transform*>& GetChildren() noexcept

[[nodiscard]] const Vector<Transform*>& GetChildren() const noexcept

Function description

Defined in Engine/Math/Transform.h as Transform::GetChildren(). Two overloads returning children by reference — the non-const form hands out mutable access to the hierarchy itself: a caller can erase, reorder or append through it, bypassing Attach's parent bookkeeping.

Parameters

None.

Return value

TypeWhat you get
Vector<Transform*>&The child list — mutable in the non-const overload.
