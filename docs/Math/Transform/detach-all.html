DetachAll

member of hbe::Transform Engine/Math/Transform.h clears the whole child list

Signature

void DetachAll() noexcept

Function description

Defined in Engine/Math/Transform.h as Transform::DetachAll(). Walks children, asserts each child's parent points back at this node ("Parent-Child Inconsistency" otherwise), clears the child's parent, and empties the list. Nothing is invalidated.

Parameters

None.

Return value

None; the child list is emptied.

Examples

Illustrative — no call site for this method exists in the repository.

root.DetachAll();  // every child becomes a root
