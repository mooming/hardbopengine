~Transform

member of hbe::Transform Engine/Math/Transform.h unlinks the node from the hierarchy without destroying anything

Signature

~Transform() noexcept

Function description

Defined in Engine/Math/Transform.h as Transform::~Transform(). If a parent exists, runs parent->Detach(*this); then DetachAll(). The children are unlinked, not destroyed — they survive as roots, and destroying a subtree requires destroying each node.

Parameters

None.

Return value

None; destruction is not a value.

Examples

Illustrative — no call site for this method exists in the repository.

{
	TFTransform node;
	root.Attach(node);
}  // node detaches itself here
