Attach

member of hbe::Transform Engine/Math/Transform.h re-parenting, with the old parent unhooked first

Signature

void Attach(Transform& transform) noexcept

Function description

Defined in Engine/Math/Transform.h as Transform::Attach(). Takes the child by address. When the child's current parent is this node's own parent, the child is detached from it first — moving a node to its sibling position unhooks it. When the child is already in children, the member asserts the parent pointers agree ("Parent-Child Inconsistency") and returns without adding a duplicate. Otherwise the child is appended and its parent is set to this. Nothing is invalidated: the child's cached world transform — if it ever computed one — is stale until Invalidate runs.

Parameters

ParameterTypeRequirement
transformTransform&The node to attach; must not be this node itself.

Return value

None; the hierarchy lands in the two nodes.

Examples

TFTransform root;
TFTransform a;
root.Attach(a);

TFTransform b;
a.Attach(b);

TFTransform c;
b.Attach(c);
