Transform

Engine/Math/Transform.h a hierarchical transform: parent, children, and a cached world transform the Set overloads keep honest

Class description

Transform is a scene-graph node: a local UniformTransform — accessible as trs or as its rotation/scale/translation members through one anonymous union — plus a parent pointer, a child list, and a cached world transform. The design shows in the pair of GetWorldTransform overloads: the non-const form returns the cache and rebuilds it only when it is missing, while the const form computes on every call without caching, because a const reader must not be able to mutate a cache through a shared reference.

What invalidates the cache — and what does not. The four Set overloads call Invalidate , which drops the cache down the whole subtree. Nothing else does: Attach, Detach, DetachAll, and direct writes to the public trs/rotation/scale/translation members leave every cached world transform exactly as it was. A node moved that way keeps serving its stale world transform until something calls Invalidate().

Copy construction is deleted. The declared operator== is also deleted — an apparent typo for operator=, which is not declared at all; a probe compiling copy assignment (b = a;) accepts it, so the implicitly-defaulted copy assignment is available and copies the parent pointer and child list by value.
