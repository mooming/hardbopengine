Function description

Defined in Engine/Math/Transform.h as Transform::Transform(). Three constructors, all starting detached — parent = nullptr — with an empty world cache. The default form default-constructs trs (identity rotation, scale 1, zero translation). The nullptr form is explicit and leaves trs uninitialized. The UniformTransform form copies the given local transform. The deleted copy constructor appears in the Signature section with them: a node is not copyable.
