Set

member of hbe::Transform Engine/Math/Transform.h the supported mutation path — compare, write, invalidate

Function description

Defined in Engine/Math/Transform.h as Transform::Set(). Four overloads: rotation+scale+translation together, rotation alone, scale alone, translation alone. Each compares against the current value first and returns without writing when nothing changed; otherwise it assigns and calls Invalidate. This is the only mutation path that keeps the cached world transforms honest — the fixture's rotation test moves nodes with Set and reads correct world transforms back.

Parameters

Return value

None; the change lands in trs and the subtree cache is dropped.
