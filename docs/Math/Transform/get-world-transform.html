GetWorldTransform

member of hbe::Transform Engine/Math/Transform.h cached when non-const, computed when const

Signature

[[nodiscard]] const TUTransform& GetWorldTransform() noexcept

[[nodiscard]] TUTransform GetWorldTransform() const noexcept

Function description

Defined in Engine/Math/Transform.h as Transform::GetWorldTransform(). Two overloads with deliberately different costs. The non-const form returns the cache when it exists; otherwise, with a parent, it computes parent->GetWorldTransform() * trs — the composition through UniformTransform's operator* — stores it in world and returns it; a root returns a reference to trs itself. The const form returns the cache by value if present, computes without storing when a parent exists, and returns trs by value for a root — a const reader can never populate or mutate the cache. The test fixture pins the algebra: a three-deep chain of translations (0,0,1), (0,1,0), (1,0,0) puts c's world translation at (1, 1, 1).

Parameters

None.

Return value

TypeWhat you get
const TUTransform& or TUTransformThe world transform — cached reference in the non-const form, a fresh value in the const form.
