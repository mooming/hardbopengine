Function description

Three constructors. The default form delegates to This(0, 0), so a default-constructed vector is the zero vector — the Vector2Test fixture relies on it. The two-component form initializes both components from its arguments. The nullptr form is explicit and initializes nothing: it exists so the shared implementation can build result vectors without paying for an initialization every member then overwrites — every operator that starts This result(nullptr) uses it. A caller who uses it gets indeterminate components.
