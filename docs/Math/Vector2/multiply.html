Multiply

member of hbe::Vector2 Engine/Math/VectorCommonImpl.inl scales by a scalar or by another vector, componentwise, in place

Signature

void Multiply(TNumber value) noexcept

void Multiply(const This& rhs) noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector2::Multiply(); the file is included into the class body, so this is a member of every vector class, not a free function. Two overloads. The scalar form multiplies every component by value; the vector form multiplies component by component by rhs (a Hadamard product, not a dot product). Both write into *this. operator*= routes through both.

Parameters

ParameterTypeRequirement
valueTNumberScalar form: the scale factor.
rhsconst This&Vector form: the per-component factor. May be the vector itself.

Return value

None; the product lands in *this.
