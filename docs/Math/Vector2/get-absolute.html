GetAbsolute

member of hbe::Vector2 Engine/Math/VectorCommonImpl.inl a copy with every component made non-negative

Signature

[[nodiscard]] This GetAbsolute() const noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector2::GetAbsolute(); the file is included into the class body, so this is a member of every vector class, not a free function. The non-mutating counterpart of ToAbsolute: the original is untouched, the copy carries Abs of every component.

None.
