Vector2

Engine/Math/Vector2.h a two-component vector: named components over an array view, shared arithmetic with Vector3 and Vector4

Class description

Vector2 is a fixed-size two-component vector: x and y in an anonymous union with a raw array a[2], so index-based generic code and named-component code read the same storage. The class is final, carries no allocation, and every operation is noexcept. Nearly all of its arithmetic lives in Engine/Math/VectorCommonImpl.inl, which is included into the class body and is therefore shared verbatim with Vector3 and Vector4 — the three classes differ only in their constructors, their named constants, and what their arity adds.

Equality is a tolerance test, not a bitwise one: operator== subtracts and asks IsZero, so two vectors within Epsilon compare equal. Division asserts its divisor in Debug and Dev builds and divides unchecked in Release — Assert is compiled out under RELEASE_BUILD, while FatalAssert is not.
