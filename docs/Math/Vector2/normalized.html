Normalized

member of hbe::Vector2 Engine/Math/VectorCommonImpl.inl a unit-length copy of the vector

Signature

[[nodiscard]] This Normalized() const noexcept

Function description

Defined in Engine/Math/VectorCommonImpl.inl as Vector2::Normalized(); the file is included into the class body, so this is a member of every vector class, not a free function. Copies *this and runs Normalize on the copy, so the original is untouched. Like Normalize, the copy is replaced by This::Forward when its length is zero.

Parameters

None.

Return value

TypeWhat you get
ThisThe same direction with length 1 — or Forward when the vector had zero length.

Examples

Illustrative — no call site for this method exists in the repository.
