Translate

member of hbe::AABB Engine/Math/AABB.h shifts both corners — refused on an empty box

Signature

void Translate(const TVec& t) noexcept

Function description

Defined in Engine/Math/AABB.h as AABB::Translate(). Asserts !IsEmpty() (Assert, Debug and Dev), then adds t to both corners. The assert is the contract: translating an empty box is a caller error, caught in Debug and Dev, unchecked in Release — where the empty box becomes a finite but meaningless box around t.
