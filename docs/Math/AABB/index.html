AABB

Engine/Math/AABB.h an axis-aligned bounding box stored as two corners, empty until the first Add

Class description

AABB is an axis-aligned bounding box stored as two corners, min and max, of whatever vector type TVec names — the template parameter sets the dimension, and every member loops over TVec::order. It is the cheap volume: growing is two comparisons per axis in Add, containment is a per-axis range test, and the empty state is a convention rather than a flag — a default-constructed box has min = Unity * MAX and max = Unity * -MAX, where MAX is float's maximum, so it is inside-out on every axis and IsEmpty reports true.

Containment and equality are exact comparisons. IsContaining tests min.a[i] > point.a[i] and max.a[i] < point.a[i] with no epsilon, and operator== is mutual containment — so two boxes whose corners differ by one ulp compare unequal, unlike the vector classes' tolerance equality underneath.

Template parameters

ParameterKindWhat it must satisfy
TVec typename The corner vector type — it sets the dimension through TVec::order. Engine code uses AABB<TFloat2> (AABB2) and AABB<TFloat3> (AABB3). The vector class supplies Unity, operator*, operator+, operator- and the a[] array view the members index; the empty-box convention multiplies Unity by float's MAX, so a floating-point vector is what the default constructor is written for
