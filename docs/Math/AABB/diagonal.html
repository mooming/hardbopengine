Diagonal

member of hbe::AABB Engine/Math/AABB.h max - min — the full extent per axis

Signature

[[nodiscard]] TVec Diagonal() const noexcept

Function description

Defined in Engine/Math/AABB.h as AABB::Diagonal(). Returns max - min. On an empty box every component is negative (the corners are ±MAX); the test fixture pins the diagonal of a box grown by four points to TFloat3::Unity.

Parameters

None.

Return value

TypeWhat you get
TVecThe extent per axis.

if (bbox.Diagonal() != TFloat3::Unity)

}
