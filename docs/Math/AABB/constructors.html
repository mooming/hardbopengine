Function description

Defined in Engine/Math/AABB.h as AABB::AABB(). Three constructors. The default form is the empty box: min(TVec::Unity * MAX), max(TVec::Unity * -MAX) — inside-out on every axis, so IsEmpty is true until the first Add. The nullptr form is explicit and initializes nothing — the shared Intersection builds its result through it. The two-corner form takes the box exactly as given; it does not normalize the corners.

Parameters

min, maxconst TVec&The corners, in that order — swapped corners make an empty box.
(unnamed)std::nullptr_tToken only — selects the uninitialized form. Internal use.

None; construction is not assignment.
