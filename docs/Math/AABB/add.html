Add

member of hbe::AABB Engine/Math/AABB.h grows the box to include a point or another box

Signature

void Add(const TVec& point) noexcept

void Add(const This& aabb) noexcept

Function description

Defined in Engine/Math/AABB.h as AABB::Add(). Two overloads. The point form walks the axes: min.a[i] = MinFast(point.a[i], min.a[i]) and max.a[i] = MaxFast(point.a[i], max.a[i]). The box form adds both corners of aabb. On an empty box the first point becomes the whole box — the ±MAX corners lose to any finite value. Note MinFast/MaxFast are the branchless MathUtil forms, not NaN-safe.

Parameters

ParameterTypeRequirement
pointconst TVec&Point form: the point to include.
aabbconst This&Box form: both its corners are added.

Return value

None; the growth lands in *this.

Examples

bbox.Add(TFloat3::Zero);
bbox.Add(TFloat3::Forward);
bbox.Add(TFloat3::Right);
bbox.Add(TFloat3::Up);
