IsContaining

member of hbe::AABB Engine/Math/AABB.h exact per-axis range test for a point or a box

Signature

[[nodiscard]] bool IsContaining(const TVec& point) const noexcept

[[nodiscard]] bool IsContaining(const This& aabb) const noexcept

Function description

Defined in Engine/Math/AABB.h as AABB::IsContaining(). Two overloads. The point form returns false immediately for an empty box, then tests min.a[i] > point.a[i] and max.a[i] < point.a[i] per axis — exact comparisons, no epsilon, boundaries inclusive. The box form requires both corners of aabb to be contained, so a box contains itself and a contained box's corners may sit on the boundary.

Parameters

ParameterTypeRequirement
pointconst TVec&Point form: the query point.
aabbconst This&Box form: both its corners must fit.

Return value

TypeWhat you get
booltrue when the query fits; an empty box contains nothing.
