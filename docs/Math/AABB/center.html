Center

member of hbe::AABB Engine/Math/AABB.h the midpoint of the two corners

Signature

[[nodiscard]] TVec Center() const noexcept

Function description

Defined in Engine/Math/AABB.h as AABB::Center(). Returns (min + max) * 0.5f. On an empty box the corners are ±MAX and the arithmetic overflows — the member computes anyway, so only call it on a box that has content.

Parameters

None.

Return value
