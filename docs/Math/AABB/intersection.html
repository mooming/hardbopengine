Intersection

member of hbe::AABB Engine/Math/AABB.h the per-axis overlap — possibly an empty box

Signature

[[nodiscard]] AABB Intersection(const AABB& aabb) const noexcept

Function description

Defined in Engine/Math/AABB.h as AABB::Intersection(). Builds the result through the nullptr constructor and takes per axis result.min = MaxFast(aabb.min, min) and result.max = MinFast(aabb.max, max). When the boxes are disjoint, some axis ends with max < min — the result is a valid empty box, which IsEmpty and HasIntersectionWith are defined against.
