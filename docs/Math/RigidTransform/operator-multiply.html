operator*

member of hbe::RigidTransform Engine/Math/RigidTransform.h applies the transform — whatever Transform accepts

Signature

template <typename T>
	[[nodiscard]] T operator*(const T& rhs) const noexcept

Function description

Defined in Engine/Math/RigidTransform.h as RigidTransform::operator*(). A forwarding template: return Transform(rhs);. With a TVec3 it resolves to the point form, with a TQuat to the rotation form, with a RigidTransform to the composition form.

Parameters

Return value
