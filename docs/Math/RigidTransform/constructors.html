Function description

Defined in Engine/Math/RigidTransform.h as RigidTransform::RigidTransform(). Four constructors, declared in the class and defined at the bottom of the header. The default form default-constructs rotation and translation — the identity transform, which the fixture pins against TQuat::Identity and TFloat3::Zero. The nullptr form is explicit and initializes nothing. The parts form takes translation then rotation — note the argument order, translation first. The Matrix4x4 form asserts the matrix is orthogonal (Assert, Debug and Dev), takes the rotation through Quaternion's asserting matrix constructor, and reads the translation from m14, m24, m34 — the fourth column.

The Signature section carries a fifth block. The checker's class-body scan does not stop at this class's closing brace — the out-of-line constructor definitions at the bottom of the header are swept into the same group. The four declarations above that artifact are the constructor surface; the artifact itself is the definitions, not a fifth constructor.
