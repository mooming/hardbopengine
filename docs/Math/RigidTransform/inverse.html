Inverse

member of hbe::RigidTransform Engine/Math/RigidTransform.h the true inverse — conjugate rotation and carried translation

Signature

[[nodiscard]] This Inverse() const noexcept

Function description

Defined in Engine/Math/RigidTransform.h as RigidTransform::Inverse(). Builds the result through the nullptr constructor, sets inverse.rotation = rotation.Inverse() and inverse.translation = inverse.rotation * -translation, and returns it. This is the correct rigid inverse — the fixture pins tm.Inverse().Inverse() == tm and tm3.Inverse() * result1 == TFloat3::Forward. Unlike UniformTransform::Inverse, this member compiles and does not touch *this.

Parameters

None.

Return value

TypeWhat you get
ThisThe inverse transform; the original untouched.
