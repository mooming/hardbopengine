RigidTransform

Engine/Math/RigidTransform.h rotation and translation with no scale — the type for cameras and physics bodies

Class description

RigidTransform is rotation and translation with no scale — the type for cameras, physics bodies and anything a scale factor would corrupt. Two members carry the state, a rotation quaternion and a translation vector, and a padding[PaddingSize] array follows them so the type can sit in a fixed-size structure — PaddingSize defaults to 8 bytes, which makes RigidTransform<float> (TRigidTR) a 32-byte object. Applying it to a point is rotation * x + translation; composing two of them carries the translation through the rotation, exactly as UniformTransform does minus the scale.

The Matrix4x4 constructor asserts the matrix is orthogonal before extracting rotation and translation — a scaled matrix is rejected, not decomposed. Applying and composing are shared with the template operator*, and the test fixture pins the algebra end to end: (tm * tm2) * v == tm * (tm2 * v) and tm.Inverse().Inverse() == tm.
