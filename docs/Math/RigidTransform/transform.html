Transform

member of hbe::RigidTransform Engine/Math/RigidTransform.h applies the transform to a point, a rotation, or another transform

Signature

[[nodiscard]] TVec3 Transform(const TVec3& x) const noexcept

[[nodiscard]] TQuat Transform(const TQuat& r) const noexcept

[[nodiscard]] This Transform(const This& rhs) const noexcept

Function description

Defined in Engine/Math/RigidTransform.h as RigidTransform::Transform(). Three overloads. The point form returns rotation * x + translation. The rotation form returns rotation * r — the orientation composed. The composition form builds result.rotation = rotation * rhs.rotation and result.translation = rotation * rhs.translation + translation — the right-hand transform applied first.
