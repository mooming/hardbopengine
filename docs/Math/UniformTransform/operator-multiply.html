operator*

member of hbe::UniformTransform Engine/Math/UniformTransform.h applies the transform — whatever Transform accepts

Signature

template <typename T>
	[[nodiscard]] T operator*(const T& rhs) const noexcept

Function description

Defined in Engine/Math/UniformTransform.h as UniformTransform::operator*(). A forwarding template: return Transform(rhs);. With a TVec3 it resolves to the point form, with a UniformTransform to the composition form. Any other argument type fails to compile at the Transform overloads.
