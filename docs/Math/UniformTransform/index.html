UniformTransform

Engine/Math/UniformTransform.h rotation, one uniform scale, translation — the shape most game objects have

Class description

UniformTransform is a position-plus-orientation in three members — a rotation quaternion, one uniform scale factor, and a translation vector — against the sixteen elements of the Matrix4x4 it converts to. It is the shape most game objects have, and the type Transform caches its world transform as. Applying it to a point is rotation * (scale * x) + translation; composing two of them multiplies the scales, the rotations, and carries the translation through.

Two members cannot be used as declared. Inverse() is declared const but assigns to its members — a call does not compile; the compiler probe reports cannot assign to non-static data member within const member function 'Inverse'. And the Matrix4x4 constructor's scale-mismatch asserts compare against the already-normalized columns, so they fire for any uniform scale other than 1 in Debug and Dev builds. Both are stated on their pages with the code or diagnostic quoted.
