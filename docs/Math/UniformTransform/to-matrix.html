ToMatrix

member of hbe::UniformTransform Engine/Math/UniformTransform.h the full homogeneous matrix — rotation, scale, translation

Signature

[[nodiscard]] TMat4x4 ToMatrix() const noexcept

Function description

Defined in Engine/Math/UniformTransform.h as UniformTransform::ToMatrix(). Builds rotation.ToMat4x4() * TMat4x4::CreateDiagonal(TFloat4(scale, scale, scale, 1.0f)) and writes the translation into the fourth column with SetTranslation. The result is the matrix whose column-vector product reproduces Transform's point form.

Parameters

None.

Return value

TypeWhat you get
TMat4x4The homogeneous transform matrix.

Examples

		TUniformTRS tm(TFloat3(4, 5, 6), TQuat(0, 47, 0), 2);
		TUniformTRS tm2(TFloat3(3, 4, 5), TQuat(41, 0, 25), 3);
		TFloat4x4 tm3 = (tm * tm2).ToMatrix();
