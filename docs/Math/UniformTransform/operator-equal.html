operator==

member of hbe::UniformTransform Engine/Math/UniformTransform.h tolerance equality on all three members

Signature

[[nodiscard]] bool operator==(const This& rhs) const noexcept

Function description

Defined in Engine/Math/UniformTransform.h as UniformTransform::operator==(). Returns rotation == rhs.rotation && scale == rhs.scale && translation == rhs.translation. The quaternion and vector comparisons are the Epsilon tolerance tests; scale is compared with == exactly — a scale of 1.0000001f makes two transforms unequal.
