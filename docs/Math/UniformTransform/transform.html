Transform

member of hbe::UniformTransform Engine/Math/UniformTransform.h applies the transform to a point, or composes two transforms

Signature

[[nodiscard]] TVec3 Transform(const TVec3& x) const noexcept

[[nodiscard]] This Transform(const This& rhs) const noexcept

Function description

Defined in Engine/Math/UniformTransform.h as UniformTransform::Transform(). Two overloads. The point form returns rotation * (scale * x) + translation — scale first, then rotate, then translate. The composition form builds result.scale = scale * rhs.scale, result.rotation = rotation * rhs.rotation, and result.translation = rotation * (scale * rhs.translation) + translation — the right-hand transform applied first, then this one, matching the order operator* reads in.
