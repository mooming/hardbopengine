Inverse

member of hbe::UniformTransform Engine/Math/UniformTransform.h declared, not usable — the body does not compile

Signature

[[nodiscard]] This Inverse() const noexcept

Function description

Defined in Engine/Math/UniformTransform.h as UniformTransform::Inverse(). The body writes scale, rotation and translation — members of *this, in a member function declared const:

[[nodiscard]] This Inverse() const noexcept
{
	This inverse(nullptr);

	scale = 1.0f / scale;
	rotation.Invert();
	translation = rotation * translation * (-scale);

	return inverse;
}

From Engine/Math/UniformTransform.h, UniformTransform::Inverse()

As a template member it is only compiled when called, which is why the engine builds. A probe that instantiates it reports:

Engine/Math/UniformTransform.h:122:9: error: cannot assign to non-static data member within const member function 'Inverse'

Two defects in one: the mutation is illegal in a const member, and the returned inverse — built through the nullptr constructor — never receives any of the computed values. Until the code changes, invert through InverseTransform per point, or build the inverse by hand from rotation.Inverse(), 1 / scale and the carried translation.
