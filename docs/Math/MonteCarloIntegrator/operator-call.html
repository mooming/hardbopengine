member of hbe::MonteCarloIntegrator Engine/Math/MonteCarloIntegrator.h the importance-sampled mean of f(x)/p(x)

Signature

	[[nodiscard]] bool operator()(TOutput& result, const TFunction& f, const TPDF& p, const TRandomGen& sample,
								  const TInteger numIterations) noexcept

Function description

Defined in Engine/Math/MonteCarloIntegrator.h as MonteCarloIntegrator::operator(). Zeros result first, then returns false through returnValueIf when numIterations is not positive. Each iteration draws x = sample(), checks the density — p_x <= 0 returns false, with result already zeroed — and accumulates f(x) / p_x. Finally result /= numIterations and the member returns true: the mean of the importance-sampled values, which estimates the integral of f under the density p. The "Calculate Pi" test integrates the unit-disk indicator under a uniform density this way and averages repeated runs.
