MonteCarloIntegrator

Engine/Math/MonteCarloIntegrator.h a stateless callable: the importance-sampled mean of f(x)/p(x), averaged over draws

Class description

MonteCarloIntegrator is a stateless callable for importance-sampled integration: it holds no data and exists so Integrator(result, f, p, sample, numIterations) reads as a function call. The estimate it computes is the mean of f(x) / p(x) over numIterations draws of sample() — the standard Monte Carlo estimator of the integral of f under the probability density p. The "Calculate Pi" test in Engine/Math/MonteCarloIntegrator.cpp integrates the unit-disk indicator under a uniform density and averages repeated runs, reporting the mean and standard deviation.

Failure is a return value, not an exception: the member returns false when numIterations is not positive or any draw's density is not positive — in both cases result has already been zeroed, so a failed call leaves a defined zero.
