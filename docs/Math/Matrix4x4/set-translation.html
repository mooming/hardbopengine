SetTranslation

member of hbe::Matrix4x4 Engine/Math/Matrix4x4.h writes the offset into the fourth column, touching nothing else

Signature

void SetTranslation(const TVec3& translation) noexcept

Function description

Defined in Engine/Math/Matrix4x4.h as Matrix4x4::SetTranslation(). Writes m14 = translation.x, m24 = translation.y, m34 = translation.z and returns nothing. The rotation block and the bottom row are untouched, which is what makes it composable with a rotation already in place — the transform types' ToMatrix() methods rely on exactly that.

Parameters

ParameterTypeRequirement
translationconst TVec3&The offset; its w-less components land in the fourth column.

Return value

None; the translation lands in *this.

Examples

TMat4x4 mat = rotation.ToMat4x4();
mat.SetTranslation(translation);
