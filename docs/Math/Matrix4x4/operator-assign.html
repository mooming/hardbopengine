operator=

member of hbe::Matrix4x4 Engine/Math/Matrix4x4.h copies a smaller matrix into the top-left block, leaving the rest as it was

Signature

This& operator=(const TMat2x2& rhs) noexcept

This& operator=(const TMat3x3& rhs) noexcept

Function description

Defined in Engine/Math/Matrix4x4.h. Two overloads. From a Matrix2x2: assigns m11, m12, m21, m22. From a Matrix3x3: assigns the nine-block. Neither writes anything else — the remaining elements keep their previous values. This is assignment onto an existing matrix, not a conversion that completes an identity.
