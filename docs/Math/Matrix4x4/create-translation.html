CreateTranslation

member of hbe::Matrix4x4 Engine/Math/Matrix4x4.h a translation matrix: identity with the offset in the fourth column

Signature

[[nodiscard]] static This CreateTranslation(const TVec3& v) noexcept

Function description

Defined in Engine/Math/Matrix4x4.h as Matrix4x4::CreateTranslation(). Builds an uninitialized matrix and writes the identity with m14 = v.x, m24 = v.y, m34 = v.z, m44 = 1 — all sixteen elements, so the result is fully initialized. The translation sits in the fourth column, which is where SetTranslation writes too and where the row-major matrix-vector product picks it up.
