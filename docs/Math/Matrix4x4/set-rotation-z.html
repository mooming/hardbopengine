SetRotationZ

member of hbe::Matrix4x4 Engine/Math/Matrix4x4.h rotation about z, in radians — but m33 is written 0.0f, so the result is not a rotation

Signature

void SetRotationZ(float radian) noexcept

Function description

Defined in Engine/Math/Matrix4x4.h as Matrix4x4::SetRotationZ(). The angle is a radian. The element writes are:

m21 = s;
m22 = c;
m23 = 0.0f;
m31 = 0.0f;
m32 = 0.0f;
m33 = 0.0f;

From Engine/Math/Matrix4x4.h, Matrix4x4::SetRotationZ() — the tail

A z rotation needs m33 = c; the code writes 0.0f instead — the same write Matrix3x3::SetEulerZ() makes — so the matrix this member produces is not a rotation about z. Until the code changes, compose the z rotation through EulerAngles, whose formula is correct.
