Function description

Six constructors. The default form is the identity — the sixteen-element list with ones on the diagonal — which is what the Identity constant is defined as. The nullptr form is explicit and initializes nothing; the shared implementation builds result matrices through it. Two array forms — one from a const array, one by std::move — take sixteen elements in row-major order. The Matrix2x2 and Matrix3x3 forms copy the block into the top-left corner and write the identity into the remaining diagonal and zero elsewhere: the 2-by-2 form sets m33 = m44 = 1 and zeros the rest; the 3-by-3 form sets m44 = 1 and zeros the fourth column and row.
