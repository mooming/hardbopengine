operator TMat2x2

member of hbe::Matrix4x4 Engine/Math/Matrix4x4.h new 2x2 or 3x3 matrices built from the corresponding block — none explicit

Signature

operator TMat2x2() const noexcept

Function description

Defined in Engine/Math/Matrix4x4.h. Two conversion operators. The Matrix2x2 form builds through its nullptr constructor and copies m11, m12, m21, m22 — all four elements, so the result is fully initialized. The Matrix3x3 form copies the nine-block — all nine elements. Neither is explicit, unlike Matrix3x3's single conversion: a Matrix4x4 converts to the smaller types wherever they are wanted, silently dropping the fourth column and row.

Parameters

None; the conversion applies to the object it is written on.

Return value

TypeWhat you get
TMat2x2 or TMat3x3A new smaller matrix holding the block; the source is untouched.
