Matrix4x4

Engine/Math/Matrix4x4.h a 4-by-4 homogeneous matrix: translation and rotation members, inverse, determinant, and the shared matrix arithmetic

Class description

Matrix4x4 is the fixed 4-by-4 row-major matrix for homogeneous transforms: rows[4] of Vector4, aliased with TNumber m[4][4], a flat std::array, and named elements m11…m44. It shares Engine/Math/MatrixCommonImpl.inl with the smaller matrices, and adds translation and rotation members for the fourth column and row: CreateTranslation, SetTranslation, the rotation setters, and EulerAngles — here a setter that writes the 3-by-3 rotation block, not a getter.

Units, per member: SetRotationX/Y/Z and EulerAngles take radians (the trig is called on the argument directly), unlike Matrix3x3's degree-taking SetEulerAngles. Inverse() is the full adjugate over the determinant, scaled once, and guarded by FatalAssert — a singular matrix terminates in every build, unlike Matrix3x3's Debug-and-Dev Assert.

One defect a caller must know about. SetRotationZ() writes m33 = 0.0f where the rotation needs c — the same write Matrix3x3::SetEulerZ() makes — so its result is not a rotation about z. The page quotes the code; build z rotations through SetRotationX/Y and a correct z source instead.
