IsIdentity

member of hbe::Matrix4x4 Engine/Math/MatrixCommonImpl.inl true when off-diagonal entries are zero and diagonal entries are 1, in float

Signature

[[nodiscard]] bool IsIdentity() const noexcept

Function description

Defined in Engine/Math/MatrixCommonImpl.inl as Matrix4x4::IsIdentity(); the file is included into the class body, so this is a member of every matrix class, not a free function. Walks every entry: off-diagonal entries must satisfy IsZero and diagonal entries IsEqual(m[i][j], 1.0f). Both tests are float-based, through MathUtil, so a Matrix<double> is judged against float tolerances.

Parameters

None.

Return value

TypeWhat you get
booltrue when the matrix is the identity within the MathUtil tolerances.
