EulerAngles

member of hbe::Matrix4x4 Engine/Math/Matrix4x4.h full Euler rotation from radians, overwriting the 3x3 block — a setter

Signature

void EulerAngles(float x, float y, float z) noexcept

Function description

Defined in Engine/Math/Matrix4x4.h as Matrix4x4::EulerAngles(). Despite the getter-like name, this writes: it computes the same nine-element composition Matrix3x3::SetEulerAngles does, with the trig called on x, y, z directly — the angles are radians, with no DegreeToRadian conversion. The 3-by-3 block is fully replaced; the fourth column, the bottom row and m44 are not touched.

Parameters

Return value

None; the rotation lands in *this.
