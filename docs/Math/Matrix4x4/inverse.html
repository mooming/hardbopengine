Inverse

member of hbe::Matrix4x4 Engine/Math/Matrix4x4.h the adjugate over the determinant, scaled once, terminating on a singular matrix

Signature

[[nodiscard]] This Inverse() const noexcept

Function description

Defined in Engine/Math/Matrix4x4.h as Matrix4x4::Inverse(). Computes det = Determinant(), FatalAsserts that it is non-zero — a check that fires in every build and terminates rather than unwinds — then fills every entry with its cofactor term scaled by invDet = 1/det and returns the result directly, with no further scaling:

		result.m44 = invDet * (m11 * m22 * m33 + m12 * m23 * m31 + m13 * m21 * m32 - m11 * m23 * m32 - m12 * m21 * m33 -
							   m13 * m22 * m31);

		return result;

From Engine/Math/Matrix4x4.h, Matrix4x4::Inverse() — the tail

This is the true inverse for every invertible input — unlike Matrix3x3::Inverse(), which scales twice. Check IsInvertible first when a singular matrix is a possible input; Inverse itself does not return a failure, it stops the program.
