destructor

member of hbe::RingBuffer Engine/Container/RingBuffer.h destroy what is still queued and return every block, from the consumer thread after producers have stopped

Signature

~RingBuffer()

Function description

Destroys every element still queued and returns every block of memory. It is DestroyAll followed by the release of the producer slot array.

The contract is the same one that makes the single-consumer rule workable: destroy the queue from the consumer thread, after the producer threads have stopped. There is no reclamation protocol protecting a producer that is inside Push when the queue dies, and producer slots are not a lifetime guard for the queue object itself — they only keep individual blocks alive while the chain is turning over. Elements are destroyed in queue order, oldest block first, and within a block in the ring's own order from its read index, so a destructor never destroys an element the consumer already handed out.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

Nothing. It is not noexcept-declared, because it runs the destructors of T, which the engine convention expects not to throw.

Examples

Illustrative — no call site for this exists in the repository.

// Producers have been joined; the consumer has drained what it wanted.
queue.~RingBuffer();
