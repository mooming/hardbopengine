AcquireBlock

member of hbe::RingBuffer Engine/Container/RingBuffer.h extend the chain under the management mutex, or report the fuse reached

Signature

[[nodiscard]] Block* AcquireBlock(Block* inFullBlock) noexcept

Function description

The only path that grows the chain, and the only place this queue takes a lock on a producer's way through. It is called when the tail block has taken every reservation its ring can hold (claim at BlockCapacity), or when no block exists yet.

Under the management mutex it first gives the deferred blocks another chance (RetryDeferredBlocks), so a producer that arrives at a full tail is the one most likely to be blocking a recycle, and it is also the one already holding the lock that would free it. It then re-reads the caller's block, so a thread that arrived a moment late reuses the block the winner created instead of building a duplicate. It then applies the fuse: maxBlocks live blocks, and no more. A new block is linked by one release compare-and-swap from null into the full block's next, and tail is advanced by compare-and-swap so that a thread whose block lost the race still ends up pointing at the block that won.

Lock order: managementLock is taken here and the allocator's own lock is taken inside it, by AllocateBlock. That order is never reversed anywhere in this file, and it has to hold, because MemoryManager's allocator may be the thread-safe multi-pool, which takes an instance mutex per allocation.

The first block of all goes into chainRoot, which is where the consumer looks when it has never had a block; the producer that loses that race frees its own block and adopts the winner's.

Parameters

NameWhat the caller must supply
Block* inFullBlock The block that is full, or nullptr to ask for the very first block of the queue.

Return value

A block that is linked into the chain and safe to claim a slot from, or nullptr when the fuse is reached or the allocator refused. The caller reports those two cases the same way it reports a refused push.

Examples

Illustrative — no call site for this exists in the repository.

Block* next = block->next.load(std::memory_order_acquire);
if (next == nullptr)
{
        next = AcquireBlock(block);
        if (next == nullptr)
        {
                return EPushResult::Full;
        }
}
