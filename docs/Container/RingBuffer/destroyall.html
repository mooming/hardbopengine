DestroyAll

member of hbe::RingBuffer Engine/Container/RingBuffer.h destroy every queued element and free the whole chain, oldest first

Signature

void DestroyAll() noexcept

Function description

Tears the whole chain down: every block is freed, oldest first, and freeing a block runs its destructor, which destroys the elements that block's ring still holds. Nothing is walked element by element, because the chain keeps no element bookkeeping — the backend destroys its own queue, in its own order, from its own read index.

It starts at head when the consumer has ever popped, because everything before it has already been recycled; when the consumer never ran it starts at chainRoot and destroys what the producers left. Elements the consumer already handed out are not destroyed twice, because the ring destroyed its copy the moment Pop moved it out.

Blocks that were retired but deferred because a producer still declared them are freed here as well: they are no longer reachable from head, so the chain walk would miss them.

It takes no lock. That is sound only under the destructor's contract — the consumer thread, with producers quiesced — and it is why that contract is stated on the destructor page rather than left to a comment.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

Nothing. On return the queue looks brand new (chainRoot, tail, head are null and blockCount is zero) but must not be used again.

Examples

Illustrative — no call site for this exists in the repository.

while (block != nullptr)
{
        Block* next = block->next.load(std::memory_order_relaxed);
        FreeBlock(block);
        block = next;
}
