FreeBlock

member of hbe::RingBuffer Engine/Container/RingBuffer.h destroy one block, and anything its ring still holds, then give its storage back to the allocator it came from

Signature

void FreeBlock(Block* inBlock) noexcept

Function description

Runs the block's destructor and then hands its storage back. The destructor is what destroys the elements: it tears down the ring backend, and the backend destroys whatever it still holds in its own queue order. That is why this method can be called on a block that was never drained — the teardown at the destructor reaches blocks full of undelivered elements — and why the caller owes no element bookkeeping of its own. The storage is released by calling Free on the AlignedStorage<Block> the block carries, which holds the unaligned pointer and the byte count exactly as AllocateBlock obtained them, so a free cannot be written with a pointer or a size that disagrees with the allocation it belongs to. The handle is read out of the block before the destructor runs, because after it there is no block left to read it from.

It is called from three places with three different guarantees — RetireBlock after the slot scan has cleared, RetryDeferredBlocks for a deferred block that is no longer declared by anyone, and DestroyAll during teardown where no producer remains — and from all three with the management mutex held or the queue single-threaded.

Parameters

NameWhat the caller must supply
Block* inBlock A block this queue allocated and has not yet freed. Elements still inside it are destroyed here, so the caller does not have to drain the block first — but it must have finished with the block: no producer may declare it, and no thread may be about to read from it.

Return value

Nothing.

Examples

Illustrative — no call site for this exists in the repository.

StorageAllocator storageAllocator{allocator};
const AlignedStorage<Block> allocation = inBlock->allocation;

inBlock->~Block();                 // destroys the ring, and whatever the ring still holds
allocation.Free(storageAllocator);   // the handle read out before the destructor ran
