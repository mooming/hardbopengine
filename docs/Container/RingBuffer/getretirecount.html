GetRetireCount

member of hbe::RingBuffer Engine/Container/RingBuffer.h report how many blocks the queue has recycled

Signature

[[nodiscard]] size_t GetRetireCount() const noexcept

Function description

A diagnostic counter over blocks this queue has recycled. Counters are relaxed atomics, so reading one never synchronises with anything and a reader can see a value that is briefly stale. Written by any producer under the management mutex; the counter is atomic, so it may be read from any thread.

These three exist because the interesting failure modes of a block-chained queue are invisible from the outside: a queue that recycles nothing, or one that spends its life blocked, behaves correctly and merely costs.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

The counter as of this call. It never decreases. The live-block count a caller derives by subtracting it from GetGrowCount does fall as blocks are recycled.

Examples

Illustrative — no call site for this exists in the repository.

if (queue.GetGrowCount()() - queue.GetRetireCount() > maxBlocks)
{
        log("ring queue passed its fuse");
}
