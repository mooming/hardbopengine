IsEmpty

member of hbe::RingBuffer Engine/Container/RingBuffer.h decide emptiness from the head block's ring and its successor pointer together, from the consumer thread

Signature

[[nodiscard]] bool IsEmpty() const noexcept

Function description

Reports whether the consumer has nothing left to take. Evaluate it from the consumer thread, like Pop: it starts from head, the consumer's own non-atomic pointer.

Two words decide it, and one word is not enough. The head block's ring answers whether its own read index has caught up with its write index, and the head block's next answers whether the chain has anything behind it. Reading the ring alone would call a queue empty the moment its head block drained, with a second block full of elements behind it; reading next alone would call a queue that holds elements empty. Note which test is not here: IsEmpty does not consult the block's claim, so it decides from what the ring can see, and the consequence is in the return value below.

The answer is a snapshot, not a promise: a producer can push the instant after it returns true. It is a drain condition and a shutdown condition, not a lock.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

true when the head block's ring holds nothing and that block is still the last block of the chain, including the case where the queue has never been pushed to at all. false otherwise. The blocked case normally reads as non-empty, because a slot the ring has reserved but not yet published keeps the ring non-empty — a queue can report non-empty while Pop returns EPopResult::Blocked, and is right to do so. The one exception is the window in which a producer has won the block's claim but its call into the ring has not yet reached the ring's own counters: in that instant the ring looks empty and so does IsEmpty, while Pop — which compares claim against GetSlotVersion() — can see that reservation and answer Blocked. IsEmpty is therefore the weaker of the two tests: a caller that must not miss a committed element asks Pop, which at least consults the chain's own counter, and treats Empty from either method as a snapshot rather than a promise.

Illustrative — no call site for this exists in the repository.
