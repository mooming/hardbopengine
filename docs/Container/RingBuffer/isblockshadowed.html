IsBlockShadowed

member of hbe::RingBuffer Engine/Container/RingBuffer.h ask whether any producer slot declares a block, which is the gate on freeing it

Signature

[[nodiscard]] bool IsBlockShadowed(Block* inBlock) const noexcept

Function description

Asks whether any producer slot declares this block, which is the only question the reclamation protocol needs answered. It scans producerSlotCount sequential-consistency loads — at most inMaxProducers of them, one LineSpacing apart — and it is called only from under the management mutex, on a path taken once per block.

A scan is a snapshot, not a lock: a producer may declare this block the instant after the scan passes. That is why the caller must have made the block unreachable from tail first, so that a producer starting from scratch can no longer find it. Between those two facts there is no window for a producer to enter, only for one already inside to leave.

Parameters

NameWhat the caller must supply
Block* inBlock A block this queue allocated and the consumer has left.

Return value

true when some slot currently declares this block, in which case its memory must not be reused yet.

Examples

Illustrative — no call site for this exists in the repository.

if (IsBlockShadowed(inBlock))
{
        deferredBlocks.push_back(inBlock);

        return;
}
