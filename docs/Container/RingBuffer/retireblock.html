RetireBlock

member of hbe::RingBuffer Engine/Container/RingBuffer.h recycle a drained block unless a producer is still standing inside it

Signature

void RetireBlock(Block* inBlock, Block* inSuccessor) noexcept

Function description

Recycles the block the consumer has just finished with: claimed to its capacity, drained in both senses — the ring reports no element and the chain reports no reservation the ring has not taken — and no longer the head, so nothing can still be arriving inside it. Freeing it runs its destructor, which destroys whatever the ring might hold; on this path the ring is empty, so that destructor has nothing to do.

It does two things in one critical section, and their order is the whole correctness argument. First it compares-and-swaps tail from this block to its successor, so from that instant no producer can acquire the block afresh — tail only ever moves forward. Then it scans the producer slots for a thread still declaring this block, and frees it or defers it accordingly. Reversing those two steps is not a detail: retiring a block that tail still names leaves producers reaching into freed memory, which is exactly the defect this order was introduced to close.

A deferred block goes on deferredBlocks and is retried by RetryDeferredBlocks on the next advance and on every attempt to grow. The scan is at most inMaxProducers words, on a path taken once per block.

Parameters

NameWhat the caller must supply
Block* inBlock The block the consumer just left. Called by the consumer only, with the cursor already moved off it.
Block* inSuccessor The block inBlock links to, which becomes the new tail if tail still names the block being retired. It must not be null: a block with no successor is never retired.

Return value

Nothing. Whether the block was freed is visible as GetRetireCount and as the live-block count the fuse enforces.

Examples

Illustrative — no call site for this exists in the repository.

Block* expected = inBlock;
tail.compare_exchange_strong(expected, inSuccessor, std::memory_order_seq_cst, std::memory_order_relaxed);

if (IsBlockShadowed(inBlock))
{
        deferredBlocks.push_back(inBlock);

}
