Find

member of hbe::LinkedList Engine/Container/LinkedList.h a pointer to the first equal element, or nullptr

Signature

[[nodiscard]] TType* Find(const TType& value) noexcept

[[nodiscard]] const TType* Find(const TType& value) const noexcept

Function description

A walk comparing elements with operator==, returning a pointer to the first equal element or nullptr. The pointer is an address into a list node — stable until that node is removed, and directly usable as the argument to Remove, which is what FindAndRemove does with it. Both overloads are [[nodiscard]]; a Find whose answer is discarded found nothing for nobody.

The walk is O(n), and the requirement it puts on TType is equality, not ordering — the inverse of Map::Find, which needs a comparator but never touches operator==.

Parameters

ParameterTypeRequirement
valueconst TType& The value to search for, compared with == against every element in order.

Return value

TypeWhat you get
TType* (or const TType*) The first matching element's address, or nullptr when nothing matches — and the mutable form is what makes the element-reference mutation pattern possible

Examples

		int* const middle = intList.Find(30);
		if (middle == nullptr)

From Engine/Container/LinkedList.cpp, LinkedListTest::Prepare()

The test then mutates around that pointer — AddNext(*middle, 35) — which is the pattern the non-const form exists for: find an element, insert beside it, remove it.
