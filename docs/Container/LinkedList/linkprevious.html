LinkPrevious

member of hbe::LinkedList Engine/Container/LinkedList.h the four-line splice that inserts before a node

Signature

void LinkPrevious(Node* node, Node* newNode) noexcept

Private — the pointer rewiring behind AddPrevious, documented here because the four-line splice is the whole insertion mechanism.

Function description

Splices newNode into the chain immediately before node: node's previous is re-pointed at the new node, the new node's next at node, the new node's previous at the old predecessor, and — the line that makes it a doubly-linked list and not two half-chains — the old predecessor's next at the new node, when one exists. The head update is not done here; it is AddPrevious's job, because only that method knows whether the list was empty.

Both pointers are asserted non-null — an empty list never reaches the splice, because AddPrevious handles that case by assigning head and tail directly.

Parameters

ParameterTypeRequirement
nodeNode* The node to insert before; non-null, asserted.
newNodeNode* The detached node to splice in; non-null, asserted.

Return value

None. The chain now runs through newNode where it used to run straight to node.

Examples

Illustrative — private, and reachable only through AddPrevious.

node->previous = newNode;
newNode->next = node;
newNode->previous = prev;

if (prev)
{
	prev->next = newNode;
}
