Add

member of hbe::LinkedList Engine/Container/LinkedList.h append at the tail — a spelling convenience for AddLast

Signature

TType& Add(const TType& value) noexcept

TType& Add(TType&& value) noexcept

Function description

Two overloads, one forwarding line each: AddLast — the element goes at the tail, and the reference returned is the element inside the node the list just allocated. The lvalue form copies, the rvalue form moves. On an empty list either form sets both head and tail to the new node.

Allocation is the only way this can be expensive: one node, through the list's allocator, per call — and it is noexcept, so an allocation failure or a throwing element copy terminates the process rather than unwinding.

Parameters

ParameterTypeRequirement
valueconst TType& or TType&& The element to append. Copied or moved into a node the list allocates; no other requirement.

Return value

TType& — a reference to the stored element, stable until its node is removed, and usable as the current argument of AddNext or AddPrevious.

Examples

			for (int i = 0; i < COUNT; ++i)
			{
				intList.Add(i);
			}
