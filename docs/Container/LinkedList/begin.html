begin

member of hbe::LinkedList Engine/Container/LinkedList.h the first node — and ConstIterator is Iterator

Signature

Iterator begin() noexcept

ConstIterator begin() const noexcept

Function description

An iterator to the first node — Iterator(head), a wrapped node pointer, forward-only (operator++ returns void and steps node->next). Together with end() it is a range that is correct in every state, because the chain is the truth: there is no buffer to wrap and no cursor arithmetic to go wrong, unlike Deque's same-looking pair.

ConstIterator is Iterator, and the const overload still hands out mutable elements. The alias is literally using ConstIterator = Iterator;, and the const begin() wraps the member pointer — a Node* const in a const method — into an Iterator over plain nodes. Ranging over a const LinkedList& yields TType&, and writing through it compiles. Const-ness of the list is not enforced through iteration.

An iterator dies when its node is removed — RemoveNode frees it — and survives every insertion, including ones that rewire the chain around it.

Parameters

None.

Return value

TypeWhat you get
Iterator (or ConstIterator, the same type) A wrapped pointer to the first node; on an empty list it equals end()
