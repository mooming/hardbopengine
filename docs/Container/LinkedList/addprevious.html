AddPrevious

member of hbe::LinkedList Engine/Container/LinkedList.h insert before an element the list owns — located by address, asserted

Signature

TType& AddPrevious(TType& current, const TType& value) noexcept

TType& AddPrevious(TType& current, TType&& value) noexcept

Node* AddPrevious(Node* current, Node* node) noexcept

Function description

Inserts before an element the list already owns. The element is located by address — GetNodeOf recovers the node from the reference, after ContainsElement's assert confirms the list actually allocated it — so the argument must be an lvalue this list owns: something from an iterator, Find, Add or AddNext. A temporary or a foreign object that merely compares equal is rejected by the assert, not silently misplaced. Taking a non-const reference is what makes that contract mechanical.

The new node is allocated through the list's allocator, spliced in by LinkPrevious, and becomes the new head when current was the head. The lvalue form copies the value, the rvalue form moves it; both are noexcept, so a failed allocation or a throwing copy terminates the process.

Parameters

ParameterTypeRequirement
currentTType& An element this list owns, located by address — the insertion point's predecessor slot.
valueconst TType& or TType&& The element to insert, copied or moved into the new node.

Return value

TType& — a reference to the newly inserted element, which now precedes current.

Examples

Illustrative — the repository exercises AddNext; this is its mirror.

int* const pos = list.Find(30);
list.AddPrevious(*pos, 25);	// 25 now sits immediately before 30
