AddNext

member of hbe::LinkedList Engine/Container/LinkedList.h insert after an element the list owns — located by address, asserted

Signature

TType& AddNext(TType& current, const TType& value) noexcept

TType& AddNext(TType& current, TType&& value) noexcept

Node* AddNext(Node* current, Node* node) noexcept

Function description

Inserts after an element the list already owns. The element is located by address — GetNodeOf recovers the node from the reference, after ContainsElement's assert confirms the list actually allocated it — so the argument must be an lvalue this list owns: something from an iterator, Find, Add or a previous AddNext. A temporary or a foreign object that merely compares equal is rejected by the assert, not silently misplaced.

The new node is allocated through the list's allocator, spliced in by LinkNext, and becomes the new tail when current was the tail. The lvalue form copies the value, the rvalue form moves it; both are noexcept, so a failed allocation or a throwing copy terminates the process.

Parameters

ParameterTypeRequirement
currentTType& An element this list owns, located by address — the insertion point.
valueconst TType& or TType&& The element to insert, copied or moved into the new node.

Return value

TType& — a reference to the newly inserted element, which now follows current.

Examples

		int* const middle = intList.Find(30);
		...
		if (intList.AddNext(*middle, 35) != 35)
