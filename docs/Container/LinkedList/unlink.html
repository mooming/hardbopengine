Unlink

member of hbe::LinkedList Engine/Container/LinkedList.h save, free, sew — the node goes back to the allocator before the gap is closed

Signature

void Unlink(Node* node) noexcept

Private — the teardown half of RemoveNode, documented here because the order of its operations is the order a caller's references die in.

Function description

Frees the node first — Delete<Node>(allocator, node), which destroys the element and returns the node's memory to the list's allocator — and then splices the neighbours together, using the previous and next pointers saved before the delete. The head and tail updates are RemoveNode's job; this method only sews the gap shut.

The order is safe because the neighbours' addresses are saved before the node's memory goes away — after Delete, the removed node's own link fields are gone, which is exactly why they were copied first. Every reference and iterator to the removed element dies at the Delete, not at the splice.

Parameters

ParameterTypeRequirement
nodeNode* A node of this list, not nullptr — asserted. Its neighbours may be null; both splices are guarded.

Return value

None. The node's memory is back with the allocator, and its two neighbours are linked to each other.

Examples

Illustrative — private; RemoveNode is its only caller.

auto prev = node->previous;
auto next = node->next;

Delete<Node>(allocator, node);

if (prev != nullptr)
{
	prev->next = next;
}

if (next != nullptr)
{
	next->previous = prev;
}
