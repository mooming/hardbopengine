Count

member of hbe::LinkedList Engine/Container/LinkedList.h how many elements compare equal — not the list's length

Signature

[[nodiscard]] Index Count(const TType& value) const noexcept

Function description

The number of elements equal to value — not the length of the list, which this class does not track at all. A full walk comparing with operator==, so O(n) always, empty or not.

The return type is hbe::Index — the engine-wide index alias from Engine/Core/Types.h, which resolves to int32_t — not the TIndex member alias the other containers in this module declare. A loop variable written as int against it happens to match today, but the type is the engine's, not this class's.

Parameters

ParameterTypeRequirement
valueconst TType& The value to count occurrences of, compared with == against every element.

Return value

TypeWhat you get
Index (int32_t) How many elements compare equal — 0 when there are none, with no upper bound short of the list's length
