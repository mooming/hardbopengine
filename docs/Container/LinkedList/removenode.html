RemoveNode

member of hbe::LinkedList Engine/Container/LinkedList.h detach a node, free it, return the node that followed

Signature

Node* RemoveNode(Node* node) noexcept

Function description

Private. Detaches one node from the chain and frees it, returning the node that followed it. Three steps, in order — the head pointer is moved up when node was the head, the tail pointer is moved down when it was the tail, and Unlink splices the neighbours together and returns the node to the list's allocator. The saved next is the return value, which is how Remove can hand the caller an iterator that stays usable.

It is the engine of both removal paths: Remove calls it with the node GetNodeOf recovered, and Clear calls it in a loop with the head until the list is empty. No assert guards the argument — the callers assert before arriving.

Parameters

ParameterTypeRequirement
nodeNode* A node of this list, not nullptr. The callers guarantee both; this method does not check.

Return value

The node that followed the removed one — nullptr when the removed node was the tail, which is exactly the end() sentinel.

Examples

Illustrative — private, and reachable only through Remove and Clear.

while (head != nullptr)
{
	RemoveNode(head);
}

That is Clear's body: the head moves up on every call, so the loop terminates when the last node is freed.
