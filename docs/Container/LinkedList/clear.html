Clear

member of hbe::LinkedList Engine/Container/LinkedList.h unlink and free one node at a time until the head runs out

Signature

void Clear() noexcept

Function description

Unlinks and frees nodes one at a time until the head runs out — a while (head != nullptr) loop over RemoveNode, so every node is destroyed and returned through the list's own allocator, in queue order. It is O(n) and the only bulk release the class offers.

Every reference and iterator into the list dies here. The test's name is the contract's sharpest edge — Clear leaves no tail behind: a clear that forgot the tail would leave a list that IsEmpty reports empty but whose tail pointer still names freed memory, and the next AddLast would link onto it.

Parameters

None.

Return value

None. Afterwards IsEmpty is true.

Examples

		intList.Add(7);
		intList.Clear();

		if (!intList.IsEmpty())

The same test then Adds again and counts — a cleared list must be a genuinely empty one, with no tail to walk.
