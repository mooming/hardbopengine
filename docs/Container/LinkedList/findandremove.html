FindAndRemove

member of hbe::LinkedList Engine/Container/LinkedList.h the value-equality removal path — first match only, bool as the whole report

Signature

bool FindAndRemove(const TType& value) noexcept

Function description

The value-equality removal path: Find locates the first element comparing equal, and Remove frees its node. Two walks when it succeeds — one to find, one that Remove's own ContainsElement assert performs — and one walk when it fails, answered as false. No exception, no assert on a miss: the bool is the whole report.

Only the first match goes; a list with duplicates keeps the rest. Callers that want every match removed loop on the return value.

Parameters

ParameterTypeRequirement
valueconst TType& The value to search for and remove. Compared with ==; any equal element may be the one that goes.

Return value

true when an element was found and removed, false when nothing matched.

Examples

Illustrative — no direct call site for this exists in the repository.

while (list.FindAndRemove(staleValue))
{
	// every match goes, one per iteration
}
