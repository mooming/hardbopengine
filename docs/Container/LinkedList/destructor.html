~LinkedList

member of hbe::LinkedList Engine/Container/LinkedList.h Clear: every node unlinked, destroyed and returned through the list's allocator

Signature

~LinkedList() noexcept

Function description

Explicitly noexcept, and its whole body is Clear: every node is unlinked and destroyed, one at a time, each returned through the list's own allocator — which therefore has to outlive the list. There is no drain and no report: elements still chained are destroyed here.

The test exercises exactly this contract with a scoped pool allocator — construct, fill, let the scope close, and the pool's bookkeeping confirms every node came back.

Parameters

None.

Return value

A destructor has no return value. The noexcept is declared, not implicit: an element destructor that throws terminates the process.
