Contains

member of hbe::LinkedList Engine/Container/LinkedList.h value equality or address identity — two different questions, one walk each

Signature

[[nodiscard]] bool Contains(const TType& value) const noexcept

[[nodiscard]] bool Contains(const TType* ptr) const noexcept

Function description

Two overloads that answer different questions. The value form walks the list comparing elements with operator== — "does an equal element exist?" The pointer form walks comparing addresses, &element == ptr — "is this object in the list?" The second is the identity test ContainsElement performs to validate a removal, and value equality is deliberately not sufficient for that: two equal elements in different nodes are different nodes.

Both walks are O(n) and both are [[nodiscard]], so discarding the answer is a compile error.

Parameters

ParameterTypeRequirement
value / ptrconst TType& or const TType* The value to compare equal against every element, or the address to match by identity.

Return value

true when a matching element (or the pointed-to object) is in the list, false otherwise.

Examples

Illustrative — no direct call site for this exists in the repository; the class's own Remove path is the identity overload's caller.

if (list.Contains(&element))
{
	list.Remove(element);
}
