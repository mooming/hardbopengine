AddFirst

member of hbe::LinkedList Engine/Container/LinkedList.h prepend — one allocation, O(1), the new node becomes the head

Signature

TType& AddFirst(const TType& value) noexcept

TType& AddFirst(TType&& value) noexcept

Function description

Prepends: one node allocated through the list's allocator, handed to AddPrevious(head, node), and the returned reference is the element inside it. The lvalue form copies, the rvalue form moves. On an empty list the new node becomes both head and tail.

It is O(1) — no walk, the head pointer is the whole story — and noexcept, so a failed allocation or a throwing element copy terminates the process rather than unwinding. Nothing is returned but the element reference; reach the node's links through the list, never directly.

Parameters

ParameterTypeRequirement
valueconst TType& or TType&& The element to prepend, copied or moved into the new node.

Return value

TType& — a reference to the stored element, now the list's first, stable until its node is removed.

Examples

Illustrative — no direct call site for this exists in the repository; the test fixture appends with Add instead.

list.AddFirst(0);	// now the first element, previous iteration order intact
