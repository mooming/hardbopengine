EPopResult

Engine/Container/EPopResult.h the one answer every pop in the ring family returns — element, empty, and the chain-only third answer

Class description

EPopResult is the one enum class over unsigned char that every pop in the ring family answers with — the four fixed rings and the RingBuffer chain. It is the read side of EPushResult: one shared type, so the concept CFixedRing<T, U> compares a backend's answer against it instead of reaching through typename U::EPopResult and re-checking enumerators.

Element means a value was moved into the out-parameter and its slot released. Empty means nothing was available and the out-parameter was untouched. Blocked is the chain's third answer: the queue is empty right now but must not be treated as finished, because a producer reserved a block ahead of publishing — popping into Blocked is the consumer learning that in-flight work exists, and it is counted at GetBlockedCount.

A fixed ring never answers Blocked. A bare ring cannot observe a reservation without taking one, so its two answers are Element and Empty, and the concept demands only those two of a backend. The enumerator exists because one type carries the family; reading a bare ring's answer, it cannot arrive.

Template parameters

None — an enumeration is not a template.

Class properties

NameDeclarationWhat it means
Element= 0 enumerator One value was moved to the caller and its slot is free again. The only enumerator that means the out-parameter holds something.
Empty= 1 enumerator Nothing was available and the out-parameter was not written. For a fixed ring this is the only no-value answer; the caller decides whether to retry, park or stop.
Blocked= 2 enumerator Chain-only. Empty for now, but a reservation exists ahead of publication, so declaring the queue finished would lose an item a producer already owns. A consumer treats it as Empty plus the knowledge that progress is in hand.

Class methods

None — the enumeration is the entire interface.

Non-member helpers

None. No operator<< exists; printing switches on the enumerator at the call site.

Coverage

This page documents the type completely. The mechanics of when Blocked appears — the three-case Pop, the reservation window, the retirement interlock — are owned by RingBuffer::Pop and the queue's design document, which link back here.
