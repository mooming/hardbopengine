IsTail

member of hbe::LinkedListNode Engine/Container/LinkedList.h true exactly when next is nullptr

Signature

bool IsTail() const noexcept

Function description

True exactly when next is nullptr. A detached node is a tail by this test for the same reason it is a head: nothing has been linked after it. A forward walk that keeps stepping next stops here, and LinkedList uses the test to find where a splice or push must rewire the tail pointer.

Parameters

None.

Return value

true when the node has no successor, false when another node follows it.

Examples

The paired test is IsHead; a single-element list answers true to both, which is the boundary case the list's own splice logic and any hand-written walk must both handle.
