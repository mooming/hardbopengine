operator!=

member of hbe::LinkedListNode Engine/Container/LinkedList.h address identity, not value equality

Signature

bool operator!=(const This& rhs) const noexcept

Function description

Node identity, not value comparison: the result is this != &rhs. Two nodes holding equal TType values are different nodes, which is the property iteration relies on — walking a range until the node pointer equals the end sentinel compares addresses, and this operator is the negated form of that test.

Parameters

ParameterTypeRequirement
rhsconst This& Another node. Its value is never read; only its address matters.

Return value

true when the two operands are distinct node objects, false when both are the same node.

Examples

There is no matching operator== declared on the node; the equality direction of the identity test is spelled &a == &b by callers that want it. Comparing node values is spelled *a != *b through operator*.
