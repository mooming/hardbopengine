operator*

member of hbe::LinkedListNode Engine/Container/LinkedList.h dereferences the node to its stored value

Signature

TType& operator*() noexcept

const TType& operator*() const noexcept
const TType& operator*() const noexcept

Function description

Dereferences the node to its stored value. The node borrows the container idiom so a LinkedListNode<T>* reads like a pointer to the element: *node is the element itself, and the const overload keeps a const walk const. It returns a reference into the node, not a copy, so writing through it writes the element the list holds.

Parameters

None.

Return value

A reference to the node's value — mutable from a non-const node, const from a const one.

Examples

Reading a node's element and comparing two nodes' elements by value are the two uses: *node for the read, *a == *b for the value comparison — as opposed to operator!=, which compares the nodes themselves.
