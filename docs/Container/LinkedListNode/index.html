LinkedListNode

Engine/Container/LinkedList.h template <typename TType> final the node LinkedList allocates and links: value plus two pointers

Class description

LinkedListNode is the node LinkedList allocates, links and returns: one struct carrying the element and the two pointers that make a chain walkable in both directions. It is a struct on purpose — the value and the two links are the entire state, and the list manipulates them directly — but it is final and its links are set only by the list, so a node in a list is never a caller's object to rewire. A node is identified by its address, not by its value: operator!= compares addresses, which is what lets iteration detect the end of a range by node identity.

A node with previous == nullptr is a head and one with next == nullptr is a tail — there is no separate end sentinel, so IsHead and IsTail are the list's own boundary tests, and a single-element list is both at once.
