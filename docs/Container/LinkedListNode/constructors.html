Function description

A node is born detached: both links are nullptr, so the fresh node is a single-element list and IsHead and IsTail both hold. Only LinkedList attaches nodes to each other. The two constructors differ only in how the argument reaches value — copied for an lvalue, moved for an rvalue — and both are explicit, so a bare {value} never silently becomes a node.

Parameters

valueconst TType& or TType&& The element to store. Copied or moved into value; the node holds its own copy afterwards.

Return value

None — a constructor.

Examples

LinkedList is the intended constructor of nodes; its allocator builds them through this pair of signatures. Direct construction is legal for tests and for building a chain by hand before handing it to the list, but an unattached node is not a list element until something links it.
