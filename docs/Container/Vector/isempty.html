IsEmpty

member of hbe::Vector Engine/Container/Vector.h count == 0 — the guard before the operations that abort on empty

Signature

[[nodiscard]] bool IsEmpty() const noexcept

Function description

count == 0 — one field read. It is a guard with teeth here: PopBack, Front and Back all fatal-assert on an empty vector, so a caller that cannot prove non-emptiness asks this first.

Parameters

None.

Return value

true when the vector holds no elements, false otherwise. [[nodiscard]], so discarding the answer is a compile error.

Examples

		v.Clear();

		if (!v.IsEmpty())
