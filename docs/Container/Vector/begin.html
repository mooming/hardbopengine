Module Index / Container / Vector / begin

begin

member of hbe::Vector Engine/Container/Vector.h a raw TElement* — contiguous storage, no wrap, genuinely const iterators

Signature

Iterator begin() noexcept

ConstIterator begin() const noexcept

Function description

The first element — and because Iterator is literally TElement*, that is a raw pointer: the vector's storage is one contiguous array, so the pair of begin and end is a plain pointer range and range-for walks it in insertion order. Unlike Deque's same-looking pair, this one is correct after the buffer wraps — there is no wrap in a Vector.

Two properties worth knowing. On a vector that never allocated, begin() is a null pointer — valid to compare, never to dereference, and equal to end(). And ConstIterator is const TElement*, a genuinely const pointer: ranging over a const Vector& yields const TElement&, unlike Map, whose ConstIterator is its mutable Iterator under an alias.

Any PushBack that grows, any Reserve, and move assignment into the vector reallocate the buffer and kill every iterator.

Parameters

None.

Return value

TypeWhat you get
TElement* (or const TElement*) A raw pointer to the first live element; dereferenceable exactly while the buffer is not reallocated
