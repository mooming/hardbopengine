Back

member of hbe::Vector Engine/Container/Vector.h the last element — fatal assert on empty

Signature

TElement& Back()

const TElement& Back() const

Function description

The last element, data[count - 1], guarded by FatalAssert(!IsEmpty()) — on an empty vector the assert fires before the arithmetic could produce data[-1]. The const overload serves read-only callers.

The reference dies on the same events as a Front reference: a PopBack destroys the element it names, and a reallocation moves the buffer. A PushBack to a non-full vector does not move Back() — it replaces what it names.

Parameters

None.

Return value

TypeWhat you get
TElement& (or const TElement&) A reference to the element at index Size() - 1 — the one PopBack would remove next

Examples

		v.PopBack();

		if (v.Size() != 2 || v.Back() != 2)
