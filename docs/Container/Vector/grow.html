Grow

member of hbe::Vector Engine/Container/Vector.h max(DefaultCapacity, capacity * 2), handed to Reserve

Signature

void Grow() noexcept

Function description

Private. The growth policy in one line — std::max(DefaultCapacity, capacity * 2), handed straight to Reserve — so the first growth lands on DefaultCapacity = 4 elements and every later one doubles. It has no state of its own and no caller but the append paths (PushBack, EmplaceBack), each of which runs it exactly when count == capacity.

Every reallocation cost the vector ever pays goes through here or through an explicit Reserve; there is no third path, and nothing ever shrinks.

Parameters

None.

Return value

None. Afterwards Capacity is 4, or double what it was, and Size is unchanged.

Examples

Illustrative — private, and reachable only through the append paths.

if (count == capacity)
{
	Grow();
}

That guard opens PushBack and EmplaceBack alike; the element is constructed only after the buffer is known to have room.
