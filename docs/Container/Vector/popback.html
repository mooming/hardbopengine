PopBack

member of hbe::Vector Engine/Container/Vector.h destroy the last element, shrink the count — capacity untouched

Signature

void PopBack() noexcept

Function description

Destroys the last element and shrinks the count by one — in that order, count first, then the destructor on data[count]. It returns nothing: read the element through Back first if you want it, because this call hands back no value at all.

FatalAssert(!IsEmpty()) guards the front, so popping an empty vector stops the process rather than wrapping the count. Capacity is untouched — popping never shrinks the allocation, and the slot's memory is immediately reusable by the next PushBack.

Parameters

None.

Return value

None. Afterwards Size is one smaller and Capacity is unchanged.

Examples

		v.PushBack(1);
		v.PushBack(2);
		v.PushBack(3);
		v.PopBack();

		if (v.Size() != 2 || v.Back() != 2)
