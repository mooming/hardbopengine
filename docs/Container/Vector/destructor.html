~Vector

member of hbe::Vector Engine/Container/Vector.h destroy every element, then free the buffer sized by capacity

Signature

~Vector()

Function description

Three steps behind a null-buffer early return: destroy every live element through DestroyAll, then return the buffer — allocator.deallocate(data, capacity), sized by capacity, not by Size, because that is the size the allocation was made with. The allocator must outlive the vector.

There is no drain and no report: elements still in the vector are destroyed here. A vector that never allocated — default-constructed and never grown — returns immediately and touches nothing.

Parameters

None.

Return value

A destructor has no return value. It is implicitly noexcept, so an element destructor that throws terminates the process.

Examples

Illustrative — no call site for this exists in the repository; every vector's lifetime ends with its owner's.

{
	Vector<int> v;
	v.PushBack(10);
}	// elements destroyed, buffer released here
