Data

member of hbe::Vector Engine/Container/Vector.h the raw buffer — nullptr until the vector first allocates

Signature

[[nodiscard]] TElement* Data() noexcept

[[nodiscard]] const TElement* Data() const noexcept

Function description

The raw buffer — the same pointer begin() returns, exposed for pointer-plus-count APIs. It is [[nodiscard]] on both overloads, so throwing it away is a compile error, and the const overload hands back a const TElement* — a genuinely const view, with no Map-style alias behind it.

A vector that never allocated hands back nullptr. The default constructor sets data to null and nothing allocates until the first PushBack, Reserve or Resize — so Data() on a fresh vector is null, not a pointer to zero elements. Treat the pair Data(), Size() the way the class treats begin(), end(): comparable, never dereferenceable when the count is 0.

The pointer is valid until anything reallocates the buffer — growth, Reserve, move assignment, Swap — and Clear does not invalidate it.

Parameters

None.

Return value

TypeWhat you get
TElement* (or const TElement*) The buffer's first element, or nullptr for a vector that never allocated
