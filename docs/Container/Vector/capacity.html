Capacity

member of hbe::Vector Engine/Container/Vector.h the allocated element count — changes only through Reserve and Grow

Signature

[[nodiscard]] TIndex Capacity() const noexcept

Function description

How many elements the buffer can hold before the next PushBack reallocates. It changes only through Reserve — which sets it to exactly what was asked — and through the private Grow, which doubles it; PopBack and Clear never shrink it, and neither does anything else.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) The allocated element count; 0 for a vector that never allocated, and at least Size always

Examples

		v.Reserve(64);

		if (v.Capacity() < 64)
