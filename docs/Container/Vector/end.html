end

member of hbe::Vector Engine/Container/Vector.h data + count — one past the last element

Signature

Iterator end() noexcept

ConstIterator end() const noexcept

Function description

One past the last element: data + count. Together with begin it is a plain pointer range over contiguous storage — no wrap, no mask — and on an empty vector the two are equal (a null data plus a zero count). It is the sentinel every standard-algorithm call over the vector compares against.

end() is not dereferenceable, and like every pointer into the vector it dies on a reallocation: growth in PushBack, an explicit Reserve, Grow.

Parameters

None.

Return value

TypeWhat you get
TElement* (or const TElement*) A raw pointer one element past the last live one; valid for comparison always, for dereferencing never
