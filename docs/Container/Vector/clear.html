Clear

member of hbe::Vector Engine/Container/Vector.h destroy every element, keep the buffer

Signature

void Clear() noexcept

Function description

Destroys every live element through DestroyAll and sets count to 0 — buffer and Capacity untouched. A cleared vector is instantly reusable at zero allocation cost, which the test pins down: 

		v.PushBack(10);
		if (v.Size() != 1 || v[0] != 10)

From Engine/Container/Vector.cpp, VectorTest::Prepare()

Every reference and iterator into the vector dies here. Contrast the destructor, which destroys the elements and returns the buffer — Clear is the bulk path when the contents should stop existing but the storage is about to be used again.

Parameters

None.

Return value

None. Afterwards IsEmpty is true.

Examples

		v.PushBack(1);
		v.PushBack(2);
		v.Clear();

		if (!v.IsEmpty())
