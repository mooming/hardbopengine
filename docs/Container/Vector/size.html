Size

member of hbe::Vector Engine/Container/Vector.h the live element count as TIndex (int)

Signature

[[nodiscard]] TIndex Size() const noexcept

Function description

The live element count, read from count. The type is the class's TIndex — int — shared with Capacity and IsValidIndex, so index arithmetic across the three is type-consistent by construction.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) How many elements are live; 0 exactly when IsEmpty is true, and the bound IsValidIndex tests against
