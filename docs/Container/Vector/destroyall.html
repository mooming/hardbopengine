DestroyAll

member of hbe::Vector Engine/Container/Vector.h destroy every live element front to back, touching nothing else

Signature

void DestroyAll() noexcept

Function description

Private. Destroys every live element, front to back — count destructor runs over data[0 .. count - 1] — and touches nothing else: no count reset, no deallocation, no cursor work (a vector has no cursors to reset).

That narrowness is why it has three callers with different tails: Clear follows it with count = 0, the destructor with the buffer deallocation, and move assignment with the steal. The element PopBack would remove next is the last destructor to run.

Parameters

None.

Return value

None. Every element that was live is destroyed; the buffer's bytes are untouched.

Examples

Illustrative — private; Clear, the destructor and move assignment are its only callers.

for (TIndex i = 0; i < count; ++i)
{
	data[i].~TElement();
}

The whole method. Unlike FixedRingBuffer's version there is no wrap arithmetic — a vector's live elements are always the front of the buffer.
