FindIndex

member of hbe::Vector Engine/Container/Vector.h linear search with operator== — first match or -1

Signature

[[nodiscard]] TIndex FindIndex(const TElement& element) const noexcept

Function description

A linear scan from the front, comparing each element with operator==, returning the index of the first match or -1 when nothing matches. It is noexcept only in the specification sense: the element comparison must not throw, because a throw inside a noexcept function terminates the process.

The cost is O(n) over Size, and the requirement it puts on TElement is equality, not ordering — the inverse of Map::Find, which needs a comparator but never touches operator==.

Parameters

ParameterTypeRequirement
elementconst TElement& The value to search for; compared with == against every live element in order.

Return value

TIndex (int) The first matching index — usable directly with operator[] — or -1

Examples
