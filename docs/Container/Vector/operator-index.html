operator[]

member of hbe::Vector Engine/Container/Vector.h the element at index, fatal-asserted in range — not noexcept

Signature

TElement& operator[](TIndex index)

const TElement& operator[](TIndex index) const

Function description

The element at index, guarded by FatalAssert(IsValidIndex(index)) — an out-of-range index stops the process rather than reading foreign memory. There is no unchecked form and no at-style checked-throwing form; this is the only indexed access.

Note what the signature does not say: neither overload is noexcept, unlike Array::operator[]. A call through a noexcept boundary is therefore treated as potentially throwing, even though nothing here can throw — the difference is real for exception specifications, and the class page records it because the two containers look interchangeable.

Parameters

ParameterTypeRequirement
indexTIndex (int) A position from the front, 0 to Size() - 1 — checked by IsValidIndex.

Return value

TElement& — a reference to the live element, mutable through the non-const overload, valid until PopBack, Clear or a reallocation moves the buffer.

Examples

		v.PushBack(10);
		if (v.Size() != 1 || v[0] != 10)
