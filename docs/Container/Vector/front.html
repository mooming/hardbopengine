Front

member of hbe::Vector Engine/Container/Vector.h the first element — fatal assert on empty

Signature

TElement& Front()

const TElement& Front() const

Function description

The first element, data[0], guarded by FatalAssert(!IsEmpty()) — an empty vector stops the process rather than returning a dead reference. The const overload is what a read-only caller gets. Neither overload is noexcept, for the same specification-level reason operator[] is not.

The reference is valid until the element is destroyed — PopBack, Clear, Resize to a smaller size — or the buffer moves under it through a reallocation.

Parameters

None.

Return value

TypeWhat you get
TElement& (or const TElement&) A reference to the element at index 0; begin() points at the same slot

Examples

		if (v.Front() != 10 || v.Back() != 20)
