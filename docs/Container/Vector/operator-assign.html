operator=

member of hbe::Vector Engine/Container/Vector.h copy deleted; move tears the destination down, then steals — the source ends truly empty

Signature

Vector& operator=(const Vector&) = delete

Vector& operator=(Vector&& rhs) noexcept

Function description

Two forms, one of them a refusal. Copy assignment is = delete; a vector is move-only. The move form is noexcept and guarded against self-assignment — assigning a vector to itself changes nothing.

For a genuine move, the destination first tears itself down — destroys its live elements and frees its buffer, when it has one — then takes the three fields (count, capacity, data) and zeroes the source. The source ends truly empty, with a null buffer: unlike FixedRingBuffer's swap-shaped move, nothing of the destination's former state survives anywhere. The allocator member is not moved — the destination keeps its own, which matters only for a stateful TAllocator.

Parameters

ParameterTypeRequirement
rhsVector&& The source vector. Its elements, capacity and buffer are taken; it is left null and empty.

Return value

*this, holding the source's former elements and buffer.
