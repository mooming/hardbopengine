member of hbe::AtomicStackView Engine/Container/AtomicStackView.h the only constructor — one null head, nothing allocated

Signature

AtomicStackView() noexcept
		: top(nullptr)

Function description

The only constructor. It initialises the single member — the std::atomic<T*> top; head — to nullptr, so a fresh AtomicStackView is an empty stack and the first Push becomes the head. It allocates nothing and touches nothing but that one pointer: the container owns no storage of its own, because the nodes live in objects the caller created.

It is noexcept, and it is the whole constructor list: there is no copy or move form, no sizing form and no range form. The copy and move operations are unavailable because std::atomic is neither copyable nor movable — two owners of one head pointer is the bug their deletion prevents.

Parameters

None.

Return value

A constructor has no return value. What you can observe afterwards is IsEmpty, which returns true on a freshly constructed stack.

Examples

AtomicStackView<TNode<bool>> stack;

From Engine/Container/AtomicStackView.cpp, AtomicStackViewTest::Prepare()

Every instantiation in the repository is a default construction followed by pushes; the test above constructs stacks of several element types purely to prove the empty state comes up for each of them.
