~AtomicStackView

member of hbe::AtomicStackView Engine/Container/AtomicStackView.h destroys the head pointer only — nodes still linked are neither unlinked nor freed

Signature

~AtomicStackView() = default

Function description

Destroys the std::atomic<T*> head and nothing else. Being defaulted, it walks no chain, frees no node and reports no leftovers: a stack destroyed while nodes are still linked simply loses the links, and the nodes — which the caller owns, because AtomicStackView is a view — survive wherever their real owner keeps them.

The destructor is not a drain. There is no count, no head accessor and no way to ask whether anything is still linked, so an owner that tears the stack down with elements still checked out leaks them without a diagnostic. The owner has to drain it — see Pop — before destruction if that matters.

Parameters

None.

Return value

A destructor has no return value. It is implicitly noexcept, and destroying a std::atomic<T*> cannot throw.

Examples

{
	AtomicStackView<TNode<bool>> stack;
	ls << "Bool Stack: [Done]" << lf;
}
