IsEmpty

member of hbe::AtomicStackView Engine/Container/AtomicStackView.h a relaxed load compared against null — a snapshot, not a reservation

Signature

[[nodiscard]] bool IsEmpty() const noexcept

Function description

One relaxed load of the top head compared against nullptr. It is a snapshot, not a reservation: the answer holds only at the instant of the load, and another thread can push or pop immediately after, so IsEmpty() == false does not make a subsequent Pop succeed — under contention that Pop can still return nullptr, and IsEmpty() == true can be stale in the other direction as well, because the load takes no part in the release ordering the push and pop use.

The [[nodiscard]] attribute is the only guard against misuse: calling it and throwing the result away asks a question and keeps no answer.

Parameters

None.

Return value

true when the head load returned null at that instant, false when some node was the head. Under concurrent access the result is advisory in both directions.

Examples

while (!stack.IsEmpty())
{
	if (stack.Pop())
	{
		++count;
	}
}

From Engine/Container/AtomicStackView.cpp, AtomicStackViewTest::Prepare()

The engine's own concurrent consumer loop shows the pattern the snapshot semantics force: IsEmpty only decides whether to keep trying, and every actual take re-tests the result of Pop — the loop trusts the pop, never the emptiness check.
