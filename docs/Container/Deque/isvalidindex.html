IsValidIndex

member of hbe::Deque Engine/Container/Deque.h 0 <= index < count — the check operator[] asserts with

Signature

[[nodiscard]] bool IsValidIndex(TIndex index) const noexcept

Function description

index >= 0 && index < count — the exact check operator[] fatal-asserts with. It tests a position from the front, not a slot in the raw buffer: in a wrapped deque the live elements occupy scattered slots, and this predicate knows nothing about them — only whether the position is inside the live range.

Parameters

ParameterTypeRequirement
indexTIndex (int) A candidate position from the front, as it would be passed to operator[].

Return value

true when the index names a live element, false when it is negative or at or past Size. [[nodiscard]], so discarding the answer is a compile error.

Examples

Illustrative — no call site for this exists in the repository; the class itself is the caller.

if (d.IsValidIndex(i))
{
	use(d[i]);
}
