Grow

member of hbe::Deque Engine/Container/Deque.h max(DefaultCapacity, Capacity * 2), handed to Reserve

Signature

void Grow() noexcept

Function description

Private. The growth policy in one line — std::max(DefaultCapacity, Capacity() * 2), handed straight to Reserve — so the buffer doubles whenever an append finds count == Capacity(), starting from the 4 slots the constructors allocate. Every append path (PushFront, PushBack, EmplaceFront, EmplaceBack) runs the same guard first; there is no other reallocation trigger and nothing ever shrinks.

Every growth moves all the elements and repacks them unwrapped (head back to slot 0), so every reference and iterator into the deque dies on the pushes that cross the capacity boundary.

Parameters

None.

Return value

None. Afterwards Capacity is 4, or double what it was, and Size is unchanged.

Examples

Illustrative — private, and reachable only through the append paths.

if (count == Capacity())
{
	Grow();
}

That guard opens every append in the class; the element is constructed only after the buffer is known to have room.
