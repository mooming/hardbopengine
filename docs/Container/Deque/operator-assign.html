operator=

member of hbe::Deque Engine/Container/Deque.h copy deleted; move assignment is a Swap — the source keeps the destination's former state

Signature

Deque& operator=(const Deque&) = delete

Deque& operator=(Deque&& rhs) noexcept

Function description

Two forms, one of them a refusal. Copy assignment is = delete; a deque is move-only. The move form is Swap and nothing else — noexcept, allocation-free, and safe on self-assignment because a swap with itself is a no-op.

Being a swap, it is not a drain: after a = std::move(b), b holds what a held — cursors, count, mask and buffer — rather than being left empty. And because capacity travels with the buffer, the two objects' ceilings are exchanged too. Each side keeps its own allocator.

Parameters

ParameterTypeRequirement
rhsDeque&& The source deque. All five fields are exchanged; it ends holding the destination's former state.

Return value

*this, holding the source's former buffer and contents.

Examples

Illustrative — no direct call site exists in the repository; the move constructor is the same operation in reverse.

a = std::move(b);
// a.Capacity() is now what b.Capacity() was
