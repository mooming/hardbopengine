Swap

member of hbe::Deque Engine/Container/Deque.h exchange all five fields — capacities travel with the buffers

Signature

void Swap(Deque& rhs) noexcept

Function description

Exchanges all five fields — both cursors, count, mask and the buffer pointer — in five std::swap calls. No element is touched, nothing is allocated, and it is noexcept by construction. It is the engine of the move constructor and move assignment, and it takes an lvalue reference, so the caller spells the move themselves.

Because capacity travels with the buffer (it is mask + 1, and mask is swapped), a swap exchanges the two objects' ceilings as well as their contents. Each side keeps its own allocator.

Parameters

ParameterTypeRequirement
rhsDeque& The deque to exchange state with. Self-swap is a harmless no-op.

Return value

None. Both deques emerge with the other's cursors, count, mask and buffer.

Examples

Illustrative — no direct call site exists in the repository; the move operations are its callers.

a.Swap(b);
// a.Capacity() is now what b.Capacity() was
