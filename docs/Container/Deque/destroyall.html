DestroyAll

member of hbe::Deque Engine/Container/Deque.h destroy every live element in queue order, wrapping — the walk that survives a wrap

Signature

void DestroyAll() noexcept

Function description

Private. Destroys every live element — count of them, starting at the head cursor and wrapping through the buffer with WrapIndex(head + i), so it visits the elements in queue order even when the ring has wrapped. It touches nothing else: no cursor resets, no deallocation, no count change.

That narrowness is why it has two callers with different tails: Clear follows it with cursor and count resets, and the destructor with the buffer deallocation. This is also the only element walk in the class that survives a wrapped buffer — the same visit through begin/end goes wrong after a wrap, which is why the class page calls those iterators unmasked.

Parameters

None.

Return value

None. Every element that was live is destroyed; the buffer's bytes are untouched.

Examples

Illustrative — private; Clear and the destructor are its only callers.

for (TIndex i = 0; i < count; ++i)
{
	auto idx = WrapIndex(head + i);
	data[idx].~TElement();
}

The whole method: queue order, head first, wrapped — the element PopFront would remove next is the first destructor to run.
