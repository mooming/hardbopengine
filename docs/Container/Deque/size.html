Module Index / Container / Deque / Size

Size

member of hbe::Deque Engine/Container/Deque.h the live element count — the one number correct across a wrap

Signature

[[nodiscard]] TIndex Size() const noexcept

Function description

The live element count, read from count — the one number that is correct across a wrapped ring, where cursor arithmetic is not: the distance from Front to Back in buffer slots is not Size() - 1 once the deque has wrapped. It is also the bound IsValidIndex tests.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) 0 when IsEmpty, Capacity when the deque is full, and the element count in between

Examples

		const size_t fifoCount = fifoQueue.Size();
