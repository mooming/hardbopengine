Clear

member of hbe::Deque Engine/Container/Deque.h destroy every element, zero the cursors — buffer and capacity untouched

Signature

void Clear() noexcept

Function description

Destroys every live element through DestroyAll and zeroes both cursors and the count — buffer and Capacity untouched, so a cleared deque is instantly reusable at zero allocation cost. The cursors going to zero also means the next fill starts at slot 0 of the raw buffer, whatever wrapping happened before.

Every reference and iterator into the deque dies here — including the unmasked range pair, which was fragile anyway. Contrast the destructor, which destroys the elements and returns the buffer.

Parameters

None.

Return value

None. Afterwards IsEmpty is true and Size is 0.

Examples

Illustrative — no call site for this exists in the repository; the engine's deques are drained by PopFront loops instead.

d.Clear();
assert(d.IsEmpty());
