PushFront

member of hbe::Deque Engine/Container/Deque.h the head cursor steps backwards — grow first when full

Signature

void PushFront(const TElement& value) noexcept

void PushFront(TElement&& value) noexcept

Function description

Inserts at the front: the head cursor steps backwards — head = WrapIndex(head - 1) — and the element is constructed in the slot it lands on. The two overloads differ only in how the element arrives: copied from an lvalue, moved from an rvalue.

Growth first, when count == Capacity(): Grow doubles the buffer and repacks it, so every reference and iterator into the deque dies on the pushes that cross the boundary — and survives on the ones that do not. The method is noexcept, so an element copy or move that throws terminates the process rather than unwinding.

Nothing is returned; reach the element afterwards through Front or operator[](0).

Parameters

ParameterTypeRequirement
valueconst TElement& or TElement&& The element to prepend. No other requirement beyond what the element's copy or move constructor imposes.

Return value

None.

Examples

		d.PushFront(10);
		d.PushFront(20);
		d.PushFront(30);

		if (d.Size() != 3 || d[0] != 30 || d[1] != 20 || d[2] != 10)
