Back

member of hbe::Deque Engine/Container/Deque.h the newest element, one slot behind the tail — wrap-correct, fatal assert on empty

Signature

TElement& Back() noexcept

const TElement& Back() const noexcept

Function description

The newest element, data[WrapIndex(tail - 1)] — the wrap arithmetic is the class's job, because the tail cursor names the next free slot, one past the last live element. FatalAssert(!IsEmpty()) guards the front, so an empty deque stops the process. This is another access that stays correct after a wrap, where end() does not.

The reference dies on PopBack (which destroys exactly this element), Clear, and reallocation. A PushBack to a non-full deque replaces what it names.

Parameters

None.

Return value

TypeWhat you get
TElement& (or const TElement&) A reference to the element one slot behind the tail cursor — index Size() - 1 through operator[]
