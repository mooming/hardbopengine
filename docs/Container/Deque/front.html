Front

member of hbe::Deque Engine/Container/Deque.h the oldest element at the head cursor — fatal assert on empty

Signature

TElement& Front() noexcept

const TElement& Front() const noexcept

Function description

The oldest element, data[head], guarded by FatalAssert(!IsEmpty()) — an empty deque stops the process rather than returning a dead reference. The const overload serves read-only callers. Unlike begin(), this address is exact no matter how far the ring has wrapped: the head cursor is always the front.

The reference is valid until the element is destroyed — PopFront, Clear — or the buffer moves under it through Reserve. A PushBack never moves it.

Parameters

None.

Return value

TypeWhat you get
TElement& (or const TElement&) A reference to the element at the head cursor — the one the next PopFront removes

Examples

			workItem = fifoQueue.Front();
			fifoQueue.PopFront();

From Engine/Core/TaskStream.cpp, TaskStream::Update()

Read then remove — the engine's shape, forced by there being no combined accessor, and safe here because the pair runs under the stream's own synchronisation.
