Module Index / Container / Deque / WrapIndex

WrapIndex

member of hbe::Deque Engine/Container/Deque.h index & mask — the bitmask that needs the power-of-two capacity

Signature

TIndex WrapIndex(TIndex index) const noexcept

Function description

The ring's arithmetic, in one line: index & mask. A bitwise mask replaces a modulo — cheaper, and only correct because Capacity is always a power of two, which is what makes mask exactly the low bits. Every cursor advance and every operator[] address in the class goes through this method, and it is public because the callers who index the raw buffer — DestroyAll, Back — are inside the class too.

Its contract is the mask's: for the non-negative index expressions the class feeds it (head + index, tail + 1, head - 1, tail - 1), the result is the index taken modulo the capacity, landing in 0 .. mask.

Parameters

ParameterTypeRequirement
indexTIndex (int) A cursor-plus-offset value. The mask is defined for what the class passes; a negative index has no stated behaviour.

Return value

TypeWhat you get
TIndex (int) The index wrapped into the buffer's slot range — the raw-buffer slot for that logical position

Examples

Illustrative — no direct call site for this exists in the repository.

// mask == 3: slots 0..3
WrapIndex(0);	// 0
WrapIndex(5);	// 1 — 5 & 3
WrapIndex(head + index);	// operator[]'s address computation
