Capacity

member of hbe::Deque Engine/Container/Deque.h mask + 1 — a power of two, never smaller than 4

Signature

[[nodiscard]] TIndex Capacity() const noexcept

Function description

mask + 1 — the element budget, kept as a bitmask minus one and reported by adding it back. A power of two, never smaller than DefaultCapacity = 4: both allocating constructors start there, Reserve doubles until a request is covered, and Grow doubles from there. Nothing ever shrinks it, and Clear leaves it standing.

The power of two is a correctness precondition, not just a size: WrapIndex masks with mask, which is only equivalent to a modulo when the capacity is a power of two.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) The allocated element count — a power of two, at least 4, fixed between growths
