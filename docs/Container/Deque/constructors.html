Function description

Four forms, one of them a refusal — and the surprise is that none of them is free. The default constructor allocates immediately: 

Deque() noexcept

From Engine/Container/Deque.h, Deque::Deque()

so an empty Deque holds a buffer of DefaultCapacity = 4 elements from birth — there is no lazy state. The sized form is explicit and reserves the larger of its argument and DefaultCapacity, rounded up to a power of two by Reserve's doubling. Copy construction is = delete.

The move constructor is Deque() then Swap: it allocates a fresh 4-slot buffer first and swaps, so moving a deque costs one allocation and the source ends holding that fresh buffer rather than nothing.

Parameters

ParameterTypeRequirement
initialCapacityTIndex (int) A floor on the buffer, not an exact size — the allocated capacity is the larger of this and 4, rounded up to a power of two.

Return value

A constructor has no return value. What you can observe afterwards is IsEmpty (true) and Capacity (at least 4, a power of two).
