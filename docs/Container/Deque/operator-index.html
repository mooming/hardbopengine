operator[]

member of hbe::Deque Engine/Container/Deque.h position from the front through WrapIndex — correct across a wrap, fatal-asserted in range

Signature

TElement& operator[](TIndex index)

const TElement& operator[](TIndex index) const

Function description

The element at index positions from the front, resolved through WrapIndex(head + index) — always wrap-correct, unlike begin/end, whose raw arithmetic goes wrong once the ring wraps. The guard is FatalAssert(IsValidIndex(index)): an out-of-range index stops the process. There is no unchecked form.

The class page pairs this with the iterators' weakness deliberately: indexing is the access that survives a wrapped buffer, iteration is the access that does not. Neither overload is noexcept.

Parameters

ParameterTypeRequirement
indexTIndex (int) A position from the front, 0 to Size() - 1 — checked by IsValidIndex, not a slot in the raw buffer.

Return value

TElement& — a reference to the live element, mutable through the non-const overload, valid until a PopFront/PopBack, Clear, Reserve or Swap moves the ring under it.

Examples

		d.PushFront(10);
		d.PushFront(20);
		d.PushFront(30);

		if (d.Size() != 3 || d[0] != 30 || d[1] != 20 || d[2] != 10)
