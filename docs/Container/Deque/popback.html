PopBack

member of hbe::Deque Engine/Container/Deque.h retreat the tail first, then destroy — fatal assert on empty

Signature

void PopBack() noexcept

Function description

Destroys the back element and retreats the tail cursor — and the order matters: tail = WrapIndex(tail - 1) runs first, then data[tail].~TElement(), because the tail cursor names the next free slot rather than the last live one. FatalAssert(!IsEmpty()) guards the front, so popping an empty deque stops the process.

It returns nothing: read the element through Back first. Capacity is untouched, and the vacated slot is immediately reusable by the next PushBack.

Parameters

None.

Return value

None. Afterwards Size is one smaller and Capacity is unchanged.

Examples

		d.PopBack();
		if (d.Size() != 2 || d.Back() != 2)
