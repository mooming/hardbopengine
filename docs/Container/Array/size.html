Size

member of hbe::Array Engine/Container/Array.h const noexcept the element count — which, for this container, is also the capacity

Signature

[[nodiscard]] TIndex Size() const noexcept;

Function description

Returns length. It is a field read: no allocation, no computation, and safe on an empty array.

Array has no Capacity to ask about, because the allocation is always exactly the element count — see Resize for what that costs and what it buys. Code ported from std::vector that expected size() and capacity() to differ finds only one number here.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) Number of constructed elements, 0 for an array that holds nothing. [[nodiscard]], so throwing the call away is a compile error. A negative value means something resized the array to a negative count — that is corruption, not an empty array

Examples

if (batch.Size() == 0)
{
        return;
}

// Size is the count, so the last valid index is Size() - 1.
const auto last = batch[batch.Size() - 1];
