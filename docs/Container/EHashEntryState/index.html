EHashEntryState

Engine/Container/HashMap.h enum class : uint8_t the state of one slot in a HashMap's open-addressed table

Class description

EHashEntryState is the one enum class over uint8_t that labels every slot of a HashMap's parallel states array. Open addressing with linear probing needs three distinguishable slot conditions, not two: a slot that has never held an entry terminates a probe, a slot that holds a live entry answers key comparison, and a slot whose entry was removed must be skippable by a probe yet reusable by an insert. Collapsing any two of those conditions either breaks lookup or leaks capacity, which is why the state array sits beside the entry array rather than inside it.

Template parameters

None — an enumeration is not a template, and this one is parameterised on nothing.

Class properties

NameDeclarationWhat it means
Empty= 0 enumerator The slot has never held an entry. A probe that reaches it may stop: no key further along the probe sequence can have hashed here.
Occupied= 1 enumerator The slot holds a live entry whose key a probe must compare against. Only slots in this state are destroyed by Remove.
Tombstone= 2 enumerator The slot's entry was removed, but its place in a probe chain must survive: a lookup that stopped here would miss keys that probed past it. An insert may reclaim the slot — HashMap decrements its tombstoneCount when it does — which is how removal never permanently shrinks the usable table.

Class methods

None — the enumeration is the entire interface, and the probe rules that give each state its meaning are owned by the HashMap pages of Insert, Find and Remove.

Non-member helpers

None. There is no operator<<: the state array is internal, so nothing outside the hash table prints a state.

Coverage

This page documents the type completely: three enumerators, their underlying width, and the probe-chain reason each state is distinct. The per-operation consequences — when a tombstone is reclaimed, when a probe stops — are owned by the HashMap method pages, which link back here.
