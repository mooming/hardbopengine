FixedRingMPSC

Engine/Container/FixedRingMPSC.h namespace hbe final Mutex-guarded fixed-size ring named for a single consumer — the same program as FixedRingMPMC, kept as a control pair

Under a mutex the number of consumers is not a variable of the program. There is no single-consumer trick left to play: the lock already serialises everything a lone consumer would otherwise be trusted with, so this class carries the same state and the same bodies as FixedRingMPMC. That is stated rather than hidden, because two names for one design had better be visibly two names for one design.

The two names are kept for a reason that is measurement rather than taxonomy: run as separate cells, their medians agree to 0.2% in the sparse regime, so the pair is a control that tells a reader how much of any difference in the table is the machine.
