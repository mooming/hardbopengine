Pop

member of hbe::FixedRingMPSC Engine/Container/FixedRingMPSC.h take the frontier element, or report nothing is ready

Signature

[[nodiscard]] EPopResult Pop(T& outItem)

Function description

Reads the frontier slot's readyIndex and, if the element there is published, takes it: move-assign into outItem, destroy the slot's element, then release the slot for the lap after next by storing index + Capacity.

The lock makes the frontier private state again: count == 0 is decided with the mutex held, so this answer is exact at the instant it is given rather than conservative. It never blocks: the lock is held for the length of the copy, and an empty ring is answered rather than waited on.

Empty can be a conservative answer, and the direction of the conservatism matters. A producer that has claimed the frontier index but not yet published it is invisible to this method, so an element may be on its way while the answer is Empty; what cannot happen is Empty while a published element sits at the frontier, or an element being reported twice.

Parameters

NameWhat the caller must supply
outItemAn object to move-assign into. It must already be a valid T; on Empty it is left untouched.

Return value

ValueMeaning
EPopResult::ElementoutItem holds the next element in order, and that slot is free again.
EPopResult::EmptyNothing is ready to take. Nothing was consumed, so the frontier is where it was.

Examples

Sample sample;
while (queue.Pop(sample) == Queue::EPopResult::Element)
{
        write(sample);
}
