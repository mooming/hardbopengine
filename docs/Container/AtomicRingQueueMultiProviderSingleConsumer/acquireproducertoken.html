AcquireProducerToken

member of hbe::AtomicRingQueueMultiProviderSingleConsumer Engine/Container/AtomicRingQueueMultiProviderSingleConsumer.h give a producer thread its hazard slot, cached in thread-local storage

Signature

[[nodiscard]] size_t AcquireProducerToken() noexcept

Function description

Gives the calling thread its producer slot: the index of the entry in producerSlots that this thread alone writes. The index is cached in a static thread_local, so the search costs one relaxed load on every push after the first and the mutex is touched once per thread per queue. Each slot sits on its own cache line, so declaring a block never contends with another producer's declaration. Caching a per-thread identity is the engine's own idiom for the same problem, used by MemoryManager (Engine/Memory/MemoryManager.h) for its scoped allocator.

The slot declares which block the thread is working on. Push writes the address there, re-reads tail to confirm nobody moved it, and only then dereferences the block; it clears the slot after its tag is published. RetireBlock will not free a block that any slot declares, and it will not retire one until tail has been moved off it, which together is what makes the reclamation sound: declaring after reading is only safe because the read is then repeated and the block's retirement is gated on the same pointer.

A slot is never released. A thread that finishes while holding one keeps it, so the number of distinct threads that ever push must not exceed inMaxProducers over the life of the queue, not merely at one instant. That is a real limit and it is stated here rather than hidden: on the engine it is comfortably satisfied, because producer threads are pool threads bounded by TaskSystem's hardware thread count.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

The thread's producer slot index, or InvalidProducerToken when every slot is claimed. Reaching that value asserts once and then repeats, because it is a construction-size error rather than a runtime condition; the caller turns it into EPushResult::TooManyProducers rather than letting the thread run untracked.

Examples

Illustrative — no call site for this exists in the repository.

const size_t token = AcquireProducerToken();
if (unlikely(token == InvalidProducerToken))
{
        return EPushResult::TooManyProducers;
}

hazards[token].block.store(block, std::memory_order_relaxed);
