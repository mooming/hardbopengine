FreeBlock

member of hbe::AtomicRingQueueMultiProviderSingleConsumer Engine/Container/AtomicRingQueueMultiProviderSingleConsumer.h give one block's storage back to the allocator it came from

Signature

void FreeBlock(LinkNode* inBlock) noexcept

Function description

Hands one block's storage back through the queue's allocator by calling Free on the AlignedStorage<LinkNode> the block carries, which holds the unaligned pointer and the byte count exactly as AllocateBlock obtained them. It does not destroy the elements inside: whoever calls this owes that there are none left, or has already destroyed them.

It is called from three places with three different guarantees — RetireBlock after the slot scan has cleared, RetryDeferredBlocks for a deferred block that is no longer declared by anyone, and DestroyAll during teardown where no producer remains — and from all three with the management mutex held or the queue single-threaded.

Parameters

NameWhat the caller must supply
LinkNode* inBlock A block this queue allocated, not yet freed, holding no live element.

Return value

Nothing.

Examples

Illustrative — no call site for this exists in the repository.

StorageAllocator storageAllocator{allocator};
inBlock->allocation.Free(storageAllocator);
