AllocateBlock

member of hbe::AtomicRingQueueMultiProviderSingleConsumer Engine/Container/AtomicRingQueueMultiProviderSingleConsumer.h allocate, align and clear one block without linking it into the chain

Signature

[[nodiscard]] LinkNode* AllocateBlock() noexcept

Function description

Asks the queue's allocator, rebound to bytes as StorageAllocator, for sizeof(LinkNode) + alignof(LinkNode) bytes and wraps the answer in an AlignedStorage<LinkNode> - the unaligned base, the aligned block address and the byte count, together as one value - which the node then carries, so FreeBlock cannot free with a pointer or a size that disagrees with the ones the allocation was made with. The node is placement-constructed at the aligned address and its BlockSlots tags are zeroed.

It links nothing and publishes nothing — that is AcquireBlock's job — which is why a block can be created and then discarded when another thread wins the race to extend the chain.

Call only with the management mutex held: it takes no lock itself, and the caller is the one that guarantees at most one thread extends the chain at a time.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

A constructed, unpublished block, or nullptr when the allocator refused. The allocator's own failure path already logs, so nothing is logged here.

Examples

Illustrative — no call site for this exists in the repository.

LinkNode* block = AllocateBlock();
if (unlikely(block == nullptr))
{
        return nullptr;
}
