Pop

member of hbe::AtomicRingQueueMultiProviderSingleConsumer Engine/Container/AtomicRingQueueMultiProviderSingleConsumer.h take the oldest element from the one consumer thread, distinguishing empty from claimed-but-unpublished

Signature

[[nodiscard]] EPopResult Pop(T& outItem) noexcept

Function description

Takes the oldest element out of the queue, if one is ready. The single consumer thread only. The cursor it advances (head, headCursor) is an ordinary non-atomic pair, and a second consumer would corrupt it silently.

It never spins and never waits. It looks at the slot the cursor points at, and that slot is in exactly one of three states: unpublished and never claimed, which makes the queue empty; claimed by a producer whose copy constructor has not finished, which makes it blocked; or published, which hands the element over. Reading a slot that is claimed but unpublished as "empty" would lose an element that is already committed, and skipping past it to the next slot would break first-in first-out, so the honest third answer is required and is what this method returns.

When the cursor runs off the end of a fully claimed block and a newer block exists, the cursor moves to that block and the one it leaves is retired. RetireBlock first moves tail off that block, so no producer can acquire it afresh, then frees it unless some producer's slot still declares it — in which case the block joins the deferred list and is freed by a later advance or by a producer that reaches the fuse. That is what bounds the chain at maxBlocks under a consumer that keeps up.

The element is move-assigned into outItem, its queue-side object is destroyed, and its tag returns to InvalidTag, so a recycled slot is indistinguishable from a virgin one.

Parameters

NameWhat the caller must supply
T& outItem Written only when the result is EPopResult::Element. On Empty and Blocked it is left exactly as the caller passed it, which the tests assert.

Return value

ValueWhat it means for the caller
EPopResult::ElementoutItem holds the oldest element. Call again to take the next.
EPopResult::EmptyNothing is claimed past the cursor and the block the cursor sits on is still the tail of the chain. A producer may add work at any moment, so this is not a promise.
EPopResult::BlockedThe oldest slot is claimed but not yet published. The element exists and is on its way; the caller must not treat this as empty and must not look past it. Each occurrence increments GetBlockedCount.

Examples

Illustrative — no call site for this exists in the repository.

Task task;
for (EPopResult result = queue.Pop(task); result != EPopResult::Empty; result = queue.Pop(task))
{
        if (result == EPopResult::Blocked)
        {
                doSomethingElseUseful();

                continue;
        }

        run(task);
}
