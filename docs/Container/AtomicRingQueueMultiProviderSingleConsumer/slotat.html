SlotAt

member of hbe::AtomicRingQueueMultiProviderSingleConsumer Engine/Container/AtomicRingQueueMultiProviderSingleConsumer.h turn a block and a claim index into a payload address with one mask

Signature

[[nodiscard]] static T* SlotAt(LinkNode& inBlock, size_t inIndex) noexcept

Function description

Turns a block and a claim index into the address of that index's payload slot. Because BlockSlots is a power of two the index is one mask, and no division appears anywhere on this path — that is the whole reason the slot count is a power of two rather than any number.

Slots are packed sizeof(T) bytes apart, and the base of the payload array is alignas(alignof(T)), so every slot address is correctly aligned for T - a precondition asserted by static_assert(sizeof(T) % alignof(T) == 0) rather than assumed. One element per sizeof(T) bytes is the densest layout available, and its cost is that neighbouring slots share a cache line. The tag array is a separate array, so a consumer draining tags walks one contiguous run of lines rather than striding over payloads.

Parameters

NameWhat the caller must supply
LinkNode& inBlock The block that owns the slot.
size_t inIndex A claim index, not a slot index: only its low bits are used.

Return value

The address of the payload inside the block's inline storage. It is valid only while the block is alive; see AcquireProducerToken for what keeps a block alive.

Examples

Illustrative — no call site for this exists in the repository.

T* slot = SlotAt(*block, claimIndex);
new (slot) T(inItem);
block->tags[claimIndex & SlotMask].store(claimIndex + 1, std::memory_order_release);
