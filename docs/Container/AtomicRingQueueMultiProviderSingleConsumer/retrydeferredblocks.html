RetryDeferredBlocks

member of hbe::AtomicRingQueueMultiProviderSingleConsumer Engine/Container/AtomicRingQueueMultiProviderSingleConsumer.h free the blocks earlier retires had to leave behind

Signature

void RetryDeferredBlocks() noexcept

Function description

Frees the blocks that earlier advances could not free because a producer declared them, keeping the ones still declared. Each freed block lowers the live-block count, which is what lets a queue that hit its fuse start accepting again without waiting for a new block to be built.

It is called from two places, both already holding the management mutex: every retire, and every attempt to grow. The second is the one that matters for liveness — a producer spinning at a full queue is a producer that keeps declaring a block, and it is also the only thread that will certainly run again soon. It never blocks on anything: a declared block is simply left on the list.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

Nothing. Freed blocks are counted by GetRetireCount; the ones still declared stay deferred until a later call.

Examples

Illustrative — no call site for this exists in the repository.

for (LinkNode* block : deferredBlocks)
{

        }
