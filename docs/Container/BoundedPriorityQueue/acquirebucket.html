AcquireBucket

member of hbe::BoundedPriorityQueue Engine/Container/BoundedPriorityQueue.h the deque for a priority, created on first use; an out-of-range priority aborts

Signature

[[nodiscard]] TBucket& AcquireBucket(std::size_t priority) noexcept

Function description

Private. Returns the deque for one priority level, creating it on first use — the mechanism that lets the queue declare 256 levels and allocate none of them until a level actually receives an item. The out-of-range case is an abort with a message, not undefined behaviour: 

	FatalAssert(priority < MaxPriority, "BoundedPriorityQueue priority is not a bucket index");

From Engine/Container/BoundedPriorityQueue.h, BoundedPriorityQueue::AcquireBucket(std::size_t)

A created bucket is sized by the BucketSizeHint template parameter when it is non-zero — emplaced with that capacity, cast to the bucket's index type — and default-constructed otherwise, leaving the deque to its own default. Only priorities actually used pay the hint, which is what makes a roomy hint affordable alongside MaxPriority = 256.

Callers never see this method: Push is the only code that calls it, and the returned reference is used immediately to append. It is documented because it owns the bucket-lifetime rule the rest of the class leans on — see ReleaseEmptyBucket for the other half.

Parameters

ParameterTypeRequirement
prioritystd::size_t A bucket index, strictly less than MaxPriority; the assert enforces it at run time.

Return value

A reference to the level's deque, created if this was the level's first item. The reference is valid until the bucket is released by ReleaseEmptyBucket or Clear.

Examples

Illustrative — private, and reachable only through Push.

auto& bucket = AcquireBucket(priority);
bucket.PushBack(item);

That pair is Push's body in miniature: acquire, append, then raise highestBucket if the level outranks it.
