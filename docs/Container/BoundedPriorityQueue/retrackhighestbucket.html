RetrackHighestBucket

member of hbe::BoundedPriorityQueue Engine/Container/BoundedPriorityQueue.h walks the tracked maximum down to the highest populated level

Signature

void RetrackHighestBucket() noexcept

Function description

Private. Walks highestBucket down to the next level that still holds items — the tracked maximum that Pop and Top serve from — after the level it named has been released by ReleaseEmptyBucket.

The walk stops at 0 even when level 0 holds nothing, which is harmless by construction: every reader checks totalSize first and never dereferences buckets[highestBucket] on an empty queue. The cost is paid when a queue drains toward empty, not on every pop — a pop from a level that still has items retracks in zero iterations.

Parameters

None.

Return value

None. Afterwards highestBucket names the highest populated level, or 0 when the queue is empty.

Examples

Illustrative — private, and reachable only through Pop, Remove and Clear's counter reset.

ReleaseEmptyBucket(servedFromLevel);
RetrackHighestBucket();

The pairing in Pop is the whole story: release what drained, then move the tracked maximum off anything that no longer exists.
