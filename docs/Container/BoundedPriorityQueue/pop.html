Pop

member of hbe::BoundedPriorityQueue Engine/Container/BoundedPriorityQueue.h the most urgent item, with its priority byte rewritten to the level it was served from

Signature

[[nodiscard]] std::optional<T> Pop() noexcept

Function description

Takes the oldest item at the highest populated priority and returns it — highest number is most urgent, and within one level arrival order rules, because each level is a Deque drained from its front. An empty queue answers std::nullopt: no assert, no abort, unlike Queue::Pop. The [[nodiscard]] attribute makes throwing the result away a compile error, and discarding it would lose the item.

The returned item's priority byte is rewritten to the level it was actually served from: 

	item.priority = static_cast<decltype(item.priority)>(servedFromLevel);

From Engine/Container/BoundedPriorityQueue.h, BoundedPriorityQueue::Pop()

That line is the contract for a quiet hazard: Push files an item by the byte and nothing afterwards re-sorts it, so code that writes the byte while the item sits in the queue leaves it filed under the old level while every read reports the new one. Rather than hand back an item whose two accounts disagree, Pop overwrites the byte with the served level. To change a queued item's priority, remove it and push it again — assignment cannot repair an order, only relocate the item.

Bookkeeping on the way out: the level's bucket is released if it drained (ReleaseEmptyBucket), the tracked maximum is walked down (RetrackHighestBucket), and totalSize drops by one.

Parameters

None.

Return value

TypeWhat you get
std::optional<T> The item, moved out of its bucket with priority rewritten to the served level, or std::nullopt when the queue was empty

Examples

	outTask = workItem;
	(void) taskQueue.Pop();

From Engine/Core/TaskSystem.cpp, TaskSystem::Dequeue

The engine's dequeue path inspects with Top first and only then pops — and the (void) cast is what silencing [[nodiscard]] looks like: legal, deliberate, and justified here because Top already produced the value the caller wanted.
