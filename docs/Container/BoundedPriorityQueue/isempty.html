IsEmpty

member of hbe::BoundedPriorityQueue Engine/Container/BoundedPriorityQueue.h totalSize == 0 — a field read, and the guard the callers run first

Signature

[[nodiscard]] bool IsEmpty() const noexcept

Function description

totalSize == 0 — one field read, no bucket walk. It is the queue's own guard for the operations that answer std::nullopt on empty: Pop and Top re-check the counter themselves, so nothing here depends on the caller asking first.

No synchronisation of any kind is declared in the header — totalSize is a plain field — so a queue shared between threads is safe only where the caller's lock says so. Engine/Core/TaskSystem.cpp holds taskQueueMutex around its taskQueue for exactly that reason.

Parameters

None.

Return value

true when the queue holds no elements, false otherwise. [[nodiscard]], so discarding the answer is a compile error.

Examples

	if (taskQueue.IsEmpty())
	{
		outTask.reset();

		return;
	}

	auto workItemOpt = taskQueue.Top();
