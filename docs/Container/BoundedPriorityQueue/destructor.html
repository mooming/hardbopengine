~BoundedPriorityQueue

member of hbe::BoundedPriorityQueue Engine/Container/BoundedPriorityQueue.h compiler-generated — destroys every live element and frees every bucket's buffer

Signature

~BoundedPriorityQueue() = default

Function description

Compiler-generated, and its work is entirely the members': the bucket array destroys each engaged optional<TBucket>, each engaged optional destroys its Deque, and each deque destroys its live elements and returns its buffer through the deque's own allocator. Every item still in the queue is destroyed here — nothing is handed anywhere, and there is no drain, no callback and no diagnostic about leftovers.

Because a bucket exists only while it holds something, the destructor frees buffers only for levels that currently have work; an idle level holds nothing to free. What a caller must arrange is exactly what the class's single ownership rule says: if the items matter, drain them before the queue dies.

Parameters

None.

Return value

A destructor has no return value. It is implicitly noexcept, so an element destructor that throws terminates the process rather than propagating.

Examples

Illustrative — no call site for this exists in the repository; every queue in the engine is a member whose lifetime is its owner's.

{
	BoundedPriorityQueue<TestItem> queue;
	queue.Push(TestItem(10));
}	// elements destroyed here, buffers released here

The engine never destroys a populated queue on purpose; the test fixtures construct, drain and let the scope close on an empty queue.
