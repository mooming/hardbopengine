Size

member of hbe::BoundedPriorityQueue Engine/Container/BoundedPriorityQueue.h the live element count as std::size_t — not the int of the contiguous containers

Signature

[[nodiscard]] std::size_t Size() const noexcept

Function description

The number of live elements across every priority level, read from totalSize — one field read, no bucket walk. Note the type: std::size_t, not the int-shaped TIndex of the contiguous containers in this module, so a loop variable written as int against this Size() is a signedness mismatch waiting for a warning to be promoted.

Parameters

None.

Return value

TypeWhat you get
std::size_t How many elements Pop can still hand out, summed over all populated buckets. 0 exactly when IsEmpty is true
