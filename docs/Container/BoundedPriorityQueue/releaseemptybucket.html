ReleaseEmptyBucket

member of hbe::BoundedPriorityQueue Engine/Container/BoundedPriorityQueue.h releases a bucket that has run dry, so an idle level holds no allocation

Signature

void ReleaseEmptyBucket(std::size_t priority) noexcept

Function description

Private. Resets the bucket's optional if the bucket exists and has run dry, so an idle priority level holds no allocation — its buffer goes back to the deque's allocator and the level costs nothing until the next Push to it.

This method maintains the invariant the rest of the class reads: engaged means non-empty. A bucket's optional is engaged only while that level holds items, and this is the only place that resets a drained bucket outside Clear. Pop, Remove and Top all lean on it — Top reads buckets[highestBucket]->Front() with no emptiness test of its own, because an engaged bucket is never empty.

Parameters

ParameterTypeRequirement
prioritystd::size_t The level to release. Callers pass a level they have just drained; a level that still holds items is left alone.

Return value

None. The bucket is either released or left engaged — the caller cannot tell which from the return.

Examples

Illustrative — private, and reachable only through Pop and Remove.

bucket.PopFront();
--totalSize;

ReleaseEmptyBucket(servedFromLevel);
RetrackHighestBucket();

That is Pop's tail: drain the item, then give the level back if it emptied, then walk the tracked maximum down.
