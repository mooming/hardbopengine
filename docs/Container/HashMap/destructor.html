Module Index / Container / HashMap / ~HashMap

~HashMap

member of hbe::HashMap Engine/Container/HashMap.h explicitly noexcept; Release destroys the pairs and returns the single block

Signature

~HashMap() noexcept

Function description

Explicitly noexcept, and its whole body is Release: destroy every occupied pair, return the buffer — one block carrying both the pairs and their state bytes — through the map's own allocator, and zero every field. There is no drain: entries still in the map are destroyed here.

A map that never allocated returns immediately; a map that did has exactly one allocation to return, because Rehash keeps pairs and states in a single block.

Parameters

None.

Return value

A destructor has no return value. The noexcept is declared, not implicit: a pair destructor that throws terminates the process.

Examples

Illustrative — no call site for this exists in the repository; every map's lifetime ends with its owner's.

{
	HashMap<int, int> m;
	m[1] = 10;
}	// pairs destroyed, buffer released here
