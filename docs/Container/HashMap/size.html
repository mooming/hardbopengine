Size

member of hbe::HashMap Engine/Container/HashMap.h the live entry count — tombstones excluded

Signature

[[nodiscard]] TIndex Size() const noexcept

Function description

The number of live entries, read from count — tombstones excluded, so it is the number of entries Find can actually return. Capacity() - Size() is therefore not the free room: the slots between the two numbers are a mix of empties and tombstones, and only ShouldGrow knows how the two count together.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) Live entries; 0 exactly when IsEmpty is true, and the count Clear returns to
