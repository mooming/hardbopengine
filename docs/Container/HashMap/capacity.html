Capacity

member of hbe::HashMap Engine/Container/HashMap.h the slot count — a power of two, 0 before the first allocation

Signature

[[nodiscard]] TIndex Capacity() const noexcept

Function description

The number of slots in the table — cap itself, a power of two once allocated and 0 before the first allocation. It changes only through Reserve and the private Grow (doubling from MinCapacity = 4), and Clear leaves it standing.

The power of two is a correctness precondition, not a tidiness preference: FindSlot and InsertInternal mask the hash with cap - 1, which is only equivalent to a modulo for a power of two.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) Slots allocated — a power of two, or 0 for a map that never allocated. Not the live count: see Size

Examples

Illustrative — no direct call site exists in the repository.

HashMap<int, int> m;
// m.Capacity() == 0 — the table does not exist yet
m[1] = 10;
// m.Capacity() == 4 — MinCapacity, from the first Grow
