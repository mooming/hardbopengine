IsValidSlot

member of hbe::HashMap Engine/Container/HashMap.h in range and Occupied — the predicate the iterators dereference through

Signature

[[nodiscard]] bool IsValidSlot(TIndex index) const noexcept

Function description

The slot predicate the iterators dereference through: index inside the table and state Occupied. Both halves matter — an in-range tombstone or empty slot is not valid, which is how iteration skips dead slots, and it is why operator* on an iterator asserts with this rather than a plain range check.

It is public because the iterator's dereference is, but a caller normally never writes it: the iteration and Find paths hand back only iterators whose slots are already valid.

Parameters

ParameterTypeRequirement
indexTIndex (int) A candidate slot index, 0 to Capacity() - 1.

Return value

true when the slot holds a live entry, false when the index is out of range or the slot is Empty or Tombstone. [[nodiscard]], so discarding the answer is a compile error.

Examples

Illustrative — no direct call site for this exists in the repository; the iterators are its callers.

FatalAssert(map != nullptr && map->IsValidSlot(index));

return map->entries[index];

That is Iterator::operator*'s guard: the assert is what makes a dereference of a stale or dead-slot iterator stop the process instead of reading whatever the slot now holds.
