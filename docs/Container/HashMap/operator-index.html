operator[]

member of hbe::HashMap Engine/Container/HashMap.h insert-or-read; a created slot gets a default-constructed value, and it can rehash

Signature

TValue& operator[](const TKey& key)

TValue& operator[](TKey&& key)

Function description

Insert-or-read, in one operator. FindSlot probes for the key; an Occupied match returns its value, and anything else — absent, or sitting on a tombstone — goes through InsertInternal, which creates the slot with a default-constructed value and returns the reference you write the real one into. There is no const overload: a lookup that may insert cannot be const, and read-only callers use Find or Contains.

It is the only way to overwrite an existing value, and it is the operation that can rehash: an inserting call may Grow the table first, which moves every entry and kills every reference and iterator into the map. The two overloads differ only in how the key arrives — copied from an lvalue, moved from an rvalue.

Parameters

ParameterTypeRequirement
keyconst TKey& or TKey&& The key to read or create. The value type must be default-constructible, because a created slot starts as TValue{}.

Return value

TValue& — a reference to the existing or just-created value, valid until the next insertion that rehashes the table.

Examples

		HashMap<int, int> m;
		m[1] = 10;
		m[2] = 20;
		m[3] = 30;

		if (m[1] != 10 || m[2] != 20 || m[3] != 30)
