Grow

member of hbe::HashMap Engine/Container/HashMap.h double from MinCapacity, hand to Rehash

Signature

void Grow() noexcept

Function description

Private. The growth policy in one line — std::max(MinCapacity, cap * 2), handed to Rehash — so the table doubles from MinCapacity = 4 whenever ShouldGrow says the load factor is reached. It is the engine behind every inserting path (operator[], Insert, InsertInternal); there is no other growth trigger and nothing ever shrinks.

Every growth rehashes — moves every live entry to a new slot computed from the new capacity — so every reference and iterator into the map dies on the insertions that cross the load boundary.

Parameters

None.

Return value

None. Afterwards Capacity is 4, or double what it was, and Size is unchanged.

Examples

Illustrative — private, and reachable only through InsertInternal.

if (ShouldGrow())
{
	Grow();
}

The guard-consequence pair is InsertInternal's opening: the load factor decides, the doubling answers.
