Function description

Four forms, one of them a refusal. The default constructor zeroes every counter and leaves both pointers null — a HashMap is born with no table at all, not even one slot, and Capacity() is 0 until the first insertion or an explicit Reserve. Unlike the module's deques and rings, nothing allocates at construction.

The sized form is explicit and forwards to Reserve — but only when the argument is positive, so HashMap<int, int> m(0) is exactly the default state. The capacity you get is the request rounded up to a power of two, at least MinCapacity = 4. Copy construction is = delete.

The move constructor steals the five fields and moves hash and keyEqual — the hashing policy travels with the table, which matters for a stateful THash — and zeroes the source.

Parameters

ParameterTypeRequirement
initialCapacityTIndex (int) A floor on the slot count. Non-positive means no allocation at all; positive means Reserve's rounding applies.

Return value

A constructor has no return value. What you can observe afterwards is IsEmpty (true) and Capacity (0 for the default form).
