Contains

member of hbe::HashMap Engine/Container/HashMap.h the const, noexcept membership test — Occupied or nothing

Signature

[[nodiscard]] bool Contains(const TKey& key) const noexcept

Function description

One probe sequence, answered true only when the slot found is Occupied — a tombstoned key reads absent, which is exactly what a caller wants after a Remove, and what makes a churned map's tombstone overhead invisible from the API. It is const and noexcept, so it is the membership test for read-only callers; operator[] cannot play this role because it would insert.

When the value is wanted too, prefer Find — this is a probe whose position is thrown away.

Parameters

ParameterTypeRequirement
keyconst TKey& The key to test for, hashed by THash and compared by TKeyEqual.

Return value

true when the map holds a live entry with that key, false otherwise. [[nodiscard]], so discarding the answer is a compile error.

Examples

Illustrative — no direct call site for this exists in the repository.

if (!m.Contains(5) || m.Contains(99))
{
	// present-and-absent, checked in one condition
}
