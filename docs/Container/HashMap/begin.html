begin

member of hbe::HashMap Engine/Container/HashMap.h the first occupied slot — found by a scan, in slot order that rehash rearranges

Signature

Iterator begin() noexcept

ConstIterator begin() const noexcept

Function description

An iterator to the first occupied slot — found by scanning the state array from slot 0, so on a sparse table begin() itself costs a walk over the empties. On an empty map the scan runs to cap and begin() == end().

Iteration order is slot order: a function of the hash, the capacity and the insertion history, and it changes on every Rehash. Nothing about it is sorted — a caller wanting ordered keys has the wrong container, and the sorted alternative in this module is Map.

The iterator skips tombstones as it advances (operator++ walks until it lands on an Occupied slot), so a range-for sees only live entries. Dereferencing asserts the slot is valid — see IsValidSlot — and every reference dies on the next insertion that grows the table.

Parameters

None.

Return value

TypeWhat you get
Iterator (or ConstIterator) An iterator over Pair — key and value — positioned at the first occupied slot
