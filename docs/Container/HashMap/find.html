Find

member of hbe::HashMap Engine/Container/HashMap.h one probe sequence — end() when the key is absent or its slot is a tombstone

Signature

[[nodiscard]] Iterator Find(const TKey& key) noexcept

[[nodiscard]] ConstIterator Find(const TKey& key) const noexcept

Function description

One probe sequence for the key — FindSlot — answered with an iterator to the entry, or end() when the slot found is not Occupied. A tombstoned key reads absent, which is the correct answer after a Remove. The [[nodiscard]] attribute gives the contract teeth: a Find whose answer is discarded found nothing for nobody.

When you want the value, this beats Contains plus operator[] — one probe instead of two, and no insertion on the miss path. The returned iterator dies on the next insertion that grows the table.

Parameters

ParameterTypeRequirement
keyconst TKey& The key to search for, hashed by THash and compared by TKeyEqual. No other requirement.

Return value

TypeWhat you get
Iterator (or ConstIterator) An iterator to the entry with that key, or end() when there is none

Examples

		auto it = m.Find(10);
		if (it == m.end() || it->value != 100)
