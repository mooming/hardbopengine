Release

member of hbe::HashMap Engine/Container/HashMap.h destroy every pair, return the block, zero every field — the only member that frees

Signature

void Release() noexcept

Function description

Private. The teardown both the destructor and move assignment run: destroy every occupied pair, return the single block — sizeof(Pair) * cap bytes of entries plus sizeof(EHashEntryState) * cap bytes of states, allocated together by Rehash — through the map's allocator, and zero every field. The map ends in its default-constructed shape: null pointers, capacity 0.

A null entries returns immediately, so releasing a never-inserted map destroys nothing and deallocates nothing. Note the asymmetry with Clear: Clear keeps the buffer and resets the states; Release is the only member that gives the memory back.

Parameters

None.

Return value

None. Afterwards Size() is 0, Capacity() is 0, and the buffer is gone.

Examples

Illustrative — private, and reachable only through the destructor and move assignment.

~HashMap() noexcept
{
	Release();
}

The destructor's whole body: everything this class does at end of life happens here, once.
