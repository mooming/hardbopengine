Grow

member of hbe::Map Engine/Container/Map.h double the buffer from DefaultCapacity, move the entries across

Signature

void Grow() noexcept

Function description

Private. Doubles the buffer — std::max(DefaultCapacity, cap * 2), so the first growth lands on DefaultCapacity = 4 pairs and every later one doubles — and moves the entries across. The new block is raw bytes from TAllocator, sized sizeof(Pair) * newCap; each live pair is move-constructed into the new array and destroyed in the old one; the old block is returned with its own byte size.

Every reference and iterator into the map dies here — the array moves to a new address. Nothing else in the class ever reallocates, so this is the single event a stored TValue& has to fear, plus the slot shifts that InsertSorted performs on top of it.

The allocator is whatever the map was constructed with; Grow allocates and deallocates through it and through nothing else.

Parameters

None.

Return value

None. Afterwards cap is at least doubled (or 4, from empty) and count is unchanged.

Examples

Illustrative — private, and reachable only through InsertSorted.

if (count == cap)
{
	Grow();
}

The guard is InsertSorted's opening move: the map grows exactly when an insertion needs one more slot than the buffer holds.
