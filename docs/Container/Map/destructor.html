Module Index / Container / Map / ~Map

~Map

member of hbe::Map Engine/Container/Map.h Release: destroy every pair, return the buffer, zero the fields

Signature

~Map()

Function description

Destroys every live pair and hands the buffer back, by way of Release — the destructor's entire body is that one call. Release early-returns on a null buffer, so a map that never inserted anything deallocates nothing, and a map that did destroys its pairs in index order (which is sorted-key order) before returning sizeof(Pair) * cap bytes through its allocator.

There is no drain and no report: items still in the map are destroyed here, full stop. The allocator must outlive the map — the deallocation happens with whatever TAllocator the map holds.

Parameters

None.

Return value

A destructor has no return value. It is implicitly noexcept, so a pair destructor that throws terminates the process rather than propagating.

Examples

Illustrative — no call site for this exists in the repository; every map in the engine is a member or local whose lifetime ends with its owner's.

{
	Map<int, int> m;
	m[1] = 10;
}	// pairs destroyed, buffer released here
