begin

member of hbe::Map Engine/Container/Map.h the first entry in sorted order — and ConstIterator is Iterator

Signature

Iterator begin() noexcept

ConstIterator begin() const noexcept

Function description

An iterator to the first entry in TCompare order. The entries live in one contiguous array kept sorted, so the pair of these methods is a plain pointer range: range-for walks the map in sorted key order with no tree, and <algorithm> binaries such as std::lower_bound are valid on it directly. On an empty map begin() == end().

The iterator is a wrapped Pair*, so what it "points at" is a slot address, not a node: any insertion at or before the slot shifts the array and the iterator with it. See Find for the invalidation story.

ConstIterator is Iterator, and the const overload still hands out mutable pairs. The alias is literally using ConstIterator = Iterator;, and the const begin() converts the member pointer — a Pair* const in a const method — to an Iterator over plain Pair. So ranging over a const Map& yields Pair&, and writing it->value through it compiles. Const-ness of the map is not enforced through iteration; only the key order is preserved by the class, and nothing stops a caller from writing a key that breaks it.

None.
