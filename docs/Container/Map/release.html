Release

member of hbe::Map Engine/Container/Map.h destroy every pair and free the buffer — the only member that gives memory back

Signature

void Release() noexcept

Function description

Private. The teardown both the destructor and move assignment run: destroy every live pair in index order, deallocate the whole buffer — sizeof(Pair) * cap bytes through the map's allocator — and zero all three fields, leaving entries null and the map in its default-constructed shape.

A null buffer returns immediately, so releasing a never-inserted map — or a map that already cleared its count without freeing its buffer — destroys nothing and deallocates nothing. Note the asymmetry with Clear: Clear keeps the buffer, Release is the only member that gives it back.

Parameters

None.

Return value

None. Afterwards Size() is 0 and the buffer is gone.

Examples

Illustrative — private, and reachable only through the destructor and move assignment.

~Map()
{
	Release();
}

The destructor's whole body: everything this class does at end of life happens here, once.
