Contains

member of hbe::Map Engine/Container/Map.h the const, noexcept membership test — a search that keeps only the verdict

Signature

[[nodiscard]] bool Contains(const TKey& key) const noexcept

Function description

FindIndex(key) >= 0 — a full binary search that throws the position away and keeps only the verdict. It is noexcept and const, which is what makes it the right membership test for a read-only caller; operator[] cannot play this role because it would insert.

When you want the value as well, prefer Find: Contains followed by Find searches the sorted array twice.

Parameters

ParameterTypeRequirement
keyconst TKey& The key to test for, ordered by TCompare.

Return value

true when the map holds an entry with that key, false otherwise. [[nodiscard]], so discarding the answer is a compile error.

Examples

		if (!m.Contains(5) || m.Contains(99))
		{
			ls << "Contains check failed" << lferr;

			return;
		}
