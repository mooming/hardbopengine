Find

member of hbe::Map Engine/Container/Map.h a binary search — end() when the key is absent

Signature

[[nodiscard]] Iterator Find(const TKey& key) noexcept

[[nodiscard]] ConstIterator Find(const TKey& key) const noexcept

Function description

A binary search for the key — FindIndex halves the sorted range until it lands on the entry — returning an iterator to it, or end() when the key is absent. The [[nodiscard]] attribute is the contract's teeth: a Find whose answer is discarded found nothing for nobody.

The returned iterator is a slot address in the entry array. It stays valid while the map is untouched, and dies on the next insertion or Remove — an insertion above the slot shifts it, one below does not, but nothing in the interface tells you which, so treat any insert or remove as invalidating every iterator.

The const overload returns the same Iterator type — see begin for what that means about const-ness.

Parameters

ParameterTypeRequirement
keyconst TKey& The key to search for, ordered by TCompare. No other requirement.

Return value

TypeWhat you get
Iterator (or ConstIterator, the same type) An iterator to the entry with that key, or end() when there is none
