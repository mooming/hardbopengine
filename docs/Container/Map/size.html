Size

member of hbe::Map Engine/Container/Map.h the entry count as TIndex (int)

Signature

[[nodiscard]] TIndex Size() const noexcept

Function description

The entry count, read from count. The type is the class's own TIndex — int — which this class spells as a member alias, unlike the std::size_t the BoundedPriorityQueue returns. There is no Capacity() beside it: the map has no way to answer "how much buffer is held", and Grow's doubling is the only thing that changes it.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) How many entries the map holds; 0 exactly when IsEmpty is true

Examples

		if (m.Size() != 3)
		{
