InsertSorted

member of hbe::Map Engine/Container/Map.h open a gap, construct the pair with a default-constructed value, return the slot

Signature

TIndex InsertSorted(const TKey& key) noexcept

TIndex InsertSorted(TKey&& key) noexcept

Function description

Private. The allocation path behind operator[] and Insert: it opens a gap in the sorted array and constructs the new pair in it, returning the slot's index. Three steps, in order —

Grow first, when count == cap; then LowerBound to find the gap; then the shift — every entry from the gap up is move-constructed one slot right and destroyed in its old slot — and finally new (&entries[idx]) Pair{key, TValue{}}: the key copied or moved in, the value default-constructed. The caller's value is assigned afterwards, which is why Insert can return false for a duplicate key but this method cannot — it always creates.

The two overloads differ only in how the key arrives: copied from an lvalue, moved from an rvalue. The method is declared noexcept, so a key copy or pair move that throws terminates the process rather than unwinding — element operations for a Map must not throw.

Parameters

ParameterTypeRequirement
keyconst TKey& or TKey&& The key to file. Duplicates are not refused here — the caller checks FindIndex first.

Return value

TypeWhat you get
TIndex (int) The index the pair now occupies — the slot the caller assigns its value into

Examples

Illustrative — private, and reachable only through operator[] and Insert.

idx = InsertSorted(key);
entries[idx].value = value;

That pair of lines is Insert's tail: create the slot, then write the value into it.
