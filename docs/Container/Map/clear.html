Clear

member of hbe::Map Engine/Container/Map.h destroys every pair, keeps the buffer

Signature

void Clear() noexcept

Function description

Destroys every live pair and sets count to 0 — and nothing else. The buffer stays allocated with its current capacity, so a cleared map is instantly reusable at no allocation cost, and Size returning to 0 does not mean the memory went anywhere. Contrast Release, which destroys the pairs and the buffer.

Every reference and iterator into the map dies here. One pass over the live entries, no reallocation, no allocator call.

Parameters

None.

Return value

None. Afterwards IsEmpty is true.

Examples

		Map<int, int> m;
		m[1] = 10;
		m[2] = 20;
		m.Clear();

		if (!m.IsEmpty() || m.Size() != 0)
		{
			ls << "Clear failed" << lferr;

			return;
		}

		m[3] = 30;

From Engine/Container/Map.cpp, MapTest::Prepare()

The test's tail — m[3] = 30; after the clear — is the reuse contract: the cleared map takes new entries without a fresh allocation.
