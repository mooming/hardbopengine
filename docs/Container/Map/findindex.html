FindIndex

member of hbe::Map Engine/Container/Map.h the binary search the whole class is built on — -1 when absent

Signature

[[nodiscard]] TIndex FindIndex(const TKey& key) const noexcept

Function description

Private. The binary search everything else is built on: Find converts the result to an iterator, Contains keeps only the sign, and operator[], Insert and Remove branch on it before touching anything. It halves the range every iteration — lo climbs past smaller keys, hi drops below larger ones — so the cost is logarithmic in the entry count, and it never touches the allocator.

-1 means absent, and it is also the answer for an empty map without a single comparison. Otherwise the return is the index of the entry whose key equals key under TCompare.

Parameters

ParameterTypeRequirement
keyconst TKey& The key to locate. TCompare must order it consistently with how the entries were inserted.

Return value

TypeWhat you get
TIndex (int) The index of the matching entry, or -1 when the map holds no such key

Examples

Illustrative — private, and reachable only through the public lookups it serves.

auto idx = FindIndex(key);
if (idx >= 0)
{
	return entries[idx].value;
}

That shape is operator[]'s opening move: locate, then either read the slot or insert into sorted position.
