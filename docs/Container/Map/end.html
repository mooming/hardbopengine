end

member of hbe::Map Engine/Container/Map.h one past the last entry — the answer Find gives when the key is absent

Signature

Iterator end() noexcept

ConstIterator end() const noexcept

Function description

One past the last entry: entries + count. Together with begin it is the whole range — a contiguous, sorted array walk — and on an empty map the two are equal, because a null entries plus a zero count is the same address on both sides. It is also what Find returns when a key is absent, so the standard it != map.end() test is the membership test.

end() is not dereferenceable, and like every iterator of this class it is an address in the entry array: an insertion that grows the buffer moves the array out from under it.

Parameters

None.

Return value

TypeWhat you get
Iterator (or ConstIterator, the same type) A wrapped pointer one slot past the last Pair; valid for comparison always, for dereferencing never
