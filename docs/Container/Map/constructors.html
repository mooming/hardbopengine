member of hbe::Map Engine/Container/Map.h an empty map with no buffer — copy deleted, move steals the three fields

Signature

Map() noexcept
		: entries(nullptr)
		, count(0)
		, cap(0)

Map(const Map&) = delete

Map(Map&& rhs) noexcept
		: entries(rhs.entries)
		, count(rhs.count)
		, cap(rhs.cap)

Function description

Three forms, one of them a refusal. The default constructor sets entries to nullptr and both counters to 0 — a Map is born with no buffer at all, whatever DefaultCapacity says; the first insertion is the first allocation, and Grow makes it four pairs wide. It is noexcept and cannot fail.

Copy construction is = delete — a map cannot be copied. The move constructor steals the three fields (entries, count, cap) and zeroes the source, so the buffer changes owner without a single element being touched. The comparison object and the allocator are not moved: each map keeps its own, which for the default template arguments is invisible and for a stateful allocator or comparator is the whole story.

Parameters

None. There is no sized form, no initialiser-list form and no allocator-taking form.

Return value

A constructor has no return value. What you can observe afterwards is IsEmpty (true), Size (0) and begin == end.

Examples

		Map<int, int> m2(std::move(m1));
