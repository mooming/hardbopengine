Module Index / Container / Map / LowerBound

LowerBound

member of hbe::Map Engine/Container/Map.h the insertion index that keeps the array sorted — count when the key appends

Signature

[[nodiscard]] TIndex LowerBound(const TKey& key) const noexcept

Function description

Private. The first index where key could sit while the array stays sorted — the first entry whose key is not less than key under TCompare. InsertSorted uses it as the insertion point, and the shift loop moves everything from there one slot right.

Like FindIndex it is a binary search, logarithmic in the entry count and allocation-free, but it never answers "absent": when every key in the map is smaller the return is count — one past the last entry, the append position — and when none is smaller it is 0.

Parameters

ParameterTypeRequirement
keyconst TKey& The key to place. Its position is decided purely by TCompare; an equal key sorts before the existing one.

Return value

TypeWhat you get
TIndex (int) The insertion index that keeps the array sorted: 0 to count inclusive

Examples

Illustrative — private, and reachable only through InsertSorted.

auto idx = LowerBound(key);

for (TIndex i = count; i > idx; --i)
{
	new (&entries[i]) Pair(std::move(entries[i - 1]));
	entries[i - 1].~Pair();
}

That is InsertSorted's shift: everything from the lower bound up moves one slot right to open the gap.
