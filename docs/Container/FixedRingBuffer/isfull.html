IsFull

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h count == cap — the one test between a caller and Push's fatal assert

Signature

[[nodiscard]] bool IsFull() const noexcept

Function description

count == cap — the one test that stands between a caller and the fatal assert inside Push. The ring never grows and never overwrites: a push to a full ring stops the process, so a caller facing a burst either checks here first or sizes the buffer for the worst case at construction.

Parameters

None.

Return value

true when the ring holds Capacity elements, false otherwise. [[nodiscard]], so discarding the answer is a compile error.

Examples

		q.Push(1);
		q.Push(2);
		q.Push(3);
		q.Push(4);

		if (!q.IsFull())
