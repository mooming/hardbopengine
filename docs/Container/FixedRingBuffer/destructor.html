~FixedRingBuffer

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h destroy every live element, then free the whole buffer

Signature

~FixedRingBuffer()

Function description

Two steps, guarded by a null-buffer early return: destroy every live element through DestroyAll — in queue order, wrapping with WrapIndex as it goes — then deallocate the whole buffer, all cap elements, through a fresh TAllocator.

There is no drain: items still in the ring are destroyed here. And the deallocation is unconditional once data is non-null — a buffer that was constructed is a buffer that is returned, whether the ring ever held anything or not.

Parameters

None.

Return value

A destructor has no return value. It is implicitly noexcept, so an element destructor that throws terminates the process.

Examples

Illustrative — no call site for this exists in the repository; the test fixtures let the scope close on drained buffers.

{
	FixedRingBuffer<int> q(4);
	q.Push(10);
}	// element destroyed, buffer released here
