Pop

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h remove the oldest element and return it by value — fatal assert on empty

Signature

TElement Pop() noexcept

Function description

Removes the oldest element and returns it — by value, in one call, which makes this the only queue in the module that hands back the element itself. Queue::Pop returns nothing and expects the read through Front first; here the move-out, the slot destruction, the cursor advance and the count drop are one operation: 

	FatalAssert(!IsEmpty(), "FixedRingBuffer is empty");
	auto item = std::move(data[head]);
	data[head].~TElement();
	head = WrapIndex(head + 1);
	--count;

From Engine/Container/FixedRingBuffer.h, FixedRingBuffer::Pop()

An empty ring is a fatal assert, not a std::nullopt — contrast BoundedPriorityQueue::Pop, which answers nullopt. Call IsEmpty first when emptiness is possible; the returned element is yours, and discarding it is a plain value drop with no [[nodiscard]] to stop you.

Parameters

None.

Return value

TypeWhat you get
TElement The former head element, moved out; its slot is destroyed and reusable by the next Push
