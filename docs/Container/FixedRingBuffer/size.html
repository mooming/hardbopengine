Size

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h the live element count

Signature

[[nodiscard]] TIndex Size() const noexcept

Function description

The number of live elements, read from count. Together with Capacity it answers the only two quantity questions the ring has; there is no third number, because the ring never grows and never shrinks.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) 0 when IsEmpty, cap when IsFull, and the bound IsValidIndex tests against

Examples

		if (q.Size() != 3 || q.Front() != 10 || q.Back() != 30)
