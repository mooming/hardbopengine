Module Index / Container / FixedRingBuffer / WrapIndex

WrapIndex

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h index & (cap - 1) — the bitmask that needs the power-of-two capacity

Signature

TIndex WrapIndex(TIndex index) const noexcept

Function description

The ring's arithmetic, in one line: index & (cap - 1). A bitwise mask replaces a modulo — cheaper, and only correct because the constructor rounds Capacity up to a power of two, making cap - 1 exactly the low bits. Every cursor advance and every operator[] address in the class goes through this method, which is why the rounding is not an optimisation detail but a correctness precondition.

It is public, and its contract is the mask's: for the non-negative indices the class feeds it (head + index, tail + 1, tail - 1), the result is the index taken modulo cap, landing in 0 .. cap - 1.

Parameters

ParameterTypeRequirement
indexTIndex (int) A cursor-plus-offset value. The mask is defined for what the class passes; a negative index has no stated behaviour.

Return value

TypeWhat you get
TIndex (int) The index wrapped into the buffer's slot range — the raw-buffer slot for that logical position

Examples

Illustrative — no direct call site for this exists in the repository.

// cap == 4: slots 0..3, mask 3
WrapIndex(0);	// 0
WrapIndex(5);	// 1 — 5 & 3
WrapIndex(head + index);	// operator[]'s address computation
