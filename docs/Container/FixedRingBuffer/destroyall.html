DestroyAll

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h destroy every live element in queue order, touching nothing else

Signature

void DestroyAll() noexcept

Function description

Destroys every live element — count of them, starting at the head cursor and wrapping through the buffer with WrapIndex(head + i), so it visits the elements in queue order even when the ring has wrapped. It touches nothing else: no cursor resets, no deallocation, no count change.

That narrowness is why it has two callers with different tails: Clear follows it with cursor and count resets, and the destructor follows it with the buffer deallocation. Calling it and then continuing to read through operator[] without resetting the count is use-after-destruction — the class's own callers never do.

Parameters

None.

Return value

None. Every element that was live is destroyed; the buffer's bytes are untouched.

Examples

Illustrative — public, but the class's own Clear and destructor are its only callers.

for (TIndex i = 0; i < count; ++i)
{
	auto idx = WrapIndex(head + i);
	data[idx].~TElement();
}
