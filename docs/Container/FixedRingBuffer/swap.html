Swap

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h exchange all five fields — capacities travel with the buffers

Signature

void Swap(FixedRingBuffer& rhs) noexcept

Function description

Exchanges all five fields — cap, both cursors, count and the buffer pointer — with rhs, in five std::swap calls. No element is touched, nothing is allocated, and it is noexcept by construction. It is the engine of the move constructor and move assignment, and it takes an lvalue reference, so the caller spells the move themselves.

Because capacity travels with the buffer, a swap exchanges the two objects' ceilings: a capacity-1 ring and a capacity-8 ring that swap keep each other's budgets. That is a feature of the exchange, and a surprise if you expected a swap of contents only.

Parameters

ParameterTypeRequirement
rhsFixedRingBuffer& The ring to exchange state with. Self-swap is a harmless no-op.

Return value

None. Both rings emerge with the other's buffer, cursors, count and capacity.

Examples

Illustrative — no direct call site exists in the repository; the move operations are its callers.

FixedRingBuffer<int> a(8);
FixedRingBuffer<int> b(2);
a.Swap(b);
// a.Capacity() == 2, b.Capacity() == 8 — capacities travelled too
