Function description

Three forms, two of them refusals — there is no default constructor and no copy. The sizing form is the only way to build a FixedRingBuffer from nothing: it fatal-asserts fixedCapacity > 0, rounds the request up to the next power of two, allocates that many elements through TAllocator once, and never reallocates. The rounding is load-bearing: 

	TIndex pow2Capacity = static_cast<TIndex>(std::bit_ceil(static_cast<unsigned int>(fixedCapacity)));

	TAllocator alloc;
	data = alloc.allocate(pow2Capacity);
	cap = pow2Capacity;

because WrapIndex computes with a bitmask that is only valid for a power-of-two cap. The observable consequence: a buffer asked for 5 elements reports Capacity() as 8, and the extra slots are spent headroom, not error.

The move constructor starts from the null state and Swaps — the buffer changes owner with no element touched, and the source is left holding the destination's fresh null state.

Parameters

ParameterTypeRequirement
fixedCapacityTIndex (int) Strictly positive — a non-positive capacity is a fatal assert, not a clamp. The allocated capacity is this value rounded up to a power of two.

Return value

A constructor has no return value. What you can observe afterwards is IsEmpty (true) and Capacity (the rounded power of two).
