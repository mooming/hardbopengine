Front

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h the oldest element — fatal assert on empty

Signature

TElement& Front() noexcept

const TElement& Front() const noexcept

Function description

The oldest element — the one the next Pop removes. Both overloads fatal-assert non-empty before touching data[head], so an empty ring stops the process rather than returning a dead reference. The const form is what a read-only caller gets.

The reference is into the raw buffer at the head cursor, so it stays valid until the ring changes under it: a Pop, a Clear, or a Swap that exchanges the buffer.

Parameters

None.

Return value

TypeWhat you get
TElement& (or const TElement&) A reference to the element at the head cursor — the same slot operator[] names as index 0

Examples

		if (q.Size() != 3 || q.Front() != 10 || q.Back() != 30)
