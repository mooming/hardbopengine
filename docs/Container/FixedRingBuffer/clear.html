Clear

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h destroy every element, zero the cursors — buffer and capacity untouched

Signature

void Clear() noexcept

Function description

Destroys every live element through DestroyAll and resets both cursors and the count to zero — buffer and Capacity untouched. A cleared ring is instantly reusable at zero allocation cost, and the reuse is exactly what the test asserts: 

		q.Push(42);
		if (q.Front() != 42 || q.Size() != 1)

From Engine/Container/FixedRingBuffer.cpp, FixedRingBufferTest::Prepare()

After the clear the ring starts filling from slot 0 again — the cursors are zeroed, not merely the count — so Front of the refilled ring is the first new element. Every reference and index into the old contents dies here.

Parameters

None.

Return value

None. Afterwards IsEmpty is true and Size is 0.

Examples

		q.Push(1);
		q.Push(2);
		q.Push(3);
		q.Clear();

		if (!q.IsEmpty() || q.Size() != 0)
