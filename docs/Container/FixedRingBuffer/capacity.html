Capacity

member of hbe::FixedRingBuffer Engine/Container/FixedRingBuffer.h the power-of-two budget — not necessarily the requested number

Signature

[[nodiscard]] TIndex Capacity() const noexcept

Function description

The element budget the ring was built with — and not necessarily the number the constructor was given. The constructor rounds the request up to the next power of two, so a buffer asked for 5 reports 8; the request only sets a floor. The capacity never changes afterwards: no growth, no shrink, no reallocation for the whole lifetime, and Clear leaves it untouched.

It is also the ceiling IsFull tests against, and the modulus WrapIndex masks with — the power of two is what makes that bitmask correct.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) The allocated element count — a power of two, at least the requested capacity, fixed for the ring's lifetime

Examples

		FixedRingBuffer<int> q(8);

		if (q.Capacity() != 8 || !q.IsEmpty())
