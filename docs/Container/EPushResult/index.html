EPushResult

Engine/Container/EPushResult.h the one answer every push in the ring family returns — a shared type that made the concept one requires block

Class description

EPushResult is the one enum class over unsigned char that every push in the ring family answers with: the four fixed rings (AtomicFixedRingMPSC, AtomicFixedRingMPMC, FixedRingMPSC, FixedRingMPMC) and the RingBuffer chain that carries their blocks. It exists as one type because the answers travel between layers: a block-level Full becomes a queue-level Full, and with one type that mapping is the identity, which cannot drift. While the enums were nested, the concept CFixedRing<T, U> had to name the backend's answer through typename U::EPushResult and then re-check in a second requires block that the enumerators the chain relies on actually existed; sharing the type retired both devices.

Pushed means the argument was constructed into a slot and is visible to the consumer. Full means nothing was constructed and the item is still the caller's: for a fixed ring this is capacity, for the chain it is the block fuse refusing growth, and in both cases the answer invites a retry rather than reporting a loss. TooManyProducers is the chain's answer when every producer slot has already been claimed — a slot is earned for the lifetime of the queue, never released, so this says thread identities ran out, not capacity.

A fixed ring never answers TooManyProducers. It does not track producer identity at all — the enumerator exists in the shared type because the chain needs it, and CFixedRing<T, U> demands only Pushed and Full of a backend. Code that switches on the type should still handle the enumerator (exhaustive switch over three cases is the shape), but code reading a bare ring's answer can rely on it never arriving.

Template parameters

None — an enumeration is not a template, and this one is parameterised on nothing.

Class properties

NameDeclarationWhat it means
Pushed= 0 enumerator The item was constructed into a reserved slot and published; the consumer will see it. The only enumerator that means success.
Full= 1 enumerator Nothing was constructed and the item was not lost; the queue was at its capacity limit — a ring's slots, or the chain's block fuse. Retrying is legitimate, and the chain counts fuse refusals at GetFuseRefusalCount so a caller can tell pressure from progress.
TooManyProducers= 2 enumerator Chain-only. Every producer slot was already claimed by a thread that has ever pushed into this queue; see AcquireProducerToken. Raising inMaxProducers is the fix; a fixed ring never answers this.

Class methods

None — the enumeration is the entire interface, and what each answer costs a caller is owned by the Push page of the class that returns it.

Non-member helpers

None. There is no operator<<: a class that prints an answer switches on the enumerator at the call site, the way the benchmark harness does.

Coverage

This page documents the type completely: three enumerators, their underlying width, and the shared-type argument that made the concept compact. The per-class consequences — whether a retry should spin, park or fail the caller — are owned by RingBuffer::Push and each backend's Push page, which link back here.
