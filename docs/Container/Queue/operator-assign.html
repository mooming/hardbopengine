operator=

member of hbe::Queue Engine/Container/Queue.h copy deleted; move assignment swaps the underlying container rather than draining the source

Signature

Queue& operator=(const Queue&) = delete

Queue& operator=(Queue&& rhs) noexcept

Function description

Two forms, one of them a refusal. Copy assignment is = delete — a queue is a move-only adapter, and assigning one from another is a compile error. Move assignment moves the underlying container and returns *this; it is noexcept.

For the default container the move is a swap, not a drain: 

Deque& operator=(Deque&& rhs) noexcept
{
	Swap(rhs);

	return *this;
}

From Engine/Container/Deque.h, Deque::operator=(Deque&& rhs)

So after a = std::move(b), a holds what b held — and b holds what a held, rather than being left empty. Code that expects the source to be cleared afterwards must call Clear on it explicitly.

Parameters

ParameterTypeRequirement
rhsQueue&& The source queue. Its container is swapped or moved from; the element type needs whatever the container's move assignment requires.

Return value

*this, holding the source's former contents.

Examples

Queue<int> q3;
q3 = std::move(q2);

From Engine/Container/Queue.cpp, QueueTest::Prepare()

The test verifies afterwards that q3 carries the two elements q2 was pushed — the assigned-to queue is the one that keeps the data.
