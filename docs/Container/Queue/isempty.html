IsEmpty

member of hbe::Queue Engine/Container/Queue.h the only guard before the operations that abort on empty

Signature

[[nodiscard]] bool IsEmpty() const noexcept

Function description

Forwarded to the container's IsEmpty — a count comparison, no allocation, no computation. It is the queue's only guard before the operations that abort on empty: Pop, Front and Back all trust the caller to have asked first.

Parameters

None.

Return value

true when the queue holds no elements, false otherwise. [[nodiscard]], so throwing the answer away is a compile error.

Examples

q.Pop();
q.Pop();
if (!q.IsEmpty())
{
	ls << "Queue should be empty" << lferr;

	return;
}

From Engine/Container/Queue.cpp, QueueTest::Prepare()

Draining to empty and then asserting the state is the test's shape; production code that cannot know the depth up front tests IsEmpty() before each Pop.
