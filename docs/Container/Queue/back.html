Back

member of hbe::Queue Engine/Container/Queue.h the newest element — aborts on empty through the container's assert

Signature

TElement& Back() noexcept

const TElement& Back() const noexcept

Function description

A reference to the most recently pushed element — the FIFO tail. Both overloads forward to the container's Back; for the default container the empty case aborts, exactly as Front does, because the container's accessor asserts non-empty before reading.

The reference dies on the same events that kill a Front reference: a Pop, a Clear, or container growth per the container's own contract. A queue exposes no way to reach any element except these two ends.

Parameters

None.

Return value

TypeWhat you get
TElement& (or const TElement&) A reference to the newest element, mutable through the non-const overload; the const form serves read-only callers

Examples

if (q.Front() != 10 || q.Back() != 30)
{
	ls << "Front/Back mismatch" << lferr;

	return;
}
