ReleaseSlot

member of hbe::AtomicFixedRingMPMC Engine/Container/AtomicFixedRingMPMC.h hand the slot to the lap that comes after next

Signature

void ReleaseSlot(size_t inIndex) noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Private. Stores inIndex + Capacity into the slot’s readyIndex with release order, after the element has been moved out and destroyed. The value is not a flag: it is the absolute index of the element this slot may accept next, which is why a producer’s fullness answer can be read off the same word with no second counter.

release here protects the other direction from the one MarkDataReady protects: the consumer’s read of the payload must not be reordered after the slot becomes writable, or a producer would overwrite data still being copied. Making that store relaxed is the second mutation that ThreadSanitizer caught, at the producer’s write.

Parameters

NameWhat the caller must supply
inIndexThe absolute index just consumed. The slot is not this thread’s after the call.

Nothing.
