TryTakeReadyElement

member of hbe::AtomicFixedRingMPMC Engine/Container/AtomicFixedRingMPMC.h consumer claim: readiness decided before the index is committed

Signature

[[nodiscard]] bool TryTakeReadyElement(size_t& outIndex) noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Private, and the consumer’s half of the design. It loads the read frontier, asks IsDataReady of that slot, and commits the compare-and-swap on the frontier only if the element there is published. Like its producer counterpart it distinguishes a real nothing to take from a frontier moved under me, because those two need opposite actions.

That ordering decision is what gives this queue its API surface: because a committed claim already implies a published payload, Pop never waits on another thread’s write, and so there is no blocked answer for it to give. The cost of the same decision is that an element under construction is invisible, so Empty may be conservative in that one direction — why the third answer is not answerable here.

Parameters

NameWhat the caller must supply

Return value

ValueMeaning

Examples

Private helper, called by Pop. The MPSC form needs no counterpart: its single consumer owns the read frontier outright.
