DestroyQueued

member of hbe::AtomicFixedRingMPMC Engine/Container/AtomicFixedRingMPMC.h destroy what is still in the ring, trusting readyIndex to say so

Signature

void DestroyQueued() noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Private, called from the destructor. Walks the indices between the two frontiers and destroys the slots whose IsDataReady says published. Trusting the ready index rather than a count is what makes the walk correct under the shape the queue allows: a claimed-but-unpublished slot is skipped, because destroying it would destroy an element mid-write.

Precondition, the same one the destructor carries: no thread may be inside Push or Pop, and for the MPSC queue the walk belongs to the one consumer thread. It cannot detect a violation, and it should not be called anywhere else — destroying live slots while producers run is the one thing the protocol cannot survive.
