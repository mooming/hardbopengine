~AtomicFixedRingMPMC

member of hbe::AtomicFixedRingMPMC Engine/Container/AtomicFixedRingMPMC.h destroy what is still queued

Signature

~AtomicFixedRingMPMC()

Function description

Destroys the elements still in the ring. It walks the indices between the two frontiers and destroys the slots whose readyIndex says published, so a slot that was claimed but never written is not destroyed and a slot already taken is not destroyed twice.

Precondition, stated because it is the one the caller can break: no thread may be inside Push or Pop when the queue is destroyed. An element under construction at that instant is either destroyed half-written or leaked, and no test the queue could run at destruction would notice, because the claim that would have revealed it is deliberately invisible.

Parameters

NameWhat the caller must supply
noneThis method takes no argument.

Return value

Nothing.

Examples

The queue is a member or a local; the destructor needs no call site of its own.
