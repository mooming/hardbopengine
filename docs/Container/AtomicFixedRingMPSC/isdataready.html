IsDataReady

member of hbe::AtomicFixedRingMPSC Engine/Container/AtomicFixedRingMPSC.h the consumer’s only question, asked of one slot

Signature

[[nodiscard]] bool IsDataReady(size_t inIndex) const noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Private, const. Loads one slot’s readyIndex with acquire and reports whether it says the element at that absolute index is here and readable, which is the test readyIndex == inIndex + 1.

The load is the design’s single gate: no payload byte is read except under a slot this predicate has accepted, which is why the ordering table gives this one line an acquire and gives the position words relaxed. It is also what the destructor walks with, because a slot that is not ready must not be destroyed.

Parameters

NameWhat the caller must supply
inIndexThe absolute index being asked about, not a slot index; the mask is applied here.

Return value

true only when the slot holds the element inIndex and that element has been published. A claimed-but-unpublished slot answers false, and that is the reason Pop has no third answer to give.

Examples

Private predicate. Its two callers are Pop and DestroyQueued.
