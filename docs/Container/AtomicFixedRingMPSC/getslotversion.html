GetSlotVersion

member of hbe::AtomicFixedRingMPSC Engine/Container/AtomicFixedRingMPSC.h Pushes this ring has accepted since construction — monotone, never decremented by Pop, and the only count that can tell a spent ring from a merely empty one.

Signature

[[nodiscard]] size_t GetSlotVersion() const noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Counts the pushes this ring has accepted since construction. A successful Push reserves one slot and the count grows by one; Pop never lowers it, so the number is monotone and its value at any moment is the absolute index the next accepted push will receive. It is not a measure of how many elements are readable — that is what Pop answers — and it is not how many slots are free, which is GetCapacity() minus what is in flight.

Reads the claim word with memory_order_relaxed: the value is the counter itself, and the caller gets no ordering guarantee with it. A caller therefore may not infer "there is room" from a stale-looking read, because a concurrent producer may have taken that slot a moment later; only Push's own answer decides that. What the count is good for is a cap a caller imposes on itself. A container that reuses one ring as one node of a chain — where every slot must be handed over exactly once before the node is retired — has to stop pushing at GetCapacity(), because a ring whose consumer has lapped it silently accepts the next push into a recycled slot. That caller needs this count to tell a spent ring from a merely empty one, which no other member can tell it.

Parameters

NameWhat the caller must supply
noneThe count belongs to the object.

Return value

The number of accepted pushes, from 0 upward. It may exceed GetCapacity() when the ring is used as a ring — that is a lap, not an error — and a caller that wants one lap only has to refuse the push that would cross the boundary, which it can only do by comparing this count against GetCapacity().

Examples

if (ring.GetSlotVersion() >= Ring::GetCapacity())
{
    // every slot of this ring has already been handed to somebody;
    // pushing now would recycle one, so the caller moves on
}
else
{
    ring.Push(item); // may still answer Full: a peer producer won the race
}
