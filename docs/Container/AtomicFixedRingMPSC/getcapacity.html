GetCapacity

member of hbe::AtomicFixedRingMPSC Engine/Container/AtomicFixedRingMPSC.h the compile-time capacity, as a value rather than as a template argument

Signature

[[nodiscard]] static constexpr size_t GetCapacity() noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Returns Capacity. The ring never grows, so this number is also the hard ceiling on how many elements the queue can ever hold and the exact size a caller should assume when sizing a drain batch or a bounded retry loop. It is static constexpr rather than a member query because nothing about it depends on the object: the answer is a property of the type, so a caller can use it in its own static_assert or as an array bound.

Parameters

NameWhat the caller must supply
noneThe value is the template argument.

Return value

The Capacity template argument, which is a power of two greater than one.

Examples

constexpr int drainBatch = Queue::GetCapacity();
static_assert(drainBatch > 1);
