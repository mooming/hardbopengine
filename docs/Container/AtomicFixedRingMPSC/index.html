AtomicFixedRingMPSC

Engine/Container/AtomicFixedRingMPSC.h namespace hbe final Lock-free bounded MPSC FIFO over one fixed-size ring; the single-consumer specialization, with no CAS on the pop side

The same ring as AtomicFixedRingMPMC with one deletion: exactly one thread drains it, so the dequeue index has a single owner and the CAS on it is not merely unnecessary but meaningless. This is the Vyukov bounded MPSC queue — the single-consumer specialization of the bounded MPMC queue, which libcds likewise names VyukovMPSCCycleQueue.

Every slot owns one std::atomic<size_t> named readyIndex holding the absolute index of the element it refers to, so free for lap L is readyIndex == L and published is readyIndex == L + 1. No lap counter exists, no ABA window exists, and a false match would need 264 items.

The consumer's whole cost is one acquire load of the frontier readyIndex plus one plain increment. That is the floor for any MPSC consumer: one atomic read of the frontier is the minimum on which a correct is there anything I may take answer depends, and this queue pays exactly that.

Any number of threads may push, but exactly one may pop. readIndex is a plain size_t owned by that thread, so a second consumer is a data race and not a slow path. Pushing from many threads is what the claim loop is for; draining from many is a different container, and the difference is not performance — readIndex is not atomic, so a second consumer races rather than contending.

The queue yields the remainder of its time slice once a retry loop has failed MaxSpinAttempts times, so a bounded busy-wait replaces an unbounded one. The measured right value for that constant is small: on a 12-CPU machine running 17 runnable threads, yielding immediately beat spinning eight times by 1.5× to 2.2×, because the thread that can unblock a producer is another thread. See the spin cap. Capacity must be a power of two greater than one, enforced by static_assert whose message carries the reason. Protocol, ordering and measurements: the design document.
