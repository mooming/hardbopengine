MarkDataReady

member of hbe::AtomicFixedRingMPSC Engine/Container/AtomicFixedRingMPSC.h the single store that makes an element visible to a consumer

Signature

void MarkDataReady(size_t inIndex) noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Private. Stores inIndex + 1 into the slot’s readyIndex with release order, which is the one moment an element stops being private to the producer and becomes available to any consumer.

The ordering is the entire correctness of the publish path: the payload write must not become visible after this store, and release is what forbids it. A relaxed store here is not a theoretical hole — it is one of the four mutations that turned ThreadSanitizer red, at the consumer’s read.

Parameters

NameWhat the caller must supply
inIndexThe absolute index this thread claimed, with the element already constructed at it.

Return value

Nothing. The store cannot fail: the slot is this thread’s to write.

Examples

Private helper, called once per successful Push, and the thing IsDataReady exists to observe.
