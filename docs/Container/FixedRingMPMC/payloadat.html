Module Index / Container / FixedRingMPMC / PayloadAt

PayloadAt

member of hbe::FixedRingMPMC Engine/Container/FixedRingMPMC.h absolute index to payload pointer, one mask and one stride

Signature

[[nodiscard]] T* PayloadAt(size_t inIndex) noexcept

Signature text is checked against the header by docs_pass.py signatures.

Function description

Private. Turns an absolute index into the address of the payload bytes for that slot: mask with IndexMask, stride by sizeof(T). Two facts make that one instruction legal instead of a memory error — Capacity is a power of two, which is what lets a mask replace a division, and sizeof(T) % alignof(T) == 0, which is what keeps every stride landing on an alignment T requires. Both are static_asserted at the top of the class.

Precondition, and it is the one a caller outside the class cannot satisfy: the slot must belong to the calling thread. That means claimed for writing after a successful Push claim, or published for reading after a successful Pop claim. Read the payload of a slot nobody has given you and you have a data race that no single-threaded test can show; ThreadSanitizer is what shows it.

Parameters

NameWhat the caller must supply
inIndexAn absolute index, not a slot index. It is masked here, so callers carry the untruncated counter.

Return value

A pointer to raw storage, not to a live object unless the slot is published. Construct into it or destroy through it; do not dereference it casually.

Examples

Private helper. It is documented because every declared name is documented, and because the two preconditions above are the reason the class is shaped the way it is.
