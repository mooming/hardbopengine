GetSlotVersion

member of hbe::FixedRingMPMC Engine/Container/FixedRingMPMC.h Pushes this ring has accepted since construction — monotone, never decremented by Pop, and the only count that can tell a spent ring from a merely empty one.

Signature

[[nodiscard]] size_t GetSlotVersion() const

Signature text is checked against the header by docs_pass.py signatures.

Function description

Counts the pushes this ring has accepted since construction. A successful Push reserves one slot and the count grows by one; Pop never lowers it, so the number is monotone and its value at any moment is the absolute index the next accepted push will receive. It is not a measure of how many elements are readable — that is what Pop answers — and it is not how many slots are free, which is GetCapacity() minus what is in flight.

Taken under the same lock that guards the slot array, so the value it returns was true at some instant and may not be true now: a peer producer can take the next slot the instant the lock is released. Only Push's own answer decides whether there was room. What the count is good for is a cap a caller imposes on itself. A container that reuses one ring as one node of a chain — where every slot must be handed over exactly once before the node is retired — has to stop pushing at GetCapacity(), because a ring whose consumer has lapped it silently accepts the next push into a recycled slot. That caller needs this count to tell a spent ring from a merely empty one, which no other member can tell it.

Parameters

NameWhat the caller must supply
noneThe count belongs to the object.

Return value

The number of accepted pushes, from 0 upward. Unlike head, which is a masked slot position and therefore wraps, this count never wraps: it is a count of events, not a position. It may exceed GetCapacity() when the ring is used as a ring — that is a lap, not an error — and a caller that wants one lap only has to refuse the push that would cross the boundary.

Examples

if (ring.GetSlotVersion() >= Ring::GetCapacity())
{
    // every slot of this ring has already been handed to somebody;
    // pushing now would recycle one, so the caller moves on
}
else
{
    ring.Push(item); // may still answer Full: a peer producer won the race
}
