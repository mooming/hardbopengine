IsEmpty

member of hbe::FixedRingMPMC Engine/Container/FixedRingMPMC.h snapshot of whether anything is queued

Signature

[[nodiscard]] bool IsEmpty() const

Function description

Takes the lock and answers from count, so the answer is exact at the instant it is given. A caller that means “is there work” should usually call Pop and read its answer; this method is for a thread deciding whether to keep a drain loop alive.
