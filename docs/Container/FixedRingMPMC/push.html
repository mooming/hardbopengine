Push

member of hbe::FixedRingMPMC Engine/Container/FixedRingMPMC.h claim a slot, construct into it, publish it

Signature

[[nodiscard]] EPushResult Push(const T& inItem)

[[nodiscard]] EPushResult Push(T&& inItem)

Function description

Claims an index, constructs the element into the slot it points at, then publishes the slot. The claim and the publication are two separate atomics on purpose: no atomic can compose “advance the index” with “write this payload”, because T is arbitrary-sized and only a {ptr, stamp}-sized value fits a double-width CAS.

The fullness test happens before the claim is committed, which is what makes a refusal leave nothing behind. The alternative — reserving first and discovering the ring was full — burns an index, and a burned index in a bounded ring makes slots permanently unusable; the measured refutation is in the design document.

Both overloads take the lock, refuse if count == Capacity, and construct in place otherwise. There is no retry loop to bound: the lock is the waiting.

Parameters

NameWhat the caller must supply
inItemThe value to enqueue. The T&& overload moves from it; the queue then owns the result.

Return value

ValueMeaning
EPushResult::PushedThe element is in the ring and will be delivered exactly once.
EPushResult::FullNothing was enqueued and nothing was reserved. Retry later, or drop, or grow elsewhere — the ring cannot grow.

Examples
