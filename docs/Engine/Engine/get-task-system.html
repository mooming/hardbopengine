GetTaskSystem

member of hbe::Engine Engine/Engine/Engine.h the busiest accessor in the class — a valid reference whose usefulness depends entirely on whether the TaskSystem level ran

Signature

auto& GetTaskSystem()
{
        return taskSystem;
}

Function description

A field read defined inline; auto& deduces to TaskSystem&. Unlike the memory manager, this member is constructed empty: its constructor records the current thread as the engine loop thread and reads the hardware thread count, but the task registry and the worker streams arrive only when Initialize runs the TaskSystem level and calls TaskSystem::Initialize(). So the reference this returns is always a real, addressable task system, and it is only a working one after that step.

Consumers do not check. Task::Start, TaskSystem's own helpers, the task registry and every window procedure in the OSAL layer all take this reference and use it without asking whether it was ever initialised, which is what makes the level a load-bearing choice rather than a tuning knob.

A task system without streams still accepts work and then fails when it routes it. Enqueue takes a mutex and pushes onto a queue, so nothing complains at the moment of the call. The failure appears where a stream index gets resolved: GetStream answers out-of-range indexes with streams[0], and with the level skipped that array is empty — which Array::operator[] treats as a fatal assert, in every configuration. The engine never reports "the task system was never initialised" at the site that asked for it; it reports a bad index somewhere downstream.
It is also the accessor the engine calls on itself. GetLogger's example passes this reference to Logger::StopTask, Run pumps and joins the same object, and ShutDown requests its stop through the ready flag rather than through this reference. Everything the engine does with its most-used subsystem, it does through here.

Parameters

None.

Return value

TypeWhat you get
TaskSystem& The member, mutable, never null. Whether it can run anything is answered by IsTaskSystemReady — the only flag in the class that faithfully tracks a level. Not [[nodiscard]]
