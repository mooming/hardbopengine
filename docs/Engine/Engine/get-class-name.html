GetClassName

member of hbe::Engine static Engine/Engine/Engine.h the log category this class writes under, obtainable without an object

Signature

static StaticString GetClassName();

Function description

Returns a function-local static StaticString holding "Engine". It is static because the value is used as a logging category, and categories are needed in places that have no instance to ask — most directly in Initialize and ShutDown, where the string is what attributes the line to this module rather than to the subsystem that happened to be writing it.

The string is interned, so the comparison a log filter performs against it is a pointer comparison (String: StaticString), and the local static means the first call constructs it and every call after returns the same object. Nothing here reads engine state: the value is the same before the constructor has finished, during member destruction, and after the object is gone.

It is not const, because it is static, and it is not [[nodiscard]], although discarding the result is meaningless — every call in the engine immediately feeds it to Logger::Get.

Parameters

None.

Return value

TypeWhat you get
StaticString (by value) The interned "Engine" — cheap to copy, comparable by identity, and the exact category name the Log lines and the two log files record this class under

Examples

Both uses in the engine are the same one: name the category, then write.

auto log = Logger::Get(GetClassName());

log.Out("Command Line Arguments");
// ...
log.Out("Engine has been initialized.");

From Engine/Engine/Engine.cpp, inside Initialize.

auto log = Logger::Get(GetClassName(), ELogLevel::Info);
log.Out("Shutting down...");

From Engine/Engine/Engine.cpp, inside ShutDown.

Note that these lines go through Logger, not through Engine::Log — the category name matters to the Logger's per-category filters, and the second argument is where the level is stated. What Engine::Log writes into its own file carries no category at all (Log: Logger).
