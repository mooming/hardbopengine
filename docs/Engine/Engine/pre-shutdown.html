PreShutdown

member of hbe::Engine Engine/Engine/Engine.h private the pre-shutdown hook — memory teardown and the memory configuration report, while every subsystem is still alive

Signature

void PreShutdown();   // private

Function description

The teardown mirror of PostInitialize: one memory hook bracketed by two log lines, plus a report that only exists in a profiling build.

log.Out("Engine PreShutdown [Start]");

#if PROFILE_ENABLED
    logger.ReportMemoryConfiguration();
#endif
    memoryManager.PreEngineShutdown();

log.Out("Engine PreShutdown [Done]");

The order is the point. Everything here runs while every subsystem is still alive — before taskSystem is joined, before the streams are freed, before the application object is released. So the memory manager gets a last step in which it can still ask its allocators what they hold, and the profiler gets one in which the logger can still write what it answers.

ReportMemoryConfiguration is compiled out unless PROFILE_ENABLED is set, so in a Dev or Release build the hook is the memory call alone. That is the same gate that keeps the accounting out of the allocators themselves: what is missing is the report, not the teardown.

Parameters

None.

Return value

None.

Notes

  • Called once, from ShutDown, before the task system is torn down. Not reachable from outside the class, and not idempotent by contract — the memory hook is expected to run exactly once.
  • The bracket is what makes it debuggable: Start without Done names the subsystem that did not return, in the one place where a hang during shutdown is usually happening.
  • Log lines emitted here may be the last thing written. The logger's own driver thread outlives the task system, so these lines are drained by StopDriverThread at destruction rather than by anything in this file.
