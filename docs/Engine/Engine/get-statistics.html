GetStatistics

member of hbe::Engine Engine/Engine/Engine.h the counters and the start time every timestamp in the log is measured from

Signature

auto& GetStatistics()
{
        return statistics;
}

Function description

A field read defined inline; auto& deduces to SystemStatistics&. The object is constructed by the engine constructor, which asserts that memory is already up and captures a start time at that instant — so this reference is always live, and its clock starts at construction rather than at Initialize.

Two uses inside the class itself make this more than an accessor. Log reads GetStartTime() to build the [h:m:s.ms] prefix on every line and increments IncEngineLogCount() as it writes, and ShutDown is the only caller of Print() and PrintAllocatorProfiles() — the closing report. Between those, code in the memory and log modules increments counters through here.

A mutable reference to shared counters, with no lock in sight. The counters that get touched from more than one thread are atomics — the log counts increment relaxed — but the frame counters and the timing fields are not, and nothing in Engine guards this reference. The rule the existing callers follow is to write counters from whichever thread observed them and to read them only at shutdown; the header states nothing stronger, and nothing enforces it. Core: SystemStatistics owns which field is which.

Parameters

None.

Return value

TypeWhat you get
SystemStatistics& The member, mutable, never null, independent of every level and of IsSystemStatisticsReady. Not [[nodiscard]]

void AllocStats::Report() noexcept
{
#if PROFILE_ENABLED
        auto& engine = Engine::Get();
        auto& stats = engine.GetStatistics();
        stats.Report(*this);
#endif // PROFILE_ENABLED
}

        auto& engine = Engine::Get();

#if PROFILE_ENABLED
        auto& stat = engine.GetStatistics();
        stat.IncLongLogCount();

From Engine/Log/LogLine.cpp.

The second form is the one to copy: the increment is a profiling cost, so it is compiled out with the profiling. Reading values is a different matter — the only read of consequence in the engine is Log's timestamp, and every other read happens in the shutdown report.
