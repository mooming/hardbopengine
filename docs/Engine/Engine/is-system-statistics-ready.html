IsSystemStatisticsReady

member of hbe::Engine const no readers in the repository a field read of a flag that is raised once and never asked about

Signature

bool IsSystemStatisticsReady() const
{
        return isSystemStatisticsReady;
}

Function description

Returns the flag, nothing else.

It is raised once, by SetSystemStatisticsReady at the end of the SystemStatistics constructor, so it is true for any engine that exists — with any level set, including EInitLevel::None. Grepping Engine/ and Applications/ finds no read of it: not in Initialize, not in ShutDown, not in GetStatistics. The flag exists, is written, and gates nothing.

What a caller usually wants instead is the object: GetStatistics returns a live SystemStatistics for every engine, and its counters say what has actually been measured. The flag cannot distinguish a statistics object with a thousand frames in it from one that was constructed two microseconds ago.

Parameters

None.

Return value

TypeWhat you get
bool False only during the first two member constructors of the engine, true for the rest of the object's existence. Not [[nodiscard]]

Examples

Illustrative — no call site for this exists in the repository.

if (!hengine.IsSystemStatisticsReady())
{
        // Unreachable for a constructed Engine: the flag is raised by the member constructor.
        return;
}

const auto elapsed = hengine.GetStatistics().GetTimeSinceStart();   // the question worth asking

The pair of lines is the honest version of this page: the guard is dead code, and the accessor beside it is what carries information. Core: SystemStatistics.
