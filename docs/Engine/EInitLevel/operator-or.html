operator|

namespace hbe Engine/Engine/EngineInitLevel.h constexpr noexcept the only way to build a level set, since a scoped enumeration converts to nothing implicitly

Signature

constexpr EInitLevel operator|(EInitLevel lhs, EInitLevel rhs) noexcept;

Function description

constexpr EInitLevel operator|(EInitLevel lhs, EInitLevel rhs) noexcept
{
        return static_cast<EInitLevel>(static_cast<uint8_t>(lhs) | static_cast<uint8_t>(rhs));
}

Both operands are cast to the fixed underlying type, combined, and cast back. Without it the enumeration could not be combined at all: scoped enumerations do not convert to integers implicitly in either direction, so EInitLevel::TaskSystem | EInitLevel::Logger would not compile and the third parameter of Engine::Initialize could only ever be a single enumerator.

Being constexpr means the combination happens at compile time, which is what lets a level set be a named constant or a template argument rather than a runtime expression. Inside the enumeration, All is written as TaskSystem | Logger | Application and evaluates to the union — its value is pinned by the header's second static_assert — and that expression is arithmetic on the underlying integer type, because the overload below is declared after the enumeration rather than before it.

One operator, and no others. There is no operator&, operator~, operator^ or operator|=. So intersection is only reachable through HasFlag, complement is unreachable at all, and accumulating a set means reassigning with levels = levels | flag; — which is exactly the form Initialize uses when it adds TaskSystem to a request that names the logger.
The cast back is unchecked, so the operator can manufacture a value with no name. Combining produces whatever bits result, and static_cast to an enumeration does not validate them. A set containing a bit outside the three enumerators is legal to construct, tests false under HasFlag for every real level, and reaches Initialize as "start nothing" — with a log line to the contrary. Only the two static_asserts in the header constrain the values, and they constrain None and All, not expressions.

Parameters

ParameterTypeRequirement
lhs EInitLevel (by value) A level or an already-combined set
rhs EInitLevel (by value) A level or set to add. Combining with None returns the other operand's bits unchanged, and combining with All returns All

Return value

TypeWhat you get
EInitLevel The union, as a value of the enumeration. It is not validated against the enumerators, and it is not [[nodiscard]] — though discarding a combination is meaningless

Examples

The engine widens a caller's set with it, which is the one call site inside the tree:

if (HasFlag(levels, EInitLevel::Logger))
{
        levels = levels | EInitLevel::TaskSystem;
}

From Engine/Engine/Engine.cpp, the first statements of Initialize.

What a caller writes at the call site — and, so far, what nobody in the repository writes:

Illustrative — no call site in Engine/ or Applications/ combines levels; every entry point passes the default EInitLevel::All.

// A converter: streams and a log drain task, no window server contact.
hengine.Initialize(argc, argv, hbe::EInitLevel::TaskSystem | hbe::EInitLevel::Logger);

// The same set, named, so it can be tested before it is used:
constexpr hbe::EInitLevel ToolLevels = hbe::EInitLevel::TaskSystem | hbe::EInitLevel::Logger;
static_assert(hbe::HasFlag(ToolLevels, hbe::EInitLevel::TaskSystem));

hengine.Initialize(argc, argv, ToolLevels);

Remember what combining cannot express: memory, statistics, the logger object and the engine's own log file arrive in the constructor, whatever this expression evaluates to (what each level does).
