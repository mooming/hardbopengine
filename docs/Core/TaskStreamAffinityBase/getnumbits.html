GetNumBits

member of hbe::TaskStreamAffinityBase Engine/Core/TaskStreamAffinity.h how many stream indices this mask addresses — the template argument, readable without an object

Signature

[[nodiscard]] static constexpr auto GetNumBits() noexcept

Function description

Defined in the header Engine/Core/TaskStreamAffinity.h as TaskStreamAffinityBase::GetNumBits(); the body is return NumBits; and the deduced return type is the template parameter's own type, unsigned int. It is the count of stream indices this mask addresses, handed out without needing an object — the only way to ask a mask's type how wide it is.

Everything in the class is measured against this figure. Set, Unset and Get treat an index at or above it as out of range; the storage is (NumBits + BitsPerUnit - 1) / BitsPerUnit words, so the width is rounded up to whole 64-bit words and the bits between NumBits and the end of the last word are unreachable by design.

The engine's instantiation is 64 bits; its stream count has no such cap. TaskStreamAffinity is TaskStreamAffinityBase<64>, and the tests use this accessor to pin the relationship between the two numbering schemes that have to agree: static_assert(TaskSystem::NonStreamIndex >= TaskStreamAffinity::GetNumBits()); (Engine/Core/TaskSystem.cpp) asserts that a thread with no stream cannot be mistaken for one, because Get refuses out-of-range indices and the no-stream index is out of range by design.

Examples

From Engine/Core/TaskStreamAffinity.cpp, TaskStreamAffinityTest

TaskStreamAffinityBase<517> affinity;

for (unsigned int i = 0; i < affinity.GetNumBits(); ++i)
{
    const bool affinityValue = affinity.Get(i);
    if (!affinityValue)
    {
        ls << "Default constructed affinity shouldn't be false at index " << i << lferr;
    }
}

The usual job for this accessor: driving every index the mask owns, which is the only way to check a mask as a whole rather than the handful of streams one call happened to name.
