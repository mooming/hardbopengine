BeginTask

member of hbe::CPUBudget Engine/Core/CPUBudget.cpp Starts charging the calling thread's CPU time; pair it on the same thread.

Signature

void BeginTask() noexcept

Function description

Defined in Engine/Core/CPUBudget.cpp as CPUBudget::BeginTask(). 

taskStart = OS::GetThreadCPUTime();
isMeasuring = true;

From Engine/Core/CPUBudget.cpp, CPUBudget::BeginTask()

Two stores: the calling thread's CPU-time reading, and the flag that says a span is open. Nothing is allocated, nothing is locked, and no decision is made — the class's entire accounting cost per task is this call, its pair, and one subtraction.

Must be followed by EndTask on the same thread. A budget charges the CPU time of the thread that owns it; pairing across threads measures the span between two unrelated threads and produces a number with no meaning (Engine/Core/CPUBudget.h). This is also why a budget window is signalled rather than reset from the pass thread: a reset executed elsewhere lands between the owner's BeginTask and EndTask (Engine/Core/TaskStream.h).
A stream with no allowance never calls this, so an unbudgeted stream's accumulation is always zero. TaskStream::Update() brackets the run with budget.BeginTask() / budget.EndTask() only when budget.GetAllowance().count() > 0.0, on the reasoning that a measurement which cannot change a decision is a syscall billed to every task for nothing. The consequence is that TaskStream::GetAccumulatedCPUTime() reports the absence of accounting, not a task that cost nothing (Engine/Core/TaskStream.h).
If the platform clock fails here, the budget is poisoned rather than spared. Every platform implementation of OS::GetThreadCPUTime returns zero when the underlying call fails (Engine/OSAL/OSXThread.cpp, Engine/OSAL/LinuxThread.cpp, Engine/OSAL/WindowsThread.cpp), so a failed reading taken here stores zero in taskStart and the matching EndTask charges the thread's whole CPU life to the budget — the exact outcome the header says an unmatched EndTask cannot cause. The fail-open protection lives in the isMeasuring guard, which covers a missing BeginTask and not a failed one.

Parameters

None. It measures the thread that calls it, which is why it takes no thread argument to get wrong.

Return value

void. It does not report that a span was already open; a second call simply re-bases taskStart and loses the elapsed CPU time.
