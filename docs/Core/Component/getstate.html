GetState

member of hbe::Component Engine/Core/Component.h The component's ComponentState, by value.

Signature

[[nodiscard]] State GetState() const noexcept

Function description

Defined in the header Engine/Core/Component.h; nothing in Engine/Core/Component.cpp. Returns the component's ComponentState by value. State is this class's private alias for ComponentState, and it is what the signature is written in.

The five states, and the four that matter to a callback. NONE is the constructed state, set by the constructor and left as soon as a system takes the component. BORN is what Init sees. ALIVE is what Update and OnEnable see. SLEEP is what OnDisable sees. DEAD is what Release sees, and the state a released component is destroyed in (Engine/Core/Component.h, Engine/Core/ComponentSystem.h, the state enum's own page).
It is a plain field read without any lock, and the callback that reads it is the reason it is not private. state is a ComponentState, not an atomic; every read and write in the engine happens on the thread that drives the system (Engine/Core/ComponentSystem.h), so the accessor is safe for exactly as long as that discipline holds. A component that reads its own state from another thread is reading a field someone else is writing mid-pass. The repository's subclass uses it as a check at every callback entry — see Update for one of those checks verbatim.

Parameters

None.

Return value

TypeWhat it tells the caller
State (a ComponentState)The state as this instant, copied by value. Which callback you are in is not part of the answer — ALIVE is returned both by a component that has just been initialised and by one woken from sleep

Examples

switch (compo.GetState())
{
    case ComponentState::ALIVE:
        compo.OnEnable();
        updateList.push_back(std::move(compo));
        break;

    case ComponentState::SLEEP:
        compo.OnDisable();
        sleepList.push_back(std::move(compo));
        break;

From Engine/Core/ComponentSystem.h, ComponentSystem::ProcessTransition()

The accessor drives the entire transition machine: the switch decides which callback runs and which list the component lands on, and its default case — for any state other than those three — is an Assert that exists only in Debug builds, after which the component is destroyed without a release (SetState).
