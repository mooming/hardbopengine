GetName

member of hbe::Component Engine/Core/Component.h The name given at construction, as a reference to the held String.

Signature

[[nodiscard]] const String& GetName() const noexcept

Function description

Defined in the header Engine/Core/Component.h. Returns the name given to the constructor, as a reference to the hbe::String this component holds.

The name is shared, not copied, when a component moves — so a copy of a component is a second name-tag on one buffer. String stores a Shareable character buffer (Engine/String/String.h), and a subclass's move constructor moves the base from a non-const lvalue, which selects the sharing constructor: 
Test(Test&& rhs) noexcept
    : Component(rhs)

From Engine/Core/ComponentSystem.cpp, ComponentSystemTest

The consequence for a caller is benign but worth knowing: two components produced by moving one another report the same name, and neither can tell. The buffer outlives any one of them, so the reference cannot dangle because a move happened — only because the object it was taken from died.

Nothing in the engine ever asks a component its name. No line in Engine/ or Applications/ calls this accessor; the system that drives components reports its own name, not its members' (Engine/Core/ComponentSystem.h). It exists for a subclass's own diagnostics and for whoever is looking at a component from outside — and it is the one field of this class a subclass cannot set after construction, since the constructor is the only writer.

Parameters

None.

Return value

TypeWhat it tells the caller
const String&The member itself, not a copy. Valid while this component object is alive — and because the system moves components between lists every pass (Update), a reference to a component is shorter-lived than the reference to its name's buffer

Examples

The name is fixed at construction, which is the one place it can be given: 

Test(bool& testResult, TestCollection::TLogOut& ls, TestCollection::LogFlush& lferr)
    : Component("Test")

From Engine/Core/ComponentSystem.cpp, ComponentSystemTest

A subclass that wants a per-instance label has to pass it here, because there is no setter and the field is header-private (Component).
