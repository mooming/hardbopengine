GetName

member of hbe::TaskStream Engine/Core/TaskStream.h The stream's name, returned by value.

Signature

[[nodiscard]] auto GetName() const noexcept

Function description

Declared and defined in the header Engine/Core/TaskStream.h; there is no counterpart in Engine/Core/TaskStream.cpp. Returns the stream's StaticString name by value — the deduction of auto is the member's type, so the return is StaticString, not a reference.

The name is set once, by the constructor, and never changes. TaskStream(StaticString name, TStreamIndex streamIndex) initialises it and uses the same value to name the stream's allocator pool; the default constructor leaves it empty and names the pool "None" (Engine/Core/TaskStream.cpp, TaskStream). Every log line this class writes begins with it, so an unnamed stream is a stream whose reports cannot be attributed.
Inside the class the member is read directly; outside, this is the only way to ask. Every log line the stream writes captures [name = name] rather than calling the accessor (Engine/Core/TaskStream.cpp). The callers are all one step away: TaskSystem::GetStreamName(int) is this accessor on a stream looked up by index, the teardown assert passes it into the message that names an unclosed stream (IsClosed), and the suite's diagnostics print it beside a measurement (Engine/Core/TaskSystem.cpp). So the accessor is the way a report identifies a stream it was handed as a number.
By value is the safe half of the contract. A StaticString copy is a fixed-size value, so the caller may keep the answer past the stream's destruction — unlike GetThread, which returns a reference into the object (Engine/Core/TaskStream.h).

Examples

From Engine/Core/TaskSystem.cpp, TaskSystem::GetStreamName()

return streams[index].GetName();

The plainest form of the use case: a caller holding an index, needing a name (Engine/Core/TaskSystem.cpp).

From Engine/Core/TaskSystem.cpp, TaskSystem::JoinAndClear()

Assert(stream.IsClosed(), "Stream ", stream.GetName(),
       " is being destroyed without having been closed. Every stream must be closed - drained if it owns a "
       "thread, "
       "marked closed by its driver if it rides one - before the task system tears itself down.");

The one call site in the engine, and it is a Debug-only assert — Assert is compiled away outside the Debug configuration (Core/Debug.h, CMakeLists.txt) — so the name that identifies a misbehaving stream is printed only in the build that stops at it.
