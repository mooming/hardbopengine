GetGeneralQueueRefusalCount

member of hbe::TaskStream Engine/Core/TaskStream.h Times this stream was refused the general queue because its allowance was spent.

Signature

[[nodiscard]] unsigned GetGeneralQueueRefusalCount() const noexcept

Function description

Declared in the header Engine/Core/TaskStream.h, defined in Engine/Core/TaskStream.cpp. Times this stream left a task in the engine's general queue because its CPU allowance was already spent — the CPU budget's gate, seen from outside.

The header names the reason a number is needed at all. "The only witness that the acquire gate exists: a stream that declines work is otherwise indistinguishable from one that has nothing to do." (Engine/Core/TaskStream.h) A throttled stream and an idle stream have identical queues, identical lanes and identical pass rates, so without this counter the throttle cannot be observed — which is why the count is taken before the report, and why the report itself is once-only (ReportGeneralQueueRefusal).
What a non-zero value means. This stream wanted work from the general queue and was refused by its own budget: the pass reached the fallback with nothing from its lanes and budget.CanTakeWork() answered false. That is the throttle working — the stream is spending its configured share — and it implies tasks are waiting in the general queue for a window that RequestWindowAdvance has not reopened yet. Two conditions make the counter uninformative rather than false: a stream with no allowance configured can never raise it, because an unlimited stream always may take work (MayTakeNewWork, ConfigureBudget); and a stream whose lanes never run dry never reaches the fallback at all, however spent it is.
Nothing resets it, so it is a life total; and it counts refusals, not tasks refused. One increment per pass that asked and was refused, so a stream that stays refused every pass grows it by one per pass (Engine/Core/TaskStream.cpp). It is the pair of GetLaneWorkRefusalCount: this one is CPUBudget, that one is StreamDrainPolicy, and a stream can raise both in the same shutdown-free minute.

None.

Return value

unsignedRefusals of the general queue since construction, read relaxed. Zero means either "never throttled" or "never hungry"; the counter cannot tell those apart
