IsCloseRequested

member of hbe::TaskStream Engine/Core/TaskStream.h Whether a close has been asked of this stream, which is not whether it has closed.

Signature

[[nodiscard]] bool IsCloseRequested() const noexcept

Function description

Declared and defined in the header Engine/Core/TaskStream.h; there is no counterpart in Engine/Core/TaskStream.cpp. Whether RequestClose has been called on this stream.

The header names the distinction this accessor exists to keep visible. "Whether this stream has been asked to close" — and its neighbour IsClosed carries the other half: "Being asked to close is not being closed: the ask is a request and this says the stream finished." (Engine/Core/TaskStream.h) Between the two answers sits the drain, which for a worker stream can take up to its shutdown deadline (DrainForShutdown).
The engine reads the flag directly in the loop instead of through this accessor. RunLoop tests closeRequested.load(std::memory_order_acquire) inline, and Update does the same; this accessor has no caller in Engine/ or Applications/ (Engine/Core/TaskStream.cpp). It is the public face of a check the class makes for itself, which is what a driver outside the engine needs and the loop inside it does not.
The acquire load pairs with the release store in the ask, so a reader that sees true also sees whatever the requesting thread published before asking — the ordering that makes a shutdown sequence safe to publish with one flag (Engine/Core/TaskStream.h). The flag is one-way: nothing clears it, so a true is permanent for the life of the object.

Parameters

None.

Return value

TypeWhat you get
booltrue once RequestClose has run, whether or not the stream has stopped; false means nobody has asked yet

Examples

From Engine/Core/TaskStream.cpp, TaskStream::RunLoop()

while (likely(!closeRequested.load(std::memory_order_acquire)))
{
    if (!Update())
    {
        WaitForWork(std::chrono::milliseconds(10));
    }
}

The same load this accessor performs, done inline by the loop that owns the field (Engine/Core/TaskStream.cpp). A driver outside the class would write this loop as while (!stream.IsCloseRequested()) and reach the same exit.
