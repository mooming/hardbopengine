GetBaseTaskStreamIndex

member of hbe::TaskSystem Engine/Core/TaskSystem.h returns 0 — the index of the base stream, so that no call site has to hard-code it

Signature

static TIndex GetBaseTaskStreamIndex() noexcept

Function description

Returns the constant BaseStreamIndex (Engine/Core/TaskSystem.h), which is 0. The base stream is the one that rides the main thread instead of owning a thread of its own, and it is the last executor to close — RequestOtherStreamsClose deliberately leaves it, and the IO stream, open while everything else drains, because the end of the run still has reporting to do through them.

Every engine-side use of it reaches a stream through the index rather than holding a pointer: Update, JoinAndClear, DispatchToMainThread and the drive-until pump in TestHelper::DriveUntil all start here. Because the value is a constant, that is also why GetStream returning stream 0 for an out-of-range index is worth reading about: the base stream is what an unchecked index silently becomes.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) 0, always. Not a count and not a validity check — before Initialize and after JoinAndClear there is no stream at this index, which is what HasStream is for
