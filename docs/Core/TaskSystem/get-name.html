GetName

member of hbe::TaskSystem Engine/Core/TaskSystem.h returns "TaskSystem" — the string every log line, filter and assert message from this class is filed under

Signature

	[[nodiscard]] StaticString GetName() const noexcept;

Function description

One getter for const StaticString name, initialised to the literal "TaskSystem" in the constructor's initializer list and never written again. There is one task system per process and its name is not configurable.

The value is load-bearing in three places. It is the logger category — Initialize installs the Log.TaskSystem filter under GetName() and every message the class emits goes through Logger::Get(GetName()). It is the name the shutdown report is filed under in JoinAndClear. And it is what makes a log line attributable when several subsystems are writing at once during teardown.

Parameters

None.

Return value

TypeWhat you get
StaticString The literal "TaskSystem", as a pointer-and-length view of static storage. Safe to hold for the life of the process, because the bytes are a string literal and not a member

Examples

From Engine/Core/TaskSystem.cpp

auto log = Logger::Get(GetName());
log.Out([this](auto& ls) { ls << "Hardware Concurrency = " << numHardwareThreads; });

The pattern recurs through the file — Initialize, Update's budget path, and every refusal inside ParallelFor and DispatchSuccessor obtains its logger this way. One name means one filter, so raising Log.TaskSystem silences or unblocks the whole subsystem at once.
