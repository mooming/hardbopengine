GetCurrentStreamIndex

returns the thread_local stream index the calling thread last claimed, or NonStreamIndex when it has claimed none

Signature

static TIndex GetCurrentStreamIndex() noexcept
{
        return StreamIndex;
}

Function description

Reads thread_local TIndex StreamIndex (Engine/Core/TaskSystem.cpp:24), written only by SetStreamIndex and initialised to NonStreamIndex — static_cast<TIndex>(-1). This is the fact that IsBaseThread and IsIOThread are built from, and the one the general task queue consults when it decides whether this thread may take a work item: see Dequeue.

Why the "no stream" value is -1 and not 0. Stream 0 is a real stream — the base stream — so a default of 0 made every thread in the process report itself the base stream until a TaskStream loop claimed it. That made IsBaseThread useless as a check, made the assert in BuildStreams pass on any thread at all, and made the general queue charge a non-stream thread's contact with a task to stream 0's affinity. NonStreamIndex is out of range for the affinity mask by construction, so a thread that is not a stream takes nothing from the general queue and is not recorded as having seen anything.

The value is per-thread and per-pass. On the two driven streams — base and IO — it is set for the length of a drain pass and restored afterwards (Engine/Core/TaskStream.cpp:365-369), so reading it from the same thread one statement outside a pass gives NonStreamIndex again, not the stream that was being served a moment ago.

Parameters

None.

Return value

TypeWhat you get
TIndex (int) The claimed stream index, or NonStreamIndex (-1). Compare against GetBaseTaskStreamIndex or GetIOTaskStreamIndex; do not compare against the name, which is a separate variable that can disagree — see SetStreamIndex

Examples

From Engine/Core/TaskSystem.cpp

const unsigned int streamIndex = GetCurrentStreamIndex();

auto& affinity = workItem.affinity;
if (!affinity.Get(streamIndex))
{
        affinity.Set(streamIndex);
        return;
}

The general-queue intake at Engine/Core/TaskSystem.cpp:337, where the returned TIndex is widened into unsigned int: NonStreamIndex arrives there as 4294967295, which TaskStreamAffinity ignores because it is past the mask's width — so a non-stream thread neither takes the item nor records a claim. The outcome is intended; it is reached by the width of the type rather than by a check, so a future change to the affinity width would change this behaviour without any line here changing.
