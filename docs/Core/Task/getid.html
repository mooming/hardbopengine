GetID

member of hbe::Task Engine/Core/Task.h the identity every work item is stamped with; null until a registry issues the record

Signature

[[nodiscard]] TaskID GetID() const noexcept

Function description

Defined in the header Engine/Core/Task.h as Task::GetID(); the body is return id;. The value is the identity the registry issued for the record this task lives in — record index plus generation — and it is written once, by LoadIntoRecord, when TaskRegistry::Create() issues the record. Nothing else ever changes it while the task is live, so the ID a caller reads at any point is the ID that will resolve it.

Its job is to be handed to something else. Every work item is stamped with it (WorkItem::WorkItem() in Engine/Core/WorkItem.cpp initialises taskID(task.GetID())), so the item can outlive the usefulness of the task and still say whose work it was; and when a stream finishes an item, it is this ID that routes the outcome (TaskStream::TryExecuteWorkItem() passes task->GetID() to TaskSystem::DispatchSuccessor).

Null for a task no registry issued. A task built through a constructor keeps the default TaskID, so GetID().IsNull() is true and any item generated from it names no record. TaskRegistry::Find() answers nullptr for a null ID, and the stream holding such an item takes the released-task path: report it, fire its abandonment notice, run nothing.

None.

Return value
