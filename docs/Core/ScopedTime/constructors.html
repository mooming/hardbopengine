constructors

member of hbe::time::ScopedTime Engine/Core/ScopedTime.h starts the clock and binds the variable the measurement will be written to

Signature

explicit ScopedTime(TDuration& outDeltaTime) noexcept
        : duration(outDeltaTime)
        , start(TStopWatch::now())
{
}

explicit ScopedTime(const ScopedTime&) = delete;

Function description

Two members are initialized and nothing else happens: the output reference is bound, and start takes TStopWatch::now(). That is the whole constructor, and its simplicity is what makes the start sample honest — there is no work between entering the statement and the clock being read beyond the constructor call itself.

explicit is deliberate. Without it a TDuration lvalue would convert to a guard implicitly, and a temporary guard materialised on an argument list would end at the end of the full expression — measuring something nobody chose to measure. Requiring the name makes the lifetime explicit at the call site.

The deleted copy constructor is the reason the guard cannot be copied or moved at all: a user-declared copy constructor, even a deleted one, suppresses the implicit move constructor. A probe confirmed both std::is_copy_constructible_v and std::is_move_constructible_v are false. Storing a guard in a container, returning one from a function or capturing it in a lambda are therefore all unavailable, which is the point: a timer that outlived its scope by a move would write a stale span into a variable that may no longer exist.

noexcept holds because neither operation can throw: binding a reference and reading a clock. It also means the guard is safe to construct in a path that must not unwind — which matters because the destructor's own noexcept means a destructor reached during unwinding would terminate rather than propagate.

Parameters

ParameterTypeRequirement
outDeltaTime TDuration& A non-const lvalue, owned by the caller, that must outlive the guard. It is overwritten at destruction, so any value it holds at construction is discarded — and it is a reference, so a temporary, a literal or the result of a conversion will not bind

Return value

A constructor, so the guard. It has no other observable effect: no clock reading is produced until it is destroyed.

Examples

From Engine/Core/TaskStream.cpp

time::TDuration duration;

{
        time::ScopedTime timer(duration);
        if (workItem->Run(*task))
        {
                taskSys.DispatchSuccessor(task->GetID());
        }
}

The duration is declared outside the block and the guard inside it, so the span covers exactly Run plus the successor dispatch, and duration is complete and readable after the closing brace. Declaring both in the same block would work equally well for correctness; the extra block is what makes the end of the measured region visible in the source.
