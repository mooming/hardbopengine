IncSlowFrameCount

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Add one to the slow-frame count - unwired, with no definition of slow anywhere.

Signature

void IncSlowFrameCount() noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Adds one to slowFrameCount with fetch_add(1, std::memory_order_relaxed). The intended companion to IncFrameCount: the pair would give "N frames, M of them slow" in the shutdown report. Neither has a caller.

No caller, and no definition of "slow" anywhere for it to use. Nothing in Engine/ or Applications/ calls this, and the class holds no threshold to compare against — no frame-time limit, and no updated frame time either, since UpdateCurrentTime is never called (Engine/Core/SystemStatistics.h, Engine/Core/SystemStatistics.cpp). So the field is not merely unwired: the decision it would record is not made anywhere in the engine.
Its place in the report is next to the frame count it qualifies. Print writes "Slow Frame Count" as the second line, immediately under "Frame Count", and both read memory_order_relaxed. Printing them as a pair when only one of them could ever be non-zero is how the report reads as Frame Count = 0 / Slow Frame Count = 0 (Engine/Core/SystemStatistics.cpp).

Parameters

None.

Return value

void. No accessor for the field besides the shutdown print.

Examples

No call site exists. A caller would need three things the class does not provide: a frame count (IncFrameCount, also unwired), a frame time (GetDeltaTime, never updated), and a threshold to compare them with (Engine/Core/SystemStatistics.h).
