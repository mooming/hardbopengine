IncLongLogCount

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Add one to the long-log-line count, behind the same compiled-out flag.

Signature

void IncLongLogCount() noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Adds one to longLogCount with fetch_add(1, std::memory_order_relaxed). Intended to count log lines too long to fit inline, which are the ones that need a system allocation. Its call site sits immediately before that allocation, inside a #if PROFILE_ENABLED block that no configuration compiles.

The counter would have marked exactly the allocations worth counting, and it is compiled out. A long log line takes a SysAllocate from the memory manager, so this count is the number of those — but with PROFILE_ENABLED at 0 (Engine/Config/BuildConfig.h) the increment is not built, the allocation still happens, and the shutdown report prints "Long Log Count = 0 / 0" beside a "Fallback Allocation Count" that is counting a different thing entirely (IncFallbackAllocCount, Engine/Log/LogLine.cpp).
It is the numerator; IncLogCount is the denominator. Print emits them on one line as "X / Y" and loads both before printing, so the two counters are meant to be read only as a ratio of long lines to all lines (Engine/Core/SystemStatistics.cpp).

Parameters

None.

Return value

void. The count is not returned; the only reader is Print.

Examples

#if PROFILE_ENABLED
    auto& stat = engine.GetStatistics();
    stat.IncLongLogCount();
#endif // PROFILE_ENABLED

    auto& mmgr = engine.GetMemoryManager();
    longTextSize = size + 1;
    longText = (char*) mmgr.SysAllocate(longTextSize);
