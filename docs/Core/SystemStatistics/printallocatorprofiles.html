PrintAllocatorProfiles

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h The allocator profile dump, whose entire body is compiled out in every configuration.

Signature

void PrintAllocatorProfiles() noexcept

Function description

Defined in Engine/Core/SystemStatistics.cpp. Meant to dump the per-allocator AllocStats entries that Report collected, one per line, at the logger's Verbose level. In every configuration this tree builds, the entire body is compiled out and the function does nothing.

The function has a caller, an empty body and no reachable way to fill it. The whole definition sits between #if PROFILE_ENABLED and #endif, and PROFILE_ENABLED is defined as 0 unconditionally in Engine/Config/BuildConfig.h — not behind an #ifndef, so a build cannot override it from the command line either. The vector it would walk, allocStats, is declared inside the same condition and so does not exist as a member in a shipping build. Meanwhile the call site is unconditional: 
statistics.Print();
statistics.PrintAllocatorProfiles();

From Engine/Engine/Engine.cpp, Engine::ShutDown()

At shutdown the engine calls it, it returns immediately, and no line of allocator profiling appears in the log — while Print, the line above it, does write its eleven. Nothing reports that the second report was empty, so the absence is silent (Engine/Core/SystemStatistics.cpp).

Even with the flag set, two more conditions stand between the call and the output. The output is opened at ELogLevel::Verbose, so a logger configured above that level still prints nothing (Engine/Log/Logger.h); and the entries come from Report, whose only caller is MemoryManager inside the same PROFILE_ENABLED condition — so the vector is filled by the memory manager or not at all, and this function never measures anything itself (Engine/Memory/MemoryManager.cpp).

Parameters

None.

Return value

void. It reports through the logger; there is no way to ask whether it had anything to print, and in a shipping build it never has.

Examples

#if PROFILE_ENABLED
    auto log = Logger::Get(GetName(), ELogLevel::Verbose);
    log.Out("= System Statistics: Allocator Profiles ========================");

    for (auto& stats : allocStats)
    {
        stats.Print();
    }
#endif // PROFILE_ENABLED

From Engine/Core/SystemStatistics.cpp, SystemStatistics::PrintAllocatorProfiles() (elided: the closing banner line)

Per-entry printing is delegated to AllocStats::Print (Engine/Memory/AllocStats.h), so the shape of each line belongs to the memory module, not to this class. What this function adds is the banner, the verbosity level and the fact that it is the only consumer of Report's collection.
