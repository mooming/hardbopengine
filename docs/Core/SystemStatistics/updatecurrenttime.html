UpdateCurrentTime

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Sample the clock: the only writer of the delta and elapsed fields - and nothing calls it.

Signature

void UpdateCurrentTime() noexcept

Function description

Defined in Engine/Core/SystemStatistics.cpp; declared in Engine/Core/SystemStatistics.h. The only writer of elapsed time in this class: it reads the clock, turns the time since the previous call into deltaTime (a float, in seconds), turns the time since the constructor into timeSinceStart (a double, in seconds), and stores the new instant as currentTime.

Nothing calls it, so the four time fields it owns are frozen at construction — and two of them were never written at all. No line in Engine/ or Applications/ calls UpdateCurrentTime() (Engine/Core/SystemStatistics.h). The constructor sets startTime and makes currentTime equal to it, and leaves timeSinceStart and deltaTime with no initializer at all, so those two hold indeterminate values for the life of the run (the constructor page). The consequence is visible in the shutdown report: Print prints Running Time = " << timeSinceStart << " sec" from that uninitialized field (Engine/Core/SystemStatistics.cpp).
The clock is this class's own, and the delta is measured from the previous call rather than from a frame boundary. 
auto newTime = time::TStopWatch::now();
const auto delta = newTime - currentTime;
deltaTime = time::ToFloat(delta);
currentTime = newTime;

const auto fromStart = currentTime - startTime;
timeSinceStart = time::ToDouble(fromStart);

From Engine/Core/SystemStatistics.cpp, SystemStatistics::UpdateCurrentTime()

time::TStopWatch is std::chrono::high_resolution_clock, and time::ToFloat / time::ToDouble return the duration in seconds (Engine/Core/Time.h). Because the delta is "since I was last called", whoever calls this defines the unit of a frame: twice per frame halves every deltaTime, and a caller that skips a frame sees the whole gap as one delta. It takes no argument, so nothing outside can supply a curated frame time.

Parameters

None — the function takes its reading from the clock, not from a caller.

Return value

void. The new values are read back through GetCurrentTime, GetTimeSinceStart and GetDeltaTime; currentTime is written last, so a caller that reads the deltas and the instant separately can see a torn pair on another thread.

Examples

No call site exists, so there is no verbatim example to give. The shape the function invites is one call per frame from the engine loop, before anything asks for a delta — and the honest statement of its current status is that the engine loop does not do that, which is why GetDeltaTime and GetTimeSinceStart have no callers either (Engine/Core/SystemStatistics.h).
