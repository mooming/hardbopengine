GetTimeSinceStart

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Seconds since construction as of the last sample - which never happened, so: uninitialized.

Signature

[[nodiscard]] auto GetTimeSinceStart() const noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Returns timeSinceStart, a double of seconds since the constructor, written only by UpdateCurrentTime via time::ToDouble (Engine/Core/SystemStatistics.cpp, Engine/Core/Time.h).

The field has no initializer, no writer with a caller, and no reader with a caller — and one of the two places it is used is the shutdown report. The constructor's initializer list stops at currentTime and the header gives the member no default (Engine/Core/SystemStatistics.cpp, Engine/Core/SystemStatistics.h), so until UpdateCurrentTime runs — which it never does — this returns an indeterminate double. Reading it is well-defined in the sense that the object exists, but the value is whatever the memory held. The accessor itself has no callers; the same field is read directly by Print, which prints it as Running Time = ... sec, so the shutdown log carries that garbage under a label that reads like a measurement (Engine/Core/SystemStatistics.cpp).
For elapsed time that is real, compute it from GetStartTime instead. That is what Engine::Log does for its timestamps — it subtracts the start instant from the clock on every line, which works whether or not this class ever samples (Engine/Engine/Engine.cpp). A double of seconds is a wider and sloppier representation than the time point it would be derived from, which is why the class keeps the point and derives the rest.
