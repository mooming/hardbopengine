GetDeltaTime

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Seconds between the last two samples - never written, so uninitialized.

Signature

[[nodiscard]] auto GetDeltaTime() const noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Returns deltaTime, a float of seconds between the last two samples, written only by UpdateCurrentTime through time::ToFloat (Engine/Core/SystemStatistics.cpp, Engine/Core/Time.h).

No initializer and no live writer, so this returns an indeterminate float in every build. The constructor does not initialize deltaTime and the header gives it no default member initializer (Engine/Core/SystemStatistics.h), and the sole writer has no caller. Nothing reads it either: no line in Engine/ or Applications/ calls this accessor, and unlike GetTimeSinceStart it is not even printed — so the uninitialized field currently has no visible effect, which is the only difference between it and its neighbour (Print).
A float where the class keeps a double, and the narrower type is the right choice for the use. Frame deltas are small numbers a game step multiplies by; the running total is the quantity that needs double (GetTimeSinceStart). Both are derived from one sample, so a caller must expect them to be consistent only in the sense that they were written back to back in the same call (UpdateCurrentTime) — there is no atomic pair, and a reader on another thread can see one updated and not the other.

Parameters

None.

Return value

TypeWhat it tells the caller
auto → floatSeconds between the last two samples — today, an uninitialized value. It is not the engine's frame time, because nothing has ever offered one here; whoever runs a frame today keeps that figure to itself

Examples

No call site exists, so there is nothing to quote. The consumer it would serve is anything that integrates over frames — Component::Update takes a deltaTime of exactly this type and unit, and its driver in the repository passes a hard-coded 0.033f rather than asking this class (Engine/Core/ComponentSystem.cpp).
