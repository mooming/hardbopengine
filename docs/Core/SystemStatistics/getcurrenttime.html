GetCurrentTime

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h The last sampled instant - frozen at construction because nothing samples.

Signature

[[nodiscard]] auto GetCurrentTime() const noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Returns currentTime by value, a time::TTime over time::TStopWatch (Engine/Core/Time.h) — the instant of the last UpdateCurrentTime. Since that function is never called, this returns the construction instant forever, which is the same answer GetStartTime gives.

No caller, and the field it reads is frozen by the missing caller of another function. Nothing in Engine/ or Applications/ calls this accessor, and the only writer of the field it returns has no caller either (Engine/Core/SystemStatistics.h, Engine/Core/SystemStatistics.cpp). Unlike GetTimeSinceStart and GetDeltaTime, the value here is at least initialized — the constructor sets currentTime = startTime — so the accessor is well-defined and merely stale.
It is not a clock. A caller wanting "now" asks the clock directly (time::TStopWatch::now(), or Engine::Log's use of chrono::steady_clock::now()); this reports when this class last sampled. Those are the same only while something samples regularly, and nothing does (UpdateCurrentTime).

Examples

No call site exists, so there is nothing to quote. The pairing it expects is with GetTimeSinceStart and GetDeltaTime: all three describe the last sample, and all three are only as fresh as the missing call to UpdateCurrentTime (Engine/Core/SystemStatistics.h).
