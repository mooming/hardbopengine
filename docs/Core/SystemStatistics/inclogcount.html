IncLogCount

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Add one to the log-line count, behind a flag no configuration compiles.

Signature

void IncLogCount() noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Adds one to logCount with fetch_add(1, std::memory_order_relaxed). Intended to count short log lines — the ones stored inline in the line object rather than in a heap buffer. Its only call site is compiled out, so in every build the engine can produce the counter stays zero.

Both the increment and its sibling are behind a flag that no configuration sets. PROFILE_ENABLED is defined as 0 unconditionally in Engine/Config/BuildConfig.h, so the block above is not compiled, and Print reports "Log Count = 0". The same condition removes IncLongLogCount, which is why that line reads "0 / 0" — the ratio it prints is computed from two fields that were never written (Engine/Log/LogLine.cpp, Engine/Core/SystemStatistics.cpp).
Printed as a pair, and read together on purpose. Print loads both counters before writing either line, so "Long Log Count = X / Y" cannot divide a long count from one moment by a total from another (Engine/Core/SystemStatistics.cpp).

Parameters

None.

Return value

void. The count is not returned; the only reader is Print.

Examples

#if PROFILE_ENABLED
    {
        auto& engine = Engine::Get();
        auto& stat = engine.GetStatistics();
        stat.IncLogCount();
    }
#endif // PROFILE_ENABLED
