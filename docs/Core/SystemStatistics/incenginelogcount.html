IncEngineLogCount

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Add one per attempted engine log line: one of the two counters a shipping build fills.

Signature

void IncEngineLogCount() noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Adds one to engineLogCount with fetch_add(1, std::memory_order_relaxed). This is the one counter in the class that a shipping build actually fills: every call to Engine::Log that survives the level filter raises it — and it is raised before the filter is applied inside the lock, so the count is of engine log lines attempted, not lines printed (Engine/Engine/Engine.cpp).

Counted once per call, whether or not the line is printed. The increment sits above the CPEnginePrintLogLevel test, so a line suppressed by the configured print level is still counted. The report line "Engine Log Count" therefore measures demand, not output (Engine/Engine/Engine.cpp, Print).

Parameters

None.

Return value

void. The count is not returned; the only reader is Print.
