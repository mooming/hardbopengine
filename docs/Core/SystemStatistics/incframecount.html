IncFrameCount

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h Add one to the frame count - a number no code in the engine ever increments.

Signature

void IncFrameCount() noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h. Adds one to frameCount with fetch_add(1, std::memory_order_relaxed). It is the headline number of the shutdown report — the first figure Print writes — and nothing in the engine calls it.

Zero call sites, so "Frame Count = 0" in every report the engine has ever written. No line in Engine/ or Applications/ calls IncFrameCount(); the engine loop counts frames for its own purposes and never tells this class (Engine/Core/SystemStatistics.h, Engine/Engine/Engine.cpp). The counter is not broken — it is unreachable, and the difference matters only if someone reads the report as a measurement.
Relaxed, 64-bit, lock-free, and never reset. The field is a std::atomic<uint64_t> and the class will not compile where such an atomic is not always lock-free (Engine/Config/BuildConfig.h excludes nothing here; the static_assert is at class scope). Relaxed ordering means the increment carries no promise about any other memory, which is right for a count that nothing synchronizes against.

Parameters

None.

Return value

void. The new count is not returned, and there is no accessor for the field other than the shutdown print.

Examples

No call site exists, so there is nothing to quote. The function it would belong to is the engine's per-frame step — the same place that would call IncSlowFrameCount — and the reader is Print, which would then have something true to say about how long the run was (Engine/Core/SystemStatistics.cpp).
