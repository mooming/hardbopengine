GetStartTime

member of hbe::SystemStatistics Engine/Core/SystemStatistics.h The construction instant, and the epoch every engine log timestamp is measured from.

Signature

[[nodiscard]] auto GetStartTime() const noexcept

Function description

Defined in the header Engine/Core/SystemStatistics.h; nothing in Engine/Core/SystemStatistics.cpp. Returns startTime by value — auto deducing time::TTime, which is a std::chrono::time_point over time::TStopWatch, that is std::chrono::high_resolution_clock (Engine/Core/Time.h). The value is written once, by the constructor, and never again.

This is the one time getter with a live caller, and it is the origin of every timestamp in the engine's own log. 
const auto diff = chrono::steady_clock::now() - statistics.GetStartTime();
auto hours = chrono::duration_cast<chrono::hours>(diff);
auto minutes = chrono::duration_cast<chrono::minutes>(diff);

From Engine/Engine/Engine.cpp, Engine::Log()

Engine::Log subtracts the start instant from the clock on every engine log line and prints the difference as [h:m:m.mmm] (Engine/Engine/Engine.cpp). That subtraction only compiles because the two clock types are the same type in the standard library this tree builds against — high_resolution_clock is an alias of steady_clock there; the pairing is a compile-time dependency of the header's choice, and a probe of this toolchain confirms the two types are identical.

It is a copy of a time point, so it is safe to hold; it is not a monotonic clock you can resample. The value never changes after construction, which is what makes it usable as an epoch from any thread without a lock. For "how long has this been running" the class offers GetTimeSinceStart, which is never updated and never initialized (UpdateCurrentTime) — so elapsed time is computed by whoever asks, from this origin.
