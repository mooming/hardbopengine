member of hbe::Exception Engine/Core/Exception.h formats the throw site and its arguments straight into the log, and builds an object that keeps none of them

Signature

template <typename... Types>
Exception(const char* file, int line, Types&&... args)
{
        using namespace std;
        PrintArgs(file, ":", line, forward<Types>(args)...);
}

Function description

One statement, and it is the whole constructor: PrintArgs(file, ":", line, forward<Types>(args)...). The file, a separator, the line and every argument are pushed at the log immediately, which is what makes this constructor worth writing at all — a throw site gets its context formatted while the context still exists, in the frame that still has the values.

Nothing is captured afterwards. The class declares no fields, so the pack is consumed entirely by the print and there is no copy of the message for a handler to read. The consequences are on the class page: this type is not a std::exception, and a handler can learn only that something was constructed.

The forwarding is ordinary perfect forwarding of an argument pack, so an lvalue argument reaches PrintArgs as an lvalue and a temporary as an rvalue. That matters only in that PrintArgs takes const T& — a mutable argument is not modified here, and nothing is moved out of anything.

Parameters

ParameterTypeRequirement
file const char* A null-terminated string, conventionally __FILE__. Not checked for null — it is handed to the log as given, so nullptr here is a fault at print time rather than a rejected call
line int Conventionally __LINE__. Printed as a number; no validity is assumed or needed
Types template parameter pack Zero or more types. Each is forwarded as written, so no conversion is imposed before the print
args Types&&... Anything Log's PrintArgs can format. The arguments are the message: this constructor has no format string, so the pack is concatenated left to right with no separators inserted between the caller's own strings

Return value

A constructor, so the object — one byte, holding nothing. Nothing about the arguments survives it.

Examples

Illustrative — no call site for this exists in the repository. A grep of Engine/, Applications/ and Examples/ finds no construction of Exception, because docs/CodingStandards.md requires the engine to be exception-free.

if (size == 0)
{
        throw hbe::Exception(__FILE__, __LINE__, "Empty buffer of capacity ", capacity);
}

The printed report is the effect the caller should expect to see, and the only one: the log line appears at the moment of construction, whether or not anything ever catches the throw.
