Exception

Engine/Core/Exception.h a throw-site formatter that prints when it is constructed and keeps nothing — the engine is exception-free by standard, and this class has no throw site anywhere in the repository

Class description

Exception is a final class whose only member is a variadic constructor. That constructor does one thing: it forwards its arguments to PrintArgs together with the file and line it was given, so the report leaves through Log while the object is being built. Nothing is stored. There is no message member, no code, no what(), and no base class — in particular no std::exception — so a handler that catches this type learns only that a throw happened, and the text it might have wanted has already been written to the log and dropped.

That shape is consistent with the rule this engine actually follows: docs/CodingStandards.md states the engine is exception-free; do not use C++ exceptions, and Engine/CodingStandards.h:332 records that no try, catch or throw appears anywhere. Error paths report through the Log module and return, or assert. So Exception is best read as the mechanism for the one spelling that rule forbids: write throw Exception(__FILE__, __LINE__, "bad size ", size) and the diagnostics arrive formatted at the throw site, which is the useful half of what a conventional exception type provides.

A caught Exception carries no information, and it is not a std::exception. Because there is no std::exception base, a handler written as catch (const std::exception&) does not catch it, and catch (...) is the only form that can. Because the constructor keeps nothing, the catch block cannot ask what went wrong: the arguments were consumed by the print at construction time. Anything a handler needs to act on must therefore still be communicated some other way, which is the same reason the engine's error paths return values instead.
No throw site exists. A grep of Engine/, Applications/ and Examples/ finds no construction of this type. Its single appearance outside its own header is the #include at Engine/Test/TestEnv.cpp:10, where the file never names the type again — a stale include, not a use. See Coverage.

Template parameters

The class itself is not a template. Its constructor is, and that page covers what its parameter pack may contain.

Class properties

None — there is no alias, no constant and no field in this class. An object of this type occupies one byte and holds nothing that could be read back.
