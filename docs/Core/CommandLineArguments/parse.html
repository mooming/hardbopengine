Parse

member of hbe::CommandLineArguments Engine/Core/CommandLineArguments.h Private: assert argc, echo argv, and assign none of the three members.

Signature

void Parse(int argc, const char* argv[])

Function description

Private, defined in Engine/Core/CommandLineArguments.cpp; the only thing the taking constructor does. Its whole body is an assertion that argc is positive and a loop that prints each entry of argv. It writes none of the three members, which is why GetArguments is empty and Print has nothing to print. 

void CommandLineArguments::Parse(int argc, const char* argv[])
{
    using namespace std;

    Assert(argc > 0, "CommandLineArguments::Parse - Incorrect argc = ", argc);

    for (int i = 0; i < argc; ++i)
    {
        cout << i << " : " << argv[i] << endl;
    }
}

From Engine/Core/CommandLineArguments.cpp, CommandLineArguments::Parse()

The name promises storage and the body delivers a print, and the two members that would hold the path are untouched. executablePath and executableFilename have no assignment anywhere in the file (Engine/Core/CommandLineArguments.cpp), so Print's two path lines are permanently empty and the class cannot answer the one question its fields advertise: which executable was run, and from where. The header's @brief says "Parses and stores"; the code stores nothing (Engine/Core/CommandLineArguments.h). This is the class's central defect, and every other page here points at it.
It reads argv[i] up to argc without checking either, and its only guard is a Debug-only assert. Assert compiles to nothing unless !RELEASE_BUILD is defined, which only the Debug configuration is (Engine/Core/Debug.h). In Dev and Release, an argc of zero skips the loop harmlessly, but an argc that overstates the array prints past it — and argv[argc] is guaranteed null by the platform, so printing one element too many means passing a null const char* to a stream, which the standard library is allowed to reject. The assert is the only check on the pair, and it is not present in the builds that ship.
The print here is the reason the class has any observable effect at all. One line per argument, to std::cout, at construction time — duplicating what Print was written to do, without the banner and without the empty count line (Engine/Core/CommandLineArguments.cpp). Neither has ever executed: the class has no construction site in Engine/ or Applications/ (the constructor page).

Parameters

Return value

void. No report of what was parsed — because nothing is parsed, there is nothing to report; a caller cannot distinguish "no arguments" from "arguments seen and dropped".

Examples

{
    Parse(argc, argv);
}
