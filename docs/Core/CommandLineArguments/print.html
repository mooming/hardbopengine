Print

member of hbe::CommandLineArguments Engine/Core/CommandLineArguments.h Path, filename, count and one line per argument, straight to std::cout.

Signature

void Print()

Function description

Defined in Engine/Core/CommandLineArguments.cpp; declared without noexcept in the header. Writes a banner, the executable path, the executable filename, an argument count, and one line per stored argument — to std::cout, not to the logger, which makes this one of the few places in the engine that writes standard output directly.

Given the state the rest of the class can reach, the output is a fixed five-line block ending in an empty list. Parse never fills the fields this prints, so "Path:" and "Executable Filename:" print empty strings and "Number of Arguments = 0" is always true (Engine/Core/CommandLineArguments.cpp): 
cout << "## Command Line Arguments" << endl;
cout << "# Path: " << executablePath << endl;
cout << "# Executable Filename: " << executableFilename << endl;
cout << "# Number of Arguments = " << arguments.Size() << endl;

From Engine/Core/CommandLineArguments.cpp, CommandLineArguments::Print()

Nothing here is wrong except the input: the fields exist, the printing is written, and the step that would populate them is missing. The class also has no caller (the constructor page), so in the tree as it stands this function has never been reachable.

Standard output, unbuffered by any log level, and a method that can throw. The output goes through std::cout with using namespace std; scoped inside the function (Engine/Core/CommandLineArguments.cpp), so it bypasses the logger's categories, levels and IO stream entirely (the log module) — it cannot be filtered, redirected to the IO stream, or suppressed by configuration, and it interleaves with whatever else writes standard output. The declaration carries no noexcept, unlike GetArguments, which is honest: stream insertion can throw.

Parameters

None.

Return value

void. Output is the effect; there is no way to obtain the same text as a string, and no indication of failure if the stream is unwritable.

Examples

No call site exists in Engine/ or Applications/, so the example is the function's own body above. For comparison, the engine's end-of-run dumps go through the logger — SystemStatistics::Print is the sibling that made the opposite choice and is the one that appears in a log file (Engine/Core/SystemStatistics.cpp).
