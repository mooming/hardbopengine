CommandLineArguments

Engine/Core/CommandLineArguments.h The interface for a parsed command line - and a Parse that echoes argv and stores none of it.

Class description

class CommandLineArguments final at Engine/Core/CommandLineArguments.h: three members — an executable path, an executable filename and an Array of Strings — one real constructor, one accessor, and two printers. The interface is the shape of a finished class; the implementation of the step that would fill it is missing, so the object is empty for all of its life.

Parse prints the argument vector and stores nothing, so every member of every instance is at its default. The function's body is an assertion that argc > 0 and a loop of cout << argv[i] (Engine/Core/CommandLineArguments.cpp). Nothing assigns executablePath, nothing assigns executableFilename, nothing appends to arguments. The consequences are mechanical:
MemberWhat it holds after constructionWhat that costs the caller
executablePathan empty StringPrint's "Path:" line is always blank; the class cannot say where the executable was run from
executableFilenamean empty StringThe same line, and no way to name the running program
argumentsan empty ArrayGetArguments always yields nothing and the count line always reads 0

The header's own @brief reads "Parses and stores command line arguments passed to the application" (Engine/Core/CommandLineArguments.h) — the parsing half is a print, and the storing half is absent.

Nothing in the engine or in any application constructs one, so none of the above has ever been observed at runtime. No line in Engine/ or Applications/ mentions this class outside its own two files (Engine/Core/CommandLineArguments.cpp), so the command line the engine is started with is never routed through it — the application's argc/argv are consumed elsewhere and this class is not part of that path. Everything on these pages is therefore a reading of the source, stated as such on each page, and the argument echo the constructor would perform has never run.
What the class does get right is the part a caller can rely on: it cannot be built without a command line, and its container cannot be mutated from outside. The default constructor is deleted (the constructor page); GetArguments is a const member returning a deduced auto&, which is a const reference, and Array deletes its own copy operations so nothing can smuggle a mutable copy out (Engine/Container/Array.h). The class is final, so there is no subclass to get the contract wrong.

Template parameters

None. The class is final and not a template; the only generic piece is its member type Array<String>, fixed in the declaration of that member (Engine/Core/CommandLineArguments.h).
