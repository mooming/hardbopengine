~CommandLineArguments

member of hbe::CommandLineArguments Engine/Core/CommandLineArguments.h Defaulted: destroys two empty strings and an empty array, because Parse filled nothing.

Signature

~CommandLineArguments() = default

Function description

Declared and defaulted in the header Engine/Core/CommandLineArguments.h; nothing in Engine/Core/CommandLineArguments.cpp. It destroys two Strings and an Array of them, and because Parse put nothing into those members, there is nothing of the command line for it to release.

Defaulted, non-virtual, and safe in the only way this class can be safe. The class is final (Engine/Core/CommandLineArguments.h), so the destructor is never dispatched through a base pointer, and no member holds a raw allocation: String frees its reference-counted buffer, and Array::Clear gives back whatever the array's allocator handed it. Since the array is always empty in practice, the destructor's real work today is destroying two empty strings.
It cannot report anything about the run it ends, because the object never learned any of it. A destructor that might want to log the command line has nothing to log: the path and filename fields were never filled, and the argument vector was forwarded to std::cout at construction and then forgotten (Parse, Engine/Core/CommandLineArguments.cpp). Combined with the absence of any construction site (the constructor page), this destructor exists in the interface and has never run.

Parameters

None.

Return value

None. It is defaulted, and every member destructor it runs is itself noexcept by the engine's convention.

Examples

Nothing destroys an instance, because nothing makes one: the class has no call sites outside its own files (Engine/Core/CommandLineArguments.h). The only observable effect of the class as written would be the argument echo performed by Parse during construction.
