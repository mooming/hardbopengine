Module Index / Core / WorkItem / ~WorkItem

~WorkItem

member of hbe::WorkItem Engine/Core/WorkItem.h defaulted, because an item owns no memory and the pointers it carries are not its to free

Signature

~WorkItem() = default

Function description

Declared in Engine/Core/WorkItem.h as WorkItem::~WorkItem(), in the same public block as the defaulted copy assignment. Nothing is released: the item owns no memory, and the two pointers it carries — abandonedUserData above all — belong to whoever supplied them, so a destructor that touched them would be a claim of ownership the engine never made.

It is spelled = default rather than left out for the same reason the copy assignment is: the special member set is part of this type's contract, and a reader should not have to deduce that an item is copyable and trivially destructible from the absence of a line. The item is copied on every queue operation, which is only cheap while the type stays trivially copyable apart from the affinity mask.

No base class, so no destructor question. WorkItem is final and derives from nothing, so there is no virtual destructor to declare and no slicing path through a base pointer.

Parameters

None.

Return value

None.

Examples

Illustrative — no translation unit calls this. It runs when the std::optional<WorkItem> holding an item is reset or goes out of scope: every take, every refusal and every drop site in TaskStream ends that way.
