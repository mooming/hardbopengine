Run

member of hbe::WorkItem Engine/Core/WorkItem.h member of hbe::WorkItem Engine/Core/WorkItem.h member of hbe::WorkItem Engine/Core/WorkItem.h noexcept run this item's slice of the task's work and report whether that call closed the join

Signature

bool Run(Task& task) noexcept

Function description

Executes the slice this item carries — current up to end of the task's reserved range — and reports whether that call closed the task's join. The item does not resolve its own task: the stream looks taskID up and hands the live record in, which is what lets a stream drop an item whose task is gone instead of running it against whatever task now occupies that slot.

Closing the join means every reserved subtask has reported and the task's result, if any, is ready to route. Under the join counting rules exactly one item of a task ever returns true, and it is the last reserved one rather than merely one of the ones past the count — a task that handed out more items than it reserved is a bug the engine asserts on, not a case this return value papers over.

Parameters

ParameterMeaning
taskThe task this item was issued for, already resolved by the calling stream. The precondition is real: the caller has confirmed the ID names a live task. Nothing here reaches for a task by itself

Return value

true when this call closed the join. That boolean is a transfer of obligation, not just information: the thread that gets true is the one that finished the work, and it owes the successor a dispatch. No other path delivers an outcome — successor routing happens at exactly one call site, so a stream that runs the item, sees true, and does not dispatch leaves the whole chain waiting.

true means "you own the hand-off", not "the result was delivered". Reading this return value and discarding it is the silent failure this engine's redesign calls out by name: the work completed, the record was correct, and no successor ever ran.

Example

if (item.Run(*task))
{
    taskSystem.DispatchSuccessor(item.taskID);   // the obligation that came with true
}
