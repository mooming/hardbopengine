WorkItem

member of hbe::WorkItem Engine/Core/WorkItem.h the only way an item comes to exist, and the reason a generated item can never run on the base or IO stream

Signature

WorkItem(Task& task, TIndex start, TIndex end, uint8_t priority) noexcept

Function description

Defined in Engine/Core/WorkItem.cpp as WorkItem::WorkItem(). It is the only way an item comes to exist, and it is private: friend class Task; and friend class TaskStream; end the header, and friend class TaskSystemTest; sits in its public block so the suite can build one by hand. A customer who wants work to run calls TaskSystem::EnqueueTask or a producer's TaskProvider::MakeWholeItem, never this.

Three things happen here that make an item more than a range, and none of them is visible in the field list:

What the constructor doesWhy it is done here and not by the caller
Takes taskID from task.GetID() An item can never be built around an identity the registry did not issue, so a stale or forged ID is not a failure mode of this type
Copies abandonedNotice, abandonedUserData and offerTime off the task This is what makes a slice inherit its parent's notice and its parent's age without any call site remembering to set them — see SetAbandonedNotice and the age rule in StreamDrainPolicy
Initialises current to start The resume point begins at the front of the slice, so a partially-run item continues rather than restarting
affinity.Unset(TaskSystem::GetBaseTaskStreamIndex());
affinity.Unset(TaskSystem::GetIOTaskStreamIndex());

From Engine/Core/WorkItem.cpp, WorkItem::WorkItem()

The body runs after affinity has been default-constructed, which permits every in-range stream, and clears two bits — so an engine-generated item is never eligible for the base stream or the IO stream. That is the only thing in the engine that excludes a stream, and TaskSystem::Dequeue is where its consequence is read.

Parameters

ParameterTypeRequirement
taskTask& A task the registry has just issued. Read for its identity, its notice pair and its age; not stored
startTIndexFirst index of the slice
endTIndexOne past the last index. Nothing here checks that start < end
priorityuint8_tThe bucket the item is filed under if it reaches the general queue; ignored on a FIFO lane

Return value

A constructed WorkItem. It is returned by value from Task::GenerateSubTask, so no caller binds it by reference and none owns it.
