Class description

class WorkItem final at Engine/Core/WorkItem.h. What a task stream's queue actually holds: one task's identity, one slice of its index range, and how far that slice has got. It is produced only by the engine — the constructor is private and Task and TaskStream are its only friends — and it is copied constantly: on every enqueue, on every re-add after an unfinished run, and on every sweep that moves work between lanes.

It replaced RangedTask, which was this data plus a copy of the task's name and measured 128 bytes. The name had exactly one reader — the warning issued when an item is dropped because its task was already released — and there the registry can no longer confirm the name belongs to the task that produced the ID, so the copy was both expensive and untrustworthy. TaskID is the identity that still means something at a drop site.

The item is where the abandonment notice and the age clock live. Both are carried on the item rather than read back from the task because at the moments they matter the task is exactly what is missing: a dropped item's record may already be released, or reused by another tenant. Anything stored only on the task is unreachable precisely when it would be needed.

The item measures 72 bytes, 16 of them the optional notice. The width is guarded by decidedWorkItemBytes, which exists to make a size change loud rather than silent. Before the notice it measured 56, and 8 of those were TaskStreamAffinity — a mask whose word count was derived from bytes per word instead of bits per word, so a 64-bit word held 8 usable bits. That defect is described on TaskStreamAffinityBase.

NameDeclarationWhat it means
FAbandonedNoticeusing FAbandonedNotice = void (*)(TaskID, void*) noexcept; alias Called on the thread that dropped the work, at most once per item, never for work that ran
The callee must not block, must not take a task-stream lock, and must not look up the task record. That record is being dropped around the call, which is the entire reason the notice carries an ID rather than a pointer. Requests are made per task through TaskSystem::SetAbandonedNotice; nothing here offers a way to install one globally, because a default that notifies is a default that notifies for every task in the engine.
