operator bool

member of hbe::TaskHandle Engine/Core/TaskProvider.h Whether the token names anything; explicit, so it will not fire by accident.

Signature

[[nodiscard]] explicit operator bool() const noexcept

Function description

Declared and defined in the header Engine/Core/TaskProvider.h; there is no counterpart in Engine/Core/TaskProvider.cpp. One null test on the stored pointer, which is the only question this type can answer about itself.

Empty is a state, not an error. "Doing nothing when the token is empty is deliberate, so that a registry entry that was never filled can be stopped on a teardown path without a caller-side guard" (Engine/Core/TaskProvider.h). That decision belongs to RequestStop; this operator exists for the caller who wants to know which case it is in — for example to report that a teardown found nothing to stop.
explicit keeps the test honest. The token cannot be silently consumed as a truth value in an expression; it must be tested. [[nodiscard]] closes the other half — asking whether a token refers to something and discarding the answer is a statement with no effect, and the compiler now says so.
A dangling token answers true. This tests whether a pointer was stored, not whether the object it names is still alive. Nothing in this class can tell — the type holds one raw pointer with no generation and no registry behind it (Engine/Core/TaskProvider.h) — so the answer to "is this token usable" is exactly "was it built from a provider that has not been destroyed since", and only the owner knows that.

Parameters

None.

Return value

TypeWhat you get
booltrue when the token names a provider address, false for a default-constructed or copied-empty token. Reads as "non-empty", not as "alive" or "usable"

Examples

Illustrative — no shipping caller stores a handle, so no call site uses this operator.

if (handle)
{
    handle.RequestStop();
}
else
{
    ls << "Nothing was registered for this subsystem, so there is no producer to stop.";
}

Written out, the operator is only worth calling when the empty case has a different report. Where it does not, RequestStop already tolerates an empty token, and the guard is noise — which is the pattern the header chose so that teardown paths stay short.
