GetProvider

member of hbe::TaskHandle Engine/Core/TaskProvider.h The controlled provider, or null - and nothing about what may be read.

Signature

[[nodiscard]] TaskProvider* GetProvider() const noexcept

Function description

Declared and defined in the header Engine/Core/TaskProvider.h; there is no counterpart in Engine/Core/TaskProvider.cpp. It hands back the stored address, null when the token refers to nothing.

The thread-safety claim stops at this pointer. The class note is explicit: "GetProvider hands back a pointer whose remaining use is limited to that same claim - reading anything on the provider other than its stop state from another thread is not covered by this" (Engine/Core/TaskProvider.h). The two calls this token makes itself — IsStopRequested and RequestStop — go through the provider's atomic stop flag and are safe from anywhere. Everything else on the provider — AttachTo, DetachFrom, its attachment lists, its name — obeys that type's rules, which are written for the thread that owns the provider.
The return is not a lease and not a validity check. A non-null result means an address was stored, nothing more; a token whose provider has been destroyed returns a dangling pointer with the same confidence as the boolean test returns true. The lifetime rule ("handles die first") is what makes this call safe, and it is enforced outside this class.
What the pointer is good for is the question this page exists to answer. In practice the token's job is RequestStop; reaching through for anything else means the caller has decided to use the provider directly and has taken on that type's threading rules — for example Produce, which must be called on a draining stream's thread with that stream's queue lock held, a condition no handle can arrange.

Parameters

None.

Return value

TypeWhat you get
TaskProvider*The controlled provider, or nullptr for an empty token. The pointee's type is complete only where TaskProvider.h has been included, which is the compile-time half of the same separation

Examples

Illustrative — no shipping caller stores a handle, so no call site uses this accessor.

auto* producer = handle.GetProvider();
if (producer != nullptr && producer->IsAttachedTo(streamIndex))
{
    producer->DetachFrom(streamIndex);
}

The shape this accessor invites, and the reason the header restricts it: DetachFrom takes the target stream's lock and is written to be called by the provider's owner, not by a token holder on an arbitrary thread. A token is the right thing to hold for a stop request and the wrong thing to reach through for a lifecycle change.
