TaskRegistry

Engine/Core/TaskRegistry.h Holds every tracked task and issues the identity that replaces a task address.

Class description

class TaskRegistry final at Engine/Core/TaskRegistry.h: the table that holds every task the engine knows about, and the issuer of the identity that replaces a task's address. A task lives in a record; the identity handed out is the record's index plus a generation that changes each time the record is issued again, so a reference to a task that has been released is recognised as stale and dropped instead of being followed into whatever task now occupies the record.

A task is never constructed into a record and never destroyed while tracked. The registry's own constructor default-constructs records on demand (new (&records[record]) Record() in AllocateBank) and Create fills one in place with Task::LoadIntoRecord. The consequence for a caller is that a record's memory never moves and its identity is the only handle — there is no reference into the table that outlives a Release safely.
Create never grows the table. A caller that runs out of records gets a null TaskID and an error log naming the task and the capacity (ReportNoRoom), because growing on the creating path would make the task — not the caller — pay for a table it had no part in sizing. Growth is an explicit Grow, made between frames by whoever owns the registry (Engine/Core/TaskRegistry.h).
A refused task is a task that never runs, and that is indistinguishable from one still waiting. This is why the refusal is logged as an error rather than returned quietly, and why a null return from the task system's create path is checked: ParallelFor logs "the split was not queued. The registry is at its capacity." when the record is refused (Engine/Core/TaskSystem.cpp).
SetSuccessor and GetSuccessor reach a record without the registry lock, on whatever thread the caller is on. Both go through FindLiveRecord and then touch Record::successor, a plain (non-atomic) 16-byte TaskID. Create writes that same field under the lock, so a chain set from one thread while another recycles the record is a data race on a field nothing here protects (Engine/Core/TaskRegistry.cpp). The lock-free path that is carefully built is Find, which takes no lock and reads acquire-ordered atomics; the successor pair has no equivalent discipline, and the pages for those two calls state exactly what a caller inherits.
Records are cheap and permanent: the default table is 1 MiB before any task exists. 4096 records at RecordSizeBytes = 256 bytes. That is the price of tracking a task at all — identity, generation, a result packet, a successor, and a cache line of its own — and it is why an engine that tracks one task still pays a megabyte (Engine/Core/TaskRegistry.h, and the test that prints the arithmetic in Engine/Core/TaskRegistry.cpp).

None. TaskRegistry is a concrete final class, one instance owned by TaskSystem.

Non-member helper functions

None. The copy constructor and copy assignment are deleted in the public section, which is a statement about identity rather than a helper: a second registry would issue identities nothing else can validate, and its banks would be a second table that Find cannot see (Engine/Core/TaskRegistry.h).
