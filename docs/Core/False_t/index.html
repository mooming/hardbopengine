False_t

Engine/Core/CommonUtil.h a type-level false: the empty class a compile-time trait names when the property it tests does not hold, which sends a dispatching class down the branch that owns real object lifetime

Class description

False_t is an empty final class, the counterpart of True_t. Neither tag holds anything; what makes them useful is that two overloads of one name can take them as parameters and be resolved by ordinary overload resolution, so a class writes two real function bodies for two compile-time cases instead of one body with a dead branch inside it.

The only producer in the tree is IsReferenceType, whose Result is False_t for every type that is not an lvalue reference — which includes value types and, because the partial specialisation matches T& only, rvalue references and forwarding references too. The only consumer is Optional, and the branch this tag selects is the one that does the lifetime work:

OverloadAtWhat the value branch does
ConstructAt(False_t, Types&&...) Engine/Memory/Optional.h:202 placement-new constructs TType in the storage, forwarding its arguments
CopyValue(False_t, const Optional&) Engine/Memory/Optional.h:214 assigns through Value() = rhs.Value(), so TType's own copy assignment runs
MoveValue(False_t, Optional&) Engine/Memory/Optional.h:227 assigns through Value() = std::move(rhs.Value()), then clears the source's hasValue
GetValue(False_t) Engine/Memory/Optional.h:244 reinterpret_cast of the storage to TType& — the object lives in place, so no pointer is dereferenced and no null check is needed
Destroy(False_t) Engine/Memory/Optional.h:269 calls Value().~TType() explicitly when hasValue, then clears the flag
The tag chooses who owns the lifetime, not how a value is compared. The True_t branch stores an address, copies the storage and destroys nothing; this branch constructs, assigns and runs the destructor. A reader who takes the names as ordinary booleans will look for a truth value that does not exist: the whole meaning is which overload the compiler picked.

Template parameters

None — False_t is not a template and is not parameterised on anything. It is the *result* of a template: IsReferenceType names it for every type whose Result is not True_t.

Class properties

None — there is no alias, no constant and no field in this class. The declaration is class False_t final { }; at Engine/Core/CommonUtil.h:13.

Class methods

None. Nothing is declared, so the implicit defaults are what a caller gets, and each of them is unobservable. That absence is what makes the tag safe to construct at a call site as Result(): a temporary of this type costs nothing and can be wrong about nothing.

Non-member helpers

None belong to this type. Engine/Core/CommonUtil.h also declares the namespace-scope functions GetAs, SetAs, CopyAs, ToAddress and CountOf, which have no relationship to the tag pair and are documented in Module functions.
