Module Index / Renderer / Mesh

Mesh

Engine/Renderer/Vulkan/VulkanRenderer.h namespace hbe::Renderer aggregate two host-side vectors — vertices and 32-bit indices — handed to SetMesh and copied out

Class description

The header describes it as "A triangle mesh to upload to the GPU", and that is exactly its role: a carrier from a generator to SetMesh. It declares no constructors, no methods and no invariants, so it is an aggregate — Mesh mesh; then two brace lists, as the example does — and copy, move and assignment are all implicit. Nothing in the module caches it, compares it or keeps a collection of them.

Nothing here survives the call either. SetMesh maps device memory and memcpys vertices.data() and indices.data() into it, so the renderer holds no reference to this object and the mesh may be a local that dies on the next line. Geometry is then fixed until the next SetMesh, which makes this the type that decides how often geometry can change — and, given what that call frees, when it is safe to.

Template parameters

None — Mesh is not a template.

Class properties

NameDeclarationWhat it means
vertices std::vector<MeshVertex> vertices; public data The vertices, uploaded as one block of vertices.size() * sizeof(MeshVertex) bytes. Empty means no draw this frame — not an error. A std::vector rather than the engine's own Array, so this host-side carrier allocates through the default allocator and nothing else
indices std::vector<uint32_t> indices; public data Triangle-list indices, three per triangle, uploaded as indices.size() * sizeof(uint32_t) bytes and drawn by vkCmdDrawIndexed(indices.size(), 1, 0, 0, 0). Empty means no draw
Indices are 32-bit, unconditionally. The bind is hard-coded VK_INDEX_TYPE_UINT32 and the element type is uint32_t, so a mesh over 65 535 vertices is representable here — and the renderer never asks supports32BitIndices, which is the capability that says the device allows it. Vulkan 1.0 makes fullDrawIndexUint32 mandatory so this is safe in practice, but the check that would prove it is not performed.

Class methods

None declared: no constructor, no validation, no accessor. Being an aggregate, all construction and assignment forms are implicit — which is the useful part, since it is what lets the example fill both vectors with brace lists.

Non-member helper functions

None in this module. The generator in the example is file-local to Applications/VulkanExample/Main.cpp (MakeQuad) rather than a shared helper, so there is no engine function that produces a Mesh.

Coverage

GapDetail
No sub-mesh, no multiple draw targets One vertex vector, one index vector, one indexed draw per frame. There is no material, subrange or instance field, and vertexCount / indexCount in the renderer are single values — so batching several meshes is not expressible in this type
One vertex format The element type is MeshVertex, matching the only pipeline built. Vertex cannot be submitted through this type
Geometry changes mid-loop Not this struct's contract but the reader's: re-uploading while a frame that binds the old buffers is in flight is unsafe today. The rule and its reasoning are on SetMesh
No mesh loading Nothing in the engine reads a mesh file into this type, and the Resource module's loaders are themselves unimplemented — the only Mesh in this tree is built in code
