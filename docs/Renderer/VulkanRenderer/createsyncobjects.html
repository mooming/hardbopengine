CreateSyncObjects

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private two semaphores per slot plus a fence, fences created already-signalled so frame 0 does not block

Signature

bool CreateSyncObjects() noexcept

Function description

Private, and the last step of Initialize: everything before it can render, this makes the frame loop safe. It creates three arrays of MAX_FRAMES_IN_FLIGHT (2) objects — one image-available semaphore per slot, one render-finished semaphore per slot, one fence per slot. 

	VkFenceCreateInfo fi{};
	fi.sType = VK_STRUCTURE_TYPE_FENCE_CREATE_INFO;
	fi.flags = VK_FENCE_CREATE_SIGNALED_BIT;

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::CreateSyncObjects()

The signalled-at-creation fence is the detail that makes frame 0 work: BeginFrame waits on this slot's fence before doing anything, and on the very first frame there has never been a submission to signal it. Created pre-signalled, the first wait falls straight through instead of blocking forever on work that was never submitted.

The semaphores divide the frame in two: semaphoresImageAvailable[currentFrame] is signalled by the acquire and waited by the submit before colour-output writes; semaphoresRenderFinished[currentFrame] is signalled by the submit and waited by the present. Both are created with an empty VkSemaphoreCreateInfo — no flags, no timeline.

A mid-loop failure leaves earlier objects alive. Each of the six creations is checked in order and a failure is logged (naming which object failed) and answered with false; semaphores or fences created before the failure are not destroyed by this function, and on a failed Initialize nothing destroys them later.

Parameters

None.

Return value

true when all six objects exist and the three arrays are filled; false at the first failed creation, logged with the object name.

Examples

Illustrative — private, and reachable only as the eleventh and final step of Initialize.

if (!CreateSyncObjects())
	return false;

initialized = true;

Only after this returns does Initialize set initialized — which is what lets Shutdown, the frame calls and SetMesh treat that flag as "every resource exists".
