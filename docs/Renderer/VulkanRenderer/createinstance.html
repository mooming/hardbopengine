CreateInstance

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private the first Vulkan object: application info, unconditional portability enumeration, and the platform surface extension

Signature

bool CreateInstance() noexcept

Function description

Private. Creates the process-wide Vulkan instance everything else in the pipeline builds on, and nothing else: no debug messenger, no validation layers, no instance-level features. The application info names the engine and requests API 1.1. The extension list is fixed at compile time and asks for three things — the surface extension every presentation path needs, VK_KHR_portability_enumeration unconditionally, and the platform surface extension the target offers (VK_EXT_metal_surface on macOS, VK_KHR_win32_surface on Windows when the Win32 platform header is in scope).

The unconditional portability request is deliberate, and it is the difference from the conditional probe in VulkanCapabilities: enabling an extension the loader does not have fails instance creation outright, and this renderer can assume a portability driver on its macOS target, so it asks without checking. The create info also sets VK_INSTANCE_CREATE_ENUMERATE_PORTABILITY_BIT_KHR, without which MoltenVK never appears in the device list at all. 

	VkInstanceCreateInfo ci{};
	ci.sType = VK_STRUCTURE_TYPE_INSTANCE_CREATE_INFO;
	ci.pApplicationInfo = &app;
	ci.flags = VK_INSTANCE_CREATE_ENUMERATE_PORTABILITY_BIT_KHR;
	ci.enabledExtensionCount = kInstanceExtensionCount;
	ci.ppEnabledExtensionNames = kInstanceExtensions;

	const VkResult result = vkCreateInstance(&ci, nullptr, &instance);
	if (result != VK_SUCCESS)
	{
		LogFailure("vkCreateInstance", result);

		return false;
	}

Failure leaves nothing behind. A non-success VkResult is reported through the always-on error logger and the function returns false; instance stays VK_NULL_HANDLE, so the next creation step never runs and there is nothing to clean up.

Parameters

None.

Return value

true when vkCreateInstance returned VK_SUCCESS and instance holds a live handle; false otherwise, with the VkResult logged.

Examples

Illustrative — private, and reachable only as the first step of Initialize.

if (!CreateInstance())
	return false;

Every later step assumes the instance exists: CreateSurface builds the surface from it, and PickDevice enumerates physical devices from it.
