CreateVertexBuffers

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private replace the mesh: release the old buffers, create and bind the new pair, map-copy the data up

Signature

bool CreateVertexBuffers(const Mesh& mesh) noexcept

Function description

Private. The mesh upload path SetMesh delegates to, and the only function in the class that both creates and destroys GPU resources in one call: it starts by releasing whatever buffers the previous mesh left, then builds the new pair. An empty mesh — zero vertices or zero indices — is not a failure: it returns true with null buffers, and the frame loop draws clear-only frames. 

	vertexCount = mesh.vertices.size();
	indexCount = mesh.indices.size();

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::CreateVertexBuffers(const Mesh&)

An empty mesh — zero vertices or zero indices — is not a failure: the function returns true right here with null buffers, and the frame loop draws clear-only frames. Non-empty meshes build two buffers via CreateBuffer — creation plus allocation, but not binding — so this function binds both itself with vkBindBufferMemory, then uploads by mapping each memory, copying, and unmapping: 

	const auto vertexBytes = vertexCount * sizeof(MeshVertex);
	const auto indexBytes = indexCount * sizeof(uint32_t);

	if (!CreateBuffer(vertexBuffer, vertexMemory, vertexBytes, VK_BUFFER_USAGE_VERTEX_BUFFER_BIT))
		return false;
	if (!CreateBuffer(indexBuffer, indexMemory, indexBytes, VK_BUFFER_USAGE_INDEX_BUFFER_BIT))
		return false;

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::CreateVertexBuffers()

Each buffer comes from CreateBuffer — creation plus allocation, but not binding — so this function binds both itself with vkBindBufferMemory, then uploads by mapping each memory, copying, and unmapping: 

	auto upload = [&](VkDeviceMemory mem, const void* data, size_t size) noexcept -> bool
	{
		void* dst = nullptr;
		const VkResult mapResult = vkMapMemory(device, mem, 0, static_cast<VkDeviceSize>(size), 0, &dst);
		if (mapResult != VK_SUCCESS)
		{
			LogFailure("vkMapMemory", mapResult);

			return false;
		}

		std::memcpy(dst, data, size);
		vkUnmapMemory(device, mem);

		return true;
	};

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::CreateVertexBuffers()

Direct mapping into host-visible, host-coherent memory is deliberate: the mesh is written once from the CPU and never modified per frame, so no staging transfer is paid for. A device-local copy with a staging upload is the long-term shape and is named as a follow-up in the source, not implemented here.

A failure after the vertex buffer exists leaves it allocated. If the index CreateBuffer, a bind, or an upload fails, the function returns false without releasing what it already created — the caller (SetMesh) zeroes the counts and logs, and the buffers survive until the next CreateVertexBuffers or Destroy releases them. Rendering with zero counts draws nothing, so the stale buffers are unreachable but not leaked.

Parameters

ParameterTypeRequirement
mesh const Mesh& The mesh to upload. Read during the call only — vertices and indices are copied into GPU-accessible memory, so the caller's mesh may die afterwards. May be empty; that is the clear-only case, not an error

Return value

true when the mesh is uploaded and bound, or when the mesh was empty and the renderer was reset to draw clear-only frames. false when any creation, bind, map or copy step failed, each logged.
