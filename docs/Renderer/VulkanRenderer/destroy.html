Destroy

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private tear everything down in dependency order — idle wait first, views before images, surface before instance

Signature

void Destroy() noexcept

Function description

Private. The teardown that Shutdown is a thin wrapper over, and the only place Vulkan handles are destroyed. Two rules organise it: wait first, and destroy in reverse dependency order.

The wait comes before anything else — if a device exists, vkDeviceWaitIdle runs once — so nothing still executing on the GPU can be pulling on an object destroyed below. Then, in order: the sync objects (both semaphore arrays, then the fences); the mesh buffers via ReleaseVertexBuffers; the command pool, whose destruction frees the command buffers with it; the pipeline, layout and both shader modules; the framebuffers; the depth view, then the depth image, then its memory; the swapchain views, then the swapchain; the device; and finally the surface and the instance. 

	if (depthImageView != VK_NULL_HANDLE)
		vkDestroyImageView(device, depthImageView, nullptr);
	if (depthImage != VK_NULL_HANDLE)
		vkDestroyImage(device, depthImage, nullptr);
	if (depthMemory != VK_NULL_HANDLE)
		vkFreeMemory(device, depthMemory, nullptr);

Every handle is null-checked, so the function is safe on a renderer whose Initialize only got partway — except that in practice it is never called on one: Shutdown early-returns when initialized is false, which is the leaked-partial-state gap the Initialize page documents. 

	if (device != VK_NULL_HANDLE)
		vkDestroyDevice(device, nullptr);
	device = VK_NULL_HANDLE;

	if (surface != VK_NULL_HANDLE)
		vkDestroySurfaceKHR(instance, surface, nullptr);
	if (instance != VK_NULL_HANDLE)
		vkDestroyInstance(instance, nullptr);

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::Destroy()

The surface dies before the instance, because it needs it. vkDestroySurfaceKHR takes the instance as its first argument; reversing that order would use a destroyed handle. The device goes before the surface for the same direction of reasoning — everything device-scoped is gone before the instance-scoped objects that created the context for it.

On the way out the scalar state is reset too: physicalDevice and graphicsQueue nulled, frameActive cleared, currentFrame and imageIndex zeroed. A destroyed renderer is back to its constructor state.

Parameters

None.

Return value

None — void. On return every Vulkan handle in the object is null or cleared, and the object is safe to have Shutdown mark uninitialized and the destructor finish off.

Examples
