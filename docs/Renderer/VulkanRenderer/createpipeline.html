CreatePipeline

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private shader modules from ShadersSpv.h, fixed-function state, and the 128-byte push range — layout first, pipeline against it

Signature

bool CreatePipeline() noexcept

Function description

Private. Builds the one graphics pipeline, and it is the step where the render's shape is baked in: two shader modules loaded from the generated SPIR-V header (gMCVertexSpv and gMCFragmentSpv in Engine/Renderer/Vulkan/ShadersSpv.h), vertex input of one binding at sizeof(MeshVertex) with position and normal as R32G32B32_SFLOAT at their offsetof, triangle list, no blend, depth test VK_COMPARE_OP_LESS with writes on, and dynamic viewport and scissor — which is why RecordFrame must set both before every draw. 

	VkPushConstantRange pcr{};
	pcr.stageFlags = VK_SHADER_STAGE_VERTEX_BIT;
	pcr.offset = 0;
	pcr.size = sizeof(PushConstants);

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::CreatePipeline()

The pipeline layout carries no descriptor sets at all — just that one push-constant range, 128 bytes for the vertex stage, the portability-guaranteed maximum that PushConstants is sized to fill exactly. The layout is created first, then the pipeline is created against both it and renderPass at subpass 0 — which is why CreateRenderPass runs earlier in the sequence. 

	rast.cullMode = VK_CULL_MODE_NONE;

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::CreatePipeline()

Nothing is culled on purpose: the marching-cubes winding the shaders produce is not guaranteed consistent, so a cull mode would drop faces arbitrarily.

Failure leaves the earlier objects of this step alive. A failed shader module, a failed layout, or a failed vkCreateGraphicsPipelines is logged with its VkResult and answered with false — but modules created before the failure are not destroyed by this function, and on a failed Initialize nothing downstream ever will be.

Parameters

None.

Return value

true when vertModule, fragModule, pipelineLayout and graphicsPipeline all exist; false at the first failure, each logged with its VkResult.

Examples

Illustrative — private, and reachable only as the tenth step of Initialize.

if (!CreatePipeline())
	return false;

After this step the renderer could render — everything left is pacing: CreateSyncObjects creates the semaphores and fences that make the frame loop safe.
