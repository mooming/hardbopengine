RecordFrame

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private record this slot's command buffer: clear, bind, dynamic viewport and scissor, push, one indexed draw

Signature

void RecordFrame() noexcept

Function description

Private. The recording half of Render: fills commandBuffers[currentFrame] from scratch — the buffer was allocated with the reset flag, and the begin carries VK_COMMAND_BUFFER_USAGE_ONE_TIME_SUBMIT_BIT. The recorded sequence is: begin; two clear values (a dark blue colour, depth cleared to 1.0); begin the render pass on framebuffers[imageIndex] with the full extent as render area; bind the pipeline; set the dynamic viewport and scissor; and, when a mesh is loaded, push constants, bind both mesh buffers, and issue one indexed draw of indexCount. 

	VkClearValue clears[2] = {};
	clears[0].color = {{0.06f, 0.08f, 0.12f, 1.0f}};
	clears[1].depthStencil = {1.0f, 0};

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::RecordFrame()

The viewProj pushed to the shader is combined on the CPU right here — projection times view, column-major — which is the one multiply that leaves room in the 128-byte push range for the model matrix as well. The matrices come from the three setters, whatever they last held.

A failed begin is logged and then… the frame is submitted anyway. If vkBeginCommandBuffer fails, the function logs the VkResult and returns without recording anything — but there is no flag to tell EndFrame, which submits commandBuffers[currentFrame] whenever the frame is active. The submit of the un-recorded buffer fails in its turn and is cleaned up by EndFrame's empty-submit release path. The draw is lost; the frame cycle survives.

Parameters

None.

Return value

None — void. The product is a recorded, ended command buffer in the current slot, or a log line when recording could not begin.
