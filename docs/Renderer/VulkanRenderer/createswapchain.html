CreateSwapchain

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private extent, format, present mode and image count, chosen once from the surface, with a colour view per image

Signature

bool CreateSwapchain() noexcept

Function description

Private. Queries the surface and makes four choices from what it answers, then creates the swapchain and a colour view per image. The choices, in order:

ChoiceRule the code implements
extent The surface's currentExtent, unless it reports 0xFFFFFFFF — the "size comes from the window" case — in which case the window's size is taken and clamped to minImageExtent / maxImageExtent
surfaceFormat VK_FORMAT_B8G8R8A8_UNORM when the surface offers it — matching the CAMetalLayer, which is configured as BGRA8Unorm — otherwise the first format listed. A surface reporting no formats fails the function
presentMode VK_PRESENT_MODE_MAILBOX_KHR when available, otherwise VK_PRESENT_MODE_FIFO_KHR, the only mode Vulkan guarantees to exist
Image count minImageCount + 1, clamped down to maxImageCount when that is non-zero 
	if (caps.currentExtent.width == 0xFFFFFFFFu)
	{
		extent.width = static_cast<uint32_t>(window->GetWidth());
		extent.height = static_cast<uint32_t>(window->GetHeight());
		extent.width = (extent.width < caps.minImageExtent.width ? caps.minImageExtent.width : extent.width);
		extent.width = (extent.width > caps.maxImageExtent.width ? caps.maxImageExtent.width : extent.width);
		extent.height = (extent.height < caps.minImageExtent.height ? caps.minImageExtent.height : extent.height);
		extent.height = (extent.height > caps.maxImageExtent.height ? caps.maxImageExtent.height : extent.height);
	}
	else
	{
		extent = caps.currentExtent;
	}

After vkCreateSwapchainKHR succeeds, the image handles are fetched and one VK_IMAGE_VIEW_TYPE_2D colour view is created per image; a view that fails is logged and fails the whole function. The images themselves are owned by the swapchain — fetched, never created, never destroyed here.

This runs once, ever. oldSwapchain is created null and no code path creates a second swapchain: there is no recreation, no resize handling, no out-of-date recovery. A lost or degraded swapchain is reported by the frame calls and drawn around, not repaired. The extent written here is consequently the extent GetExtent reports for the life of the object.

Parameters

None.

Return value

true when the swapchain exists, swapchainImages and swapchainImageViews are filled, and extent, surfaceFormat and presentMode are all chosen; false on the first failed Vulkan call, each logged with its VkResult.

Examples

Illustrative — private, and reachable only as the fifth step of Initialize.

if (!CreateSwapchain())
	return false;

Its outputs feed everything downstream: CreateRenderPass needs surfaceFormat, CreateDepthResource and CreateFramebuffers need extent, and the framebuffers need the views this function created.
