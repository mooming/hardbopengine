CreateDevice

member of hbe::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h private one queue, no optional features, VK_KHR_swapchain only — and the capability query runs here, the first moment a device exists

Signature

bool CreateDevice() noexcept

Function description

Private. Turns the adapter chosen by PickDevice into a logical device with exactly one queue — from queueFamilyIndex, priority 1.0 — and deliberately requests nothing else: no optional features at all, because asking for one the driver does not support makes vkCreateDevice fail outright rather than degrade. The only device extension enabled is VK_KHR_swapchain; without it the loader leaves the swapchain entry points null and CreateSwapchain could not run at all. 

	const char* deviceExtensions[] = {VK_KHR_SWAPCHAIN_EXTENSION_NAME};

	VkDeviceCreateInfo ci{};
	ci.sType = VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO;
	ci.queueCreateInfoCount = 1;
	ci.pQueueCreateInfos = &queueCI;
	ci.enabledExtensionCount = 1;
	ci.ppEnabledExtensionNames = deviceExtensions;

From Engine/Renderer/Vulkan/VulkanRenderer.cpp, VulkanRenderer::CreateDevice()

On success the function fetches the queue into graphicsQueue — the one queue used for both submission and presentation — and then immediately calls QueryCapabilities. That placement is the point: this is the first moment a real physical device is in hand, so it is the first moment real capability data exists, and querying once here keeps GetCapabilities a cheap copy afterwards.

Failure leaves nothing behind. vkCreateDevice failing is logged with its VkResult and answered with false; the device member stays VK_NULL_HANDLE and no earlier step created anything this function would have to undo.

Parameters

None.

Return value

true when the device exists, the queue was fetched, and the capability query has run; false when vkCreateDevice failed, with the VkResult logged.

Examples

Illustrative — private, and reachable only as the fourth step of Initialize.

if (!CreateDevice())
	return false;

Everything after this step needs device: the swapchain, the render pass, the buffers, the pipeline.
