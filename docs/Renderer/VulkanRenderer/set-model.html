SetModel

member of hbe::Renderer::VulkanRenderer Engine/Renderer/Vulkan/VulkanRenderer.h noexcept copy sixteen column-major floats into the model slot — unchecked, usable before Initialize, pushed verbatim

Signature

void SetModel(const float* m) noexcept;

Function description

The body is std::memcpy(modelMat, m, sizeof(modelMat)); — sixteen float, nothing else. It is the only one of the three matrix setters whose value reaches the shader unchanged: PushConstants carries model as a byte-for-byte copy of modelMat, pushed during Render.

Layout is column-major, element [col * 4 + row], matching the GLSL mat4 the vertex shader declares — the same convention Matrix4x4 produces and the example's own matrix helpers write. The constructor pre-fills this slot with identity through IdentityMatrix, so geometry renders at the origin even if nobody calls this.

Timing is decided by Render, not by the frame. The value is read when the command buffer is recorded, so a SetModel before Render is in this frame and one after Render is in the next. The example relies on that ordering: compute the rotation, call SetModel, then run the frame trio.

Parameters

ParameterTypeRequirement
m const float* Sixteen readable float, column-major. Not checked for null and not length-checked in any form — this is a raw pointer into a fixed array, so a null or short argument is a memcpy across invalid memory, not a graceful rejection. The sixteen values are copied during the call, so the caller's array may be a stack local reused or destroyed immediately afterwards. No Initialize is required: this setter touches no Vulkan object, and the value survives into the first frame

Return value

void, and there is nothing to check — no allocation, no driver call, no validation of the numbers.

Examples

The example keeps its own rotation builder and pushes the result once per loop, before the frame trio:

From Applications/VulkanExample/Main.cpp

// All matrices are column-major (element [col * 4 + row]), matching the GLSL mat4
// layout that VulkanRenderer pushes to the shader.

void SetRotationY(float m[16], float radians) noexcept
{
        SetIdentity(m);
        const float c = std::cos(radians);
        const float s = std::sin(radians);
        m[0] = c;
        m[2] = -s;
        m[8] = s;
        m[10] = c;
}

// in the loop:
SetRotationY(model, angle);
renderer.SetModel(model);

renderer.BeginFrame();
renderer.Render(deltaTime);
renderer.EndFrame();

Where an identity is wanted rather than a transform, the module ships one: IdentityMatrix fills a float[16] in place.
