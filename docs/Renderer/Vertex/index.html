Module Index / Renderer / Vertex

Vertex

Engine/Renderer/Vertex.h namespace hbe::Renderer 28 bytes position and colour as engine math types — the module's example vertex format, and the one nothing renders

Class description

The header calls it "Position + color vertex used by the renderer's simple mesh path": a Vector3<float> and a Vector4<float>, constructor taking the seven scalars in field order. It is deliberately the engine-vector cousin of MeshVertex — math types rather than raw arrays, colour rather than a normal.

The second half of that description is where the truth needs stating: nothing in this tree renders one. The only pipeline the only backend builds takes MeshVertex input — stride sizeof(MeshVertex), two R32G32B32_SFLOAT attributes — and Mesh::vertices is a vector of those. Grepping Engine/ and Applications/ for Vertex outside its own two files returns nothing: no container of them, no test, no pipeline, no upload path. The type compiles into the Renderer library and has no user.

Do not build geometry in this format and expect it to draw. There is no overload of SetMesh that takes it, no way to express its layout in the existing pipeline, and no second pipeline to switch to. A colour-per-vertex path means a new vertex struct with a normal-or-colour decision, a new attribute array in CreatePipeline, a shader that reads location 1 as a colour, and a regenerated ShadersSpv.h. That is a feature, not a call to make; on this tree the type is a declaration with no behaviour attached.

Template parameters

None — Vertex is not a template. The <float> in its two members is fixed, not parameterised: there is no Vertex over double.

Class properties

NameDeclarationWhat it means
position Vector3<float> position; public data Offset 0, twelve bytes. Same meaning as MeshVertex::position, reached through the math type — so it has operators and named components instead of [0..2]
color Vector4<float> color; public data Offset 12, sixteen bytes: RGBA. This is what MeshVertex lacks, and the reason two vertex formats exist at all. Spelled color, American, matching the rest of the engine's naming

Twenty-eight bytes overall. Neither math type carries an alignment specifier, so the two members sit flush — a point worth knowing if this layout ever is uploaded, because nothing checks it.
