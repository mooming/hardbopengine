GetOSAllocationCount

member of hbe::MemoryManager Engine/Memory/MemoryManager.h Request count for the OS-image bucket — it attributes libc++ growth to the OS instead of to the testlet that triggered it.

Signature

[[nodiscard]] static uint64_t GetOSAllocationCount() noexcept

Function description

Defined in Engine/Memory/GlobalAllocation.cpp as MemoryManager::GetOSAllocationCount(): one relaxed load of the globalOSAllocationCount atomic. The request count behind GetOSAllocationBytes, incremented in the same if (IsOSImageCaller(caller)) block, so the two OS allocation counters always move together.

The mechanism — __builtin_return_address(0) taken inside the replacement operator new, the lazily-cached _dyld_get_shared_cache_range bounds, the Apple-only guard — is documented once on GetOSAllocationBytes and is not repeated here. What this getter adds over the byte figure is the ability to tell "the OS asked once for a large block" from "the OS asked many times", which is the distinction that matters when a testlet's global request count is higher than its own allocations can explain.

Its whole purpose is subtraction. Nothing in the tree reads this counter in isolation. Engine/Test/TestCollection.cpp, TestCollection::RunTestAt() takes the difference across a testlet body, prints it as of which OS-image N requests, and subtracts the OS bytes from the global bytes to get the engine-owned figure a per-testlet ceiling is compared against. A non-zero absolute value on a platform other than macOS means something is wrong with the platform guard, because off __APPLE__ the accounting receives a null caller and the range test is compiled to return false.

Parameters

None.

Return value

TypeWhat you get
uint64_tCumulative requests attributed to callers inside the OS shared cache; a subset of GetGlobalAllocationCount, always 0 off Apple platforms, and never decremented by a release (GetOSFreeCount is the release side).

Examples

const auto osRequestsBefore = MemoryManager::GetOSAllocationCount();

grow.push_back('y');

const auto osRequestsAfter = MemoryManager::GetOSAllocationCount();

if (osRequestsAfter <= osRequestsBefore)
{
	ls << "A libc++ reallocation inside the shared cache was not bucketed as OS image traffic" << lferr;
}
