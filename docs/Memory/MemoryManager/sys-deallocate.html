SysDeallocate

member of hbe::MemoryManager Engine/Memory/MemoryManager.h The matching release for SysAllocate — a null function pointer drops it silently, it does not crash.

Signature

void SysDeallocate(void* ptr, size_t nBytes)

Function description

Defined in Engine/Memory/MemoryManager.cpp as MemoryManager::SysDeallocate(), the release half of SysAllocate. It indexes slot 0 by name, checks the function pointer and calls through it with the proxy slot as userData — the same shape as the allocation side, and the same reason that is harmless here (RegisterSystemAllocator's lambdas ignore their first argument). 

auto& allocator = allocators[SystemAllocatorID];
if (unlikely(allocator.deallocate == nullptr))
{
	Log(ELogLevel::FatalError, ...);

	return;
}

allocator.deallocate(&allocator, ptr, nBytes);

From Engine/Memory/MemoryManager.cpp, MemoryManager::SysDeallocate()

A null function pointer turns a release into a silent leak. Where Deallocate asserts on a null deallocate function, this path logs at FatalError and returns: the block is never freed and nothing else reports it. That is reachable exactly when slot 0 has been cleared — after DeregisterSystemAllocator at shutdown, or after a refused deregistration nulled the pointers — and it is the reason ~MemoryManager's teardown order matters for anything that frees late.
The size argument is nearly advisory on this path. It travels down to SystemAllocator::deallocate() (Engine/Memory/SystemAllocator.h), which under PROFILE_ENABLED reports OS::GetAllocSize(ptr) instead of it, under MEMORY_VERIFICATION_ENABLED asserts nBytes <= allocated, and otherwise hands the pointer to free(), which ignores size entirely. Contrast the pool paths, where the size is what makes a release addressable at all (PoolAllocator::Deallocate).
A null pointer is not filtered here. Deallocate returns early on a null block and asserts that its size was zero too; this method passes it down, where SystemAllocator::deallocate() carries the Assert(ptr != nullptr) — a trap in Debug and Dev, and a harmless free(nullptr) in Release, where Assert is compiled away (Engine/Core/Debug.h).

Parameters

ParameterTypeRequirement
ptrvoid*A pointer obtained from SysAllocate. A block from anywhere else — an Allocated buffer, a newed object — must not be released here.
nBytessize_tThe size the block was requested with. Used for verification and profiling, not for the release itself on the default path.

Return value

void. A dropped release is reported in the log and nowhere else.
