LogError

member of hbe::MemoryManager Engine/Memory/MemoryManager.h Log at Error — reporting a bad release is the caller's problem to follow up, not this wrapper's.

Signature

void LogError(const TLogFunc& func) const

Function description

Defined in the class body of Engine/Memory/MemoryManager.h as Log(ELogLevel::Error, func); — an inline one-liner with no .cpp half, identical to LogWarning except for the level it picks.

ELogLevel::Error is the fifth ordinal in Engine/Log/LogLevel.h, so it clears any threshold the "Log.Memory" parameter can hold short of FatalError and MAX (IsLogEnabled). In practice the module uses it for one thing: a release that arrived for a block this allocator does not own, or a release whose arithmetic does not add up.

Error is not fatal, and the call site decides what happens next. Nothing in this wrapper stops anything: PoolAllocator::Deallocate() logs and returns, dropping the block; StackAllocator::Deallocate() logs and then calls Assert(false), which traps outside Release and does nothing in it. That is the difference between a dropped release and a stopped process, and it lives entirely in the caller — ELogLevel::FatalError, the level used for the manager's own undeliverable conditions, is a logger distinction, not an execution one.
In this tree the line is dropped along with the block. MEMORY_LOGGING_ENABLED is 0, so Log discards the callable and the caller carries on as if it had reported something. The LOG_BREAK_IF_ERROR flag that would at least trap is also 0 in Engine/Config/BuildConfig.h. A foreign pointer released into a pool therefore leaves no trace at all here — which is why the pages for those two paths describe the outcome in terms of what the allocator does, not what it says.

Parameters

ParameterTypeRequirement
funcconst TLogFunc&A std::function<void(std::ostream&)>, normally a lambda. Built at the call site whether or not it will be called; invoked at most once.

Return value

void. Returning normally tells the caller nothing about whether anything was reported.

Examples

auto expected = buffer + cursor;
auto provided = static_cast<Byte*>(ptr) + size;
if (unlikely(expected != provided))
{
	mmgr.LogError([this, ptr, expected, provided](auto& lout)
	{
		lout << "StackAllocator[" << static_cast<int>(GetID()) << "]: Pointer mismatched! ptr = " << ptr << ", "
			 << static_cast<void*>(expected) << " is expected. But " << static_cast<void*>(provided)
			 << " is provided.";
	});

	Assert(false);

From Engine/Memory/StackAllocator.cpp, StackAllocator::Deallocate()

The pair of shapes this wrapper gets: log the arithmetic, then either Assert(false) and hope a developer is attached (StackAllocator), or return quietly and lose the block (PoolAllocator::Deallocate(), whose message for a bad index is "is not alloacted by this." — misspelling in the source, quoted as written because a reader will grep for it).
