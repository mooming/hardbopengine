operator bool

member of hbe::Shareable Engine/Memory/Shareable.h The handle's only liveness test: true unless a move or a Release emptied it - and an implicit conversion.

Signature

operator bool() const

Function description

Defined inline in the class body of Engine/Memory/Shareable.h; the body is return body != nullptr;. It is the only liveness test the class offers, and the internal one: the copy constructor and operator= both consult it before dereferencing, and the destructor uses the same pointer test directly.

False means "moved from" or "released" — nothing else. The class has no default constructor that yields an empty handle: the variadic constructor always allocates a Body (constructors), so a constructed handle is true. The only ways to reach false are a move, an assignment from an empty handle, or Release. That is why the tests in Engine/String/String.cpp — for instance return buffer ? buffer.Get().data() : ""; — are guards against a moved-from String rather than an uninitialised one, and why a false answer is worth branching on: the other accessors have no such check (Get, operator*, operator->).
The conversion is implicit, so a handle converts anywhere a bool will do. The declaration is operator bool() const with no explicit, which is what makes if (buffer) and buffer ? x : y read naturally — and also lets a handle convert without warning in an arithmetic or overloads-resolution context where an integral value would be accepted. There is no [[nodiscard]] either, so calling it and discarding the answer is silent. Neither is documented as intended by anything in the source.

Parameters

None.

Return value

TypeWhat you get
booltrue when the handle names an object. It says nothing about the object's own state — an empty Vector still answers true — nor about how many others share it, which is GetReferenceCount.

Examples

	return buffer ? buffer.Get().data() : "";

From Engine/String/String.cpp, String::ToCharArray

The shape the tree uses this in most: test the handle, then reach the object. Engine/String/String.h combines it with a second condition where the empty case has two sources — return static_cast<bool>(buffer) && buffer->size() > 0 ? buffer->size() - 1 : 0; — the explicit cast there being the caller's way of naming the conversion rather than relying on it.
