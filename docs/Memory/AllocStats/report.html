Report

member of hbe::AllocStats Engine/Memory/AllocStats.h Under PROFILE_ENABLED copies the record to the engine's statistics collector; an empty function without it

Signature

void Report() noexcept

Function description

Declared in Engine/Memory/AllocStats.h, defined at Engine/Memory/AllocStats.cpp. The entire body sits behind #if PROFILE_ENABLED: it takes Engine::Get().GetStatistics() and hands this record to SystemStatistics::Report, which appends a copy to its own vector of AllocStats (Engine/Core/SystemStatistics.cpp). Without PROFILE_ENABLED the function exists but its body is empty — the call compiles everywhere and does something only in a profiling build.

The one caller the module shows is the source-location form of MemoryManager::DeregisterAllocator (itself PROFILE_ENABLED-only), which calls this under statsLock just before the plain deregistration runs (Engine/Memory/MemoryManager.cpp). The semantics follow from the copy: the statistics collector sees a snapshot taken at release time — the final ledger of an allocator that is leaving cleanly — and the printed profile (SystemStatistics::PrintAllocatorProfiles) is that snapshot's later rendering, not a live view.

Parameters

None.

Return value

None. Under PROFILE_ENABLED a copy of the record has been appended to the engine's statistics collector; without it, nothing has happened.

Examples

#if PROFILE_ENABLED
	auto& engine = Engine::Get();
	auto& stats = engine.GetStatistics();
	stats.Report(*this);
#endif // PROFILE_ENABLED
