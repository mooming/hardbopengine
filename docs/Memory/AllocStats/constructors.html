Function description

Defined at Engine/Memory/AllocStats.cpp. The initializer list writes every field: name(""), isInline(false), and zero for all ten size_t fields. This is the state of a record that has never been registered — it is also the state Reset rebuilds a released record into, because Reset's placement-new calls this constructor.

Return value

Constructs an empty, unnamed, unregistered statistics record. Nothing is logged and nothing is registered.
