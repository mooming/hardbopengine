OnRegister

member of hbe::AllocStats Engine/Memory/AllocStats.h Adopts a registration's name, inline flag and capacity, and zeroes every counter: the record's history restarts

Signature

void OnRegister(const char* name, bool isInline, size_t inCapacity) noexcept

Function description

Defined at Engine/Memory/AllocStats.cpp. It copies name into the StaticString member, stores isInline and inCapacity, and zeroes all eight counters plus maxUsage. Registration therefore restarts the record's history: nothing about a previous identity or a previous run survives this call.

Both callers the module shows run under the manager's statsLock: MemoryManager::RegisterAllocator calls it with the registration arguments (after substituting "None" for a null name and adding the capacity into the inline or non-inline aggregate UsageRecord chosen by the same flag), and RegisterSystemAllocator calls it for slot 0 with the literal "SystemAllocator", isInline false and Config::MemCapacity (Engine/Memory/MemoryManager.cpp). The name is the only copy the record keeps; the header's own field table shows why — name is written nowhere else.

Parameters

ParameterTypeRequirement
nameconst char*Copied into a StaticString; a null pointer is not tested here — the manager's paths replace it with "None" before calling.
isInlineboolWhether the registered capacity is inline storage; also the key the manager uses to pick its aggregate record.
inCapacitysize_tBytes the allocator declares; stored verbatim into capacity.

Return value

None. On return the record describes the new registration and every counter reads zero.

Examples

			auto& stats = allocProxy.stats;
			stats.OnRegister(name, isInline, capacity);
