~AllocStats

member of hbe::AllocStats Engine/Memory/AllocStats.h Defaulted; destroys the registered name and nothing else, which is why Reset is a destroy-and-rebuild rather than an assignment

Signature

~AllocStats() = default

Function description

Declared defaulted in the class body of Engine/Memory/AllocStats.h. It destroys the StaticString name and needs nothing else — the ten size_t fields and the two scalars have trivial destruction. The manager never destroys the embedded records; a record is destroyed with the MemoryManager that owns the array it lives in, or is explicitly ended in place by Reset, which is exactly where this destructor runs in normal operation.

Defaulted does not mean "does nothing". The only non-trivial member is name, so destroying a record ends the lifetime of the string that holds the registered allocator's name. This is why Reset is written as an explicit destructor call followed by placement-new rather than as field assignment: the string is destroyed and rebuilt, not truncated.

Parameters

None.

Return value

None; a defaulted destructor. Nothing outside the object's own storage is touched.

Examples

this->~AllocStats();
new (this) AllocStats();

From Engine/Memory/AllocStats.cpp, AllocStats::Reset

The one place this destructor runs on a live record: the body of Reset ends the object and reconstructs the identical state through the constructor.
