Reset

member of hbe::AllocStats Engine/Memory/AllocStats.h Ends the record in place and reconstructs it empty; called on the clean release path before the slot is reused

Signature

void Reset() noexcept

Function description

Defined at Engine/Memory/AllocStats.cpp as the pair this->~AllocStats(); new (this) AllocStats(); — the destructor followed by placement-new. The record is ended and rebuilt in its own storage, which returns every field, including the StaticString name, to the constructor's empty state. It is not an assignment: whatever owned the name's storage has released it by the time the call returns.

The module shows one caller: the clean path of MemoryManager::DeregisterAllocator, under statsLock, after the leak check has passed and the aggregate UsageRecord has been corrected (Engine/Memory/MemoryManager.cpp). It runs immediately before the proxy record is pushed back onto the free list, so a record never enters reuse still wearing a dead allocator's name or counters. Note the ordering the manager imposes: when usage > 0 the release path warns and returns early, and on that path Reset is not called — the record keeps its contents.

Parameters

None.

Return value

None. The object's storage holds a freshly constructed empty AllocStats afterwards.
