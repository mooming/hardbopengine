Print

member of hbe::AllocStats Engine/Memory/AllocStats.h Six Verbose log lines: name, inline flag, usage, requested, fallback and count triples, with integer-division averages

Signature

void Print() noexcept

Function description

Defined at Engine/Memory/AllocStats.cpp. It opens one logger channel — category "AllocStats", level Verbose — and emits six lines: the name; the inline flag; the usage triple usage / maxUsage / capacity; the requested triple (average, peak, cumulative); the fallback triple in the same shape; and the count triple alloc/dealloc/fallback with the fallback share as an integer percentage of allocCount. Unlike Report, this function is not compiled out by PROFILE_ENABLED — what makes it silent in a shipped build is the logger's level filter, not the preprocessor.

The averages are integer divisions with an inline guard, and the percentage can round a real fallback rate to zero. The requested and fallback averages read allocCount > 0 ? totalRequested / allocCount : totalRequested and its sibling — when no allocation has been counted, the "average" printed is the cumulative total, not zero. The percentage is fallbackCount * 100 / allocCount, zero when allocCount is zero. The display is a debugging aid with truncated arithmetic, not a figure to parse.

Parameters

None.

Return value

None; output goes to the logger at Verbose level under category "AllocStats".

Examples

	static const StaticString moduleName("AllocStats");
	auto log = Logger::Get(moduleName, ELogLevel::Verbose);

	log.Out([this](auto& ls) { ls << "name = " << name; });

From Engine/Memory/AllocStats.cpp, AllocStats::Print

The channel open and the first of the six lines. The engine's own driver of this function is SystemStatistics::PrintAllocatorProfiles (Engine/Core/SystemStatistics.cpp), which walks the reported copies under PROFILE_ENABLED; nothing outside that loop calls it.
