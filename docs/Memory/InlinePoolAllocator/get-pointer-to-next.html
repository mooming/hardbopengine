GetPointerToNext

member of hbe::InlinePoolAllocator Engine/Memory/InlinePoolAllocator.h Read a free block's link and make it the new head - the read half of the free list, with no validation at all.

Signature

static void* GetPointerToNext(void* ptr)

Function description

Private and static, defined inline in the class body of Engine/Memory/InlinePoolAllocator.h, and the read half of WritePointerToNext: it interprets the first sizeof(void*) bytes of the block at ptr as a pointer and returns them.

One caller, and the order of that one call is the contract. AllocateBytes reads the link out of availableBlock and only then assigns the new head, so the link is consumed before the block leaves the pool. A caller who handed the block to a constructor first would read back whatever the constructed object wrote into its own first eight bytes — and the block belongs to the caller from the moment it is returned, so the window is zero-width, not merely small.
The value is trusted completely. No assertion, no range test, no alignment check: PoolAllocator::ReadNextIndex asserts that the link it reads names a block inside its own buffer, and this function has no equivalent. The value read becomes availableBlock, so anything that corrupts a free block's first bytes — a buffer overflow from a neighbouring object, a block allocated twice, a release of a pointer the pool never handed out — silently replaces the head of the free list with an arbitrary address, and the next allocation returns it. The only structural defence in the class is IsValidPointer, which guards releases, not allocations. No testlet in Engine/Memory/InlinePoolAllocator.cpp corrupts a link deliberately.

Parameters

ParameterTypeMeaning
ptrvoid*The block whose link to read — in practice always availableBlock, a block the pool currently owns and has not handed out.

Return value

TypeWhat you get
void*Whatever the block's first sizeof(void*) bytes hold: the address of the next free block, nullptr at the end of the list, or — if the block was never linked — unrelated data.

Examples

T* ptr = static_cast<T*>(availableBlock);
auto nextPtr = GetPointerToNext(availableBlock);
availableBlock = nextPtr;

From Engine/Memory/InlinePoolAllocator.h, hbe::InlinePoolAllocator::AllocateBytes()

Three lines that are the entire pop operation: take the head, read its link, make the link the head. The block itself is not written, not cleared and not counted, which is why a request of any size up to BlockSizeInBytes costs the same three pointer operations.
