GetName

member of hbe::InlinePoolAllocator Engine/Memory/InlinePoolAllocator.h The fixed text "InlinePoolAllocator", shared by every pool of every instantiation.

Signature

[[nodiscard]] static StaticString GetName()

Function description

Defined inline in the class body of Engine/Memory/InlinePoolAllocator.h. The body declares a function-local static StaticString name("InlinePoolAllocator") and returns it by value, so the string is built once per process on the first call and copied out afterwards.

Every pool in the engine answers with this one string. It is static, and its text is fixed: it carries no T, no BlockSize, no NumBlocks. An HInlineString<128> and an HInlineVector<Foo, 16> and a test pool of InlinePoolAllocator<int, 1024, 32> are all named "InlinePoolAllocator", which is also the literal RegisterAllocator hands the manager — the two agree by spelling, not by one reading the other. So MemoryManager::GetAllocatorName(id) tells you that an id is an inline pool and nothing else, and a profile that lists several of them cannot tell them apart. Contrast PoolAllocator::GetName, which returns the name its constructor was given.

Parameters

None. The function is static: it can be called through the type without an object, and it names no instance.

Return value

TypeWhat you get
StaticStringA copy of the fixed text InlinePoolAllocator. It stays valid after every pool is gone, because nothing in it refers to an object.

Examples

No caller in Engine/ or Applications/ asks a pool for its name; the search that found the users of this class (listed on the class page) found no use of GetName among them. The name that reaches the manager is the literal inside RegisterAllocator.
