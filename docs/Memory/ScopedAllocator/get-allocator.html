GetAllocator

member of hbe::ScopedAllocator Engine/Memory/ScopedAllocator.h The only door to the owned allocator object: a live reference in two constness flavours, valid exactly as long as the owner

Signature

[[nodiscard]] auto& GetAllocator()

[[nodiscard]] auto& GetAllocator() const

Function description

Two overloads defined in the class body of Engine/Memory/ScopedAllocator.h, each a bare return allocator;. The deduced reference follows the constness of the object: through a const ScopedAllocator the second overload returns a reference to the const allocator, and nothing in the class offers a way to reach a non-const reference through a const object. Both are [[nodiscard]], and both exist because the members are private — this is the only door to the owned object.

What the reference is good for is everything the scope does not do: the scope routes allocations, while the returned reference reads and drives the allocator itself — usage and free-space figures, capacity, or any operation the owned class offers. The reference names the object itself, not a copy, and it stays valid exactly as long as the ScopedAllocator does: the type is undeletable and unmovable, so there is no earlier invalidation to reason about beyond holding the reference past the owner's destruction.

None.

Return value
