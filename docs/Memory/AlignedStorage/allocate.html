Allocate

member of hbe::AlignedStorage Engine/Memory/AlignedStorage.h static [[nodiscard]] noexcept request the padded buffer and return the base, the aligned address and the byte count as one value

Signature

template <typename TAllocator>
	[[nodiscard]] static AlignedStorage Allocate(TAllocator& inAllocator, const size_t inCount) noexcept

Function description

Three steps, none of them optional and none of them repeated anywhere else in the engine:

StepWhat happensWhy it is that shape
1 bytes = sizeof(TObject) * inCount + alignof(TObject), then inAllocator.allocate(bytes) One extra alignof(TObject) is the most the rounding can ever consume, so it is the least that always suffices. The count is passed to the allocator as bytes, never as elements — this class deliberately binds to allocators whose unit is a byte
2 if the allocator returned null, return the handle as it stands Failure is a value. The function is noexcept and throws nothing, so the caller's only channel is raw == nullptr — which is why bytes is already filled in at this point and must not be used as the test
3 aligned = (address + alignof(TObject) - 1) & ~(alignof(TObject) - 1) Round up to the type's alignment. alignof is a power of two, so the mask is exact; the worst-case advance of alignof - 1 bytes is inside the slack from step 1

Nothing is constructed. The returned aligned points at raw storage, and it is the caller who placement-news inCount objects into it and who destroys them before Free. That is the whole reason this class exists rather than a sized new: the object being built usually lives inside a larger structure — a ring block, a slot array — whose layout the caller owns.

The reinterpret_cast between the allocator's byte pointer and std::byte* lives here and in Free, twice in total, and nowhere else. Free recovers the allocator's byte-pointer type from what allocate returns, so no call site writes the allocator's element type by hand.

Parameters

ParameterTypeRequirement
inAllocator TAllocator& An lvalue allocator with allocate(size_t bytes) returning a pointer and deallocate(pointer, size_t bytes) — a byte-unit allocator, such as DefaultAllocator<uint8_t> obtained by rebind<std::uint8_t>. Not stored: the same allocator, or one that accepts the same pointer and count, must be passed to Free
inCount const size_t Number of TObject the buffer must hold, at least 1. The padded size is computed in size_t unchecked, so a count that overflows it is a precondition violation, not a detectable error

Return value

An AlignedStorage<TObject> by value — three words, and the only way to obtain a buffer this class can release. On failure, raw and aligned are null and bytes is non-zero. It is [[nodiscard]]: discarding the return value leaks the buffer permanently, because no other handle to the base pointer exists.

Examples

These are the engine's two real call sites, from RingBuffer.

One line-spaced block, whose type is declared alignas(LineSpacing):

StorageAllocator storageAllocator{allocator};
auto allocation = AlignedStorage<Block>::Allocate(storageAllocator, 1);
returnValueIf(nullptr, unlikely(allocation.raw == nullptr));

auto* block = new (allocation.aligned) Block();   // placement: the handle never constructs
block->allocation = allocation;                  // the block carries the handle to its own free

An array whose element type is not the queue's element type:

slotAllocation = AlignedStorage<ProducerSlot>::Allocate(storageAllocator, inMaxProducers);
returnIf(unlikely(slotAllocation.raw == nullptr));

producerSlots = new (slotAllocation.aligned) ProducerSlot[inMaxProducers];  // the array the queue indexes from now on
