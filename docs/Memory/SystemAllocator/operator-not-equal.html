operator!=

member of hbe::SystemAllocator Engine/Memory/SystemAllocator.h Always false - the exact complement of the equality operator, and the same missing const qualification

Signature

template <class U>
	bool operator!=(const SystemAllocator<U>&) noexcept

Function description

Defined in the class body of Engine/Memory/SystemAllocator.h as a literal return false;, for every U — the exact complement of operator==, and the same kind of statement: these allocators are indistinguishable because they are stateless, so no two of them can differ. It reads no operand and touches no state, and carries the same qualification gap described on the equality page: it is not a const member, so it will not serve a comparison through a const allocator.

Parameters

ParameterTypeRequirement
(unnamed)const SystemAllocator<U>&Any instantiation; it is not examined.

Return value

false. Always, for every pair of instantiations, in both build configurations.

Examples

As with the equality operator, no call site exists in the tree; the pair documents the allocator model rather than steering any engine code.
