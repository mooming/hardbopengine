Module Index / Memory / SystemAllocator / ~SystemAllocator

~SystemAllocator

member of hbe::SystemAllocator Engine/Memory/SystemAllocator.h Defaulted; the class owns nothing, which is what lets one instance live as the manager's process-lifetime static in slot 0

Signature

~SystemAllocator() = default

Function description

Defaulted in the class body of Engine/Memory/SystemAllocator.h. The class owns nothing — no buffer, no registration, no handle — so destruction has no work, and any lifetime story is legal: a temporary in one expression, a member of a container, or the function-local static that RegisterSystemAllocator keeps for the life of the process. The last of these is the one the engine depends on: the two lambdas installed into proxy slot 0 capture that static object, so the slot's function pointers must never be called after it is destroyed — and the manager clears slot 0's operations from its own destructor path (DeregisterAllocator). What orders the two teardowns against each other is engine shutdown, not this class.

Parameters

None.

Return value

None. Destroying an instance changes nothing observable: no allocation is affected, no registration exists to lose.

Examples

There is no example of one being destroyed deliberately. The engine's static instance is destroyed with the process, and the slot-0 bookkeeping around that teardown belongs to the manager's shutdown page.
