allocate

member of hbe::SystemAllocator Engine/Memory/SystemAllocator.h Room for n elements of T: element arithmetic over the private byte layer, with no test of the result before it reaches the caller

Signature

[[nodiscard]] T* allocate(std::size_t n) noexcept

Function description

Defined in the class body of Engine/Memory/SystemAllocator.h, and the whole function is return reinterpret_cast<T*>(AllocateBytes(n * sizeof(T))); — element count in, byte count computed, raw result reinterpreted as a typed pointer. Everything that decides where the bytes come from lives in AllocateBytes: the system heap in the shipped configuration, page-rounded virtual blocks with deliberately placed pointers in an investigation build, and a profiling report filed under GetID when PROFILE_ENABLED is on.

The function is noexcept in every configuration, so a failure of the underlying allocation cannot be an exception either: in the default build the chain reaches malloc, whose null return this function passes through unchanged. The class page's gap note records who checks the result — the callers above this class, never this class. Note also the element arithmetic: n * sizeof(T) is unguarded multiplication, so an n large enough to wrap the product asks the byte layer for the wrong size; no caller in the tree builds a request that way, and no guard here would catch one that did.

Parameters

ParameterTypeRequirement
nstd::size_tElement count; the product with sizeof(T) must be the byte count the caller meant. Zero is passed straight down to the underlying allocator, whose answer the C standard leaves open.

Return value

A T* with room for n elements — raw, uninitialised — or whatever the underlying allocator returns on failure: the pointer is not tested here. It belongs to this allocator's source (the system heap in the shipped configuration) and must return through deallocate with the same element count.

Examples

		auto allocFunc = [](void*, size_t nBytes) -> void* { return systemAllocator.allocate(nBytes); };
		auto deallocFunc = [](void*, void* ptr, size_t nBytes)
		{ systemAllocator.deallocate(static_cast<uint8_t*>(ptr), nBytes); };

From Engine/Memory/MemoryManager.cpp, MemoryManager::RegisterSystemAllocator()

Slot 0's registered operations call exactly this pair on the instantiation SystemAllocator<uint8_t>, which is why every byte figure carrying the system allocator's id passed through an element width of one: here n * sizeof(uint8_t) is the byte count unchanged.
