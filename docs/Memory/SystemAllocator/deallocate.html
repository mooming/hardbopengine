deallocate

member of hbe::SystemAllocator Engine/Memory/SystemAllocator.h Returns n elements through the byte layer; a null pointer is asserted against twice, in Debug and Dev only

Signature

void deallocate(T* ptr, std::size_t n) noexcept

Function description

Defined in the class body of Engine/Memory/SystemAllocator.h: Assert(ptr != nullptr); then DeallocateBytes(ptr, n * sizeof(T));. The byte arithmetic mirrors allocate — element count in, bytes down — and DeallocateBytes decides what "returning the bytes" means in the active build configuration: plain free in the shipped configuration, base-pointer recomputation and either a page release or a guard-page protection step in an investigation build.

The count is load-bearing only in investigation mode: the shipped path hands the pointer to free and the size is used only by the profiling report, while the investigation path needs the requested byte count to recover the block's base from the end-aligned pointer it was handed. A mismatched n is therefore invisible in one build configuration and corrupting in the other, and nothing in the call can tell you which one you are in — pass the count the allocation was made with.

The null check is a Debug-and-Dev guard: outside builds where Assert has teeth (Engine/Core/Debug.h), a null pointer continues into the byte layer, where the same assert — with its own message — stands again before the build-specific teardown. Two asserts guard the one precondition, and neither of them ships.

Parameters

ParameterTypeRequirement
ptrT*Memory returned by allocate of any SystemAllocator instantiation (all instances are one allocator) — non-null, because a null release is not ignored, only asserted against.
nstd::size_tThe element count the block was allocated with; see above for what a mismatch costs in each configuration.

Return value

None. After the call the block belongs to the system heap again — or, under the dangling-pointer investigation switch, stands protected so that touching it faults instead of silently succeeding.

Examples

		Assert(ptr != nullptr, "[SysAlloc][Dealloc] Null Pointer Error");
