GetName

member of hbe::AllocatorProxy Engine/Memory/AllocatorProxy.h The registered name under PROFILE_ENABLED, the literal NoName without it: one declaration, two definitions behind a build guard

Signature

#if PROFILE_ENABLED
	[[nodiscard]] const char* GetName() const

#else
	[[nodiscard]] const char* GetName() const

Function description

One declaration, two definitions, selected at compile time by #if PROFILE_ENABLED inside the class body of Engine/Memory/AllocatorProxy.h. Under PROFILE_ENABLED it returns the name held in stats.name, which AllocStats::OnRegister filled from the name argument of RegisterAllocator (that call substitutes the literal "None" for a null name, so even a nameless registration has a name here). Without PROFILE_ENABLED the record stores no name at all — stats is not a member of the class in that configuration — and the call returns the literal "NoName" for every allocator, registered or not.

This is the header's AllocStats coupling in one line: the proxy carries profiling state only in profiling builds, and the accessor keeps compiling either way so callers may ask a record its name unconditionally. The build configuration of this tree sets PROFILE_ENABLED 0 (Engine/Config/BuildConfig.h), so the shipped answer is always "NoName" and only the profiling build can tell two allocators apart through this call. MemoryManager::GetAllocatorName makes the same split for the same reason (its page).

Parameters

None.

Return value

ConfigurationWhat you get
PROFILE_ENABLEDThe registered name, read from stats.name — valid while the record stays registered under that name.
otherwiseThe literal "NoName", for every record, including the empty and the unregistered.

Examples

Nothing in the tree calls AllocatorProxy::GetName outside the header itself; manager-side logging names allocators through stats.name or MemoryManager::GetAllocatorName instead (Engine/Memory/MemoryManager.cpp). The call exists so that code holding a proxy reference can name it without knowing the build configuration; see the Coverage row of the class page for what this page does not promise about the returned pointer.
