Defined in Engine/Memory/PoolAllocator.cpp as PoolAllocator::GetIndex(Pointer ptr) const. Private, and the arithmetic that turns an address into a block number. 

auto bytePtr = reinterpret_cast<Byte*>(ptr);
auto delta = bytePtr - buffer;
auto index = static_cast<TSize>(delta / blockSize);

return index;

From Engine/Memory/PoolAllocator.cpp, PoolAllocator::GetIndex(Pointer ptr) const

It checks nothing, because it is only ever called on something already known to be inside. The single caller is Deallocate, and what it passes is the free-list head — in range by construction, not by inspection. Give this a pointer from another allocation, or a pointer to a pool that has been moved from, and the answer is a number computed from a difference that means nothing (or a division by a stride of zero). The public way to ask the same question is IsMine first.
Integer division means the middle of a block answers its own block's index. An offset of 20 bytes into block 4 at a 32-byte stride is block 4. That is the same tolerance IsMine has: both work on ranges, neither knows where a block begins.

Parameters

ptrPointerAn address inside buffer, from a pool that owns a buffer. Nothing here enforces either half, and neither is checked.

Return value

TypeWhat you get
TSizeByte offset from the buffer base divided by the block stride. For a pointer inside the pool, the block's ordinal, in the same numbering the constructor laid the blocks out in; outside it, an unusable number.

The real use, quoted from its only caller: the index of the free-list head is compared against the block count, and a head that names a block past the end is taken as evidence the free list itself has been damaged — the corruption report Deallocate describes.
