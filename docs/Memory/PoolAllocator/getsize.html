GetSize

member of hbe::PoolAllocator Engine/Memory/PoolAllocator.h nodiscard The pool's block size, whatever pointer it is handed.

Signature

[[nodiscard]] size_t GetSize(Pointer) const

Function description

Defined in the class body of Engine/Memory/PoolAllocator.h as a one-line return of blockSize. The parameter is declared and never named: this accessor answers a question about the pool, not about the pointer it is handed.

Whatever pointer you pass, the answer is the same. A pointer the pool owns, a pointer it forwarded to its parent, a pointer into the middle of its buffer and a pointer from an unrelated allocation all produce the same number. A caller reading "how big is this block?" out of the signature will get the pool's stride even when the pointer is not the pool's — pair it with IsMine if the pointer's provenance matters.
It is the block's size, not the request that filled it. A pool constructed with a 24-byte request reports 32 (Config::DefaultAlign rounding, constructors), and a caller that asked for 50 bytes out of a 4096-byte block is told 4096. That is the honest figure for "how many bytes may I touch" — the whole block belongs to the holder (Allocate) — and the wrong figure for accounting, where the pool's own usage counters already charge every block at this stride.

Parameters

ParameterTypeRequirement
(unnamed)PointerIgnored. The declaration gives it no name and nothing in this class reads it; Engine/Memory/StackAllocator.h declares the same shape, a GetSize(Pointer) that is indifferent to its argument as well.

Return value

TypeWhat you get
size_tThe pool's block size in bytes, for any argument. Zero on a moved-from pool.

Examples

auto ptr = pool.Allocate(allocSize);
auto size = pool.GetSize(ptr);

if (size != 4096)
{
	ls << "The size is incorrect. " << size << ", but 4096 expected." << lferr;
	break;
}

From Engine/Memory/PoolAllocator.cpp, PoolAllocatorTest::Prepare()

The test asks a pool built with a 4096-byte block size what it handed out, and the answer is the block size rather than the 50 bytes requested — which is the whole contract of this accessor in two lines.
