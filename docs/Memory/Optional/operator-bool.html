operator bool

member of hbe::Optional Engine/Memory/Optional.h implicit conversion the implicit test - the same boolean as HasValue, with none of the ceremony

Signature

[[nodiscard]] operator bool() const noexcept

Function description

A single conversion function defined in the class body of Engine/Memory/Optional.h, returning hasValue. It is const, noexcept, marked [[nodiscard]], and touches nothing but the flag — no assert, no storage access, no destructor or constructor involvement.

It is what makes if (opt), while (opt), opt && *opt and !opt mean the same thing as opt.HasValue(). The flag is the only state the class has, so three spellings of the same test cannot drift apart; the operator exists for the callers who write the test as a condition rather than as a call.

The conversion is implicit, not explicit. Unlike std::optional, which declares explicit operator bool, this one has no explicit — so an optional converts to bool anywhere a boolean is wanted, including where it was not intended: a function taking bool, a comparison against an integer, or a stream formatting a flag. That is a real overload- resolution hazard in a type whose interesting operations are the ones that take a TType.

It answers "is the flag set", not "is there a live object in there". The two are the same as long as only this class writes hasValue, which nothing enforces — the field is public. And the flag is the field the copy and move constructors leave unset when their source is empty, so an optional built by copying an empty one can convert to true without ever having held a value, and the following operator* then walks straight past its assert into unconstructed storage.

Parameters

None.

Return value

TypeWhat you get
boolThe current value of hasValue. The function is marked [[nodiscard]], so discarding the test is a compile error rather than a silent no-op.

Examples

The operator's body and HasValue's are the same single line:

return hasValue;

From Engine/Memory/Optional.h, Optional::HasValue

A caller that wants the test as a value uses HasValue; a caller that wants it as a condition uses this conversion. Both then reach the element through operator* — the only read that re-checks the flag before handing out a reference.
