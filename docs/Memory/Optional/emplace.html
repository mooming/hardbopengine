Emplace

member of hbe::Optional Engine/Memory/Optional.h 2 overloads destroy any current value, then construct a new one in the same bytes

Signature

void Emplace(TType& value)

template <typename... Types>
	void Emplace(Types&&... args)

Function description

Two overloads defined in the class body of Engine/Memory/Optional.h, both with the same two steps: destroy whatever is currently held if hasValue says something is, then build a new element in the same bytes through ConstructAt. Both leave the optional holding a value.

OverloadWhat it forwardsWhich construction it selects
Emplace(TType&) One modifiable lvalue, as value ConstructAt(typename IsReferenceType<TType>::Result(), value) — so the trait decides: for a reference element type that is the form which stores the object's address, for a value element type it is the variadic form, which placement-copy-constructs TType from value
Emplace(Types&&...) Any argument pack, perfectly forwarded ConstructAt(False_t, std::forward<Types>(args)...) — the value path only, which placement-news TType from the pack

The variadic form is therefore the one that can build an element from constructor arguments without a temporary; the single-argument form is the one a reference element type uses, because it is the only one whose call does not place-construct a reference.

The destruction comes first and is not undoable. If construction of the new element throws (or fails), the old value has already been destroyed and the flag has not yet been set — ConstructAt writes hasValue = true only at its end. The optional is left empty rather than half-replaced, which is the safe direction, but the previous value is gone and nothing reports that the operation did not complete.

It is not a no-op on a filled optional, and it is not the same as assignment. operator=(TType&) assigns into a live element and only emplaces when the optional is empty; Emplace always destroys and rebuilds. For a type whose assignment is cheap and whose construction is not, that difference is the whole cost of the call.

Parameters

ParameterTypeRequirement
valueTType&A modifiable lvalue of the element type. For a reference element type this is the object the optional will refer to afterwards — the optional stores its address and does not extend its life
argsTypes&&...Arguments usable to construct a TType in place. Only meaningful for a value element type; the pack is forwarded straight into a placement new

Return value

None. Whether anything was destroyed on the way in is not reported, and whether construction completed is only observable through HasValue afterwards.
