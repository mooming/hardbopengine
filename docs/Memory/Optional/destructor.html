~Optional

member of hbe::Optional Engine/Memory/Optional.h runs the element destructor the flag claims is needed, and nothing else

Signature

~Optional()

Function description

Defined in the class body of Engine/Memory/Optional.h, and its whole body is one call: Destroy(typename IsReferenceType<TType>::Result());. The trait selects which of the two Destroy overloads runs, so the destructor has two behaviours and no branch of its own.

For a value type that means the destructor of TType is run explicitly on the storage, but only if Destroy finds hasValue true. For a reference type it means the flag is cleared and nothing else — the referred-to object is not destroyed, because it was never the optional's to destroy (ConstructAt only stored its address).

The destructor trusts the flag completely. It never consults the storage, so it will run a destructor over bytes that were never constructed if the flag says so — the exact risk left open by the copy and move constructors, which do not initialise the flag when their source is empty. It also means a caller who writes hasValue = true directly (the field is public) has scheduled a destructor call for whatever those bytes hold.

Nothing releases memory here. This class allocates nothing — the storage is a member array — so the destructor returns no bytes to any allocator and takes no part in the TAllocatorID bookkeeping the rest of this module is concerned with. Whatever owns the optional owns its bytes outright.

Parameters

None.

Return value

A destructor returns nothing. The only observable effect is that hasValue is false afterwards, which Destroy guarantees on both paths.

Examples

The trait decides the destructor's behaviour, not an if:

Destroy(typename IsReferenceType<TType>::Result());

From Engine/Memory/Optional.h, Optional::~Optional

The same call appears in Reset, in both assignment operators and in the Emplace overloads, always with the same argument — which is why "empty this out" means one thing everywhere in this class. See Destroy for the two things it then does.
