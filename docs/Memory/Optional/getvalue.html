GetValue

member of hbe::Optional Engine/Memory/Optional.h private 4 overloads the four casts that turn the byte array back into an element, and the only place an empty optional stops being a state

Signature

Function description

Private, and the lowest layer of Optional: the four casts that turn the member byte array back into a reference to TType. Every read of an element in this class ends here, reached through Value (and therefore through operator*), plus a self-check inside ConstructAt. The True_t/False_t parameter comes from IsReferenceType<TType>::Result, and each tag has a const and a non-const form.

OverloadWhat it returns
GetValue(True_t) / const GetValue(True_t) const The stored address, read out of the array through reinterpret_cast<TypePtr&>(value[0]), checked with Assert(valuePtr != nullptr) and then dereferenced — so an optional of a reference type hands back the referent, not a pointer
GetValue(False_t) / const GetValue(False_t) const reinterpret_cast<TType&>(value[0]) — the array itself reinterpreted as the element. No test of any kind: not of the flag, not of alignment, not of whether anything was ever constructed there

These are the functions where "empty" stops being a state and becomes undefined behaviour. Value performs no check, so an empty optional of a value type yields a reference to raw bytes; an empty optional of a reference type yields a dereference of whatever the array holds. The guard on the reference path is Assert, and Engine/Core/Debug.h gives Assert an empty definition when RELEASE_BUILD is set — so the shipped build dereferences a possibly-null pointer with no complaint. The checked entry point is operator*, which asserts hasValue before it gets here.

Alignment is assumed, not asserted. The array is declared alignas(std::max(IsReferenceType<TType>::TypeSize, Config::DefaultAlign)), which is what makes the cast honest — and what makes the engine-wide 16-byte alignment rule (Config::DefaultAlign) part of this type's correctness. Unlike the module's GetAs helper in Engine/Core/CommonUtil.h, this cast does not check alignment at all.

Examples

The value path is one cast and nothing else:

return reinterpret_cast<TType&>(value[0]);

From Engine/Memory/Optional.h, Optional::GetValue(False_t)

Its reference-type counterpart checks the pointer first and then dereferences it. Both are called through Value, and the only thing standing between either of them and a wrong answer is the flag tested by HasValue — the rest of the class is bookkeeping around that one boolean.
