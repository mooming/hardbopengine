SetFloat

member of hbe::ConfigSystem Engine/Config/ConfigSystem.h one overload write a duration or threshold parameter by name, in the map where zero is never a neutral value

Signature

void SetFloat(const StaticString& key, float value);

Function description

Looks key up in floatParams and calls the setter stored in that entry, which forwards to ConfigParam<float>::Set. The value goes in as given: no clamp, no range, no rejection of a negative or NaN argument.

Exactly one float parameter exists in a stock engine, and it is read on the hot path of every task stream — "TaskStreamDurationThreshold", default 0.16f, defined inside the task stream loop in Engine/Core/TaskStream.cpp. A task that holds a lane longer than it produces a warning, so this is the knob that decides how noisy a frame is, and because the stream re-reads the parameter each iteration rather than caching it, a write here does take effect immediately — the opposite of the size parameters, which one subsystem latches at start-up (SetSize).

Parameters

ParameterTypeRequirement
key const StaticString& The name of a registered float parameter. Null is logged at Warning; absent is logged at Info under EngineSettings
value float The new threshold or quantity. A threshold of 0.0f warns on every task that ran at all, and 0.0f is also what GetFloat answers for an unknown key — so zero is the value that makes "the setting is off" and "the setting is missing" behave identically

Return value

void, with a log line as the only failure report. Read back with GetFloat if the write has to be certain; compare floats rather than treating the answer as exact.

Whether a write is safe from your thread depends on the parameter, not on this function. The stored setter calls Set on the owning ConfigParam, and only the atomic form is safe off its home thread (Engine/Core/TaskStream.cpp registers its threshold as ConfigParam<float, true>, so that one is). A non-atomic parameter asserts on thread identity under __DEBUG__ — Debug and Dev — see ConfigParam::Set.

Examples

The registration is real code; the write is illustrative — nothing in the tree writes this key.

static hbe::ConfigParam<float, true> thresholdDuration(
        "TaskStreamDurationThreshold",
        "Print a warning log if it detects slower task. (seconds)",
        0.16f);

From Engine/Core/TaskStream.cpp

Illustrative — no call site for the write exists in the repository.

auto& settings = hbe::ConfigSystem::Get();
settings.SetFloat("TaskStreamDurationThreshold", 0.33f);   // a 30 Hz frame before the stream warns

The engine's own log level knobs live in a different map and are written with SetByte; the sizes with SetSize. Using this function on either reports not-found and changes nothing.
