SetByte

member of hbe::ConfigSystem Engine/Config/ConfigSystem.h one overload the runtime knob for the byte map — in practice, for every log level the engine has

Signature

void SetByte(const StaticString& key, uint8_t value);

Function description

Looks key up in byteParams and calls the setter stored there, which forwards to ConfigParam<uint8_t>::Set or ConfigParam<bool>::Set — both register in this map. No entry is created by a write, and the value lands in the owning parameter, not in the registry.

This is the function that makes the engine's logging adjustable without a rebuild. Every log-level parameter the engine registers is a uint8_t in this map: Log.Level registered by Logger::AddLog, Log.Engine and Log.Engine.Print registered by Engine::Log, Log.TaskSystem registered by TaskSystem::Initialize, and Log.Memory registered by MemoryManager::IsLogEnabled — that last one only inside #if MEMORY_LOGGING_ENABLED, so it is absent from a default build and writing it there logs not-found. Their values are ELogLevel numbers held as uint8_t, which is why the argument here is a number and not an enumeration.

Because those parameters are the atomic form, writing them from any thread is legitimate — the store is an std::atomic<uint8_t> store. It takes effect on the next log call, not on the call that wrote it: a filter that already ran for this line has nothing to re-read.

Parameters

ParameterTypeRequirement
key const StaticString& A registered byte-map name. Null is logged at Warning; absent is logged at Info, both under EngineSettings
value uint8_t The new byte. For a log-level parameter that means a 0–5 level; the number is stored as given, so 9 is accepted and afterwards filters every line out — nothing here validates a level against ELogLevel

Return value

void: one log line on failure and no status on success. A write you cannot see did not necessarily happen — read it back with GetByte, keeping in mind that its not-found answer is 0.

Examples

The engine reads these parameters; the commented-out pair in Engine::ShutDown is the shape of writing them, and is reproduced below as an illustrative snippet rather than as live code.

Illustrative — adapted from commented-out code in Engine/Engine/Engine.cpp; no live call site exists.

auto& settings = hbe::ConfigSystem::Get();

// Verbose = 0. Both keys exist in a stock engine and both are uint8_t atomics.
settings.SetByte("Log.Engine", 0);
settings.SetByte("Log.Level", 0);

settings.PrintAllParameters();   // now visible: the dump itself is emitted at Verbose

PrintAllParameters explains why the second line is the one that matters — a Verbose dump is filtered by the global Log.Level before the category is ever consulted.
