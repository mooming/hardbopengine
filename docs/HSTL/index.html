HSTL

namespace hbe Engine/HSTL 3 headers, 2 sources — standard containers rebound to engine allocators, and nothing else

Module description

HardBop STL is a thin layer: each header declares aliases that plug an engine allocator into a standard container. There is no wrapper class, no reimplementation, and therefore no second behaviour to learn — you get std::vector's guarantees with the engine's accounting. Where the engine's own Container module exists, prefer it for engine internals; use these where a standard container is needed, which is mostly at boundaries with code that expects one.

HString (Engine/HSTL/HString.h)

Class description

The engine's string type at interfaces — OSAL window titles and resource paths travel as HString. Three aliases, differing only in where the characters live.

Template parameters

Not applicable — these are aliases, so the storage is the standard container's own.
