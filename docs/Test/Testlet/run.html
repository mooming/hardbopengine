Run

member of hbe::Testlet Engine/Test/Testlet.h runs the closure, writing to outLog

Signature

void Run(TLogOut& outLog) const noexcept

Function description

Runs the closure: dispatch->invoke(storage, outLog), where outLog is a write-only parameter by the standard's out-prefix convention — the testlet's whole effect is what it writes there, plus whatever its assertions record.

noexcept is a promise about the suite, not about this function: a testlet signals failure by logging and asserting, the engine is exception-free, and a testlet that ever threw would terminate rather than unwind the run — the loud version of the alternative.

A testlet that has been moved from reports itself and does nothing, rather than running a closure that no longer lives in its storage: the null-dispatch path writes an error to std::cerr naming the testlet, then asserts.

Parameters

ParameterTypeRequirement
outLogTLogOut& (std::stringstream&) Write-only. Receives everything the closure streams; flushed by the collection's LogFlush mechanism.

Return value

None — the testlet's outcome is what it logs and asserts, not what it returns.

Examples

Callers are the harness, not tests: TestEnv::RunTestlet invokes this through the collection's RunTestAt.
