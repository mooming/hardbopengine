GetName

member of hbe::Testlet Engine/Test/Testlet.h the registered name, valid for the testlet's lifetime

Signature

[[nodiscard]] const char* GetName() const noexcept

Function description

The registered name, null terminated: the char array the constructor copied into the inline buffer. The header's own note is the contract: the name outlives the run because AddTest accepts literals only — a literal has static storage, so the buffer copy is the only copy that ever needs to exist, and the pointer stays valid for the testlet's lifetime.

Parameters

None.

Return value

A null-terminated const char* owned by the testlet's inline buffer. Callers may print it freely; the failure report and the task registry both do.

Examples

TestCollection::GetTestName forwards to this; TestEnv::GetTestletLabel builds its "Collection TC<n>.<name>" label around it.
