Testlet

Engine/Test/Testlet.h template <size_t TClosureBytes = 32> final one registered test, owning its closure inline

Class description

Testlet is one registered test: a name, a retention ceiling, and the test's closure — all held inline. The inline storage is the design's whole point: registering a test cannot allocate, so a suite's registration is a known-cost operation, and the TestletDispatch table (one constexpr instance per closure type) is what lets the closure be invoked, destroyed and relocated without a virtual table or a heap slot.

The type is parameterised on TClosureBytes rather than fixing a constant inside itself, because the ceiling has to be set where the captures are known — by whoever holds the testlets — and because raising it is then a visible edit at the use site instead of a change to a shared type. The measured basis for the default: 375 of the 379 closures in this suite fit in 32 bytes, and the four that do not are all 40 bytes (the importance-sampling tests, whose [&] captures are wider).
