Destructor

member of hbe::Testlet Engine/Test/Testlet.h destroys the closure through the dispatch table; nothing on a moved-from testlet

Signature

~Testlet()

Function description

Destroys the closure through TestletDispatch::destroy — but only when the dispatch pointer is still set. A moved-from testlet has a null dispatch, so its destructor does nothing: the closure it once held now lives in the testlet it was moved into, and destroying it here would be the second destruction of one object.

The name needs no destruction — it is a plain char array — and the storage needs none: it is inline bytes, not an allocation.

Parameters

None.

Return value

None — a destructor.

Examples

The destructor runs when a TestCollection's std::vector<TTestlet> is destroyed, which is the normal end of a suite.
