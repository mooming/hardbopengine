GetMaxRetainedGlobalBytes

member of hbe::Testlet Engine/Test/Testlet.h const noexcept how much engine-owned global heap this one testlet is permitted to still hold when its body ends

Signature

[[nodiscard]] std::size_t GetMaxRetainedGlobalBytes() const noexcept;

Function description

A testlet carries its own ceiling, declared where it was registered. The registration form without an argument passes TestCollection::MaxRetainedGlobalBytes; the form with one passes whatever that particular test needs. The harness reads the value once per run, after the body finishes, and compares it against what the testlet actually retained.

Why the testlet owns the value

The alternative was a parallel array in the collection, indexed alongside the testlets. Rejected: a second container has to be kept in step by hand, and every way of getting that wrong - an insert that forgets a slot, a sort that moves one and not the other - produces a test judged by another test's budget. That failure is silent and reads as a flaky test. Owning the value costs eight bytes per testlet, which took sizeof(Testlet) from 184 to 192: about three kilobytes across the 372 testlets in the suite.

There is no test of this guard, and there cannot be one

A testlet cannot run a testlet. And a testlet that went over its own ceiling would fail the very run whose behaviour it was trying to demonstrate, so an in-suite test of this mechanism is not merely missing - it is not expressible. What stands in for one is mutating the ceiling and reading the refusal. Done in both directions: with the default lowered to 1 KiB, nine testlets were refused under the wording "a testlet may hold" while a testlet that declared 64 KiB for itself survived retaining 12,352 bytes, and another that declared only 256 was refused under the wording "this testlet declared for itself".

Return value

The allowance in force, which is the suite default unless the registration site said otherwise. Never zero: a testlet with no allowance would fail unconditionally, so the value is a limit rather than an optional.
