EPerfGrade

Engine/Test/PerfHarness.h namespace hbe::Test scoped enum the colour a performance cell prints, and never a test failure

Class description

The colour a performance cell prints. It is information: no grade calls the test framework’s error or warning path, and none of them changes whether the suite passed. A cell exists to make a number hard to misread, and a failing suite whose failure is a ratio is a suite whose owner learns to ignore the ratio.

The rule that chooses a colour is GradeOf, and the grading section of the design document carries the measurements that set the margins it compares against.

Class properties

Type + NameDefault ValueDescription
Nonenot applicableThe cell carries no claim, or names an arm that was never added: the numbers are printed and nothing is judged.
Greennot applicableThe claim held on the fastest round and on the middle round, and the noise floor was too small to explain the margin.
Ambernot applicableThe fastest round cleared the margin; the middle round did not. The claim is alive on the best case only.
Rednot applicableThe claim did not hold on this machine in this configuration, by the fastest round as well as the middle one.
Noisenot applicableThe measured margin is inside the noise floor: the same code, run as a second arm, varied by more than the claim is ahead. No colour is supportable.
Rejectednot applicableThe winning arm lost, duplicated or corrupted an item, or a round gave up at its deadline. The cell measured nothing, so nothing is graded.

Class methods

None. The rule that chooses one of these six values is GradeOf, a member of the benchmark rather than of the enumeration, so the colour stays a property of a measurement rather than an object with behaviour.

Coverage

All six enumerators are listed. The enumerator’s underlying type is unsigned char because it is stored in no container and printed as a word; the order is the report’s order, with None first so a zero-initialised value reads as “no claim” rather than as a colour.
