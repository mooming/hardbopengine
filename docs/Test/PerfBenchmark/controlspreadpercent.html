ControlSpreadPercent

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h the noise floor a grade is allowed to trust

Signature

[[nodiscard]] std::size_t ControlSpreadPercent() const noexcept

Function description

Private. The spread of the arm named by Control; when no arm was declared, the widest spread among the arms that are not the claimed winner. The fallback is honest but weaker, so the report labels the number control in the first case and spread in the second rather than pretending they are the same measurement.

This is the quantity that decides whether a GREEN means anything. A same-code control measured 3% to 29% spread on the machine this module was developed on, so a claim ahead by 20% on a control that moved 29% is reported as NOISE even though the ratio is real in the data.

Parameters

NameWhat the caller must supply
noneReads the declared control arm, or the arms that are not the winner.

Return value

Spread in percent, zero when there is no other arm to compare.
