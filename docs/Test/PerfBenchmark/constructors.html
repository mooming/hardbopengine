member of hbe::PerfBenchmark Engine/Test/PerfHarness.h an empty cell that will measure the given number of rounds

Signature

explicit PerfBenchmark(std::size_t inRounds) noexcept

Function description

Leaves the cell with no arms, no claim and no control arm, and remembers the round count clamped to MaxRounds. The clamp rather than a rejection is deliberate: an over-large round count is a wish, not a bug, and a cell that silently measured fewer rounds says so in Report, which prints the arm and round counts beside the wall time.

The object holds fixed arrays — MaxArms arms of MaxRounds figures — so it allocates nothing and can live on the stack of the testlet that built it.

Parameters

NameWhat the caller must supply
inRoundsRounds per cell, at least one. Anything above MaxRounds is measured as MaxRounds.

Return value

None.
