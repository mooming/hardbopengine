Report

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h print the cell as plain text, aligned and colourless

Signature

void Report(std::ostream& ioOut) const

Function description

Prints one shape line, one row per arm with its fastest, middle and slowest round and its violation count, the wall time of the cell, and — only when the cell carries a claim — the claim, the two ratios it produced, the winner’s own spread, the noise floor and the colour.

The output is plain text with no ANSI colour even on a terminal, because these lines are meant to be grepped and diffed across runs, and a colour escape inside a field breaks both. A colour for a human reader is the benchmark binary’s choice to make, not this report’s.

Every figure is formatted with snprintf into a local buffer rather than with stream manipulators. The suite hands a testlet a log stream that arrives with fixed notation, internal adjustment and forced signs already set, and a report that inherited that state printed 31    .9 where it meant 31.9. Formatting into a buffer makes the report the same text whatever stream carries it, which is the reason a testlet’s report and the benchmark app’s report cannot drift apart.

Parameters

NameWhat the caller must supply
ioOutDestination stream. Its formatting state is read by nothing this function writes.

Return value

None.
