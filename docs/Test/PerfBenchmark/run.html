Run

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h measure every arm once per round, rotating the order

Signature

void Run() noexcept

Function description

Runs the cell. For each round it calls every arm’s measure function once, starting at a different arm each round, and stores the resulting figure. It blocks until the last arm returns; everything a cell costs is inside this call, which is why the wall time it records is what a reader checks a time budget against.

The rotation is not decoration. Measured in this module, an arm that was always measured first carried a cold-start penalty of tens of percent, because each round creates its threads and touches its pages for the first time. Rotating distributes that penalty across arms instead of handing it to one of them, and it distributes it unevenly on purpose: a fixed penalty that lands on a rotating arm cannot be confused with a design property.

Figures are kept internally in tenths of a nanosecond per item. An integer count of nanoseconds would round a 12 ns/item figure to two significant digits and report a 12.5x ratio as 12x; tenths cost one multiply per sample and leave the report honest.

Parameters

NameWhat the caller must supply
noneThe arms and the round count were set by AddArm and the constructor.

Return value

None. Call Report or GetGrade afterwards.

Example

bench.Run();
bench.Report(ioOut);
