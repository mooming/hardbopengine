Control

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h say which arm measures the machine rather than the design

Signature

void Control(const char* inArmName) noexcept

Function description

Names the arm whose spread is the noise floor. In practice that is a second copy of the winning arm: same code, same shape, different queue instance, so the difference between its fastest and slowest round is the machine talking about itself.

GradeOf asks that floor how far the ratio could be wrong, and answers NOISE when the margin fits inside it. Without a declared control the fallback is the widest spread among the arms that are not the winner, which is weaker evidence — the spread of a rival design is partly that design’s own behaviour — and is printed under a different label so a reader can tell the two apart.

Measured spreads of a same-code control on a 12-CPU machine ran between 3% and 29% across the cells of this module, which is why a 20% margin on a 1.20x claim is not supportable there and why the noise measurements come before any claim in the design document.

Parameters

NameWhat the caller must supply
inArmNameThe name already passed to AddArm. A name that was never added restores the fallback.

Return value

None.

Example

bench.AddArm("AtomicFixedRingMPSC (control)", &shape, &RunPerfCell<TAtomicMPSC>);
bench.Control("AtomicFixedRingMPSC (control)");
