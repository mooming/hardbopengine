AddArm

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h register one implementation of the cell

Signature

void AddArm(const char* inName, const void* inUserData, TPerfMeasure inMeasure) noexcept

Function description

Appends an arm. The three arguments are a name, an address and a function pointer, all of which must outlive the benchmark: the name goes into the report, the address goes back into the measure function once per round, and nothing copies them. A testlet therefore passes the address of a namespace-scope shape rather than one it built on its own stack.

The measure function owns everything it measures. It builds the queue, its threads and its bookkeeping, runs the round, checks the invariants and destroys it all, returning one PerfSample. That is what makes the arms independent: no queue is shared between rounds, and a warm ring never flatters the arm measured second.

A call past MaxArms is dropped rather than growing the table, so a cell that asks for six arms reports five — the arm count on the report line is where that becomes visible.

Parameters

NameWhat the caller must supply
inNameStatic-storage name, as a literal. It is the arm’s identity: Expect and Control name arms by it.
inUserDataAddress passed back to inMeasure, uninterpreted. May be null.
inMeasureFunction that measures one round and returns the sample. It must not throw, and it must leave nothing running behind it.

Return value

None.

Example

bench.AddArm("FixedRingMPSC (mutex)", &shape, &RunPerfCell<TMutexMPSC>);
bench.AddArm("AtomicFixedRingMPSC (control)", &shape, &RunPerfCell<TAtomicMPSC>);
