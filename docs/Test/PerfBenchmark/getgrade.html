GetGrade

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h the colour, or None when the cell owns no claim

Signature

[[nodiscard]] EPerfGrade GetGrade() const noexcept

Function description

Resolves the two names given to Expect and applies GradeOf. Returns None when the cell owns no claim or names an arm that was never added. After Report it is the same colour the report printed; nothing caches it, so calling it before Run grades an empty table and is the one way to read this function wrong.

Parameters

NameWhat the caller must supply
noneThe claim and the arms were set before Run.

Return value

One of EPerfGrade.

Example

if (bench.GetGrade() == EPerfGrade::Rejected)
{
	// The cell is not slow, it is void. Say so before quoting its ratio.
}
