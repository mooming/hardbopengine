SpreadPercent

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h how far one arm’s own rounds disagree, in percent

Signature

[[nodiscard]] std::size_t SpreadPercent(const PerfArm& inArm) const noexcept

Function description

Private. (slowest - fastest) * 100 / fastest: the arm’s own wobble. It is printed as wobble for the winning arm and used as the noise floor for the control arm, and the two are the same arithmetic — what differs is what the arm is a copy of.

An arm whose fastest round measured zero answers zero rather than dividing by nothing.

Parameters

NameWhat the caller must supply
inArmThe arm to read. Read-only.

Return value

Spread in percent, 11 meaning the slowest round took 11% longer than the fastest.
