Expect

member of hbe::PerfBenchmark Engine/Test/PerfHarness.h the claim this cell is graded against

Signature

void Expect(const char* inWinner, const char* inLoser, std::size_t inMinRatioPercent) noexcept

Function description

States the claim: inLoser should take at least inMinRatioPercent percent of the time inWinner takes, per item. 200 therefore reads “the loser is at least twice as slow”. Names, not indices, because a cell whose arms were registered in a different order keeps the same claim.

Without this call the cell grades nothing: GetGrade returns None and the report prints the table and the wall time and stops. That is not a degraded cell — a cell that carries numbers but no claim is the honest shape for a regime where no claim is owned, and the sweep uses it for exactly that reason, as the measured claims records.

A name that was never added is not an error; it leaves the grade at None. A cell whose claim names an arm it forgot to register grades nothing, which is the loudest failure this class is allowed to make, and the reason a new cell should be read once before it is trusted.

Parameters

NameWhat the caller must supply
inWinnerArm name the claim says is faster.
inLoserArm name the claim is made against.
inMinRatioPercentMargin, in percent, at least 100. 120 is a 1.20x margin, 200 a 2.00x margin.

Return value

None.

Example

bench.Expect("AtomicFixedRingMPSC", "FixedRingMPSC (mutex)", MpscLowProducerMinRatioPercent);
