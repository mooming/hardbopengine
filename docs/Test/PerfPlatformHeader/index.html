PerfPlatformHeader

Engine/Test/PerfHarness.h namespace hbe::Test the free function every performance report starts with

Entry description

One free function, hbe::Test::PerfPlatformHeader, declared in Engine/Test/PerfHarness.h and defined in its source alongside the harness it serves. It exists because a performance number without its machine and its build configuration is not a reusable measurement: the same cell on the same box measured a 2.00× margin in Release and 66% of noise in Dev, so a reader who cannot see which line printed the number will read the wrong thing into it.
