PerfPlatformHeader

member of hbe::PerfPlatformHeader Engine/Test/PerfHarness.h the machine and build a report was measured on

Signature

void PerfPlatformHeader(std::ostream& ioOut)

Function description

Prints the line a report is meaningless without: the logical CPU count, the cache-line spacing the build was compiled with, the build configuration, and what the columns of the table mean. It is a function rather than text at each call site because a report without its machine is a number without a unit, and a call site that forgets the line is a call site that cannot be reviewed.

The configuration matters more than it sounds: the measured claims are graded only in an optimised build, and the same cell in Dev prints its numbers with no grade at all. A reader who does not know which line printed the numbers will read the wrong thing into them.

Parameters

NameWhat the caller must supply
ioOutThe stream the cell reports to. The function writes one line and touches no stream state of its own.

Return value

None. The line goes to ioOut.

Example

PerfPlatformHeader(log);
