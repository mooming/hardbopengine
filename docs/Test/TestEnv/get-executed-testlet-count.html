GetExecutedTestletCount

member of hbe::TestEnv Engine/Test/TestEnv.h how many testlets have actually been run

Signature

[[nodiscard]] std::size_t GetExecutedTestletCount() const noexcept

Function description

How many testlets have actually been run. Compare with GetTestletCount; a shortfall is a failure — the suite's own report treats it as one.

Parameters

None.

Return value

The number of testlet executions so far.

Examples

The count is what Finalize checks against the registered total when it decides whether the run was complete.
