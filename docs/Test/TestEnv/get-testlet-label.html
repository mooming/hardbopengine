GetTestletLabel

member of hbe::TestEnv Engine/Test/TestEnv.h the Collection TC<n>.<name> label that names a stuck testlet in the registry

Signature

[[nodiscard]] const char* GetTestletLabel(std::size_t testletIndex) const

Function description

"Collection TC<n>.<name>" for one testlet — the label used as its task name, so the registry names what is stuck rather than a bare index. Built from the collection's title and the testlet's GetName.

Parameters

ParameterTypeRequirement
testletIndexstd::size_t Index into the flattened sequence, not into a collection.

Return value

The label string; the storage it points at lives with the environment's label table.

Examples

The harness hands this label to the task it posts, which is why a hung testlet's registry entry names the test instead of a stream position.
