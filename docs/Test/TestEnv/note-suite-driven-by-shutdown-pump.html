NoteSuiteDrivenByShutdownPump

member of hbe::TestEnv Engine/Test/TestEnv.h records that the shutdown path, not the engine loop, drove the run

Signature

void NoteSuiteDrivenByShutdownPump() noexcept

Function description

Records that a testlet ran while the shutdown path was pumping the base stream, not the engine loop. Reported as a failure rather than printed, because a suite that prints its own defect and still exits 0 is exactly the shape that let a missing engine loop ship green once already.

Held as its own flag, not appended to the failed-tests list: that list is cleared when the suite prepares, and a finding about who drove the run has to survive being recorded before the run is over. GetFailureCount adds one for it.

Parameters

None.

Return value

None.

Examples

The caller is the shutdown pump itself; the finding surfaces in the suite report's failure count.
