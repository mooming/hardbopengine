GetGlobalAllocationCount

member of hbe::TestEnv Engine/Test/TestEnv.h requests every testlet body sent to the global allocation door, suite-wide

Signature

[[nodiscard]] std::uint64_t GetGlobalAllocationCount() const noexcept

Function description

Requests — not bytes — every testlet body sent to the global allocation entry points, summed over every collection. One request is the fact that matters; its size is only context, which is why the suite keeps both figures. The window is testlet bodies only, exactly as GetGlobalAllocationBytes describes it.

Parameters

None.

Return value

Cumulative request count; zero before any testlet has run.

Examples

The suite-level report prints this beside the byte total; the per-collection views are TestCollection::GetGlobalAllocationCount.
