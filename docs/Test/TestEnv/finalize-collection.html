FinalizeCollection

member of hbe::TestEnv Engine/Test/TestEnv.h closes one collection once its last testlet has run

Signature

void FinalizeCollection(TestCollection& testCollection)

Function description

Closes one collection: hands it to Complete, which decides success from its accumulated errors and reports. Collections are finalised in registration order because their testlets are contiguous in the flattened sequence and a collection's verdict needs all of them.

Parameters

ParameterTypeRequirement
testCollectionTestCollection& The collection whose last testlet has run.

Return value

None.

Examples

Called from RunTestlet once a collection's last testlet has run; the suite-wide close is Finalize.
