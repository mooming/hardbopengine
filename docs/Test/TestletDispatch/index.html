TestletDispatch

Engine/Test/Testlet.h the three-function-pointer table that keeps a closure inline without a vptr

Class description

TestletDispatch is the three-function-pointer table that lets a Testlet hold an arbitrary closure without a virtual table: one invoke, one destroy, one relocate, each operating on the testlet's inline storage through a void*. A constexpr instance exists per closure type — built by Testlet::GetDispatch<TClosure>() — so the pointer is stable for the program's lifetime and holding it allocates nothing.

The type exists so the storage question stays answered at compile time. A vptr would make every testlet two words larger and its closure heap-adjacent; this table keeps the closure inline, and the static_asserts in the constructor are what refuse a capture that does not fit.

Template parameters

None — the struct is not a template.

Class properties

Type + NameDefault ValueDescription
void (*invoke)(const void* object, std::stringstream& log); public none in the headerRuns the closure held at object, writing its output to log.
void (*destroy)(void* object) noexcept; public none in the headerDestroys the closure in place; the destructor calls it.
void (*relocate)(void* source, void* destination) noexcept; public none in the headerMove-constructs the closure into destination and destroys the one at source; the move constructor calls it.

Class methods

None — the struct is pure data: three function pointers, no member functions.

Non-member helpers

None. The only producer of instances is Testlet::GetDispatch<TClosure>(), a private static of Testlet.
