member of hbe::RingBufferPerfTest Engine/Test/RingBufferPerf.h name the collection, which is the log category its cells print under

Signature

RingBufferPerfTest()

Function description

Passes "RingBufferPerfTest" to TestCollection. That string is the log category of every line the collection produces, so it is the text a reader greps for and the name that appears in the [TC0.…] prefix of each cell’s report — the compact cells, the ones that run inside every EngineTest.

Nothing else happens here. Registration is Prepare’s job, and the framework calls Prepare once, later, after the fixture has been constructed and before any of this collection’s testlets run — which is why a shape or a margin cannot be captured here.
