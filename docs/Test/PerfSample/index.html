PerfSample

Engine/Test/PerfHarness.h namespace hbe::Test one measure function’s result for one round

Class description

What one measure function returns after one round: the wall time it spent, how many items it moved, and how many of them were wrong. PerfBenchmark turns the first two into one figure — nanoseconds per item, carried internally in tenths of a nanosecond — and adds the third to the arm’s violation total.

Items belong in the sample rather than in the shape because a measure function is free to move a different number of items each round: a design that refuses work when the ring is full has moved exactly what it accepted, and it is the ratio that matters, not the count.

Class methods

None. PerfSample is a plain aggregate: its three members are the whole interface, and the arithmetic that turns them into a figure belongs to PerfBenchmark, which is the only thing that reads a sample.

Coverage

The struct has no methods. How a measure function produces these three numbers — the start gate, the per-item invariant, the deadline escape — is described in the design document’s cell anatomy, because it is the recipe every cell in this module follows rather than a contract of this type.
