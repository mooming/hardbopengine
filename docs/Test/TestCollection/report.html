Report

member of hbe::TestCollection Engine/Test/TestCollection.h prints the collection's verdict line

Signature

void Report() const

Function description

Prints the collection's verdict line: "= Collection Result: [SUCCESS] =================" at Info level, or the FAIL banner at Error level, through a TLog named after the collection. isSuccess was decided by Complete from the errors the testlets accumulated; this is the last thing a collection does.

Parameters

None.

Return value

None.

Examples

Called from Complete; the suite-level equivalent is TestEnv::Finalize.
