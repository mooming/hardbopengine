GetGlobalAllocationBytes

member of hbe::TestCollection Engine/Test/TestCollection.h bytes the testlet bodies asked the global allocation door for

Signature

[[nodiscard]] std::size_t GetGlobalAllocationBytes() const noexcept

Function description

Bytes this collection's testlet bodies asked the global allocation entry points for. Measured across each testlet body, so it excludes the fixture that prepares it. This is the number an AllocatorScope cannot see: a std::vector or std::string inside a test reaches the heap through operator new, which no scope redirects — without this accounting, a testlet could allocate freely off the books.

Parameters

None.

Return value

Cumulative bytes requested through the global door during testlet bodies.

Examples

Paired with GetGlobalAllocationCount (requests) and GetTestletCountWithGlobalAllocations (how many testlets touched the heap at all).
