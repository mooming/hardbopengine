GetTestName

member of hbe::TestCollection Engine/Test/TestCollection.h the name a testlet registered itself under

Signature

[[nodiscard]] const char* GetTestName(std::size_t testIndex) const noexcept

Function description

The name a testlet registered itself under, for the task name and the failure report. Owned by the testlet and null terminated by construction, so callers may print it freely. An index past the registered count returns the empty string rather than asserting — the caller that asks for a testlet that does not exist gets a printable answer.

Parameters

ParameterTypeRequirement
testIndexstd::size_t Index into this collection's registered testlets. Out-of-range returns "".

Return value

A null-terminated name owned by the testlet's inline buffer; empty for an out-of-range index.

Examples

Forwards to Testlet::GetName, which documents why the name outlives the run.
