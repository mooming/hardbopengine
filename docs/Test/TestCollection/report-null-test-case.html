ReportNullTestCase

member of hbe::TestCollection Engine/Test/TestCollection.h reports a registration that handed over no callable

Signature

void ReportNullTestCase(std::string_view testName) noexcept

Function description

Reports a registration that handed over no callable: the logger gets "Test <name> was registered with no callable, so it will not run" at Error level. Kept out of the AddTest template on purpose so that this header needs no logger — the logger's own headers are order-sensitive about the allocator they use, and a test file should not have to include that allocator first to compile. The template calls this only on the null-pointer path.

Parameters

ParameterTypeRequirement
testNamestd::string_view The name the registration carried, for the report.

Return value

None.

Examples

The only caller is AddTest's std::is_pointer_v branch — a null function pointer registered as a test.
