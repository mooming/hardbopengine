HasError

member of hbe::BufferOutputStream Engine/Resource/BufferOutputStream.h const noexcept [[nodiscard]] the one-question form of the error tally

Signature

[[nodiscard]] bool HasError() const noexcept { return errorCount > 0; }

Function description

One comparison against the same counter GetErrorCount returns, for callers that only need to decide whether to keep the result. It is the form the engine uses, because the count itself is rarely actionable — a caller that cannot name which write failed has no recovery that depends on the number.

The one case where the magnitude matters is probing mode: a null-block buffer that ran out of its claimed size reports more than once, since every later value overflows too. Counting tells you the buffer was far too small rather than merely wrong.

Parameters

None.

Return value

TypeWhat you get
bool true when at least one write has been refused. Does not clear anything — see ClearErrorCount
