IsDone

member of hbe::BufferOutputStream Engine/Resource/BufferOutputStream.h const noexcept [[nodiscard]] the cursor has reached the end of the block

Signature

[[nodiscard]] bool IsDone() const noexcept { return cursor >= buffer.GetSize(); }

Function description

Asks whether the write position has reached or passed the end of the block — a position test, not a completion test. It says nothing about whether the caller still had values left to push, and nothing about whether the bytes written form a valid image.

For an output stream the name is closer to "full" than to "finished": once the cursor is at the end, every further write is refused and raises the error count. So the useful reading of true here is "this buffer is used up", and the reading you must not take from it is "everything I sent was written".

Both edge cases follow from the comparison rather than from any special case: a buffer of size zero reports done before a single write, and a probing buffer — size == max, pointer null — reports not-done however much is pushed through it, which is exactly what makes the probing technique on GetCursor work.
