destructor

member of hbe::BufferInputStream Engine/Resource/BufferInputStream.h = default nothing to release: a reader owns no bytes

Signature

~BufferInputStream() = default;

Function description

Generated over a reference and two counters, so it does nothing, and that is the whole of the class lifetime story: opening a reader takes nothing from the buffer and closing it returns nothing. Ownership of the block stays entirely with the Buffer and its releaser.

The consequence worth stating is that discarding a reader mid-image is harmless. Nothing is buffered or staged here, so abandoning a read part-way leaves the block untouched and the partially read values simply absent — as opposed to the writer, where a partially written image can leave a length prefix with no payload behind it.
